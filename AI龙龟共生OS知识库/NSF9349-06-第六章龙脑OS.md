# AI龙龟共生OS·第六章 方法论约束层：龙脑OS

> [!info] 龙心 OS 1+5 结构化笔记 · 批次：AI龙龟共生OS·顶层设计

## 一、核心定义（金字塔顶端·结论先行）
龙脑OS是约束层(大脑)，掌握78个思维模型(内部库42+麦肯锡+教员+外部Obsidian 79)，以动态组方引擎(辨证→组方→输出→存案)推荐模型链；四大方法论域(格式塔具身/象道全息/AI原生组织/驾驭工程)划定边界，并承载 self-improving 自主进化。

## 二、详细内容（逐行保全·不遗漏）
### 第六章 方法论约束层：龙脑OS


> **定位**：龙脑OS管"运行边界在哪"——每一项都是约束。思维模型约束推理过程，格式塔方法论约束感知方式，AI原生组织约束治理决策，驾驭工程约束执行路径。

### 6.1 定位：约束而非工具

龙心OS管"怎么运行"，龙脑OS管"运行边界在哪"。这是两者最本质的区别。

龙脑OS的每一项内容都是"宪法"：
- 思维模型 → 约束推理过程
- 格式塔方法论 → 约束感知方式
- 象道全息方法论 → 约束认知根基
- AI原生组织方法论 → 约束治理决策
- 驾驭工程 → 约束执行路径

### 6.2 78思维模型体系

龙脑OS掌握78个思维模型，分为：
- **内部模型库**：思维模型库（42个通用模型）+ 麦肯锡思考框架 + 教员方法论
- **外部知识库索引**：Obsidian知识库中79个标准化文档

三层感知雷达结构：
| 层级 | 模型 | 激活方式 |
|------|------|---------|
| **核心层** | 9大高频本能模型 | 0步激活 |
| **模式层** | 4大模式×20个中频模型 | 1步激活 |
| **工具层** | 71个低频模型 | 按需加载 |

### 6.3 动态组方引擎

龙脑OS v3.0起将选刃机制从"硬编码映射"升级为"动态组方系统"，实现**辨证→组方→输出→存案**四步闭环：

```
Step 1: 辨证（辨证引擎.py）→ 输入原始问题，输出ProblemFeature特征向量
Step 2: 组方（组方引擎.py）→ 根据特征动态组合（主模型+辅模型+串联逻辑+验证模型）
Step 3: 输出（选刃引擎.py）→ 双面方案文档（YAML frontmatter + Markdown五段正文）
Step 4: 存案（存案引擎.py）→ 医案记录+置信度评分（非固化，医案是参考不是规则）
```

**核心能力**：冲突检测（互斥模型自动声明）、信息完备度驱动（无数据时切苏格拉底式提问）、多样性（variant参数产出多组合）、降级熔断（绝不空返回）。

### 6.4 四大方法论域 + 自主进化

| 方法论域 | 功能 |
|---------|------|
| **格式塔具身方法论** | 横切感知：合于场域之道→疗愈自然显化 |
| **象道全息方法论** | 认知根基：全息三层+四象入道，合于道→自然显化 |
| **AI原生组织方法论** | 横切治理：Agent护照治理+成熟度评估+工作流 |
| **驾驭工程** | 四层架构确保AI行为受控且可预测 |

**自主进化**：self-improving（自我改进）、self-learning（自主学习）、capability-evolver（能力进化）——龙脑OS不仅是约束层，也是进化引擎所在地。
