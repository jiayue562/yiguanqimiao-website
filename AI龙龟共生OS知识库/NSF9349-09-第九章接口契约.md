# AI龙龟共生OS·第九章 核心机制·接口契约：三OS协同

## 一、核心定义（金字塔顶端·结论先行）
三OS经龙心OS统一调度、不直接互相调用；接口定义龙心→龙脑(模型推荐/约束)、龙心→龙爪(执行/进度)、龙爪→龙脑(步骤模型)；统一错误码E000-E010+降级策略；引擎级契约(Engine接口/注册表延迟加载)+治理层契约(红绿灯授权)+深度共生(凤系列常驻执行子系统)。

## 二、详细内容（逐行保全·不遗漏）
### 第九章 核心机制·接口契约：三OS协同


> **核心原则**：三OS通过龙心OS总智能体统一调度，不直接互相调用。龙爪OS执行前可查询龙脑OS获取推荐模型。

### 9.1 统一调度架构

```
用户输入 → 龙心OS总智能体（唯一入口）
    ├──→ 龙脑OS（查询方法论/思维模型）→ 返回：模型ID+组合规则+约束条件
    └──→ 龙爪OS（执行工作流/SOP）→ 返回：执行状态+步骤结果+进度
```

### 9.2 三OS接口定义

**龙心OS → 龙脑OS**：
- `GET_MODEL_RECOMMENDATION`：任务类型+描述 → 首选模型链+备选链+置信度
- `GET_METHODOLOGY_CONSTRAINT`：引擎ID+任务类型 → 约束规则+禁用模式

**龙心OS → 龙爪OS**：
- `EXECUTE_WORKFLOW`：工作流ID+步骤列表+回调 → 执行结果+进度
- `GET_WORKFLOW_PROGRESS`：工作流ID → 状态+进度+预计剩余时间

**龙爪OS → 龙脑OS**：
- `GET_STEP_MODELS`：步骤名+描述 → 推荐模型（至少选1个primary）

### 9.3 统一错误码与降级策略

| 错误码 | 含义 | 处理方式 |
|:------:|------|---------|
| E000 | 成功 | 正常处理 |
| E001 | 引擎不可用 | 切换备选引擎或降级到基础模式 |
| E002 | 请求超时 | 重试1次，仍超时则跳过 |
| E003 | 输入格式错误 | 返回具体格式要求 |
| E004 | 模型不适用 | 声明切换理由，换备选模型 |
| E005 | 工作流中断 | 保存当前进度，下次可续跑 |
| E010 | 未知错误 | 返回错误详情，人工介入 |

**降级策略**：龙脑OS不可用→内置基础模型；龙爪OS不可用→直接输出模型推荐；选刃无匹配→五层分析法兜底；引擎超时→返回部分结果。

### 9.4 引擎级契约 + 治理层契约 + 深度共生

**引擎级契约（ENGINE_INVOKE/ENGINE_RESULT）**：所有引擎实现统一`Engine`接口，经注册表延迟加载。规范：不抛异常、只读task_ctx、结构化输出、人类可读text。

**治理层契约（GOVERNANCE_RUN/GOVERNANCE_RESULT）**：治理层以调度统计为输入，输出瓶颈识别、压缩策略、红绿灯授权：
| 灯 | 授权范围 | 人类职责 | AI职责 |
|----|---------|---------|--------|
| 绿 | AI自主执行 | 事后抽查 | 全流程执行 |
| 黄 | 人机协同 | 关键节点把关 | 常规推进 |
| 红 | 人类全权 | 决策拍板 | 参谋建议 |

**深度共生（凤系列）**：龙心OS 1+5总调度下常驻执行子系统（龙爪OS + 五行人格心理学OS），四层持续共生闭环：龙心(总调度)→凤爪(执行入口)→凤心(五行决策)→凤脑(知识底座)，多轮反哺影响后续路由。
