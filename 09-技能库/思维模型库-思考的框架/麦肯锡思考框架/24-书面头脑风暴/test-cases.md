# 书面头脑风暴 · 测试用例

## 测试场景一：远程团队创意会议

### 输入
情境：某分布式团队需要线上产生20个APP功能创意

### 期望输出
```
【书面头脑风暴 · APP功能创意】

■ 议题定义
议题：未来6个月APP应该增加哪些功能？
背景：竞品近期推出多个新功能
目标：找到差异化突破点

■ 流程执行

第一步：发布议题
 - 明确时间和提交方式
 - 强调独立思考原则

第二步：独立撰写
 - 每人至少产出5个想法
 - 15分钟限时

第三步：汇总（收集12人产出）
 - 汇总60个想法
 - 匿名整理

第四步：分类
 - 效率工具类（20个）
 - 社交功能类（18个）
 - 内容消费类（12个）
 - 其他（10个）

第五步：快速筛选
 - 每人10票
 - 选出8个高票创意

第六步：细化讨论
 - 评估可行性和资源需求
 - 制定优先级
```

## 测试场景二：营销活动创意

### 输入
情境：某品牌需要双十一营销活动创意

### 期望输出
```
【书面头脑风暴 · 双十一营销】

■ 收集阶段（产出35个创意）
 - 促销玩法15个
 - 内容营销10个
 - 用户互动8个
 - 跨界合作2个

■ 分类整理
用户互动类：
 - 抽奖大转盘
 - 盖楼挑战
 - 分享有礼
 - 问答游戏

■ 筛选结果
高票TOP5：
1. 直播+限时秒杀
2. UGC内容征集
3. 会员专属优惠
4. 游戏化互动
5. 跨界联名款

■ 行动计划
第一名进入执行方案
第二三名作为备选
```
