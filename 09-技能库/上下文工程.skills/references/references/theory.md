# 上下文工程理论

## 核心概念

### 上下文窗口
大模型每次调用能处理的 token 数量有限（4K-128K），需要在有限的窗口内放置最重要的信息。

### 上下文优先级
根据相关性、时效性和重要性对上下文项排序，确保关键信息不被截断。

### 跨 Skills 上下文协议
多个 Skills 链式调用时，需要统一的上下文格式和传递机制。
