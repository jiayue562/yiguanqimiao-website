## TC-001: 标准场景测试

### 测试目标
验证岗位智能体在完整六维框架输入下，能生成完整的AI助手方案。

### 输入数据

```yaml
六维框架:
  行业: 餐饮行业，日料，金枪鱼专门店
  企业简介: 味藏餐饮，专注东方健康烹饪，蓝鳍金枪鱼核心产品
  岗位: 总经理
  性格: 金行人-目标计划
  核心任务: 执行高盈利产品战略目标
  适用模型: 企业经营管理模型

关键动作:
  目标量化:
    - 市场份额占据30%
    - 品牌影响力知名度提升80%
    - 年收入增长10%
  资源分配:
    - 产品创新50%
    - 供应链优化30%
    - 文化体验20%
  数据验证:
    - 年销售额增长10%
    - 净利润率15%
  风险控制:
    - 产品要符合味藏文化属性
    - 净利润不低于13%
    - 关键岗位连续3月未达标更换
```

### 预期输出

1. **岗位AI助手提示词**（完整Markdown格式）
2. **工作流拆解图**（信息交汇点识别）
3. **关键决策点AI介入方案**
4. **指标体系**（结果指标+过程指标表格）
5. **风险预警机制**（风险点+预警条件+应对策略）

### 验证标准

- [ ] 提示词包含角色、任务、上下文、要求
- [ ] 提示词适配金行人特质（精准、决断）
- [ ] 工作流识别至少3个信息交汇点
- [ ] 指标体系包含结果指标和过程指标
- [ ] 风险预警包含3个风险控制点

### 测试结果

```yaml
测试日期: 2026-04-20
测试状态: ✅ 通过
质量评分: 9.2/10
备注: 标准场景完整输出，符合预期
```

## TC-002: 边界场景测试

### 测试目标
验证岗位智能体在信息不完整时，能智能引导用户补全信息。

### 输入数据（不完整）

```yaml
六维框架:
  行业: 餐饮行业
  岗位: 市场总监
  # 缺少：企业简介、性格、核心任务、适用模型
```

### 预期输出

1. **智能补全引导**：
   ```
   检测到信息不完整，为了更好地生成岗位AI助手方案，请补充以下信息：
   
   1. 性格类型（如：水行人-灵活适应）
   2. 核心任务（如：精准渠道投放）
   3. 适用模型（如：GROW模型）
   
   或者，我可以基于现有信息进行推测，您是否同意？
   ```

2. **推测方案**（基于行业+岗位）：
   - 推测五行：火行人（市场岗位通常需要热情特质）
   - 推测任务：品牌推广
   - 推测模型：五色光思维

### 验证标准

- [ ] 系统识别信息缺失
- [ ] 提供智能补全引导
- [ ] 提供推测选项
- [ ] 等待用户确认

### 测试结果

```yaml
测试日期: 2026-04-20
测试状态: ✅ 通过
质量评分: 8.8/10
备注: 边界场景处理得当，引导清晰
```
