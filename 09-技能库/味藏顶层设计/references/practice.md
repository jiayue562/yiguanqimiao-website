# 🔨 味藏顶层设计 · 实操指南

---

## 一、快速启动流程

### 1.1 初次使用（5分钟上手）

```
Step 1: 明确场景
  → 你的企业处于什么阶段？（初创/扩张/成熟/转型）
  → 你最头疼的问题是什么？（文化/战略/运营/人才）

Step 2: 选择维度
  → 文化问题 → 调用文化层智能体
  → 战略问题 → 调用战略层智能体
  → 运营问题 → 调用运营层智能体
  → 人才问题 → 调用人才层智能体
  → 综合问题 → 调用四维联动智能体

Step 3: 获取诊断
  → 回答AI的3-5个诊断问题
  → 获取定制化的诊断报告

Step 4: 执行改进
  → 按照报告中的优先级执行
  → 使用配套的SOP和检查清单
```

### 1.2 深度使用（完整流程）

```
Phase 1: 诊断（1-2周）
  → 四维全面诊断
  → 输出诊断报告
  → 确定改进优先级

Phase 2: 设计（2-4周）
  → 针对性方案设计
  → SOP和工具开发
  → 试点测试

Phase 3: 实施（1-3个月）
  → 全面推广
  → 数据监控
  → 持续优化

Phase 4: 评估（每季度）
  → PDCA闭环
  → 效果评估
  → 迭代升级
```

## 二、文化层实操

### 2.1 使命清晰度检测

**检查清单**：
```
□ 员工能准确说出使命（误差<10%）
□ 日常决策参考使命
□ 客户能感知到使命
□ 使命体现在产品/服务中
□ 新员工入职首先学习使命
```

**改进模板**：
```
使命落地五步法：
1. 使命拆解：将"以食载道，传递美好"拆解为部门级、岗位级行动
2. 使命可视化：在门店、办公室、制服上体现使命
3. 使命考核：将使命践行纳入绩效考核（占比≥10%）
4. 使命故事：每月收集1个使命践行故事
5. 使命仪式：晨会/周会/月会的使命重申
```

### 2.2 文化罗盘校准

**五方饕餮能量检测表**：

| 方位 | 颜色 | 检测项 | 健康标准 | 当前状态 | 改进措施 |
|------|------|--------|---------|---------|---------|
| 中央 | 白 | 客户中心 | 所有决策以客户为优先 | | |
| 北方 | 绿 | 事业长青 | 员工对企业未来有信心 | | |
| 东方 | 蓝 | 健康发展 | 可持续经营，不透支 | | |
| 南方 | 黄 | 财富基础 | 盈利稳定，现金流健康 | | |
| 西方 | 红 | 关系和谐 | 团队/客户/伙伴关系良好 | | |

**食材层面五大军规检查**：

## 三、战略层实操

### 3.1 三重重生能力评估

**机制重生评估表**：

| 评估项 | 权重 | 评分(1-5) | 加权分 | 改进建议 |
|--------|------|----------|--------|---------|
| 堂食标准化程度 | 20% | | | |
| 酒水产品创新周期 | 20% | | | |
| 外卖运营效率 | 20% | | | |
| 三单元协同机制 | 20% | | | |
| 可复制性验证 | 20% | | | |
| **总分** | 100% | | | |

**评分标准**：
- 5分：完全成熟，可立即复制
- 4分：基本成熟，小幅调整即可
- 3分：初步成型，需要优化
- 2分：刚起步，需要大量投入
- 1分：尚未开始，需要从零建设

### 3.2 经济生命体属性检测

| 属性 | 检测问题 | 是/否 | 证据 |
|------|---------|-------|------|
| **纯粹** | 是否专注单一赛道？ | | |
| **高利润** | A级食材+SOP+溢价是否实现？ | | |
| **可复制** | 标准化程度是否支持复制？ | | |
| **有灵魂** | 文化独特性是否明显？ | | |
| **自适应** | 能否快速响应环境变化？ | | |

### 3.3 三共同体闭环检测

**使命共同体检测**：
```
□ 员工能准确说出核心价值观
□ 日常行为体现价值观
□ 违反价值观的行为有纠偏机制
□ 价值观考核纳入绩效
□ 有价值观榜样人物
```

**事业共同体检测**：
```
□ 员工清楚自己的成长路径
□ 有明确的晋升标准
□ 授权机制健全
□ 有挑战性工作机会
□ 员工对企业未来有信心
```

**利益共同体检测**：
```
□ 薪酬有竞争力
□ 薪酬结构透明
□ 绩效评估公正
□ 奖金/分红及时兑现
□ 有长期利益绑定机制
```

## 六、四维联动检查表

### 6.1 周度检查清单

**文化→战略检查**：
```
□ 本周决策是否符合使命愿景？
□ 是否偏离了老饕赋的客户定位？
□ 定海神针的"双重螺旋"是否在运转？
```

```
□ 三单元的目标达成情况？
□ 营业额三线是否按预期？
□ 质性价比是否有偏差？
```

**运营→人才检查**：
```
□ 轮岗人员的学习进展？
□ 项目制的参与度和产出？
□ 数据反馈是否及时用于人才评估？
```

```
□ 是否有值得表扬的文化践行案例？
□ 师徒传承是否在进行？
□ 团队氛围是否积极正向？
```

## 七、工具模板汇总

### 7.1 核心公式速查卡

```
文化罗盘 = 五方饕餮 × 圈层结构 × 三维解析
定海神针 = 第一层（传递美好）× 第二层（成就伙伴）
匠心 = 质性价比 = 有序经营 = 内在驱动力
三昧真火 = 产品结构 × 会员复购 × 文化匠心
服务效率 = 产品稳定 × 上菜快 × 服务适时
总营业额 = 堂食 + 酒水 + 外卖
客户流转 = 入口→客户池→储值→高客单→裂变
味藏进化 = (机制×人才×文化重生) - 核心矛盾
激励效果 = 薪酬 × 关系
```

### 7.2 紧急问题处理卡

| 问题类型 | 立即行动 | 责任人 | 24小时内 | 72小时内 |
|---------|---------|--------|---------|---------|
| 口味不稳定 | 停售该菜品 | 厨师长 | 复盘原因 | 更新SOP |
| 上菜慢 | 启动应急预案 | 店长 | 优化动线 | 培训员工 |
| 服务投诉 | 立即安抚客户 | 服务经理 | 复盘案例 | 更新SOC |
| 人员离职 | 交接+备份 | HR | 启动招聘 | 复盘原因 |
| 营业额下滑 | 分析三线数据 | 运营总监 | 制定对策 | 执行方案 |
