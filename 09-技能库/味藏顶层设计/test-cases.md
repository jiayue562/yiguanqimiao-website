## 测试用例2：三创业单元协同

### 基本信息

| 项目 | 内容 |
|------|------|
| **用例ID** | TC-002 |
| **用例名称** | 三创业单元协同诊断 |
| **测试类型** | 功能测试 |
| **优先级** | P0 |
| **测试状态** | ✅ 通过 |

### 输入

**用户输入**：
```
"我们餐厅有堂食、酒水、外卖三个业务，但各自为政，
怎么让它们协同起来？"
```

**触发检测**：
- P1场景："堂食" + "酒水" + "外卖" + "协同" → 4分
- P2信号："各自为政" + "协同" → 3分
- 总分：7分 → **激活**

### 预期输出

**系统响应**：
```
🍣 味藏顶层设计引擎启动

检测到您的需求属于【战略层+运营层协同诊断】，
正在调用战略层智能体和运营层智能体...

诊断结果：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📊 三单元协同度评分：35/100（需重点改进）

🔴 核心问题：
1. 三单元缺乏交叉引流机制
2. 未建立统一的客户池管理
3. 各单元KPI独立，缺乏协同激励
4. 储值会员未成为三单元的信任枢纽

💡 改进方案：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【协同机制设计】

1. 交叉引流矩阵：
   堂食（品牌+流量）
      ╱        │        ╲
     │    交叉引流     │
     ↓         ↓        ↓
  酒水（利润）←→ 外卖（规模）
     │         ↑        │
     └────→ 客户池 ←─────┘
               │
          ★储值会员（信任枢纽）

2. 协同KPI设计：
   - 堂食：引流转化率（到酒水/外卖）
   - 酒水：堂食客户酒水渗透率
   - 外卖：堂食客户外卖复购率

3. 储值会员策略：
   - 储值通用：三单元均可使用
   - 储值激励：跨单元消费享额外折扣
   - 储值权益：会员日三单元联合活动

📋 配套工具：
- 三单元协同检查表
- 交叉引流SOP
- 储值会员运营手册
```

### 验证标准

| 检查项 | 标准 | 结果 |
|--------|------|------|
| 正确识别场景 | 战略+运营协同 | ✅ |

Step 2: 五行人格匹配（5维）

  L1 初级 → L2 中级 → L3 高级 → L4 专家 → L5 大师
  师徒制：12-18个月，评估节点3/6/12/出师

Step 4: 赛马机制（优胜劣汰）
  项目类型：改善类/创新类/专项任务
  发掘流程：项目发布→自愿报名→组建团队→执行交付→成果评审→能力评估→人才标记→重点培养

Step 5: 三共同体激励
  利益层：薪酬/奖金/福利/分红
  事业层：晋升/授权/挑战性工作
  使命层：认可/荣誉/意义感/归属

📋 配套工具：
