## 二、决策升级路径

### 当AI判断需要升级时

```
C级标准决策
  ├─ 异常幅度<20% → 标记在日报中，不升级
  ├─ 异常幅度20-50% → 升级至B级，推送对应负责人
  └─ 异常幅度>50% → 升级至A级/S级，推送决策层

B级运营决策
  ├─ 涉及金额<5,000元 → 店长自主决策
  ├─ 涉及金额5,000-50,000元 → 升级至A级，总经理审批
  └─ 涉及金额>50,000元 → 升级至S级，董事长审批
```

### 超时自动升级

| 决策等级 | 标准响应时间 | 超时5分钟 | 超时30分钟 | 超时2小时 |
|---------|------------|----------|-----------|----------|
| S级 | 4小时 | 提醒 | 提醒+上级 | 紧急通知 |
| A级 | 1天 | 提醒 | 提醒 | 提醒+上级 |
| B级 | 4小时 | 提醒 | 提醒+上级 | 升级至A级 |
| C级 | AI自动 | N/A | N/A | N/A |
| D级 | 立即 | 15分钟后升级 | 紧急通知决策层 | 启动应急预案 |

## 三、决策追溯要求

每个决策完成后生成决策卡片：

```markdown
## 决策卡片 #YYYY-MM-DD-NNN
- **决策类型**：[S/A/B/C/D]
- **触发时间**：YYYY-MM-DD HH:MM
- **决策内容**：[一句话描述]
- **AI输入**：[提供了什么分析/数据/方案]
- **考虑选项**：[A/B/C三个方案]
- **最终决策**：[选择了哪个+为什么]
- **决策人**：[谁拍板]
- **预期效果**：[量化预期]
- **30天复盘**：待填写
```

## 四、月度决策审计

每月5日，AI自动生成上月决策审计报告：

| 审计维度 | 指标 |
|---------|------|
| 决策总数 | S级X个·A级X个·B级X个 |
| 平均响应时间 | 按等级分类 |
| 超时决策数 | 按等级分类 |
| 决策追溯率 | 已生成决策卡片/总决策数 |
| 30天复盘率 | 已复盘/应复盘 |
| 决策质量评分 | 基于实际效果vs预期 |
| 瓶颈决策类型 | 频繁超时的决策类型 |
