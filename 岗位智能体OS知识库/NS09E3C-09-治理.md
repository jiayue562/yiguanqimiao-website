### 9.1 五维对齐校验

每次生成智能体前，自动执行五维校验，全部通过才允许输出：

```
1. 层级归属正确——与智能体清单中的层级一致
2. 智能体编码正确——编码与清单一致，P值在85-99之间
3. 六元组数据链绑定正确——责任锚点字段有明确定义
4. L1-L4人才链匹配正确——技能等级不低于L1
5. 宪法5Gate门禁全部通过
全部通过 → 智能体输出 | 任意未通过 → 自动标记偏差 → 推送宪法守护进程
```

### 9.2 宪法5Gate门禁

| 门禁 | 校验内容 |
|:----|---------|
| Gate1 | 7S维度覆盖验证——每项任务至少归属1个S维度 |
| Gate2 | 核心公式一致性——产出与核心公式不冲突 |
| Gate3 | 味藏文化价值观——仁义礼智信贯穿可追溯 |
| Gate4 | 人机分工边界——AI不替代人判断/决策/例外处理 |
| Gate5 | 执行偏差门禁——承诺兑现率≥80% |

### 9.3 宪法常驻守护进程

宪法守护进程执行三类扫描：承诺兑现扫描（每日自动）、注册停滞扫描（每周自动）、执行偏差扫描（实时）。守护进程的职责是让治理从"生成时校验"延伸到"运行中监管"。

### 9.4 多智能体调度架构

岗位智能体OS位于味藏总智能体（注册中心）之下的应用层，与已注册岗位智能体（运行态）、宪法守护进程、5Gate门禁共同构成多智能体治理网络。

### 9.5 风险与应对

| 风险 | 概率 | 影响 | 应对 |
|:----|:----:|:----:|------|
| 公共因素提取过度泛化 | 中 | 高 | 每个公共模版标注适用范围，超范围自动退回 |
| 新用户数据不足导致校准偏差 | 高 | 中 | 不足4周使用同岗位默认值，标注置信度 |
| 5Gate门禁拦截率过高 | 中 | 中 | 先自动修正后提交，降低人工介入频率 |
| 12人预设参数过度拟合 | 低 | 高 | 每个新用户独立校准，不使用他人数据做比对基线 |
| 输出SKILL.md部署失败 | 中 | 中 | 每个输出增加自动部署测试 |
