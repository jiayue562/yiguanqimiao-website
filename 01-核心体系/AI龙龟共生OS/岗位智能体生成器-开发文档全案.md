# 岗位智能体生成器 · 开发文档全案

> 版本：v1.0
> 生成时间：2026-07-28
> 数据基础：味藏12个管理岗位连续7-9周真实周报 + AI原生组织顶层设计全案 + 26智能体体系
> 定位：输入岗位属性+个人周报/日报数据+性格特征 → 自动输出该岗位的专属AI智能体

---

## 第一部分：产品定位

### 1.1 一句话定义

岗位智能体生成器是一个**输入岗位属性+个人数据+性格特征→自动生成专属岗位智能体**的系统。不是手动开发26个独立的智能体，而是用一套引擎动态拼装，为每一个岗位按需输出一个与AI原生组织架构对齐的智能体。

### 1.2 与现有SKILL.md岗位智能体的关系

现有的岗位智能体（POS-MGR）是一个**单次生成工具**——输入六维框架，输出一份岗位智能体方案。生成器是它的升级版：不仅生成方案，还**生成一个可以直接运行的智能体**，并且能从连续数据中学习进化。

| 维度 | POS-MGR（现有） | 生成器（v2.0） |
|:----|:---------------|:---------------|
| 输入 | 六维框架 | 六维框架 + N周连续数据 + 性格测评 |
| 公共因素提取 | 无 | 自动从多人数据中提取共性模版 |
| 个性化校准 | 人工手动 | 自动比对数据偏差并校准 |
| 输出 | 方案文档 | 可运行的智能体 + 方案文档 |
| 进化机制 | 无 | 每月从新数据校准一次 |
| 与AI原生组织对齐 | 手动的 | 自动五维校验 |

### 1.3 核心设计原则

1. **公共因素一次提取，多次复用**：从12人数据中提取的共性模版不重复开发
2. **个性化因素自动校准**：每个人的性格特征和做事风格自动匹配到对应模版
3. **持续进化**：每月一次增量校准，从新数据中学到的模式不断注入智能体
4. **宪法对齐**：所有输出通过5Gate门禁校验，不违反AI原生组织宪法

                                      │

                ┌─────────────────────────────────────┐
                │        生成器调度核心                  │
                │  ① 公共因素提取 → 基础模版拼装         │

                │  ③ 五维对齐校验 → 宪法门禁             │

                └─────────────────────────────────────┘

### 2.2 三个核心引擎

#### 引擎一：公共因素提取引擎

功能：从多人的连续数据中提取共性模版。

| 公共因素层 | 内容 | 来源 |
|-----------|------|------|
| **L0-通用能力** | 日反馈采集、下周计划生成、复盘画布格式化、数据预警追踪、7S自评输出 | 12人数据共同模式 |
| **L1-层级能力** | 决策层（战略推演/文化布道）、赋能层（跨部门协同/智能体路由）、执行层（运营追踪/异常处理） | 按层级分类提取 |
| **L2-职能能力** | 财务的AI工作流、采购的TCO比价、培训的三阶段体系、市场的会员运营、人事的onboarding SOP | 各职能专有特征 |
| **L3-门店差异** | 金月湾（业绩锚点·土行）、狮山（标准推手·金行）、松山湖（社区连接·水行） | 三店差异化配置 |

公共因素存储为模版仓库，生成器按岗位匹配自动调用。

#### 引擎二：个性化校准引擎

功能：根据个人的连续周报/日报数据，校准公共模版中的偏差参数。

校准维度：

| 校准维度 | 输入数据 | 校准对象 |
|---------|---------|---------|
| **五行校准** | 性格测评结果或从周报风格推导 | 沟通方式、决策偏好、风险偏好 |
| **能力基线校准** | 连续4周以上的完成率/通过率/达标率 | 目标值、阈值、预警线 |
| **瓶颈模式校准** | 周报中重复出现的同一类型问题 | 瓶颈触发机制、干预建议 |
| **成长轨迹校准** | 自我诊断的迭代方向 | 成长建议、学习资源推荐 |
| **表达风格校准** | 周报的语言风格、数据密度、结论先行程度 | 输出格式、详细程度 |

12人已有数据作为预训练样本。新用户输入4周以上数据后自动校准，4周前使用同类岗位默认值。

#### 引擎三：五维对齐校验引擎

功能：每次生成智能体前，自动执行以下五维校验。

```
校验通过条件（全部满足）：
1. 层级归属正确——与26智能体清单中的层级一致
2. 智能体编码正确——编码与清单一致，P值在85-99之间
3. 六元组数据链绑定正确——责任锚点字段有明确定义
4. L1-L4人才链匹配正确——技能等级不低于L1
5. 宪法5Gate门禁全部通过：
   - Gate1: 7S维度覆盖验证——每项任务至少归属1个S维度
   - Gate2: 核心公式一致性——产出与9条核心公式不冲突
   - Gate3: 味藏文化价值观——仁义礼智信贯穿可追溯
   - Gate4: 人机分工边界——AI不替代人判断/决策/例外处理
   - Gate5: 执行偏差门禁——承诺兑现率≥80%
全部通过 → 智能体输出 | 任意未通过 → 自动标记偏差 → 推送宪法守护进程
```

## 第三部分：输入框架

### 3.1 六维输入框架（通用）

| 维度 | 字段 | 说明 | 示例 |
|:----|------|------|------|
| **行业** | industry | 所属行业 | 餐饮·日料 |
| **企业** | company | 所在企业及阶段 | 味藏蓝鳍金枪鱼专门店·AI原生组织转型期 |
| **岗位** | position | 岗位名称+层级 | 堂食创业单元总·执行层 |
| **五行** | element | 五行人格类型 | 金行 |
| **任务** | tasks | 核心任务清单（按7S分类） | 详见第三部分 |
| **模型** | models | 适用的思维模型组合 | 选刃决策树推荐 |

### 3.2 周报/日报数据输入格式

**最少数据量**：连续4周以上周报。少于4周只能生成通用版本，无法做个性化校准。

**建议格式**：

```yaml
周报 #N:
  周期: 2026-07-13 ~ 2026-07-19
  关键数据:
    门店整体: {目标: 303170, 实际: 288259, 完成率: 95.1%}
    金枪鱼: {目标: 43750, 实际: 43100, 完成率: 98.5%, 渗透率: 17.4%}
    酒水: {目标: 19030, 实际: 14102, 完成率: 74.1%}
    外卖: {目标: 32125, 实际: 33687, 完成率: 104.9%}
    新增会员: {目标: 70, 实际: 52, 完成率: 74.3%}
    储值: {目标: 41986, 实际: 73990, 完成率: 176.3%}
  核心问题:
    - 金枪鱼日常渗透率仅15%，远低于50%目标
    - 酒水6/7天未达标
    - 会员拉新连续6天未达10人
  下周计划:
    - 前厅基本素养启动会
    - 8月业绩目标分解
    - 桌桌必推金枪鱼日追踪表建立
```

### 3.3 性格特征输入

两种方式二选一：
1. **五行测评结果**：直接输入五行人格类型（金/木/水/火/土）和阴阳倾向
2. **从周报推断**：提供连续4周周报，自动推断性格特征

## 第五部分：个性化校准层

### 5.1 校准流程

```
Step 1：加载公共模版
  → 根据用户输入的岗位/层级/门店匹配对应公共模版

Step 2：加载人设基座
  → 如果用户已有连续数据，加载数据推断的性格特征
  → 如果用户是新人，使用岗位默认值

Step 3：偏差校准
  → 对比用户的周报数据与公共模版的默认值
  → 识别偏差并生成校准参数

Step 4：瓶颈模式识别
  → 分析连续数据中重复出现的同一类型问题
  → 标记为该用户的瓶颈模式

Step 5：输出个性化智能体
  → 公共模版 + 校准参数 → 个性化智能体
```

### 5.2 校准参数表

| 参数 | 公共默认值 | 校准输入 | 校准算法 |
|------|-----------|---------|---------|
| 目标值 | 同岗位历史均值 | 本人连续4周完成率 | 加权平均 |
| 预警线 | 同岗位标准阈值 | 本人连续4周偏差幅度 | 均值±1.5σ |
| 瓶颈模式 | 岗位通用瓶颈 | 周报中重复问题 | 连续3周同频为模式 |
| 沟通风格 | 岗位通用 | 周报语言特征分析 | NLP风格分类 |
| 决策偏好 | 同层级标准 | 从周报决策记录推断 | 归类分析 |
| 成长阶段 | L1 | 7S自评得分趋势 | 趋势线判断 |

### 5.4 持续进化机制

每月执行一次增量校准：

```
收集新数据（N周新周报）
→ 与现有校准参数做偏差对比
→ 偏差超过阈值 → 自动更新校准参数
→ 偏差未超过阈值 → 维持现有参数
→ 新数据中发现新模式 → 添加到公共因素仓库
```

新用户需要至少连续4周数据才能完成首次个性化校准。4周前使用岗位默认值。
