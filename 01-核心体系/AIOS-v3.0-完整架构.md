# AI OS v3.0 — 超级个人的个人操作系统·完整架构

## 〇、哲学根基

> AI OS 不是"AI工具集"，而是**超级个人的个人操作系统**。
> 它的设计哲学源于三个核心命题：

**命题一：身体不是孤立的生理实体，而是关系场中的动态样态。**
→ 格式塔具身智能横切所有层的感知根基。

**命题二：组织的核心问题不是"谁的效率低"，而是"哪里在逼人串行排队"。**
→ AI原生组织横切所有层的治理哲学。

**命题三：知识与代码一样，需要版本控制、分布式备份、不可篡改的归属。**
→ 六向同步+AI印记构成知识资产的硅基永生。

## 二、两个横切层详解

### 📐 AI原生组织 — 横切治理层

| 组件 | 位置 | 功能 |
|------|------|------|
| 串行瓶颈诊断引擎 | 龙心OS/engines/ | 四大结构性瓶颈(BN-INF/BN-DEC/BN-CRD/BN-CTX)自动检测 |
| 瓶颈压缩策略引擎 | 龙心OS/engines/ | 6类瓶颈×压缩策略自动匹配+预期效果 |
| AI原生组织成熟度评估 | diagnosis/ | L1-L5成熟度+死亡陷阱预警+演进路线图 |
| AI原生组织工作流 | diagnosis/ | [AI]/[人]/[⇄]三标注+5工作流模板 |
| Agent护照治理 | governance/ | 红绿灯三区制+疲劳度动态权限+审计追踪 |
| 人机握手协议 | 味藏AI原生组织/ | S/A/B/C/D五级决策标准+4类握手模板 |
| 组织心跳仪表盘 | 味藏AI原生组织/ | 27项健康指标+每日/周度/月度报告 |

**核心原则**：
- 方向盘在人的手里 / AI做AI擅长的 / 每一层都透明 / 瓶颈可见压缩持续 / 进化不是可选项

### 🫁 格式塔具身智能 — 横切感知层

| 组件 | 位置 | 功能 |
|------|------|------|
| 具身样态推断 | 龙心OS/engines/具身引擎/E0 | 文本→呼吸/肩颈/能量/压力点/在场（20种身体模式） |
| 注意力范围检测 | 龙心OS/engines/具身引擎/E1 | 6种范围+僵化标记（固化格式塔识别） |
| 五行具身映射 | 龙心OS/engines/具身引擎/E2 | 具身样态→五行元素自动映射+一致性判断 |
| 场域压力分析 | 龙心OS/engines/具身引擎/E3 | 瓶颈率→人格偏移方向（5种偏移） |
| 内摄模式识别 | 龙心OS/engines/具身引擎/E4 | 7种核心内摄×神经系统身体映射+四步干预 |
| 特质律动分析 | 龙心OS/engines/具身引擎/E5 | 5种律动模式(断奏/连奏/柔板/快板/弹性)×在场练习 |
| 分层干预生成 | 龙心OS/engines/具身引擎/E6 | L0紧急/L1短期/L2中期/L3长期×5维度 |
| 三条管道 | 管道一/二/三 | 人格↔系统↔治理双向实时反馈 |

**理论来源**：《Embodied Relational Gestalt》(Clemmens, 2020) 全10章 → 12文件/3044行代码/24测试

## 四、自主调用链路

### 4.1 技能发现

```
opencode.json → skills.paths → 遍历 ~/.agents/skills/ 全部SKILL.md
                                    │
                    ┌───────────────┼───────────────┐
                    ▼               ▼               ▼
            00-foundation      10-kernel        20-claws
            (4 底座技能)      (8引擎+治理)     (4龙爪/80+技能)

                             30-tools ← 40-rules ← 50-security
```

### 4.2 调度器路由

```
scheduler_main.py
  ├── intent_recognizer.py    → 识别意图类型
  ├── scene_classifier.py     → 分类场景
  ├── engine_router.py        → 路由到龙心OS引擎
  └── skill_discovery.py      → 发现龙爪OS技能（默认路径: ~/.agents/skills/）

```
governance.py

  ├── 疲劳度动态调整 (管道三: >70自动降级)
