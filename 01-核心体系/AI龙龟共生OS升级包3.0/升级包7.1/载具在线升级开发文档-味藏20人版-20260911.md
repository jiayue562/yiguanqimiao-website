## 一、为什么做这件事（原理，三句话）

### 1.1 载具不是「提示词」，是私有世界

大模型出厂就带着语言、推理、常识。它不知道你主人是谁、在哪个岗位、这家公司有哪几家店、7S 权重怎么分、什么话不能说。**这些不是「背景资料」，这些是载具。**

### 1.2 「在位」不等于「在起作用」——这是本次升级要解决的真问题

很多载具只做「清单检查」：文件在不在。但一本字典放在桌上，不代表它在替你思考。**载具真正的价值，是它在输出里留下了指纹。**

### 1.3 判定标准：能被证伪

所以本次升级的核心不是「加功能」，而是**让载具的作用每天可被测量**：

登记若干条「大模型训练语料里绝不可能存在」的私有断言，每天逐条校验它们还能不能在载具里找到。找得到 = 载具装着；找不到 = 载具空了。

**这个数字（装载率）能被证伪，才配叫证据。**

### 1.4 一句话口径（记住它）

> **模型给「能」，载具给「对」和「这里」。**
> 没有模型，载具是一堆没人读的字；没有载具，模型是一个每次醒来都失忆、还会自信编造公司数字的通用助手。

## 三、第一步：盘点载具（不要跳）

### 3.1 对伙伴而言，「载具」是什么

对总部是龙心OS／龙脑OS／龙爪OS／共生OS。对你主人，可能是：

- 岗位智能体 SKILL（最核心的一件）
- 记忆文件（`MEMORY.md` 或类似）
- 岗位专属资料（考核表、作业手册、话术库…）
- 语言风格规范（从事写作／培训／对外的岗位尤其需要）
- 知识库索引（如果主人有本地知识库）

**宁少勿滥**：只登记「你主人真的每天都在依赖」的文件。凑数的载具会让装载率失去意义。

### 3.2 盘点清单（照此填写）

| 载具名称 | 文件绝对路径 | 类型 | 主人每天怎么用它 | 是否登记 |
|---|---|---|---|---|
| 例：我的岗位智能体 | C:/Users/xxx/.workbuddy/skills/岗位智能体/SKILL.md | SKILL | 每天查考核口径 | 是 |
| | | | | |

### 3.3 向主人提问模板（问不清就照此问）

1. 「你手上哪几个文件／技能，是你每天都在用的？」
2. 「哪些东西是你绝对不希望我编造、必须查文件的？」（→ 未来的断言）
3. 「有没有一些事，是你明确禁止我做的？」（→ 禁令类断言）
4. 「你在公司里的岗位、考核指标、上下级是谁？」（→ 私有事实类）
5. 「你希望我用什么语气跟你说话、写东西？」（→ 风格类）

### 3.4 产出：一段可复核的盘点记录

把结果写成表格或一段文字，**放在文档旁边备查**。这份记录就是心跳脚本 `CARRIERS` 配置的直接来源。

## 四、第二步：登记私有断言（审计器的灵魂）

### 4.1 五类断言的定义

| 分类 | 定义 | 判定要点 |
|---|---|---|
| A·私有事实 | 训练语料里根本不存在的事实 | 自问：这个信息在外网能查到吗？查不到才算 |
| B·禁令铁律 | 明确禁止做的事 | 模型默认倾向恰恰相反的，最有价值 |
| C·身份连续 | 你是谁、跟主人什么关系、跨会话要继承什么 | 模型无记忆，全靠载具 |
| D·风格腔调 | 输出语气、结构、人称、代价要求 | 训练默认腔调往往正相反 |
| E·判断准则 | 主人特有的判断标准、优先级、挂起规则 | 模型没有私人判据，会自己拍板 |

### 4.2 味藏通用示例（可直接用，也可按岗位增补）

| 分类 | 断言 | 关键词示例 | 为什么大模型给不出 |
|---|---|---|---|
| A | 味藏岗位代码体系 | DU-DS／WU-JS／SM- | 外网不存在 |
| A | 三店名与人名 | 江甜／俞腾芳／柳冬叶／狮山／金月湾／松山湖 | 私有信息 |
| A | 人名—五行对应 | 马循德／熊进 | 私有信息 |
| A | 7S 考核权重 | Sf／SV／Sk + 权重 | 通用模型只会背麦肯锡 7S 定义 |
| A | 五行生克顺序 | 木克土／水克火／金克木 | 通用回答经常记反 |
| B | 不发明数字 | 不发明数字／无源则问 | 模型默认爱把答案补完整 |
| B | 骨架级只提示不自动改 | 骨架级／待总部仲裁 | 模型默认看到好资料就吸收 |
| B | 内部文档不上公开端 | 公开端 | 模型默认「能发就发」 |
| C | 味藏岗位智能体身份 | 味藏／岗位智能体 | 裸模型只是「AI 助手」 |
| C | 经验沉淀与自进化 | 经验／自进化／沉淀 | 裸模型每次从零开始 |
| D | 悟空语言风格（附录九） | 三态／七签名／可算代价 | 默认 AI 腔正相反 |
| E | 大库是档案库、非最新版仓库 | 档案库／版本比对 | 模型默认新资料优先 |
| E | 口径冲突须挂起 | 三版本／冲突／待定 | 模型会自己挑一个「最合理」的 |

### 4.3 质量要求（三条硬标准）

1. **至少 10 条**，五类都要覆盖（业务岗若没有「禁令」类，用岗位红线替代）。
2. **每条必须能写出「反事实基线」**——即：抽掉载具，裸模型会怎么答。写不出这一栏，说明这条断言太泛，不私有。
3. **宁少勿滥**。「什么是 7S」这种通用知识**不算**——那是模型的功劳，不是载具的。

### 4.4 反面示例（这样写等于没写）

| 错误写法 | 为什么错 |
|---|---|
| 「了解餐饮行业」 | 通用知识，模型本来就会 |
| 「掌握公司战略」 | 太泛，无法定位到具体文件、无法校验 |
| 「服务意识强」 | 不是断言，是形容词 |

### 5.2 心跳脚本全文

```python
# -*- coding: utf-8 -*-
"""载具在线心跳 · 通用版 v1.0
=============================================================
给味藏伙伴的龙龟：配好「你的载具清单」后，每天唤醒一次，做两件事——
  1. 在位检查：载具文件在不在、非空、能解析版本号
  2. 效力抽检：调用同目录的 _carrier_audit.py，算「私有断言装载率」
最后把「在线」印记追加到台账（append-only，断了一天台账上就空一格，肉眼可见）。

【必改配置】只改下面 CONFIG 区三处：CARRIER_DIR / CARRIERS / EVO_DIRS
用法：python _aios_heartbeat.py
退出码：0 = ONLINE（全部在位）；1 = DEGRADED（有缺失，逐条列出）
"""
import os, re, io, sys, subprocess
from datetime import datetime

# ==================== CONFIG（按你的盘点结果改这里）====================
BASE        = os.path.expanduser("~/.workbuddy")
CARRIER_DIR = os.path.join(BASE, "skills")            # 你的载具 SKILL 所在目录
EVO_DIR     = os.path.join(BASE, "aios-evolution")    # 台账目录（不存在会自动创建）

# 载具清单：(显示名, 目录名, [需要检查的子目录...])
# 把你主人手上的载具逐个列进来。子目录没有就留空列表。
CARRIERS = [
    ("我的岗位智能体", "岗位智能体", []),
    # ("第二件载具", "目录名", ["references"]),
]
EVO_DIRS = ["experiences", "knowledge", "reports"]    # 没有的会自动标 ✗
# ======================================================================

LEDGER = os.path.join(EVO_DIR, "heartbeat.md")


def parse_version(text):
    head = text[:1500]
    m = re.search(r'version:\s*"?([0-9]+(?:\.[0-9]+)+)"?', head, re.I)
    if m:
        return "v" + m.group(1)
    m = re.search(r'版本[：:]\s*\**\s*v?([0-9]+(?:\.[0-9]+)+)', text)
    if m:
        return "v" + m.group(1)
    m = re.search(r'\bv([0-9]+\.[0-9]+)\b', head)
    if m:
        return "v" + m.group(1)
    return "?"


def main():
    warns, lines, ok, total = [], [], 0, 0

    # 1. 载具在位检查
    for label, skill, subs in CARRIERS:
        total += 1
        f = os.path.join(CARRIER_DIR, skill, "SKILL.md")
        if not os.path.isfile(f) or os.path.getsize(f) == 0:
            warns.append(f"[缺] 载具 {label} → {f}")
            lines.append(f"  ✗ {label:20} 缺失")
            continue
        size = os.path.getsize(f)
        ver = parse_version(io.open(f, encoding="utf-8", errors="ignore").read())
        info = []
        for s in subs:
            d = os.path.join(CARRIER_DIR, skill, s)
            c = len(os.listdir(d)) if os.path.isdir(d) else -1
            info.append(f"{s}:{'✗' if c < 0 else c}")
            if c < 0:
                warns.append(f"[缺] {label}/{s} 目录不在")
        ok += 1
        lines.append(f"  ✓ {label:20} {ver:6} {size // 1024:>4}KB  {' '.join(info)}")

    # 2. 进化/台账目录
    evo = []
    for d in EVO_DIRS:
        p = os.path.join(EVO_DIR, d)
        if os.path.isdir(p):
            evo.append(f"{d}({len(os.listdir(p))})")
        else:
            evo.append(f"{d}(✗)")

    # 3. 效力抽检
    eff = "n/a"
    audit = os.path.join(os.path.dirname(os.path.abspath(__file__)), "_carrier_audit.py")
    if os.path.isfile(audit):
        try:
            r = subprocess.run([sys.executable, audit, "--quiet"],
                               capture_output=True, text=True, timeout=90)
            last = (r.stdout or "").strip().splitlines()
            if last and last[-1].startswith("EFFICACY"):
                eff = last[-1].split()[2]
            else:
                warns.append("[弱] 载体效力抽检无输出")
        except Exception as e:
            warns.append(f"[弱] 载体效力抽检失败：{e}")
    else:
        warns.append("[弱] 同目录未找到 _carrier_audit.py，效力抽检跳过")

    status = "ONLINE" if not warns else "DEGRADED"
    ts = datetime.now().strftime("%Y-%m-%d %H:%M")

    print("=" * 62)
    print(f"  载具在线心跳 | {ts} | 状态：{status}")
    print("=" * 62)
    print("【载具】")
    for l in lines:
        print(l)
    print(f"【进化目录】{' '.join(evo)}")
    print(f"【载体效力】私有断言装载 {eff}（阈值 85%——证明载具不只在位，还在起作用）")
    if warns:
        print("【异常】")
        for w in warns:
            print("  ⚠️ " + w)
    else:
        print("【异常】无 —— 载具全部在位，在线 ✓")
    print("-" * 62)

    # 4. 台账写入（append-only）
    os.makedirs(EVO_DIR, exist_ok=True)
    is_new = not os.path.exists(LEDGER)
    with io.open(LEDGER, "a", encoding="utf-8", newline="\n") as f:
        if is_new:
            f.write("# 载具在线心跳台账\n\n")
            f.write("> 由 `_aios_heartbeat.py` 每日追加。ONLINE=载具全绿；DEGRADED=有缺失。\n\n")
            f.write("| 时间 | 状态 | 载具 | 效力 | 异常 |\n|---|:--:|:--:|:--:|---|\n")
        fault = "；".join(warns).replace("|", "/") if warns else "无"
        f.write(f"| {ts} | {status} | {ok}/{total} | {eff} | {fault} |\n")

    return 0 if not warns else 1


if __name__ == "__main__":
    sys.exit(main())

```

```python
def load(paths):
    cache = {}
    for k, p in paths.items():
        try:
            cache[k] = io.open(p, encoding="utf-8", errors="ignore").read() if p else ""
        except Exception:
            cache[k] = ""
    return cache


def main():
    to_md = "--md" in sys.argv or "-m" in sys.argv
    quiet = "--quiet" in sys.argv or "-q" in sys.argv
    docs = load(FILES)

    rows, hit, miss = [], 0, []
    cat_stat = {}
    for cat, name, kws, srcs, base in PROBES:
        where, found = None, False
        for kw in kws:
            for s in srcs:
                if kw and kw in docs.get(s, ""):
                    where, found = s, True
                    break
            if found:
                break
        cat_stat.setdefault(cat, [0, 0])
        cat_stat[cat][1] += 1
        if found:
            hit += 1
            cat_stat[cat][0] += 1
        else:
            miss.append(f"{cat}｜{name}")
        rows.append((cat, name, "✓" if found else "✗", where or "-", base))

    total = len(PROBES)
    rate = hit / total * 100 if total else 0
    ts = datetime.now().strftime("%Y-%m-%d %H:%M")

    lines = ["=" * 74,
             f"  载具效力审计 | {ts}",
             "=" * 74,
             f"  私有断言装载：{hit}/{total}  ({rate:.1f}%)   阈值 85%   →  {'PASS' if rate >= 85 else 'FAIL'}",
             "", "  【分类装载率】"]
    for c in sorted(cat_stat):
        a, b = cat_stat[c]
        bar = "█" * int(a / b * 20) + "·" * (20 - int(a / b * 20))
        lines.append(f"    {c:14} {bar}  {a}/{b}")
    lines += ["", "  【逐条】"]
    cur = None
    for cat, name, st, where, base in rows:
        if cat != cur:
            lines.append(f"    ── {cat} ──")
            cur = cat
        lines.append(f"    {st} {name:26} ← {where}")
    if miss:
        lines += ["", "  【未定位（先查是不是断言没按实际内容改写）】"]
        for m in miss:
            lines.append(f"    ⚠️ {m}")
        if rate < 50:
            lines.append("")
            lines.append("  ⚠️ 命中率低于 50%：极可能是 PROBES 未按你的载具实际内容改写，")
            lines.append("     而不是载具无效。请先打开载具文件，把断言换成里面真实存在的事实。")
    lines += ["", "  【反事实基线：抽掉载具，裸模型会怎样】"]
    for cat, name, st, where, base in rows:
        lines.append(f"    · {name}：{base}")
    lines.append("=" * 74)

    out = "\n".join(lines)
    print(f"EFFICACY {hit}/{total} {rate:.1f}%" if quiet else out)

    ledger = os.path.join(HERE, "载体效力台账.md")
    is_new = not os.path.exists(ledger)
    with io.open(ledger, "a", encoding="utf-8", newline="\n") as f:
        if is_new:
            f.write("# 载体效力台账\n\n> 由 `_carrier_audit.py` 追加。装载率=「私有断言」在各载具中可定位的比例，阈值 85%。\n\n")
            f.write("| 时间 | 装载率 | 命中 | 未定位 |\n|---|:--:|:--:|---|\n")
        f.write(f"| {ts} | {rate:.1f}% | {hit}/{total} | {'；'.join(miss) if miss else '无'} |\n")

    if to_md:
        md = ["# 载具效力审计报告", "",
              f"> 生成：{ts}　|　装载率 **{hit}/{total}（{rate:.1f}%）**", "",
              "## 一、逐条断言与反事实基线", "",
              "| 分类 | 断言 | 装载 | 来源 | 抽掉载具后裸模型会 |", "|---|:--:|:--:|---|---|"]
        for cat, name, st, where, base in rows:
            md.append(f"| {cat} | {name} | {st} | {where} | {base} |")
        md += ["", "## 二、结论", "",
               f"- 装载率 **{rate:.1f}%**（{hit}/{total}），阈值 85%。",
               "- 这些断言全部是训练语料中不可能存在的：私有事实、禁令、身份、风格、判据。",
               "- 载具的作用不是让模型「更聪明」，而是让模型知道「这里是什么地方、什么不能编、什么要停下」。"]
        p = os.path.join(HERE, "载体效力审计报告.md")
        io.open(p, "w", encoding="utf-8", newline="\n").write("\n".join(md) + "\n")
        print(f"[saved] {p}")

    return 0 if rate >= 85 else 1


if __name__ == "__main__":
    sys.exit(main())

```

## 九、常见问题

### Q1：装载率很低（比如 46%），是不是载具无效？

**先怀疑断言，不是载具。** 九成情况是 `PROBES` 还是模板里的示例，或关键词与你主人文件里的实际写法不一致。
做法：打开载具文件，用你写进 `PROBES` 的关键词搜一遍；搜不到，就换成文件里真实存在的说法。

### Q2：全部 miss（0%）？

多半是路径错。检查 `FILES` 里的绝对路径是否存在、载具目录是否指对。审计器在命中率低于 50% 时会专门提示这一点。

### Q3：主人没有记忆文件怎么办？

去掉 `MEMORY` 这一项，只登记 SKILL 本体即可。断言来源相应减少，但 10 条底线仍要满足——可以从岗位资料里补。

### Q4：主人是业务岗，没有「禁令」类断言？

用岗位红线替代。任何「绝对不能做」的事都算，例如食品安全红线、客诉处理红线、财务禁区。

### Q5：某个断言死活定位不到，但它确实重要？

说明它**没落在载具上**——这正是审计的价值。
做法：把它补进载具（写进岗位 SKILL 或主人备忘），然后复跑。**不要为了好看把它从断言表里删掉。**
