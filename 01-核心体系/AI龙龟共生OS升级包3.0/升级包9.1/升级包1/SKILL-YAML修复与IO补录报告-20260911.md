### 2.4 ⚠️ 一处自我披露：有一个是我上一轮捅的

`五行人格心理学/辅助Skills/03-记忆上下文/会话上下文管理/SKILL.md` 的 `outputs` 里，有一行：

```yaml
outputs: [关于[X], 我们之前分析到[结论]]
```

**这不是原有内容，是我上一轮（全量补齐 frontmatter）时，从正文自动提取 IO 写进去的脏值**——没做 YAML 转义，`[` 嵌套导致非法。它被同一个文件里原有的粘连键问题掩盖了（所以「改前 59 = 改后 59」没暴露出来）。

本轮已修正为合法写法：

```yaml
outputs: ["关于[X]", "我们之前分析到[结论]"]
```

**教训**：批量脚本往 frontmatter 写值，必须过 YAML 转义（或事后全量解析复验）。这条已补进 `载具安全改造` 技能。

### 3.2 「不发明」是怎么守的

- **7 载具**：每条 IO 都挂到该载具正文里出现的具体字段——如龙心OS 的『题面四及格』『路由宣告』、龙脑OS 的『问题特征向量』『君 1 臣 ≤3』、龙爪OS 的『磁盘持久化』、共生OS 的『路由铁律 6 条』、自进化引擎的『三咬合』。
- **17 岗**：以同族唯一有真值的 `GM-CHIEF` 为模板锚，按四组（决策层／经营单元／职能部门／数据层）分型，每条挂到该岗自己的 KPI 名、数据源、SOP 名、协作对象。
- **46 刀**：『主治』句优先取正文里的 `一句话描述:`，其次取 description，再次取正文首句——**一个字不编**。例：

```yaml
# 思维模型库/博弈论
inputs:
  - 待解的题／现象（主治：策略互动的科学，预测理性决策者之间的行为）
  - 已知材料与约束条件
outputs:
  - 博弈论 视角的判断与结论
  - 据此产生的下一步动作
```

## 四、自查抓到的注册表缺陷（第三件事）

补完 IO 重跑注册表，出现一个**反常信号**：

```
轮次       AVG    4分   IO真值
补录前     2.55   12    24
补录后     2.54   10    21   ← 改了 IO 反而掉分？
```

追下去，是 `_skill_registry_build.py` 的 `parse_fm` **只认「键值同行」的写法**，遇到块式列表（`inputs:` 换行 + 缩进项）直接跳过——于是把我刚补的块式 IO 判成「空值」，白扣了分。

修掉解析器后：

```
轮次           AVG    4分   IO真值
补录前         2.55   12    24
补录后(坏解析) 2.54   10    21
修解析器后     2.83   51    92   ← 真实值
```

**这条值得记**：如果当时不查这个「掉分」，就会得出「IO 补录没有效果」的错结论。**指标掉头时先怀疑尺子，再怀疑东西。**
