## 一、为什么做这件事（原理）

### 1.1 一个真实现场

主人对你说：「先把这份资料整理一下，再写个方案，最后发到群里。」

三件事，你都能做。但你能**说清楚**——第一件事的产出，怎么交给第二件事吗？

说不清，你就是在「凭记忆串活」。凭记忆干活，平时没事，一出错就难查：不知道是「技能选错了」，还是「参数传错了」。

### 1.2 病根：技能有说明，没有接口

打开一个典型的技能文件，frontmatter 常常长这样：

```yaml
---
name: 某技能
description: 用于处理各类文档。
---
```

「用于处理各类文档」——它**吃什么**？**吐什么**？**什么时候该用它**？一个都没说。

这不是技能写得不好，是**没有接口**。就像一把很好的螺丝刀，但没标型号——你知道它有用，但不知道该插哪个孔。

### 1.3 一句话原理（记住它）

> **记忆会错，接口不会。**

「我记得它俩能接上」——这是记忆，会错。
「它输出 A，它输入 A」——这是接口，不会错。

### 1.4 代价（可算的）

| | 不贴标签 | 贴标签 |
|---|---|---|
| 每次串新流程 | 多花 3-5 分钟试错 | 直接查表，秒接 |
| 出错时 | 查不出是「选错了」还是「传错了」 | 逐项对照，立刻定位 |
| 一次性投入 | 0 | 主人手头几个技能，**约 1 个工作时段** |

### 1.5 触发边界（哪些技能要贴，哪些不用）

| 技能类型 | 要不要贴标签 |
|---|---|
| 主人的岗位智能体（核心那一件） | ✅ **必须贴** |
| 主人天天用、会与别的技能配合的 | ✅ 要贴 |
| 一次性的、用完就扔的 | ❌ 不用 |
| 纯资料（参考手册、话术库、考核表） | ❌ 不是技能，不用贴 |

> 铁律：**宁少勿滥**。凑数的标签会让注册表失去意义。

## 三、第一步：盘点你的技能（不要跳）

### 3.1 什么算「技能」

技能 = 一个**你能按需调用、并且会产出东西**的模块。在机器上，它的标志是目录里有一个 `SKILL.md` 文件。

对味藏伙伴而言，通常是这几类：

- **岗位智能体**——主人那一件最核心的（如某个岗位 SKILL）
- **辅助技能**——主人自己攒的、常用的（如「会议纪要整理」「话术生成」）
- **工具类技能**——总部下发的通用工具

### 3.2 去哪找

默认位置：`~/.workbuddy/skills/`（`~` 就是主人的用户目录）。

你不用手工翻。第五节的脚本会自动扫这个目录，把全部 `SKILL.md` 找出来。

### 3.3 盘点清单（人工过一遍）

| 技能名称 | 路径 | 主人在什么场景用它 | 会不会和别的技能配合 | 要贴标签吗 |
|---|---|---|---|:--:|
| 例：我的岗位智能体 | ~/.workbuddy/skills/xxx/SKILL.md | 每天查考核口径 | 会 | ✅ |
| | | | | |

### 3.4 一个反常识

**不是技能越多越好。** 如果主人只有 3 个技能，这份盘点 10 分钟就完了——那就 10 分钟做完，**不要为了凑数去找技能**。

## 四、第二步：接口四维（贴什么标签）

### 4.1 四维是什么

一个技能要能被「串起来用」，frontmatter 必须写清四件事：

| 维度 | 字段 | 一句话 | 类比 |
|---|---|---|---|
| 1 | `name` | 它叫什么 | 螺丝刀的型号 |
| 2 | `description` | 它**治什么** | 螺丝刀的用途 |
| 3 | `triggers` | 什么时候该用它 | 什么时候该拿螺丝刀 |
| 4 | `inputs` + `outputs` | 它吃什么、吐什么 | 刀头多大、拧完出什么 |

**四维缺一，就不算「能被编排」。**

### 4.2 正例 / 反例

**反例（现状，只能被人读，不能被机器串）**

```yaml
---
name: 某技能
description: 用于处理各类文档。
---
```

病在哪：`description` 没说治什么（「各类文档」等于没说）；没有 `triggers`（不知道啥时候用）；没有 `inputs`/`outputs`（不知道怎么调）。

**正例（四维全满，能被人读，也能被机器串）**

```yaml
---
name: 会议纪要整理
description: 把一段会议速记或录音转写，提炼成「决议 + 待办 + 责任人」三栏纪要。
triggers: [整理会议纪要, 会议速记, 会后待办]
layer: 辅助技能
inputs:
  - name: 会议速记文本
    type: text
    required: true
    desc: 会议原始记录或转写稿
outputs:
  - name: 结构化纪要
    type: file
    desc: 决议 / 待办 / 责任人三栏
---
```

### 4.3 完整度分级（0-4 分）

| 分 | 条件 | 状态 |
|---|---|---|
| **0** | 连 frontmatter 都没有 | ❌ 不可用 |
| **1** | 有名字 | ⚠️ 可被人找 |
| **2** | + 有「治什么」 | ⚠️ 可被人理解 |
| **3** | + 有触发条件 | ⚠️ 可被半自动调用 |
| **4** | + 有 inputs/outputs | ✅ **可被编排** |

脚本会按这四维给每个技能打分。**目标不是全部 4 分，是主人真正要串的那几个先到 4 分。**

### 4.4 两个「AIOS 特色字段」（可选，但建议有）

- `cost`：**可算代价**（时间／精力／风险）——每条建议都要能算出代价，这是本院语言风格的硬要求。
- `asserts`：**验证断言**（怎么知道做对了）——没有验证轴的流程等于没有刹车。

## 五、第三步：跑脚本（一个入口，三个模式）

### 5.1 落盘

把下面 5.7 的脚本全文，原样保存到主人的工作目录，文件名 `_skill_iface_wz.py`。

### 5.2 一个入口，三个模式

| 命令 | 干什么 | 会不会改文件 |
|---|---|:--:|
| `python _skill_iface_wz.py` | **scan**：扫描 + 打分 + 出注册表 | ❌ 只读 |
| `python _skill_iface_wz.py validate` | **validate**：校验 frontmatter 是否合法 | ❌ 只读 |
| `python _skill_iface_wz.py fill` | **fill**：dry-run，只列出要补什么 | ❌ 只读 |
| `python _skill_iface_wz.py fill --apply` | **fill**：落盘补齐 | ✅ 写入（先备份） |

> 默认扫 `~/.workbuddy/skills/`。要扫别处，加 `--root <目录>`。

### 5.3 第一步：scan（先看清家底）

```
python _skill_iface_wz.py
```

看三个数：**活跃技能数 / 接口完整度均分 / 四维全满个数**。完整度均分低于 3、四维全满为 0，说明该补了。

### 5.4 第二步：validate（防带病加载）

```
python _skill_iface_wz.py validate
```

任何 `不合法` 或 `无 frontmatter` 都要先修——**frontmatter 有语法错，技能会整体加载失败**。

### 5.5 第三步：fill（先 dry-run，不改一个字）

```
python _skill_iface_wz.py fill
```

它只会告诉你「要补哪几个字段、各几个」，**不会动文件**。看清了再加 `--apply`。

### 5.6 第四步：fill --apply（落盘）

```
python _skill_iface_wz.py fill --apply
```

**五道安全闸（写在代码里，不靠自觉）：**

| # | 闸 | 说明 |
|---|---|---|
| 1 | **只动 frontmatter 块** | 正文逐字节比对，不一致就拒绝写入 |
| 2 | **已有字段绝不覆盖** | 只在末尾追加「完全没有的键」 |
| 3 | **幂等** | 补完再跑，显示「待补 0」 |
| 4 | **dry-run 默认** | 不加 `--apply` 绝不动文件 |
| 5 | **集中备份** | `_skill_iface_backup_<日期>/`，整目录覆盖即回滚 |

### 5.7 脚本全文（原样保存为 `_skill_iface_wz.py`）

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
技能接口层工具（味藏 20 人版）—— 一个入口，三个模式
=====================================================

为什么要有这个脚本：
  大模型出厂带的是一张白纸，不知道你主人是谁、在哪个岗位、这家公司
  有哪几家店。这些"私有世界"全装在技能文件（SKILL.md）里。
  但技能文件如果没写清"吃什么、吐什么"，就没法被串起来用——
  只能靠"我记得它俩能接"。记忆会错，接口不会。

本脚本做三件事（对应接口四维）：
  scan      扫描 + 打分 + 出注册表      ← 先看清家底
  validate  校验 frontmatter 是否合法   ← 防止技能集体加载失败
  fill      补齐缺失的 frontmatter      ← 给技能贴标签（先 dry-run）

用法（命令行，在脚本所在目录执行）：
  python _skill_iface_wz.py                      # = scan，出注册表
  python _skill_iface_wz.py validate             # 校验 YAML 合法性
  python _skill_iface_wz.py fill                 # dry-run：只列出要补什么
  python _skill_iface_wz.py fill --apply         # 落盘补齐（先自动备份）
  python _skill_iface_wz.py scan --root <目录>   # 指定别的技能目录

三条底线（写在代码里，不靠自觉）：
  1. 只动 frontmatter 块 —— 正文逐字节比对，不一致就不写
  2. 已有字段绝不覆盖 —— 只在末尾追加缺的键
  3. 不发明 —— 能从文件自身派生的才补，语义字段（IO）一律留 TODO 骨架
"""

import io
import os
import re
import sys
import json
import shutil
import hashlib
import datetime

# ---------------------------------------------------------------- 路径与常量

HOME = os.path.expanduser("~")
DEFAULT_ROOT = os.path.join(HOME, ".workbuddy", "skills")
HERE = os.path.dirname(os.path.abspath(__file__))

# 归档目录标记：名字命中即跳过（不算"活跃技能"）
ARCHIVE_MARKERS = ("_archive", "_重复合并", "_backup", "_trash")

# 接口四维：前两维"能被人用"，后两维"能被机器编排"
WANTED = ("name", "description", "triggers", "layer", "inputs", "outputs")
TODO_MARK = "TODO 待补"


def is_archive(dirname):
    n = dirname.strip()
    if n.startswith("_"):
        return True
    return any(m in n for m in ARCHIVE_MARKERS)


def find_skills(root):
    """递归找全部 SKILL.md，跳过归档目录。"""
    hits = []
    for dirpath, dirnames, filenames in os.walk(root):
        dirnames[:] = [d for d in dirnames if not is_archive(d)]
        if "SKILL.md" in filenames:
            hits.append(os.path.join(dirpath, "SKILL.md"))
    return sorted(hits)


def read_text(path):
    with io.open(path, "r", encoding="utf-8", errors="replace", newline="") as f:
        return f.read()


def write_text(path, text):
    with io.open(path, "w", encoding="utf-8", newline="") as f:
        f.write(text)


def md5(s):
    return hashlib.md5(s.encode("utf-8")).hexdigest()


# ---------------------------------------------------------- frontmatter 解析

FM_RE = re.compile(r"\A\ufeff?---[ \t]*\r?\n(.*?)\r?\n[ \t]*---[ \t]*(?:\r?\n|$)", re.S)


def split_fm(text):
    """切出 (fm块文本, 正文)。无 frontmatter 返回 (None, 原文)。"""
    m = FM_RE.match(text)
    if not m:
        return None, text
    return m.group(1), text[m.end():]


def parse_fm(fm):
    """宽松解析 frontmatter 为 dict（支持块式列表 / 多行标量）。"""
    d = {}
    if not fm:
        return d
    lines = fm.split("\n")
    i = 0
    while i < len(lines):
        line = lines[i].rstrip("\r")
        m = re.match(r"^([A-Za-z_][\w\-]*)[ \t]*:[ \t]*(.*)$", line)
        if not m:
            i += 1
            continue
        k, v = m.group(1), m.group(2).strip()
        # 块式列表：  key:\n  - a\n  - b
        if v == "" and i + 1 < len(lines) and re.match(r"^[ \t]+-[ \t]", lines[i + 1]):
            items, j = [], i + 1
            while j < len(lines) and (re.match(r"^[ \t]+-[ \t]", lines[j]) or lines[j].strip() == ""):
                if lines[j].strip():
                    items.append(re.sub(r"^[ \t]+-[ \t]*", "", lines[j]).strip().strip('"').strip("'"))
                j += 1
            d[k] = items
            i = j
            continue
        # 多行标量： key: |  或 key: >
        if v in ("|", ">", "|-", ">-", "|+", ">+"):
            block, j = [], i + 1
            while j < len(lines) and (lines[j].startswith(" ") or lines[j].strip() == ""):
                if lines[j].strip():
                    block.append(lines[j].strip())
                j += 1
            d[k] = " ".join(block)
            i = j
            continue
        d[k] = v.strip('"').strip("'")
        i += 1
    return d


def has_real_value(v):
    """真值判定：非空、且不含 TODO 占位。"""
    if v is None:
        return False
    if isinstance(v, list):
        vals = [x for x in v if x and TODO_MARK not in x]
        return len(vals) > 0
    s = str(v).strip()
    return bool(s) and TODO_MARK not in s


def score(fm):
    """接口完整度 0-4：name → description → triggers → inputs+outputs。"""
    if not fm:
        return 0
    s = 0
    if has_real_value(fm.get("name")) or has_real_value(fm.get("title")):
        s += 1
    if has_real_value(fm.get("description")):
        s += 1
    if has_real_value(fm.get("triggers")):
        s += 1
    if has_real_value(fm.get("inputs")) and has_real_value(fm.get("outputs")):
        s += 1
    return s


# ------------------------------------------------------------- 派生与嗅探

def first_sentence(body):
    """正文首个自然句（用于兜底 description）。逐行扫描，跳过标题/代码/列表符号。"""
    in_code = False
    for raw in body.replace("\r\n", "\n").split("\n"):
        s = raw.strip()
        if s.startswith("```"):
            in_code = not in_code
            continue
        if in_code or not s:
            continue
        if s[0] in "#>|-*`+":
            continue
        if re.match(r"^\d+[\.、]", s):
            continue
        s = re.sub(r"^[>#\-*+\d\.\s　]+", "", s)
        s = re.sub(r"\*\*|__|`", "", s).strip()
        if len(s) >= 8:
            return re.split(r"[。！？\n]", s)[0][:80].strip()
    return ""


def sniff_triggers(desc):
    """从 description 摘「当…时 / 用于…」，抓不到就留空（不编）。"""
    if not desc:
        return []
    out = []
    for m in re.finditer(r"(当[^。；，,\n]{2,24}时|用于[^。；，\n]{2,24}|收到[^。；，\n]{2,20}时)", desc):
        t = m.group(1).strip()
        if t and t not in out:
            out.append(t)
    return out[:4]


def guess_layer(rel_dir):
    """按相对路径首层推断所属层。只有一层时标「未分层」，提示主人补。"""
    parts = [p for p in rel_dir.replace("\\", "/").split("/") if p]
    return parts[0] if len(parts) >= 2 else "未分层"


# ------------------------------------------------------------------ scan

def cmd_scan(root):
    paths = find_skills(root)
    rows, total, full4, skel = [], 0, 0, 0
    by_layer = {}
    for p in paths:
        rel = os.path.relpath(os.path.dirname(p), root)
        text = read_text(p)
        fm_text, body = split_fm(text)
        fm = parse_fm(fm_text)
        sc = score(fm)
        total += 1
        if sc >= 4:
            full4 += 1
        io_ready = ("inputs" in fm and "outputs" in fm)
        if io_ready:
            skel += 1
        layer = fm.get("layer") or guess_layer(rel)
        rows.append({
            "path": p, "rel": os.path.relpath(p, root), "name": fm.get("name") or fm.get("title") or os.path.basename(os.path.dirname(p)),
            "desc": (fm.get("description") or "")[:60], "score": sc, "layer": layer,
            "has_fm": fm_text is not None, "io_ready": io_ready,
        })
        by_layer.setdefault(layer, []).append(rows[-1])

    avg = (sum(r["score"] for r in rows) / total) if total else 0.0

    # ---- 人读注册表
    md = []
    md.append("# 我的技能注册表\n")
    md.append("> 由 `_skill_iface_wz.py scan` 自动生成。**用法：按「治什么」找技能，不按名字找。**\n")
    md.append("> 生成时间：%s ｜ 扫描目录：`%s`\n" % (datetime.datetime.now().strftime("%Y-%m-%d %H:%M"), root))
    md.append("")
    md.append("| 指标 | 值 |")

def render_missing(key, ctx):
    if key == "name":
        return ["name: %s" % ctx["name"]]
    if key == "description":
        return ["description: %s" % ctx["desc"]]
    if key == "triggers":
        tg = ctx["triggers"]
        if tg:
            return ["triggers: [%s]" % ", ".join(tg)]
        return ["triggers: []  # %s：何时该用这个技能" % TODO_MARK]
    if key == "layer":
        return ["layer: %s" % ctx["layer"]]
    if key == "inputs":
        return ["inputs: []  # %s：本技能吃什么（文件/文本/数据）" % TODO_MARK]
    if key == "outputs":
        return ["outputs: []  # %s：本技能吐什么" % TODO_MARK]
    return ["%s: " % key]


def cmd_fill(root, apply_=False):
    paths = find_skills(root)
    stamp = datetime.datetime.now().strftime("%Y%m%d")
    backup_dir = os.path.join(HERE, "_skill_iface_backup_%s" % stamp)
    todo, done, skipped = [], 0, 0

    for p in paths:
        text = read_text(p)
        fm_text, body = split_fm(text)
        fm = parse_fm(fm_text)
        rel = os.path.relpath(p, root)
        d = os.path.basename(os.path.dirname(p))

        # 已有键则跳过（含骨架）——只补"完全没有这个键"的，绝不覆盖
        missing = [k for k in WANTED if k not in fm]
        if not missing:
            skipped += 1
            continue

        ctx = {
            "name": fm.get("name") or fm.get("title") or d,
            "desc": first_sentence(body) or (d + "技能"),
            "triggers": sniff_triggers(fm.get("description") or first_sentence(body)),
            "layer": fm.get("layer") or guess_layer(os.path.dirname(rel)),
        }
        new_bits = []
        for k in missing:
            new_bits.extend(render_missing(k, ctx))

        if fm_text is None:
            new_fm = "\n".join(new_bits)
            new_text = "---\n%s\n---\n%s" % (new_fm, body)
        else:
            new_fm = fm_text.rstrip() + "\n" + "\n".join(new_bits)
            new_text = "---\n%s\n---\n%s" % (new_fm, body)

        # 安全闸①：正文必须逐字节不变
        _, new_body = split_fm(new_text)
        if md5(new_body) != md5(body):
            print("  ⚠️ 正文被改动，拒绝写入：%s" % rel)
            continue

        todo.append((p, rel, missing))
        if apply_:
            src = os.path.join(backup_dir, rel)
            os.makedirs(os.path.dirname(src), exist_ok=True)
            shutil.copy2(p, src)
            write_text(p, new_text)
            done += 1

    print("【补齐 frontmatter】%s" % ("已落盘" if apply_ else "DRY-RUN（未改动任何文件）"))
    print("  待补技能：%d ｜ 已是最新：%d ｜ 备份：%s" % (len(todo), skipped, backup_dir if apply_ else "（未生成）"))
    stats = {}
    for _, _, ks in todo:
        for k in ks:
            stats[k] = stats.get(k, 0) + 1
    for k in WANTED:
        if k in stats:
            print("    + %-12s %d 个" % (k, stats[k]))
    print("  ⚠️ inputs/outputs 只留 TODO 骨架 —— 它们吃什么、吐什么，只有主人知道，脚本不编。")
    if not apply_ and todo:
        print("  确认无误后加 --apply 落盘。")
    return 0

    root = DEFAULT_ROOT

    rest = argv[1:]

    if mode == "scan":
        return cmd_scan(root)
    if mode == "validate":

    if mode == "fill":

    print("未知模式：%s（可用：scan / validate / fill）" % mode)
    return 2

    sys.exit(main(sys.argv))

inputs:
  - name: 门店日报数据
    type: text
    required: true
```

**这几行只有主人写得出来。** 写完再跑一次 `validate` 确认合法。

## 六、第四步：编排三律落载具

### 6.1 编排三律

接口建好，是为了**能串**。串的方法只有三步：

| 步 | 名字 | 做什么 |
|---|---|---|
| 1 | **选** | 按「治什么」查注册表 → 命中技能（**不按名字找**） |
| 2 | **串** | 上游的 `outputs` 喂给下游的 `inputs`（变量传递） |
| 3 | **验** | 每个技能的 `asserts` 逐条过；`cost` 累计，超预算先停下问主人 |

### 6.2 增补节模板（直接贴进主人岗位智能体的 SKILL.md）

> 用「增补节」形式追加，**不动正文主体**——可追溯、可回滚。

```markdown
## 第X节 技能编排（增补 2026-XX-XX）

### 选
- 需要多步任务时，先查 `我的技能注册表.md`，按「治什么」选技能，不按名字选。
- 命中多个时，优先选 `asserts` 更明确的。

### 串
- 上游技能的 `outputs` 直接作为下游技能的 `inputs`，不做隐含转换。
- 中间数据落在文件里，不靠「我还记得」。

### 验
- 每个技能跑完，逐条过它的 `asserts`；有一条不过，就停下来报告，不硬着头皮往下走。
- 累计 `cost`，超过预算先停下来问主人。

### 查不到怎么办
- 注册表里没有合适的技能：先报告「缺哪一类技能」，不硬凑。
```

### 6.3 一个串起来的例子

```
「会议纪要整理」                        「任务清单生成」
  inputs:  会议速记文本 ─────────┐
  outputs: 结构化纪要（决议/待办/责任人） ──┤
                                          ↓
                                    inputs: 待办清单
                                    outputs: 带责任人的任务表
```

两件技能，靠 `outputs → inputs` 咬着，就是一条流水线。**没有接口，这条线只能靠「我记得」。**

## 七、可选：记忆体检（只建议，绝不自动删）

### 7.1 为什么

记忆文件（`MEMORY.md`）有个天生的毛病——**只增不减**。日子一长会膨胀到系统读不完，然后被**截断**；截断时丢掉哪一条，是不确定的。

等它自己坏掉，不如先给它做个体检。

### 7.2 硬约束（写在代码里）

- **只读记忆文件**——脚本从头到尾没有一行写 `MEMORY.md`
- **只出报告**——删除/合并永远由主人拍板
- 不联网、不调用任何接口

### 7.3 怎么用

```
python _memory_tidy_wz.py                          # 默认读 ~/.workbuddy/MEMORY.md
python _memory_tidy_wz.py --file <记忆文件路径>
```

它会出三类建议：**永久保留（P0 纪律）/ 可压缩 / 可合并**。

> ⚠️ P0 一条都不许删——那是纪律，删了会出事。

### 7.4 脚本全文（原样保存为 `_memory_tidy_wz.py`）

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
记忆整理器（味藏 20 人版）—— 只出建议，绝不自动删改
=====================================================

为什么需要它：
  记忆文件（MEMORY.md）有一个天生的毛病——**只增不减**。
  日子一长，它会膨胀到系统读不完，然后被截断；截断时丢掉哪一条，
  是不确定的。等它自己坏掉，不如先让它体检。

它做什么：
  逐条解析记忆文件 → 给每条打"该不该留"的建议 → 出报告。
  建议分三类：永久保留 / 可压缩 / 可合并。

它绝不做什么（写在代码里的硬约束）：
  1. 只读记忆文件 —— 本脚本从头到尾没有一行写 MEMORY.md
  2. 只写独立报告 —— 删除/合并永远是主人（或主人授权的龙龟）动手
  3. 不联网、不调用任何接口

用法：
  python _memory_tidy_wz.py                       # 默认读 ~/.workbuddy/MEMORY.md
  python _memory_tidy_wz.py --file <记忆文件路径>
  python _memory_tidy_wz.py --min 4000            # 超过 4000 字才提醒要整理
"""

import io
import os
import re
import sys
import datetime

HOME = os.path.expanduser("~")
DEFAULT_FILE = os.path.join(HOME, ".workbuddy", "MEMORY.md")
HERE = os.path.dirname(os.path.abspath(__file__))

# P0：命中即原样永久保留（这些是纪律，删了会出事）
P0_PAT = re.compile(r"⚠️|铁律|禁令|禁止|永久|最高优先级|红线|不准|绝不|必须|一律|冻结|作废")
# P1：含具体锚点（路径/数字/引号术语）→ 保留，不易压缩
P1_PAT = re.compile(r"[A-Za-z]:[\\/]|\.md|\.py|/|`|\d{3,}|：「|\*\*[^*]{2,20}\*\*")


def read_text(path):
    with io.open(path, "r", encoding="utf-8", errors="replace") as f:
        return f.read()


def parse_items(text):
    """解析出 (节标题, 条目文本, 行号) 三元组。"""
    items = []
    section = "(文首)"
    lineno = 0
    for raw in text.split("\n"):
        lineno += 1
        line = raw.rstrip()
        if line.startswith("#"):
            section = re.sub(r"^#+\s*", "", line).strip() or section
            continue
        m = re.match(r"^\s*[-*]\s+(.+)$", line)
        if m:
            items.append((section, m.group(1).strip(), lineno))
    return items


def classify(txt):
    if P0_PAT.search(txt):
        return "P0", "永久保留"
    if P1_PAT.search(txt):
        return "P1", "保留（含具体锚点）"
    if len(txt) >= 160:
        return "P2", "可压缩（长但无锚点）"
    return "P1", "保留"


def tokens(txt):
    """粗提关键词（中文 2 字词 + 英文单词 + 数字），用于找合并候选。"""
    zh = re.findall(r"[\u4e00-\u9fa5]{2,4}", txt)
    en = re.findall(r"[A-Za-z_]{3,}", txt)
    return set(zh) | set(en)


def main(argv):
    path = DEFAULT_FILE
    limit = 4000
    rest = argv[1:]
    while rest:
        a = rest.pop(0)
        if a == "--file" and rest:
            path = rest.pop(0)
        elif a == "--min" and rest:
            limit = int(rest.pop(0))
    if not os.path.isfile(path):
        print("找不到记忆文件：%s" % path)
        print("用 --file <路径> 指定。")
        return 2

    text = read_text(path)
    items = parse_items(text)
    size = len(text)

    rows = []
    for sec, txt, ln in items:
        code, label = classify(txt)
        rows.append({"section": sec, "text": txt, "line": ln, "code": code, "label": label, "size": len(txt)})

    # 合并候选：关键词重合度 > 0.5 且不同节
    merge_pairs = []
    for i in range(len(rows)):
        for j in range(i + 1, len(rows)):
            a, b = tokens(rows[i]["text"]), tokens(rows[j]["text"])
            if not a or not b:
                continue
            jac = len(a & b) / float(len(a | b))
            if jac >= 0.5:
                merge_pairs.append((jac, rows[i], rows[j]))

    p0 = [r for r in rows if r["code"] == "P0"]
    p2 = [r for r in rows if r["code"] == "P2"]

    out = []
    out.append("# 记忆体检建议（%s）" % datetime.datetime.now().strftime("%Y-%m-%d"))
    out.append("")
    out.append("> 由 `_memory_tidy_wz.py` 生成。**本报告只是建议——脚本没有改动记忆文件一个字。**")
    out.append("")
    out.append("| 指标 | 值 |")
    out.append("|---|---|")
    out.append("| 记忆文件 | `%s` |" % path)
    out.append("| 字符数 | %d %s |" % (size, "⚠️ 已超过 %d，建议整理" % limit if size > limit else "（未超限）"))
    out.append("| 条目数 | %d |" % len(rows))
    out.append("| 永久保留（P0 纪律） | %d |" % len(p0))
    out.append("| 可压缩（P2 长条） | %d |" % len(p2))
    out.append("| 合并候选 | %d 对 |" % len(merge_pairs))
    out.append("")
    out.append("## 一、建议压缩（长且无锚点，可改写为一句）")
    out.append("")
    if p2:
        out.append("| 节 | 字符 | 摘要 |")
        out.append("|---|:--:|---|")
        for r in sorted(p2, key=lambda x: -x["size"]):
            out.append("| %s | %d | %s… |" % (r["section"], r["size"], r["text"][:50]))
    else:
        out.append("（无——说明当前记忆条条有锚点，健康。）")
    out.append("")
    out.append("## 二、合并候选（内容相近，可并成一条）")
    out.append("")
    if merge_pairs:
        for jac, a, b in sorted(merge_pairs, key=lambda x: -x[0])[:10]:
            out.append("- **相似度 %.0f%%**" % (jac * 100))
            out.append("  - 第 %d 行：%s" % (a["line"], a["text"][:60]))
            out.append("  - 第 %d 行：%s" % (b["line"], b["text"][:60]))
    else:
        out.append("（无）")
    out.append("")
    out.append("## 三、体积 Top 10（最占地方的条目）")
    out.append("")
    out.append("| 行 | 字符 | 开头 |")
    out.append("|:--:|:--:|---|")
    for r in sorted(rows, key=lambda x: -x["size"])[:10]:
        out.append("| %d | %d | %s… |" % (r["line"], r["size"], r["text"][:48]))
    out.append("")
    out.append("## 四、怎么用这份报告")
    out.append("")
    out.append("1. **P0 一条都不许删**——那是纪律，删了会出事。")
    out.append("2. P2 条目：保留信息，把长句压成一句（锚点不能丢）。")
    out.append("3. 合并候选：判断是不是真的重复，是才合。")
    out.append("4. **改完必须复核**：改记忆等于改载具，改完跑一次载具体检。")
    out.append("")
    out.append("> ⚠️ 本脚本永远不替你删。删记忆是不可逆动作，必须由主人拍板。")

    out_path = os.path.join(HERE, "记忆体检建议-%s.md" % datetime.datetime.now().strftime("%Y-%m-%d"))
    with io.open(out_path, "w", encoding="utf-8", newline="\n") as f:
        f.write("\n".join(out))

    print("【记忆体检】%s" % path)
    print("  字符数：%d ｜ 条目：%d ｜ P0 纪律：%d ｜ 可压缩：%d ｜ 合并候选：%d 对"
          % (size, len(rows), len(p0), len(p2), len(merge_pairs)))
    print("  报告 → %s" % out_path)
    if size > limit:
        print("  ⚠️ 已超 %d 字，建议按报告整理（P0 一条不动）。" % limit)
    return 0


if __name__ == "__main__":
    sys.exit(main(sys.argv))

## 十、常见问题

### Q1：我的技能目录不在 `~/.workbuddy/skills/` 怎么办？

加 `--root`：`python _skill_iface_wz.py scan --root D:/我的技能`。三个模式都支持。

### Q2：`fill` 补出来的 `description` 有点糙？

正常。它是从技能正文**第一句**提取的——**提取，不是编造**。主人可以看一遍，改成更准的一句话（这是允许的，因为改的是主人自己的内容）。

### Q3：`triggers` 补成了 `[]  # TODO`？

说明脚本没从描述里嗅到明确的触发词。这比乱填一串触发词**安全**。主人自己补 2-3 个常用说法即可。

### Q4：只有一层目录，`layer` 显示「未分层」？

正常。脚本只在有两层以上目录时才推断层名；只有一层时标「未分层」，提示主人按用途自己分（如「岗位／辅助／工具」）。

### Q5：技能本来是好的，会不会被脚本改坏？

三道防线：①只动 frontmatter 块，正文逐字节比对，不一致就拒写；②已有字段绝不覆盖，只追加缺的；③改前自动备份。真出问题，`_skill_iface_backup_<日期>/` 整目录覆盖即回滚。

### Q6：主人没有记忆文件怎么办？

跳过第七节。本升级的主线是技能接口，记忆体检是可选加分项。
