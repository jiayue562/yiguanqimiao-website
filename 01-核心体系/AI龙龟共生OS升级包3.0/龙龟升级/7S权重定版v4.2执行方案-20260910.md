## 四、第 3 问推荐方案：按岗基线 + 按人调权两层并存（带日落条款）

**推荐：两层并存，按岗为纲、按人为过渡。**

**理由（四条）**：
1. **v9.0 不是野数字**——它出自组织架构文档 v1.0 §6.3 权威框架，且已与薪酬、五行人格 SOP 挂钩宣贯；一刀切抹平会当场推翻现行三店长考核；
2. **三店长差异是味藏"五行识人、因材施考"的招牌**——江甜（土·老店守成 Sy25%★）、俞腾芳（金·总教练 Sf30%★）、柳冬叶（水·柔性 Sk15%最高）各有其理，抹平即自废武功；
3. **按岗基线解决的是公平与可复制**——新店长上任即用 3.2 基线，不必每次重新定权；这正好补 v9.0 没有"新店长默认值"的缺口；
4. **与既定的"两制并存、渐进优化"战略同构**——不搞一夜切换，避免体系震荡。

**具体设计**：
- **第一层（纲）**：3.2 店长基线 SV30/S35%★/St5/Sy5/Sty5/Sf15/Sk5——写入三个店长 SKILL 头部 + PERF-MGR 基线表，所有**新任店长**直接适用；
- **第二层（过渡调权）**：现任三店长继续按 v9.0 个人矩阵评分，PERF-MGR 输出时**双列对照**（个人调权得分 / 基线得分）并标注偏离度；
- **日落条款（建议）**：2026-12-31 本考核年度结束后，三店长收敛到 3.2 基线（或由你在年度考核复盘时决定延长）；
- **单元三总不设调权层**——直接按 3.2 执行（现行双轮本就是刚写入的、尚未跑完一个考核周期，切换成本最低）。

**备选**：若你嫌两层记账麻烦，可退一档——"3.2 基线立即生效 + v9.0 个人矩阵降级为'教练参考'（不进考核分）"，一步到位但三店长当期分数会有可见波动。
