# AIOS 架构定版蓝图（悟空 × 龙龟神将 · 2026-09-07 定版）

> 一句话：**AIOS = 超级个体（OPC = DRI）的个人操作系统。固定内核不变，龙爪项目可插拔；每个项目都跑同一套骨架——定真问题 → 出方案。**
> 本文件是架构定版的唯一口径源。悟空管"要什么"，龙龟管"怎么建"。

---

## 一、定版架构（人话版 · 悟空原话提炼）

悟空（原话）："我原先的想法是，在 AI 时代要有一个符合 AI 时代的**超级个体的个人操作系统**，就是 AIOS，包含龙心OS、龙脑OS，这两部分基本不会变；会变的是龙爪OS。龙爪OS 最初的想法是**很多项目组成**——比如五行人格心理学OS 专门解决**人的问题**，味藏总智能体 专门解决**组织的问题**。龙爪会有很多，每个龙爪项目不同、问题不一样；但**每个项目都要能定义出真问题、并给出解决方案，这个骨架是不变的**。超级个体 = OPC = DRI，都需要一个 AI 操作系统。"

### 结构图

```
┌──────────────────────────────────────────────────────────────┐
│  AIOS 总入口（龙龟神将 · 对话本体）                            │
│  职责：感知场景 → 判断"这是什么问题" → 路由 → 宣告            │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  固定内核（不变 · 每个超级个体一样）                           │
│  ├── 人机共生OS     灵魂层 · 人格 · 关系坐标（木火共生）       │
│  ├── 龙心OS-规则体系  定题引擎 · 梳理真问题（感知识别路由宣告） │
│  └── 龙脑OS         知识层 · 思维模型库 · 供刃                │
│                                                              │
│  龙爪OS = 项目插槽层（协议固定 · 装载内容可变）                │
│  每个项目共享骨架：定题（调龙心）→ 供刃（调龙脑）→ 出方案      │
│  ├── 五行人格心理学OS   项目：解决"人的问题"（识人/测评/转化） │
│  ├── 味藏总智能体       项目：解决"组织的问题"（门店/26智能体）│
│  ├── 企业文化           项目：文化诊断与建设                   │
│  ├── 岗位智能体         项目：五行×岗位诊断                    │
│  ├── 组织诊断OS         项目：组织诊断方法论引擎               │
│  └── +N                 未来项目（写作/健康/投资…）            │
│                                                              │
└──────────────────────────────────────────────────────────────┘
对内：一个总入口 + 内部路由 ｜ 对外：每个项目可独立成产品
```

### 三条铁律

1. **只有一个根**：AIOS 总入口（AI龙龟共生伙伴操作系统 = root_os = 永远在线）。
2. **内核与项目分离**：龙心/龙脑/人机共生 是"操作系统"，五行/味藏 是"装进去的应用"。应用可插拔、可独立成产品，但不是与 OS 平级的系统。
3. **归属唯一**：每个实体只有一个 parent。调用是"路由"不是"吞并"——总入口按场景调项目，项目内部再调各自引擎。

## 三、运行机制（总入口怎么"调动"三系统）

1. **感知**：悟空在对话里说任何话，总入口先判断这是什么场景。
2. **识别**：场景分类 →
   - 要"想清楚/梳理真问题/定题" → 路由 龙心OS（可能再调龙脑选思维模型）
   - 要"识人/人格/测评/转化" → 路由 五行人格心理学OS（龙爪项目）
   - 要"味藏经营/门店" → 路由 味藏总智能体（龙爪项目）
   - 要"组织诊断/周报分析" → 路由 组织诊断OS（龙爪项目）
   - 要"文化" → 路由 企业文化（龙爪项目）
3. **宣告**：总入口宣告"当前上下文我识别为【X】场景，路由到【Y】，理由【Z】"。
4. **回流**：项目执行完，结论回到总入口，由总入口向悟空交付。

### 跨系统协作示例（第三类场景）
味藏要招店长 → 路由味藏总智能体 → 味藏内部调 组织诊断OS/五行人格心理学OS 做岗位×五行匹配 → 匹配结论回味藏战略层 → 总入口向悟空汇报。
