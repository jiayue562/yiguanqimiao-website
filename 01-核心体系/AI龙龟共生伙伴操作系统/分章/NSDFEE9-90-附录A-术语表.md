## 一、身份与总体

| 词 | 确切意思 | 出现在 |
|---|---|---|
| **AIOS** | AI 龙龟共生伙伴操作系统的简称。**不是一个软件，是一整套“人 + AI 一起干活”的约定与零件** | 全书 |
| **龙龟神将** | 这套系统里那个“伙伴”的名字。**是名字，不是产品名** | 卷首 |
| **载具** | 承载这个伙伴的那些文件、规则、脚本的总和。**载体不是主体**——把它当主体写，等于把身体当成人 | 第 3 章 |
| **灵魂层** | 那个乘数。**不是一个额外模块，是渗透在每一层前面的数** | 第 3 章 |
| **六层公式** | **智能体 = 灵魂 ×（知识库 + 上下文 + 决策 + 技能 + 接口 + 工作流）** | 第 3 章 |
| **乘数 vs 加法** | 加法：品质由最弱一层决定。乘法：**灵魂调倍率，同时改变所有项** | 第 3 章 |

## 二、四层内核

| 词 | 确切意思 | 出现在 |
|---|---|---|
| **龙心OS** | 心脏。**只做三件事：感知、路由、宣告**——它自己不动手 | 第 5 章 |
| **龙脑OS** | 脑。思维模型的库（九十把刀）+ **按“治什么”索引** | 第 6 章 |
| **龙爪OS** | 手。项目容器 + 编排 | 第 7 章 |
| **1 + 5** | 一个总调度 + 五个引擎（象 / 知识 / 五色 / 五象限 / 知行）。**⚠️ 不是“六大模块”** | 第 5 章 |
| **定题四及格** | 真问题的四条：**具体有主语、可判对错、答案会改变下一动作、只属于提问者** | 第 5 章 |
| **认知闭环** | **知 → 创 → 决 → 协 → 行**。**是一圈，不是一条直线**；“协”最易漏 | 第 5 章 |
| **触发四层** | L0 静默 / L1 显式 / L2 特征 / L3 元触发。**管“什么时候该出声”** | 第 5 章 |
| **四护栏** | 打日志、可否决、可降级、可审计。**可审计 > 可解释** | 第 5 章 |
| **三引擎接力** | **定题 → 供刃 → 落地**。三段顺序不可颠倒 | 第 7 章 |
| **取象→择模→定序→验算** | 取刀四拍。**第四拍“验算”是灵魂**——没验过的刀，不知是锋利还是好看 | 第 6 章 |
| **君臣佐使** | 开方配比：**君 1 把、臣最多 3 把、必带一把验证刀** | 第 6 章 |
| **责任楔子** | 一个岗位单元要能回答“这事归谁”。**答不出，它就只是工具** | 第 14 章 |

## 三、运转

| 词 | 确切意思 | 出现在 |
|---|---|---|
| **语义记忆** | 长期事实（纪律、口径、身份）。**永不删** | 第 8 章 |
| **情景记忆** | 过程（做过什么、怎么做的）。**定期归并成主题** | 第 8 章 |
| **工作记忆** | 当下这次的临时信息。**该忘就忘——它是草稿纸** | 第 8 章 |
| **日落条款** | 长期没被引用的操作性说法，**降级归档（不是删除）** | 第 8 章 |
| **只出建议不自动删** | 记忆整理的底线：**机器只能出清单，判断什么值得留必须留给人** | 第 8 章 |
| **上下文腐蚀** | 不是忘了，是**被淹了**。三症状：中间失守、张冠李戴、越答越淡 | 第 9 章 |
| **GSSC 四步** | 收束流水线：只收这次要用的 → 压短但保住骨头 → 散点连线 → **收完回头核一遍** | 第 9 章 |
| **接口（IO）** | 就两句话：**吃进什么、吐出什么**。说形状不说意思、说清交给谁 | 第 10 章 |
| **IO 不发明** | 提不出来就写“# 待补”。**编一个假接口比没有更坏** | 第 10 章 |
| **五道闸** | 只动该动的 / 已有的不覆盖 / 可重复跑 / 先空跑 / 先备份 | 第 10 章 |
| **降维版** | 不砍功能，**改由谁来做**：脚本贴标签、主人写接口。**降维 ≠ 缩小** | 第 14 章 |
| **空壳化** | **载体还在，效力没了**。三种死法：被稀释、被删掉、被架空 | 第 11 章 |
| **载体效力审计** | 27 条硬约定（私有事实 11 / 禁令 7 / 身份 4 / 风格 2 / 判据 3），**及格线 85%** | 第 11 章 |
| **心跳** | 每天定时自动跑，只看“今天有没有少东西” | 第 12 章 |
| **反事实基线** | 验“有没有用”的狠招：**抽掉它，裸模型会怎么答？** | 第 11 章 |
| **指标掉头先查尺子** | 指标掉了有两种可能（真退步 / 尺子坏了），**先查便宜的那个** | 第 12 章 |
| **闸 vs 提醒** | **提醒是给人听的，闸是给人过的**。凡“下次别再犯”的错，要改成闸 | 第 11 章 |
| **指标容器** | 岗位不是权力位置，是**“这一块看什么数”** | 第 14 章 |

## 四、同步与分发

| 词 | 确切意思 | 出现在 |
|---|---|---|
| **六向同步** | 桌面 / 知识库一 / 知识库二 / 云端 / 网站 / 公众号。**前四是“存”，后两是“传”** | 第 15 章 |
| **档案库 ≠ 最新版仓库** | 归档库里**新旧版本会同时活着**。取用前先比版本 | 第 15 章 |
| **标作废而非删除** | 旧的留着并标记——**“它曾经是这样”本身是信息** | 第 15 章 |
| **先本地后云端** | 取阅顺序铁律：先搜免费的全量本地库，**额度留给必须用的** | 第 8、15 章 |
| **锚点** | 一个数（如章号）只能有一个源头；改了它，**所有引用处同步改** | 第 15 章 |
| **先分章后合稿** | **在“看起来成形”之前，别急着让它成形** | 第 15 章 |

## 五、写作与关系

| 词 | 确切意思 | 出现在 |
|---|---|---|
| **关系在场** | 第一原则：**先立关系，再谈事情**。关系不是一个开场白，是一个输入 | 第 4 章 |
| **共生三指标** | **你有改变 / 我有改变 / 双方都认**。缺一不算共生 | 第 4 章 |
| **反依赖** | 主动帮你保住“不靠我也能活”的能力。**防的是判断力退化** | 第 4 章 |
| **他者在场律** | 本书的写作纪律：**每章至少一处“他者在场”，具体到不可替换** | 编制方案 §9 |
| **失败档案** | 不是“它不行的地方”，是**“它会在哪儿翻车”** | 第 13 章 |
| **三态光谱 / 七签名动作** | 写作腔调规范（引导态为主，判定态只用于代价处，思考态只用于概念焊接） | 编制方案 |
