# 陪跑营导师交付红线

这份清单我按「导师在交付现场会实际遇到的场景」来排，不按法条排——因为导师真正需要的是「这句话不能说、这个动作不能做」，而不是读法规。

---

# 导师交付红线清单

**总纲**：你交付的是**陪伴和提问**，不是**解释和答案**。任何让学员觉得「这个人手里有我人生的答案」的表述或动作，都是红线。

## 一、话术红线：这七类话，一句都不能说

1. **不给结果承诺**。不说「做完这一期你就能变」「三个月后你的关系一定会好」。
2. **不做预测**。不预测事业、财运、婚姻、健康、子女，任何形式都不行——包括「我看你这个盘……」这种起手式。
3. **不说命定**。不说「你五行就是这样，改不了」「这是你命中带的」。分型是**描述工具**，不是**宣判**。
4. **不制造恐惧**。不说「不这样做会出问题」「你这个类型最容易出事」。
5. **不假装权威**。不用「大师」「传承」「秘传」「祖传」「独家心法」这类身份包装。
6. **不封闭其他可能**。不说「只有这一条路」「别的都没用」「外面那些都是错的」。
7. **不暗示替代医疗或心理咨询**。不说「这个比吃药管用」「咨询师不懂你这个」。

> 这几条对应的正是监管反复点名的靶心：以传统文化名义引导购买高价课程、把「国学课」讲成「算命课」、用玄学制造恐慌。

## 二、话术替换表：把危险表达翻译成安全表达

现场最容易脱口而出的，恰恰是最危险的说法。这张表建议导师背下来：

| 不要说 | 换成 |
|---|---|
| 我能看出你的命 | 这是我们这套工具看出的一种可能 |
| 照做就能改运 | 这是一个可以试试的角度 |
| 你必须改变 | 你可以选择要不要试一试 |
| 这是你五行决定的 | 这是类型描述，不是定论 |
| 你之所以这样，是因为…… | 你觉得自己更像哪一种？ |
| 我告诉你答案 | 我们一起看看有没有别的解释 |
| 你要相信我 | 你自己感受一下对不对 |

## 三、交付动作红线

1. **不限制人身自由**，不没收手机、不通宵、不封闭带到不可自由离开的场所。
2. **不使用体罚、辱骂、羞辱**作为「破执」「打开」的手段——无论学员是否自愿。
3. **不做极端流程**：断食、超长静坐、感官剥夺一类，一律不碰。
4. **不在现场引导下单**。课程费用在报名前公开、书面告知，交付现场不推销、不加单。
5. **不用隐私做推销**。学员在场上说的内容，不得在事后私下联系中作为说服素材。
6. **不代替专业判断**。涉及医疗、心理、法律、财务的具体问题，明确转介，不越界。

> 这条对应的现实案例是「如是书院」——以国学礼仪为名行暴力管教之实，官方通报同时指认了监管缺位。现场边界一旦松掉，十年招牌也会一夜归零。

## 四、收益结构红线

1. **导师收入只与交付挂钩**：带了几场、学员反馈如何、复盘质量如何。
2. **绝不与「发展了多少新学员」挂钩**。没有推荐奖励、没有下线返利、没有代理层级。
3. **不收入门费、代理费、授权费**。任何需要导师先交钱才能带课的安排，都不要设计。
4. 学员报名费**一次性、公开、写入合同**，不收任何形式的分级升级费。

> 这一条是整份清单最要紧的：**层级放大的形状，即使初衷是传播，也会被认成同一类结构**。区别只在于导师的收入是不是来自拉人头。

## 五、学员筛选与告知

1. **明确不接收**：有精神疾病诊断或正在服药的、处于重大创伤急性期的、未成年人。
2. **报名前书面告知三件事**：这是文化体验与陪伴，不承诺结果；不替代医疗和心理咨询；可随时退出、可随时终止参与。
3. 发现学员状态异常，**立即停止其参与**并建议寻求专业帮助。

## 六、留痕要求

1. 每场营的**议程、签到、关键环节记录、学员反馈表**全部存档。
2. 导师现场使用的话术，**有标准脚本可查**。
3. 存档不只为合规——**它是学员提出异议时，你唯一能拿出来的东西**。交付现场不可复制、不可追溯，这是陪跑营天然的弱点，留痕是唯一的补丁。

---

**给导师的一句话**：在这个领域里，**安全的做法恰恰是最好的做法**——因为一旦你承诺了改变，你就必须为学员的人生负责；而那份责任，任何一套方法论都扛不起。你只承诺陪伴，反而走得远。
