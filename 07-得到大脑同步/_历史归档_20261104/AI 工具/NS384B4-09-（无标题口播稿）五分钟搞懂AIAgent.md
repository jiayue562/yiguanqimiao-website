# （无标题口播稿）五分钟搞懂AI Agent

今天我们就有一个目标，搞懂AI Agent。把笔拿出来，五分钟教会你。

想搞清楚什么是Agent，我们先要搞清楚第一个问题是，AI是怎么干活的？由于这件事情在AI Agent出现之前和出现之后差异非常的大，这个时间节点大概是2025年的中旬。所以我们把时间线拆成为2025年中旬之前和中旬之后。

在中旬之前呢，AI有一个特别形象的比喻，叫做缸中之脑。这什么意思呢？我画一幅图大家就明白了。这是一个水缸，这里面呢养了一个大脑。AI的大脑就是我们之前说过的大模型LLM。这个大模型呢连接了互联网，它学习到了互联网上人类所有的知识。但是你跟他交流只能通过一根网线，你通过这根网线跟他交流的内容只能是文字。因为大模型叫做大语言模型嘛，他最擅长处理的就是文字。所以在2025年中旬之前，很多人认为AI就约等于一个聊天机器人，他是不能操作任何其他软件的。为什么不能呢？因为他没有手没有脚，他没有办法跟任何其他软件进行交互。那这时候那一帮聪明的科学家就非常的着急，想给AI加上眼睛啊，加上手脚。这些手脚就是Agent。

这个时间节点大概在2025年中旬之后，Agent开始广泛使用。Agent广泛使用之后，AI开始有了手和脚，他就可以开始自己干活了。

当AI有了Agent的时候，他是怎么干活的呢？我来举个生活中的常见的例子，你就很容易理解了。假设你今天早晨刚刚开了一个会，你有一个会议录音，你希望把这个会议录音整理成一个总结，假设这个总结是一个Word文档吧，然后你需要把这个文档发送到你的邮箱。从这个录音到发到邮箱中间可能会有几步呢？可能第一步你拿到这个录音之后，你可能会去把它转成文字，然后再把它发给AI让他AI给你总结。总结完了之后再打开你的Word，把AI给你的总结复制粘贴到Word里面，然后保存成一个总结文档，然后你再打开你的邮件客户端给他发出去。这应该是大多数人的工作方式。那这就是一个你设计好的工作流程，也叫Workflow。这个工作流程你自己去做或者是你设计好之后交给AI去做都是可以的。那这个Workflow其实就是Agent的小时候的样子。你会发现，在这个Workflow里面有一个重大的缺点。如果是一个稍微复杂一些的流程，比如说中间有十个二十个环节，那么你设计这个工作流程所花费的精力远远超过AI执行帮你节省的时间，完全不划算。因此他的缺点就是设计成本太高。

那到了Agent这个问题就被很好的解决了。我们看看Agent是怎么做的呢？还是一样的，你有一个会议录音，你最后希望他给你发送一封邮件。AI Agent的整个工作流程由AI自己设计。因为AI的大脑非常的强大，他完全可以通 过Agent来自己设计流程了。你把录音给他，他第一就会想，我通过什么方式把他转成文字呢？你是不是还没给我邮件地址呀？没给我肯定要去问一问。如果给了的话我就直接发送。我是不是还要去打开我的Word文档去创建这一份总结呢？我是不是还要做一下排版？整个识别过程中是不是还有错别字，我需要一并修改一下呢？整个思考过程和处理的流程完全由AI自己设计。整个Agent工作的过程是一个黑箱。黑箱的意思就是说由AI Agent自己去思考完成这个工作的过程和需要的步骤。人类没有办法知道他具体发生了什么。你只知道你过了一会儿收到了一份会议总结报告。你就可以理解成你开完会之后把这个会议录音交给了你们办公室一个同事，过了一会儿那个同事给你发了一封会议总结的邮件。至于这个同事是怎么做到这一点的，你不用管他。现在你的这个同事就是AI Agent。

甚至更进一步，你连这个会议录音都不用给他，Agent会自己去拿。Agent怎么拿到这个录音呢？这里我们就要引入另外一个概念，工具。AI有手有脚之后他还需要工具，这些工具的名字就叫做MCP和CLI。MCP和CLI具体是什么，你完全不需要管他，这是那帮天才科学家们去管的事情，我们完全不用管他。你只需要知道Agent需要使用这些工具就可以了。为了方便你理解呢，我们把AI比作一个人。假设AI等于人的话，大模型就是他的大脑，Agent就是他的手脚。那刚说的MCP和CLI是他的工具。这时候你就理解了Agent有多么的重要，他是一个承上启下的关系。如果没有Agent，那AI就是一个植物人。

你最近听到的非常火的OpenClaw小龙虾，以及被很多人认为2026年必学的一个Agent CodeX，还有他的一个竞争对手叫Cloud Code，这些都是属于Agent。

好，总结一下，什么是Agent？Agent就是AI的手和脚。如果AI没有手脚就像一个植物人，他只能和你聊天。有了手脚之后AI就可以帮你干活了。另外他还需要一些工具，工具是MCP和CLI。AI Agent是怎么工作的呢？他是由AI自己设计了整个工作流程。你只需要告诉他工作从哪出发，工作的目标和结果是什么，他自己设计这些流程。这个流程是一个黑箱，只有AI自己知道，人类并不清楚这中间具体发生了什么。如果把AI比作一个人的话，那大模型就是他的大脑，Agent就是他的手脚。他用手脚操作工具来帮你干活，工具就是MCP加CLI。那目前最火的Agent OpenClaw、CodeX和Cloud Code。

好，接下来是截屏时间。恭喜你，你已经知道了什么是AI Agent。那么现在最火的CodeX、Cloud Code和OpenClaw你应该去学一个呢？他们又有什么区别呢？他们能为你做什么呢？下期视频我来告诉你。
