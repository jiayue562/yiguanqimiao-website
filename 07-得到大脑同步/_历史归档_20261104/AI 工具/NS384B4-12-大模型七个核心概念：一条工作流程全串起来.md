# 大模型七个核心概念：一条工作流程全串起来

更新一下你对 AI 模型的认知。七个概念——Token、分词器、注意力机制、稀疏模型、稠密模型、自回归、扩散——不是孤立的名词，它们正好对应大模型从接收到输出的完整工作流程。

---

## 完整流程总览

当你给大模型发一段提示词，它会经历这几步：

```
提示词 → 分词器（拆成Token）→ 注意力机制（找重点）→ 稀疏/稠密（决定激活哪些参数）→ 自回归/扩散（生成答案）→ 输出
```

下面逐个拆开说。

---

## 1. Token：模型处理信息的最小单元

**定义**：Token 就是模型处理信息的最小基本单元。

以文字大模型为例，一个 Token 可能是：
- 一个汉字
- 几个汉字组成的词
- 一个标点
- 几个数字

**工作过程**：你发一段提示词 → 大模型先用分词器拆碎 → 每个碎片对应一个 Token → 模型运算这些 Token → 一个 Token 一个 Token 地猜出答案 → 拼起来就是完整输出。

一句话：**大模型不是"读"文字，是"拆"成 Token 再"拼"回去。**

---

## 2. 分词器：把文字拆成 Token 的工具

分词器（Tokenizer）就是执行上面"拆碎"动作的东西。它负责把人类的自然语言，切成模型能理解的 Token 序列。

不同模型的分词规则不一样，同一个词在不同模型里可能被拆成不同数量的 Token——这也是为什么同样长度的文字，不同模型消耗的 Token 数不一样。

---

## 3. 注意力机制：模型知道该盯着什么

哪怕你只说一句话——"给我讲个笑话"——里面也有重点。重点是"笑话"，不是"给我"。

**注意力机制**（或者叫注意力分配机制）就是干这件事的：帮大模型决定哪些词需要格外注意，哪些词不用倾注那么多注意力。

提示词越短，注意力机制的作用越不明显；但任务越复杂、提示词越长，注意力机制就越关键——它能让大模型聚焦真正重要的内容，而不被无关信息带偏。

一句话：**注意力机制就是大模型的"专注力"。**

---

## 4. 稀疏模型 vs 稠密模型：参数怎么激活

用人类大脑做类比：人脑有 800-1000 亿个神经元，但你说话、运动、读书、工作的时候，不是全部神经元都激活——需要用到哪儿就激活哪儿。

为什么这样设计？**节能**。全部激活能耗太大，身体扛不住。

大模型也是一样的道理：

| 类型 | 做法 | 类比 |
|---|---|---|
| **稠密模型** | 做任务时激活全部参数 | 大脑所有神经元同时工作 |
| **稀疏模型** | 只激活对应任务需要的那部分参数 | 大脑按需激活特定区域 |

现在大模型的主流是稀疏模型，主要原因就是节能——几万亿个参数全激活一次，成本高得离谱。

一句话：**稀疏模型是"专家会诊"，稠密模型是"全员上阵"。**

---

## 5. 自回归模式：一个一个猜

大模型产出答案，是一个 Token 一个 Token 猜出来的。

**自回归模式**的逻辑：
1. 猜出第一个 Token
2. 把第一个 Token 加回到上下文里
3. 基于（原文 + 第一个 Token）猜第二个 Token
4. 把第二个 Token 再加回去
5. 猜第三个……
6. 循环往复，直到全部猜完

优点：准确度高，因为每一步都基于前面所有的信息。
缺点：慢，必须一个接一个，不能并行。

一句话：**自回归就是"走一步看一步，步步为营"。**

---

## 6. 扩散模式：一起猜，再拼起来

自回归一个一个猜太慢了——有没有办法一次性多猜几个？

有，这就是**扩散模式**（也叫并行生成）：
1. 把大任务拆成好几个小任务
2. 每个小任务对应一小段答案
3. 大模型同时猜好几个小任务的 Token
4. 猜完之后拼接到一起，就是完整答案

优点：快，可以并行生成。
缺点：拼接处可能出现逻辑断层，准确度略低于自回归。

（注：视频里叫"发散模式"，行业内更常见的说法是"扩散模型"或"并行生成"，本质都是"非自回归"的思路。）

一句话：**扩散就是"分头干活，最后拼图"。**

---

## 七步总结，一张表收束

| 步骤 | 概念 | 干什么 |
|---|---|---|
| 第一步 | 分词器 | 把提示词拆成 Token |
| 第二步 | Token | 模型处理的最小单元 |
| 第三步 | 注意力机制 | 决定重点关注哪些内容 |
| 第四步 | 稀疏/稠密模型 | 决定激活哪些参数来干活 |
| 第五步 | 自回归/扩散 | 决定用什么方式生成答案 |
| 第六步 | —— | 一个 Token 一个 Token 产出结果 |
| 第七步 | —— | 拼成完整答案输出给你 |

一句话记住整个流程：
> **拆成碎片 → 找到重点 → 唤醒专家 → 逐词/并行生成 → 拼出答案**
