# 天人合一与万物一体：中国哲学一体性思维的核心特质

### 🏛️ 这篇文章核心在讲什么？

文章提出**一体性思维**是中国哲学的基本思维模型，与西方主客二分思维有根本差异。
- **作者出处**：李春颖，中国政法大学国际儒学院教授，原文载《中国哲学史》2026年第1期，本文转自《社会科学文摘》2026年第8期。
- **核心命题**：天人合一与万物一体 → 标识中国哲学**一体性思维** → 主客关系形态与西方哲学差异极大。
- **研究意义**：挖掘中国哲学基本思维模型，揭示其整体性、生成性、实践性特质，标识中华文明独特话语体系与价值立场。

### ⚖️ 西方主客二分思维是怎么来的，有什么问题？

主客二分是西方近现代哲学的**基本思维模型**，至今仍影响深远但难以根本超越。
- **起源脉络**：
  - **古希腊源头**：柏拉图理念论、亚里士多德形而上学 → 设立可感世界/可知世界二元结构 → 为主客关系奠定基础，但核心是探讨本体问题，并非直接的主客关系。
  - **笛卡尔确立**：建立以主体为中心、主客二分的认识论体系 → 西方哲学**认识论转向** → 哲学从追问世界本质转向主体如何获得对客体的确证知识。
- **基本模型**：主体—客体—主体如何认识客体并获得确证知识。
- **现实影响**：笼罩自然科学领域，推动了科学和技术的长足发展。
- **理论困境**：
  - 主体无法真正认识独立于自身之外的客观世界（物自体），无法确证经验知识的正确性。
  - 现代、后现代哲学各流派都在批判、超越主客二分，但底层思维仍接受主客二分预设，难以从根本上消除。
  - 代表路径：康德先天综合判断、胡塞尔意向性、德里达解构、福柯知识考古学。

### 🌌 中国哲学的一体性思维是什么样的？

天人合一是**具有中国文化特质**的一体性思维，核心是人与世界本来为一。
- **历史演变**：
  - 先秦：天人一体、万物与我为一、天道人事相贯通 → 各家共用的思想基础。
  - 汉代：董仲舒**天人感应**说。
  - 宋明：万物一体追求贯穿整个理学；张载在《正蒙·乾称》中**首次明确提出"天人合一"表述**；另有"民胞物与""一体言仁""以天地万物为一体"等多种表达。
- **核心特质**：
  - 不是分立的主客双方交融合一，而是**人与世界本来为一**，人从来不是孤立的。
  - 不是认识论意义上主体对客体的认识，而是对世界整体的理解。
  - 不是抽象理念，而是从根源上将天地万物视为息息相通的整体。
  说白了，人和世界不是先分开再想办法合到一起，而是打一开始就是一个整体里的部分。
- **思想形态层次**：
  - 宇宙生成论层面：气论、《周易》系统（最基本的理论形态和思想根源）。
  - 身体层面：天人感应、气质之性。
  - 德性层面：尽心知性知天、天命之谓性、性即理、心即理。
  - 延伸领域：政治设计、社会礼俗、音乐艺术、中医五运六气、命理天干地支。
- **《周易》与气论**：
  - 《易传》"易有太极，是生两仪" → 阴阳交感为宇宙生成演化基本模型 → 天地运行、万物生长、人世变迁共享同一模型。
  - 广义气论（阴阳二气、五行、天地之气、天下一气）→ 万物是气的不同状态，相通相感 → 构成连续的同质系统。
  - 例子：《礼记·月令》中历法、星象、动植物生息、人类饮食礼俗政治祭祀农事本为一体，息息相通。

### 🤝 一体性思维里的主体和主客关系是什么样的？

主体在**一体中定位自身**，主客鸿沟从根源上被消弭。
- **近代以来的误读**：西方近代科学主义视角下，人与自然分立为二，人是主体，自然是被认识改造的客体，底层逻辑即主客二分。
- **新儒家的局限**：唐君毅、牟宗三等新儒家从德性主体、道德形而上学层面阐发中国哲学主体问题 → 将儒学划界为道德哲学或宗教 → 但儒学是整全的思想体系，并非只有道德教化一个面向。
- **主体与一体的关系模型**：
  - 西方主客关系：主体 vs 自我之外的他者（客体）→ 两个独立存在者。
  - 中国一体关系：主体本性源自天 → 主体实现自身本性 = 体认天 → 主体追求是通过一体而实现自身。
- **具体表现**：
  - 朱子《孟子集注》以五行论证五常 → 不是类比，而是根本上视为**同一个系统**。
  - 五行、五常、五伦、五音、五脏 → 都源自同一个关联宇宙系统。
  - 天地万物是连续性的同质系统，主体在一体中生长变化，与万物息息相通。
- **修养与价值实现**：
  - 主体与万物的区分隔阂是**暂时的**，本然为一。
  - 主体通过格物致知、正心诚意等功夫提升 → 体认自我与万物一体。
  - 主体价值实现 = 参与天地整体运行，而非单纯认知真理。
- **超越性问题**：
  - 生命意义不需要超感性存在者赋予，就在当下现实生活中展现。
  - 主体是有限的也是无限的：个体生命有限，但作为天地整体的一部分，与天地共同具有超越性。
  - 无限与超越 = 突破个体有限性，体认万物一体，主动投入无限的宇宙流行。

### 📌 补充细节
- **一体性思维非儒家独有**：天人合一、天人同构、万物一体是先秦各家共享的思想基础，并非儒家专利。
- **与西方一体性思想的区别**：西方也有一体性思维（如舍勒"宇宙同一感"、叔本华"生命之形而上学的统一性"），但天人合一具有鲜明的中国文化特质。
- **关于"象思维"**：原文未直接提及"象思维"概念。一体性思维以阴阳交感、气论、五行关联为核心，侧重宇宙整体的生成性与关联性；象思维则以取象比类为核心方法，二者同属中国传统思维体系，均有别于西方概念化、对象化的思维方式，但本文未展开二者关系的讨论。
