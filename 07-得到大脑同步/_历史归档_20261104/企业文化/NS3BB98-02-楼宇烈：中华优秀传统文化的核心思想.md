# 楼宇烈：中华优秀传统文化的核心思想

### 🏛️ 这篇文章的作者和背景是什么？

作者是**楼宇烈**，原文刊发于《人民教育》**2020年第15-16期合刊**。
- **作者身份**：北京大学哲学系（宗教学系）教授、博士生导师，北京大学宗教文化研究院原名誉院长，当代重要中国哲学史家。
- **获得奖项**：2018年第三届全球华人国学传播奖「公共建设力奖」、2019年第二届中华文化玄奘奖「学术成就奖」、2020年第六届「会林文化奖」。
- **文章性质**：为《中华优秀传统文化教育读本》所作的序言，阐释「仁爱、民本、诚信、正义、和合、大同」六大思想精髓。

### 🌍 为什么说这六个思想有当代价值？

这六个理念**对应现代人类的四大危机**，比西方商业文化更具普世性。
- **人类面临的危机**：生态危机 + 道德危机 + 不可持续危机 + 人类异化危机。
- **西方文化局限**：主流围绕**资本利益**，只为资本利益集团服务，对普通民众利益只是敷衍，工具性强。
- **中国文化三大特性**：
  - **天下性**：从人类、世界、宇宙的全局思考问题，不局限于自身、国家。
  - **道德性**：道德贯穿政治、法律、经济、教育、军事各领域。
  - **社会主义性**：以民本、仁爱、大同为核心，「以人民为中心」，追求均平与天下为公。

### ❤️ 仁爱思想的核心和实现路径是什么？

仁爱的核心是**人与人相感**，根本方法是「己所不欲，勿施于人」。
- **核心内涵**：你敬我一尺，我敬你一丈；君以礼待臣，臣以忠事君；也包含「以直报怨」。
- **实现路径**：从**孝悌**开始 → 推及夫妻为义、朋友为信、君臣为忠 → 形成五伦 → 构建礼制。
- 说白了，仁爱是从身边最亲的人做起，一层层往外推，最后让天下像一家人。

### 👥 民本思想具体指什么？

民本就是**以百姓利益为根本**，对应今天的「以人民为中心」。
- **实现途径（仁政王道）**：制民恒产 + 薄赋轻税 + 量入为出 + 打击豪强 + 盐铁专卖 + 节制私人资本 + 选贤与能 + 讲信修睦。
- **目标状态**：老有所安、壮有所用、少有所怀、女有所归，鳏寡孤独废疾者皆有所养。
- **对民众的要求**：财富要**取之以道**，不能靠投机、赌博、贩毒、污染环境发财，反对只讲GDP不讲道德。

### 🤝 诚信和西方契约精神有什么不一样？

中国诚信**有道德内核**，不是无条件遵守形式契约。
- **诚信内涵**：至诚之心，言行一致，不口是心非，努力践行人生信条。
- **与西方契约的区别**：
  - 西方契约 = 形式上不违约，哪怕契约不公平、是武力强迫的也要遵守。
  - 中国诚信 = 唯「义之所在」才言必行行必果，不合道义的契约不必遵守。
- **典型例子**：新中国成立后废除西方列强强加的不平等条约，是对人民的诚信，对列强的违约。

### ⚖️ 正义思想的本义是什么？

正义 = **沿着礼义之路不偏不斜地走**，为道义而行。
- **字源解析**：
  - 「正」：会意字，原指前往某地，引申为平正、正直、公正。
  - 「义（義）」：会意字，从羊从我，原指礼仪，后指礼义。
- **最早出处**：《荀子·正名》「正利而为谓之事，正义而为谓之行」，即为道义去做才叫德行。
- **教化原则**：陈义**不能太高**，要以大众普遍性为原则，否则容易弄虚作假。
  - 佛家讲因果报应、儒家讲「积善之家必有余庆」，都是以利导善、义利合一，效果比只讲义不言利更好。

### 🔄 和合思想是一种怎样的思维方式？

和合是**整体兼容的思维**，强调天人合一、体用不二。
- **核心观点**：天人相合相感、心外无物、体用不离，其大无外其小无内，事事无碍。
- **与西方思维的对比**：
  | 维度 | 中国和合思维 | 西方分析思维 |
  | :--- | :--- | :--- |
  | 心物关系 | 心物一体 | 心物分离 |
  | 人文立场 | 上薄拜神教，下防拜物教 | 宗教与科学二分 |
  | 制度性质 | 道德与制度合一 | 法律经济政治是理性工具 |
  | 人际/天人关系 | 相互依赖、同舟共济 | 你死我活的博弈斗争 |
- **现实意义**：斗争性要在和谐性之下，核武器杀伤力已超出人类承受力，核战争会导致人类毁灭。

### 🌐 大同理想是什么？

大同是**人类社会的终极理想**，是前五个价值的推扩。
- **核心图景**：人类像一家人，老吾老以及人之老，幼吾幼以及人之幼，四海之内皆兄弟。
- **当代对应**：就是习近平总书记提出的**人类命运共同体**，实现天下太平、人与自然和谐、人与人和谐。
- **文化使命**：中华优秀传统文化复兴的使命，就是为全球化背景下的人类提供「平天下」的价值支撑。

### 📌 补充细节
- 六大思想的官方表述为「讲仁爱、重民本、守诚信、崇正义、尚和合、求大同」，是习近平总书记对中华优秀传统文化精神的总结。
- 文章认为这六个理念不仅是中华优秀传统文化的核心思想，也是**人类的核心价值观**，具有普遍意义。
- 经济领域的道德性体现为：黜奢崇俭、贵义贱利、不伤害三农。
- 军事领域的道德性体现为：出师有名、以防御为主、不首先侵略他国。
