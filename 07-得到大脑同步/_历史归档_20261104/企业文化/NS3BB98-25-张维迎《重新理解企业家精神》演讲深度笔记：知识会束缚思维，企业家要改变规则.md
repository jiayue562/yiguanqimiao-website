# 张维迎《重新理解企业家精神》演讲深度笔记：知识会束缚思维，企业家要改变规则

### 📚 这场分享核心想讲什么？

主流经济学**排除了企业家**，知识反而会**束缚人的思维**，真正的企业家精神是改变约束条件、靠想象力创造未来。

### 🧠 为什么说知识不一定带来进步？

**知识会形成思维范式**，反而可能把人框在错误认知里。
- **零和博弈误区**：普通人把财富当成固定蛋糕 → 认为别人富就是抢了自己的 → 影响政策走向，中外都存在。
- **新古典经济学的问题**：假设市场永远均衡、所有人同等理性 → 从理论上排除了企业家存在的可能 → 按这套逻辑，地上的真钞票早就被捡走了，根本不用弯腰。
- **学经济反而难成企业家**：统计了北大企业家俱乐部49位理事、胡润财富榜前500、中国新经济500强的企业家，学经济学出身的比例**不成比例地低**。
  说白了，经济学教你算来算去觉得啥钱都赚不到，反倒不敢创业了。

### ⚖️ 主流经济学怎么误导了反垄断政策？

**把"做得好"等同于"垄断"**，完全忽略产品是企业家创造出来的。
- **垄断原意的演变**：300多年前英文里的垄断 = 政府授予的特权（比如1600年英国女王给东印度公司的东方贸易专营权）→ 后来经济学把企业做大做强也定义成垄断。
- **边际成本定价的荒谬**：按新古典理论，微软软件卖几百美元就是垄断，因为边际成本只有一两美分 → 但这套逻辑默认产品本来就存在，完全没考虑研发成本和企业家的创造。
  - 如果所有产品都按边际成本定价，我们现在还停留在300年前，不会有任何新产品。

### 📊 现实里的大企业真的能高枕无忧吗？

**市场份额再大也挡不住新的竞争者**，所谓"垄断地位"根本不稳固。
- **阿里巴巴电商份额变化**：2013年 **92%** → 2017年 **61.2%** → 2022年 **42.7%**，一直在下降。
- **拼多多的崛起**：2017年电商份额仅 **1.8%** → 2022年达到 **15.5%**，短短5年从无足轻重冲到第二梯队。
- **手机行业的颠覆**：2010年诺基亚占全球智能手机份额 **39.7%**，是绝对老大 → 2020年已基本退出主流；2010年刚成立的小米，10年后出货量做到**世界第三**。
- **Google的焦虑**：搜索市场一家独大，ChatGPT出来后依然紧张 → 因为企业家精神就是不服气，总有人想超越你。

### 🎯 企业家决策和管理决策有什么不一样？

**管理是在给定条件下求解，企业家是改变约束条件本身**。
- **决策占比**：一个企业里 **95%以上是管理决策**，不到5%是企业家决策。
  - 管理决策可以授权给别人，甚至能用AI、ChatGPT完成；企业家决策只能由企业家自己做。
- **核心差异**：
  | 维度 | 管理决策 | 企业家决策 |
  | :--- | :--- | :--- |
  | 目标 | 实现给定目标 | 创造新目标 |
  | 方式 | 在约束内优化 | 突破、改变约束 |
  | 可替代性 | 可授权、可自动化 | 只能本人做 |
- **接班人困境**：老板喜欢的听话员工，往往**没有企业家精神**；真正有企业家精神的人，可能早早就自己出去创业了。
- **大企业的宿命**：企业做大后必然引入职业经理人 → 职业化管理本质上和企业家精神对立 → 大企业创新能力下降，给了新企业颠覆的机会（柯达、索尼、诺基亚都是如此）。

### 💡 企业家最核心的能力是什么？

**想象力是企业家最重要的能力**，未来不是不确定，而是"未定性"。
- **未定性 vs 不确定性**：
  - 不确定性 = 未来已经定了，只是我们不知道（比如地下有没有煤、明天下不下雨）→ 人只能被动适应、猜对错。
  - 未定性 = 未来**可以被我们的行动改变**，依赖于我们怎么想、怎么做 → 这才是企业家存在的意义。
- **想象力的定义**：能看到**不存在的东西**，别人看不到你能看到 → 比如把马车和发动机组合成汽车，比如乔布斯相信不用键盘的手机能做出来。
- **哥伦布立鸡蛋**：第一个想出磕破鸡蛋立起来的，是企业家精神；别人学会之后再做，就只是管理问题了。

### 🏛️ 为什么不能用多数投票做企业家决策？

**企业家判断经常是少数派正确**，多数人认同的事反而很平庸。
- **云计算之争**：2010年深圳IT峰会，马化腾、李彦宏都不看好云计算，只有马云看好 → 二比一的投票，最后少数派是对的。
- **理念冲突 ≠ 利益冲突**：企业里很多分歧不是谁想占便宜，而是对未来的想象不一样 → 比如刘氏四兄弟1984年一起创业，母亲去世不到一年就分家，四个人后来各自都做得很成功。
- **产权自由的意义**：企业家精神要发挥，必须允许多样化，不能按统一标准、少数服从多数来定方向。

### 📖 这本书是写给谁看的？

写给**所有能读书的人**，尤其是四类群体：
- **经济学家**：需要范式转变，否则错误的理论会成为不当政策干预的依据。
- **普通人**：摆脱道听途说的错误观念，比如零和博弈思维。
- **政府官员**：很多干预政策的理论基础，恰恰来自号称研究市场的经济学。
- **企业家**：不要迷信"科学决策"，不要因为多数人反对就怀疑自己 → 所有人都说对的事，一定是平庸的事，不是企业家该做的。

### 📝 补充细节
- 演讲时间：**2023年4月21日**，地点是第七届中国企业领袖读享盛典"重振企业家精神"读书分享会，主办方为总裁读书会。
- 引用名言：英国作家乔治·奥威尔——"一些理念是如此愚蠢，以至于只有某些知识分子可能相信它，因为没有任何一个普通人会愚蠢到相信这些理念。"
- 作者研究时长：张维迎研究企业家**将近40年**，本人没有企业工作经历。
