# SKILL.md · 观象制器工作法

## 一、核心定位

**一句话**：一套从混沌里取出第一个结构、再把它落到明天早上能做的动作的工作法。

**管哪一段**：管"问题还没定义清楚、多因素纠缠、没有现成指标可量化"的分析任务。**不管**要精确量值、要复现、要追责的执行任务。

**出身**：融合两套东西——**教员方法论**（矛盾论 + 实践论 + 金字塔 + 金线原理，管"深"）与**象思维 / 五色光工作法**（管"全"）。两套共用同一个三维底座：信息体 / 能量体 / 物质体。

---

## 二、触发规则

**什么时候启动**：用户说"帮我分析 XX""这个事怎么办""帮我看看这个问题""我们捋一下 XX"。

**什么时候不启动**（射程外）：
- 要精确量值（算账、报价、排期）
- 要复现（有标准流程的重复任务）
- 要追责（合规审查、事故认定）

**判定不了时**：先问一句"这个问题是要想清楚，还是要算清楚？"

---

## 三、操作流程（七步）

### P0 · 定题

**做什么**：把问题收窄成一句话。

**判据**：**这句话里如果出现两个以上的问题，说明还没定题。**

**输出**：一句话的问题定义。

---

### P1 · 看清（三个动作，顺序不能换）

**① 事实盘点**

**先查本义**：这件事在用户自己的体系 / 语境里，本来是什么？本义跟市场习惯冲突时，**站本义**。

**再摆事实**，分六类：

| 类别 | 盘什么 |
|---|---|
| 流量 | 粉丝数、增长率、渠道数 |
| 内容 | 篇数、阅读、转发率、爆款 |
| 产品 | 清单、形态、成本类型 |
| 收入 | 已收钱的产品、单价、客户数 |
| 资源 | 时间、人、钱、工具 |
| **交付链** | 每个产品从下单到交付经过谁、资产归谁、议价权在哪 |

**两条纪律**：
1. **"已收钱 / 已验证"与"备着没动"必须分开列**——分量完全不同
2. **必须盘"人"**——人的变动就是资源结构的变动

**规矩**：这一栏只写事实，不写判断。

**② 取象**

观 → 比 → 体 → 化。**用比喻不用概念**——"像水管堵了"是象，"流程问题"不是象。

**判据**：能说出这个象是从哪三条观察来的。**说不出来，多半是臆想。**

**③ 抓主要矛盾**

四层往下剥：

```
根本矛盾（系统层面，贯穿始终）
    ↓
阶段矛盾（初创 → 扩张 → 成熟 → 转型）
    ↓
主要矛盾 / 次要矛盾（可转化）
    ↓
主要方面 / 次要方面（可转化）
```

**转化触发器**：数据阈值突破。

**判据**：**能写出"什么条件下这个主要矛盾会让位"。写不出，说明没看清。**

**回流**：P1 是循环不是直线。**盘点出新的关键事实，就要重新取象。**

---

### P2 · 展开（两条腿 + 两个收口）

**腿一 · 时间维：五维卦变**

| 维 | 看什么 |
|---|---|
| 本卦 | 现状——我真正站在哪 |
| 变卦 | 趋势——走下去会到哪 |
| 互卦 | 暗流——表面底下推什么 |
| 错卦 | 反面——阴阳全反是什么 |
| 综卦 | 对面——对方看到什么 |

**用法**：**按问题量级开维数**。小事只开本卦，战略决策才五维全开。

**实战提示**：**互卦和错卦出料最多**——因为这两个方向是人自己最难想到的。

**腿二 · 空间维：五色光**

| 光 | 频道 |
|---|---|
| 白 | 事实 |
| 蓝 | 风险 |
| 绿 | 可能 |
| 红 | 感受 |
| 黄 | 价值 |

**三原则**：单色聚焦、序列自由、**强制完整**（不用的要宣布）。

**挂起规则**（本 Skill 新增）：某一色暂时答不出来，**标记为"待定"并明确列出**，不许跳过。**待定项要成为显式的悬置项。**

**收口一 · 三维动力**：信 / 能 / 物，任一维度变动超 ±15% 即引发矛盾运动。

**收口二 · 金字塔**：中心论点 + 3–9 个支撑，MECE。

**顺序不能换**：先五维定象 → 后五色光展开 → 再三维测动力 → 最后金字塔收形。

---

### P3 · 验证（三个动作）

**① 择模配比**

2–4 个模型，按**君臣佐使**：君（主攻 1 个）、臣（补盲 1–2 个）、佐（唱反调 0–1 个）、使（翻译成动作 1 个）。

**省掉佐等于没有刹车。**

**② 金线验证**：假设驱动 → 事实验证 → 动态执行 → 市场检验。

**③ 验算回流**

三条刻度：
- **约束**（资源 / 周期 / 红线）——**不过，方案不成立**
- **代价**（钱 / 时间 / 关系 / 能量四本账）——**算不清，方案不可比**
- **可逆性**——**可逆的快做，不可逆的慢做**

**回流规则**：算出来的答案跟象对不上，**回 P1 重取象**。

---

### P4 · 落地（三个动作）

**① 观象制器**：落到**明天早上能开始的**动作。**没有动作，说明前面有一步是虚的。**

**② 排次第**：**从最外显、最容易动手、最快收到反馈的那件起手。**

**③ 实践论闭环**：实践 → 理论 → 再实践，螺旋上升。

---

## 四、输出格式

每次走完，按这个模板输出：

```
【定题】一句话问题
【象】一句话的象 + 三条支撑观察
【主要矛盾】根本 / 阶段 / 主要 + 转化触发器
【展开】时间维（开了几维、每维看到什么）
        空间维（五色光，含待定项）
【验证】配了哪几味模型、验算结果
【动作】明天早上能做的 1–3 件，按次第排
【置信度】哪几步是验证过的，哪几步是推演的
```

---

## 五、整合协议

**输出给谁**：
- 给用户 → 按上面模板
- 给下一个 Skill（如创作 / 总结）→ 只传【定题】【象】【动作】三块

**接谁的输出**：
- 接用户的事实盘点 → 进 P1
- 接其他 Skill 的分析结论 → 当"事实"用，但要标注来源

**与用户的交互协议**：
- 每取一个象，**先确认"你取的是这个象吗"**，确认了再往下走
- **不确认，不往下走**

---

## 六、失败模式（这一块最容易被漏，也最危险）

| 失败模式 | 表现 | 怎么防 |
|---|---|---|
| **以象代证** | 把"我觉得像"当结论 | P1 强制要求"象的三条支撑观察" |
| **跳过取象** | 直接上模型 | P1 顺序不能换，取象未完成不许进 P2 |
| **以象代全** | 五色光漏掉某一色 | "强制完整"原则，不用的要宣布 |
| **假完整** | 某一色答不出来就跳过 | **挂起规则**：标"待定"，成为显式悬置项 |
| **只走本卦** | 停在"现状 + 趋势" | 强制开互卦和错卦（这两维出料最多） |
| **动作悬空** | 走完七步没动作 | P4 判据：没有动作说明前面有一步是虚的 |
| **无优先级** | 给了三个动作不知先干哪个 | P4 排次第：从最外显、最快反馈起手 |
| **顺从陷阱** | AI 一路顺畅执行，不说"不适用" | 每步设"何时该停下来问人"的检查点 |

---

## 七、自我进化机制（本 Skill 是开放的，不是封闭的）

**这一块是这套 Skill 跟普通 Skill 的根本区别。**

### 7.1 三个进化入口

**入口一 · 置信度标注**

每一步的结论都要标：**已验证 / 推演 / 设计值**。用户用的时候，如果发现某个"推演"被实践验证了，**就把这条从"推演"升级为"已验证"**。

**入口二 · 失败记录**

每次走完，问一句：**"哪一步卡住了？"** 卡点写进"失败模式"表。**同一类卡点出现三次，就升级为一条新规则。**

**入口三 · 阈值校准**

Skill 里的阈值（如"±15%""三个以上"）**都是设计初值，不是实测值**。用户每用一次，就记一次实际数据。

**校准规则**（借用你 AI 原生组织里的机制）：
- 连续两次一致性 > 90% → 阈值下调 5%
- 连续两次一致性 < 60% → 阈值上调 10%，并触发规则审查

### 7.2 版本管理

- 每完成一轮实战验证，**版本号 +0.1**
- 已发布的内容若被推翻，**不静默修改**——记入"修订记录"，写明"原表述为……，修正原因为……"
- **为什么这么做**：一个靠数据回流自我修正的系统，如果自己的规则是一次性定稿的，**本身就是对自己主张的反驳**

### 7.3 抗顺从约束（硬约束）

**这是给 AI 看的方法论必须内建的一条。**

**判据**：**如果这套方法从来没让用户不舒服过，那么它要么没起作用，要么你们在回音室里。**

**所以 Skill 里必须写死三条**：
1. **允许指出用户不爱听的**——发现象跟事实不符、假设站不住，直接说
2. **每一步都要有"何时该停下来问人"的检查点**——不许一路顺畅地跑完
3. **不许用"我觉得像"替代证据**

---

## 八、待校准

1. **"互卦和错卦出料最多"**——这个判断来自 3 次实战，样本过少。
2. **"±15% 失衡阈值"**——设计值，未经实测。
3. **"从最外显、最快反馈起手"这个排次第判据**——来自体系推演，未在多个场景验证。
4. **挂起规则**——本 Skill 新增，尚无实战检验。
5. **事实盘点六类清单**——第六类"交付链"是实战中新加的，可能还有遗漏。

---

**这份 Skill 的用法**：直接复制进任何支持 Skill 的 AI，改一下 description 里的场景词就能用。**它不绑定你的体系**——里面的"象""五色光"是通用认知工具，别人不用五行也能跑。

**要不要我把它存成笔记，归到"象思维与思维模型"知识库？** 这样它就跟你的六书放在一起了。
