# 麦肯锡深度解读：AI把分析提速20倍，为什么决策反而变慢了？

### ⏱️ 这篇文章核心在说什么问题？

AI让分析**大幅提速**，但人的判断力成了新瓶颈，决策整体速度反而可能变慢。
- **发布信息**：2026年10月15日，麦肯锡季刊（McKinsey Quarterly）发布《The judgment bottleneck: Balancing AI and human speeds in strategy》。
- **核心概念**：**判断力瓶颈（judgment bottleneck）** = 分析按AI速度运行，判断仍按人的速度推进，两者错位形成的流程堵点。
- **核心观点**：AI投资能否改善战略决策，取决于企业如何重新安排**分析、判断与执行**的分工。

### 🔄 战略决策流程里，哪部分快了哪部分慢了？

前两个环节AI大幅加速，后三个环节仍受**人的节奏**约束。

| 决策环节 | 主导速度 | 核心任务 |
| :--- | :--- | :--- |
| 扫描与感知 | AI加速 | 捕捉趋势、机会与威胁 |
| 分析与建模 | AI加速 | 建模、推演、情景模拟 |
| 解释与判断 | 人类主导 | 验证证据、检验假设 |
| 决策并负责 | 人类主导 | 拍板取舍、承担责任 |
| 对齐与执行 | 人类主导 | 形成共识、调动资源 |
- **真实案例**：某企业战略团队财务分析从**5周**缩短到**不到2天**，但高管审阅时间反而变长，因为看不清背后的假设与数据来源。
- **系统速度定律**：整体速度由最受限的环节决定，分析再快，判断跟不上也没用。

### 🚀 AI的快时钟，具体能加速哪些事？

AI主要在**扫描、模拟、触发**三类工作上创造价值。
- **扫描新趋势**：持续分析专利、创业活动、投资流向、新产品发布等信息，接近实时输出业务观察。
- **低成本情景模拟**：用模型检验不同条件下的结果，找出影响创新或市场转向的关键因素。
- **预设行动触发条件**：AI监测指标，条件满足时触发动作，减少临时讨论时间。
  - 现状：多数高管仍把触发器当作**信号**，最终决策由人做出；少数组织在探索部分决策自动执行。
  - 边界：监测 ≠ 授权，系统发现条件满足，不代表自动获得行动权限。

### 🐢 人的慢时钟，为什么快不起来？

重大战略决策中，人有四项**不可替代**的工作。
- **解释证据、检验假设**：追问数据来源、核对矛盾信息、评估风险，决策责任在这个过程中形成。
- **发现意外情况**：有经验的领导者能捕捉初始假设之外的模式和联系，AI提示词未必覆盖这些因素。
- **推动跨部门共识**：好分析只是第一步，执行团队要理解并支持，分歧需要真实讨论来化解。
- **调动组织执行**：看见机会和能抓住机会是两回事，需要及时重新配置人和资金。
  说白了，以前那些"磨洋工"的讨论不是没用，它是在帮团队理解问题、建立共识，AI把过程省了，理解和对齐的机会也没了。

### ⚠️ 分析提速后，企业容易踩哪三类坑？

分析提速的好处立即可见，判断不足的代价要等出错才显现，所以组织容易盲目追速度。
- **第一类：效率压过质量**
  - 表现：分析产出太快，高管看不过来 → 审查步骤被跳过，或交给经验不足的初级员工。
  - 叠加效应：**自动化偏差（automation bias）** = 人因为结果来自机器，就倾向于相信它，不愿质疑。
  - 极端情况：用AI审查AI，一个模型生成、一个解释、一个再处理，人对证据的理解和责任感持续减弱。
- **第二类：判断成新拥堵点**
  - 表现：送到高管面前的判断任务变多，无法辨别可信度时还要从头核验，决策耗时反而增加。
  - 历史参照：过去IT变革中出现过**数据过载（data overload）**和**分析瘫痪（analysis paralysis）**，本质都是一个环节先加速，其余没跟上。
- **第三类：经验出现断档**
  - 表现：找资料、做分析、搭模型原本是初级员工练手的机会，AI接走后，练习判断的场景大幅减少。
  - 长期风险：短期是经验不足的人被迫处理超纲决定，长期是下一代战略人才培养断层。

### 🎯 怎么破局第一步：把高管注意力用在刀刃上？

**扩充判断容量**，按决策类型分层，让不同事项进入不同流程。
- **材料优化**：把需要拍板的假设、不确定性和 **what you'd have to believe（要接受方案必须相信哪些前提）** 突出呈现，减少高管逐页找问题的时间。
- **决策三层分法**：
  - **常规决策（参数明确、高频）**：在清晰的**规则边界（guardrails）**内，AI自动执行，比如动态定价、需求预测、反欺诈。
  - **中等决策（不确定性高、环境变化）**：人主导，AI辅助，比如进入新市场、冲击后重新定价。
  - **重大决策（后果严重）**：领导者亲自掌握，比如大型并购、业务剥离、裁员重组、重大安全决策。

### 🧠 怎么破局第二步：主动补上判断力训练？

基础任务被AI接走后，要**主动设计学习机制**，不能让经验自然流失。
- **机制名称**：**有结构的学徒培养（structured apprenticeships）**，除了教AI工具和数据安全，还要练怎么理解和核验AI分析。
- **具体做法**：要求AI列出每一步的公式、数据、计算和假设，团队成员必须能回答追问，理解从数据到结论的完整路径。
- **HR动作**：岗位重构时，要检查初级员工原来的学习来源（反复建模、上级追问、业务争论），哪些被AI减少了，就在真实工作中重新安排练习和反馈。

### 🤝 怎么破局第三步：守住人的决策责任感？

防止人对AI产出的责任感被削弱，**重要决定必须有人兜底**。
- **指定负责人**：每个重要决策都要有一位有经验的负责人，能挑战假设、评估风险、最终担责。
- **AI辅助复核**：让不同AI智能体分别从风险经理、创业者、数学家、**魔鬼代言人（devil's advocate，专门提反对意见的角色）** 的角度审视分析，提前暴露错误和可疑假设。
- **额外收益**：分析成本下降后，企业可以把资源配置评审从**每年一次**改成**每季度/每月一次**，更频繁地检查关键判断，灵活调整资源。

### 📝 补充细节
- **历史参照**：文章提到**双速IT（two-speed IT）** —— 面向客户的数字应用迭代快，核心交易系统运行稳，企业通过解耦和管理交接来平衡，判断力瓶颈也需要类似的流程设计。
- **适用边界**：输入明确、边界清楚、取舍可预先界定的**日常改进型决策**，AI可以多承担；后果重大的战略决策，人的判断不可替代。
- **作者信息**：Alex D’Amico、Bruce Delteil、Laura LaBerge、Matt Banholzer。
