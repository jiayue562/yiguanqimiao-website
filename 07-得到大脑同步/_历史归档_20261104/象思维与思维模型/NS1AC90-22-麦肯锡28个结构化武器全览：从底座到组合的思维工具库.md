# 麦肯锡28个结构化武器全览：从底座到组合的思维工具库

### 🏗️ 28个工具的底层底座是什么？

**MECE管拆解、金字塔管表达**，是所有工具的共同基础。
- **MECE原则**：分类时**相互独立、完全穷尽**，铁律是「宁可重复，不可遗漏」
  - 四种分解法：要素分解 + 时间分解 + 概念分解 + 因数分解
- **金字塔原理**：芭芭拉·明托创建，**结论先行**，守四条原则
  - 操作逻辑：自上而下问「为什么」，自下而上验「所以呢」

### 🧠 逻辑思考类有哪6把武器？

用于**让思维严密、表达清晰**，覆盖推理与沟通场景。
- **MECE原则**：基础分类工具，层层深挖到本质
- **金字塔结构**：结论先行的思考与表达框架
- **五色光思维**：爱德华·德·波诺平行思维，6种视角避免对抗
  - 六角色：白光（事实）+ 红光（情感）+ 黄光（积极）+ 蓝光（风险）+ 绿光（创新）+ 主持人（控场）
- **认知重建**：把劣势重新框定为优势，含意义重建与状况重建两种路径
- **PREP法**：结论-理由-事例-结论的商业表达结构
- **归纳法与演绎法**：归纳提炼共性、演绎推导结论，实战常结合使用

### 💡 创意思考类有哪7把武器？

用于**突破定势、生成新意**，覆盖发散与决策场景。
- **书面头脑风暴法**：6人6轮30分钟可产108个创意，核心是严禁批判、只求数量
- **KJ法（亲和图）**：川喜田二郎创立，卡片直觉分组、自下而上涌现洞察
- **SCAMPER法**：7维创意展开 = 替代+合并+借用+修改放大+转用+消除简化+重组反转
- **曼陀罗思考法**：九宫格层层展开，理论可产81+创意点
- **利弊均衡表**：正反因素列清赋权，价值在强迫系统思考
- **支付矩阵**：效果×可行性双轴排序，右上「速赢区」优先
- **决策矩阵**：3-7个指标加权打分，克服主观与二维局限

### 🔧 问题解决类有哪8把武器？

用于**从定位到行动的闭环**，覆盖分析到执行全流程。
- **逻辑树**：分What/Why/How三种，MECE拆解到可行动层面
- **流程图**：可视化业务流程，定位瓶颈与浪费环节
- **差距分析**：对比理想与现状，差距即问题本身
- **议题树**：假设驱动版逻辑树，先提假设再验证迭代
- **ABC理论**：事件A→信念B→结果C，结果由信念决定
- **空-雨-伞**：事实→解释→行动三步法，严禁跳步
- **重要度/紧急度矩阵**：四象限分类，重点投**重要不紧急**第二象限
- **假设思考**：信息有限时快速「假设→执行→验证」循环

### 📊 市场与战略类有哪7把武器？

用于**看清内外部局面**，覆盖宏观到组织诊断。
- **PEST分析**：政治+经济+社会+技术四维度扫描宏观环境
- **五力分析（波特）**：5种竞争力量判断行业吸引力，短板是偏静态
- **3C分析**：顾客+竞争者+自身，找三者交集的战略甜区
- **SWOT分析**：优劣势+机会威胁，须用TOWS矩阵交叉推导战略
- **价值链分析（波特）**：基本活动+支持活动，找成本或差异化源泉
- **波士顿矩阵**：市场增长率×相对份额，分明星/现金牛/问题/瘦狗四类
- **7S分析**：3硬S（战略/结构/制度）+ 4软S（价值观/风格/员工/技能），软要素最难改

### 🎯 工具怎么选、怎么组合？

**先诊断卡点，再对症选2-3把**，切忌为用框架而堆砌。
- **按场景速查**：
  - 想不清问题 → 差距分析、逻辑树（Why树）
  - 信息太杂 → MECE、金字塔
  - 缺创意 → 书面脑暴、KJ法、SCAMPER、曼陀罗
  - 选方案 → 利弊表、支付矩阵、决策矩阵
  - 怕跳步 → 空-雨-伞
  - 看市场 → PEST、五力、3C、SWOT
  - 看内部 → 价值链、7S、波士顿矩阵
- **经典三层组合**：
  - 宏观到微观：PEST + 3C + 价值链
  - 发现到解决：差距分析 + 逻辑树 + 议题树 + 空-雨-伞
  - 战略到执行：SWOT + 安索夫 + STP + 4P

### ⚠️ 工具有哪些局限？

共5条核心局限，**避免被工具所役**。
1. **依赖信息完整**：数据不准时，再严密结构也推荒谬结论
2. **要求专业素养**：同一工具，新手与专家输出质量差异极大
3. **限制创新思维**：框架易成路径依赖，颠覆式创新常生于框架外
4. **西方文化预设**：根植理性还原论，东方语境需情境化调整
5. **难处理非线性**：多基于线性逻辑，易割裂复杂系统的要素互动

### 📝 有哪些刻意练习方法？

先练6个高频动作，**30天可实现自动化**。
1. 每日一MECE：遇到分类就拆一遍，查重叠遗漏
2. 表达必金字塔：先写结论，再列三点理由
3. 卡住用逻辑树：画Why树追问三层「为什么」
4. 决策用空雨伞：分三栏写事实/解释/行动，不跳步
5. 创意用SCAMPER：逐问7维，至少出3个新点子
6. 周复盘用优先级矩阵：检查是否陷在「救火」象限
