# 一文讲透商业模式定位：5个维度找准生意的导航图

### 🎯 商业模式定位到底是什么？

它是**整个交易结构的起点**，决定一门生意的基本盘。
- **朴素定义**：想清楚用什么产品、通过什么渠道、以什么价格、服务什么客户、赚什么钱，以及在产业链上站什么位置。
- **理论出处**：魏炜、朱武祥在《发现商业模式》中提出，定位是交易结构设计的起点，定位错了所有努力都会南辕北辙。
- **典型对照（手机行业）**：

| 维度 | 苹果 | 小米 |
| :--- | :--- | :--- |
| 产品 | 高端智能手机 + iOS生态 | 高性价比科技产品矩阵 |
| 客户 | 追求品质体验的中高端用户 | 追求性价比的大众消费者 |
| 渠道 | 官网 + 直营店 + 授权经销商 | 线上为主 + 小米之家 |
| 价格 | 高溢价 | 贴近成本，性价比优先 |
| 产业链 | 做设计、品牌、生态 | 做品牌、生态整合 |
| 盈利 | 硬件利润 + 分成 + 服务 | 硬件微利 + 互联网服务 |

### 🧩 商业模式定位包含哪五个核心维度？

**客户、产品、渠道、价格、产业链**，五个维度缺一不可。

#### 维度一：客户定位——你到底服务谁？

**客户定位是所有定位的起点**，服务所有人等于谁都没服务好。
- **核心问题**：核心客户是谁？有什么特征？有什么未被满足的需求？
- **酒店行业例子**：
  - 如家 → 出差商务人士，对价格敏感、要求干净方便 → 经济型酒店
  - 亚朵 → 新中产，追求品质文化体验 → 人文酒店

#### 维度二：产品定位——你给客户什么？

产品定位的核心是**选择满足需求的方式**，不是卖什么。
- **关键区分**：营销定位着眼于需求，商业模式定位着眼于满足方式。
- **出行需求的5种满足方式**：
  - 卖车 → 拥有一辆车
  - 出租车 → 按次付费的出行服务
  - 网约车平台 → 连接司机和乘客的交易平台
  - 共享单车 → 短途共享出行
  - 地铁公交 → 公共交通服务

#### 维度三：渠道定位——你怎么触达客户？

渠道是**与客户发生交易的场所**，直接改变交易结构。
- **核心问题**：通过什么方式把产品送到客户手里？
- **化妆品行业4种渠道对比**：
  - 线下专柜 → 成本高、客单价高、体验好
  - 电商平台 → 投流运营成本高、覆盖面广
  - 微商/私域 → 门槛低、管理难度大
  - 直播带货 → 起量快、利润薄

#### 维度四：价格定位——你收多少钱、怎么收钱？

价格定位的本质是**设计收费机制**，影响客户决策和现金流。
- **核心问题**：收多少钱？一次性还是持续收费？客户容易接受吗？
- **软件行业3种收费模式**：
  - 卖license → 一次性大额收费、客户决策慢
  - SaaS订阅 → 按月/年收费、客户决策快、需持续服务
  - 免费+增值 → 获客容易、转化率是关键

#### 维度五：产业链定位——你站在哪一环？

这是**最容易被忽略但最重要**的维度，直接决定生意天花板。
- **产业链三层分工**：
  - 上游 → 原材料、核心技术、关键零部件 → 有定价权、门槛高、周期长
  - 中游 → 加工、制造、组装 → 靠规模效率、议价弱、利润薄
  - 下游 → 品牌、渠道、终端 → 离用户近、获客成本高、竞争激烈
- **贾宁观点**：行业总体价值在产业链上分配极不均匀，有的环节吃肉，有的喝汤，有的啃骨头。
- **手机行业利润分配**：上游芯片/操作系统赚大头 → 中游代工赚加工费 → 下游品牌赚品牌渠道钱

### 📋 怎么用一张表诊断自己的定位？

对照五个维度逐条自问，**答得清晰才算定位明确**。

| 定位维度 | 回答的问题 | 自我提问 |
| :--- | :--- | :--- |
| 客户定位 | 服务谁 | 核心客户是谁？特征？核心需求？ |
| 产品定位 | 给什么 | 用什么方式满足需求？产品/方案/服务/体验？ |
| 渠道定位 | 怎么触达 | 通过什么渠道成交？是效率最高的吗？ |
| 价格定位 | 怎么收钱 | 收多少钱？一次性还是持续收费？客户接受吗？ |
| 产业链定位 | 站在哪 | 在产业链哪一环？利润空间多大？能往高利润环节移吗？ |

### ❓ 为什么中小企业更要想清楚定位？

没有清晰定位，**资源少、试错成本高**的小企业更容易走偏。
- **理由一：明确边界**：定位像指南针，告诉你什么该做、什么不该做，避免盲目跟风。不符合定位的钱，再多也不赚。
- **理由二：资源聚焦**：中小企业钱少、人少、时间少，定位清晰才能把资源用在刀刃上，不撒胡椒面。
- **理由三：跳出价格战**：大家定位一样才会打价格战，找到差异化定位就能避开正面竞争。

### 🏔️ 战略、模式、品牌三个定位怎么区分？

三层定位**各管一段、向下传导、向上支撑**，对齐才有效率。

| 层级 | 定位类型 | 解决的问题 |
| :--- | :--- | :--- |
| 最高层 | 战略定位 | 去哪里（做什么不做什么、进哪个赛道） |
| 中间层 | 商业模式定位 | 怎么干（产品、渠道、价格、客户、产业链） |
| 最底层 | 品牌定位 | 用户怎么看你（心智占位、差异化认知） |
- **传导逻辑**：战略变 → 模式变 → 品牌变；上面动下面不动就会拧巴。
- **支撑逻辑**：品牌做好 → 模式更顺 → 战略走得更远。
- **小米三层对齐案例**：
  - 战略定位：做性价比科技生态
  - 商业模式定位：高性价比产品 + 线上渠道 + 生态链模式，服务大众消费者
  - 品牌定位：性价比、年轻、科技感
  说白了，从上到下说的都是一回事，劲儿往一处使，效率才最高。
