# 中国哲学形上之道的三种诠释路径与核心论争——兼与象思维视角的融合观察

### 🏛️ 形而上之道的思想源头在哪里？

**先秦已有道器上下观念**，《易传》首次明确提出"形而上者谓之道"命题。
- **文本出处**：仅见于《易传·系辞上》，是中国古典本体论核心命题，也是汉语"形而上学"的文本来源。
- **儒家渊源**：孔子重道轻器 → "君子不器" + "下学而上达"，以道为人生最高价值；《礼记·乐记》提出"德成而上，艺成而下"。
- **道家渊源**：老子"朴散则为器" → 朴是道的混沌状态，器从道中分化而来。
- **近代转义**：日本学者**井上哲次郎**借"形而上"翻译亚里士多德*Metaphysics*，此后成为第一哲学、本体论的代名词。
> 与象思维的融合点：象思维以"象"为核心把握世界，道器之分本质上是**无形之象 vs 有形之器**的层级区分；孔子"下学而上达"、老子"朴散为器"，都体现了象思维从具象上升到抽象、从整体分化为万殊的运思模式。
---
### 📜 历代解释形而上下有哪三种路径？

形成**先后说、体用说、隐显说**三条经典诠释脉络。

| 路径 | 代表人物 | 核心区分标准 |
| :--- | :--- | :--- |
| 先后说 | 孔颖达、戴震 | 生成时序 / 成形前后 |
| 体用说 | 崔憬、朱熹 | 本体与功用 / 道与器 |
| 隐显说 | 程颐、王夫之 | 主体感知 / 可见与不可见 |

#### 1. 先后说：从时间维度区分道器
- **孔颖达（唐）**：以老子**无、有**解形而上下 → 道是无体之名（形上），器是有质之称（形下），有生于无，先道后形。
- **陈致虚、黄元吉（元）**：延伸为**先天/后天**、**未发/已发**两对范畴 → 先天、未发为形上，后天、已发为形下。
- **戴震（清）**：明确"形而上 = 形以前，形而下 = 形以后" → 阴阳、五行之气未成形质时为形上，成形质后为形下；抨击程朱以阴阳属形下是"失道之名义"。
- **刘师培（民国）**：未有形者丽于虚（形上），既有形者证于实（形下）。
> 与象思维的融合点：先后说的"成形前后"逻辑，与象思维中**"象→形→器"的生成序列**高度契合——气之虚象是形上，凝聚成形为形下，体现了象思维"观物取象、由象致形"的演化路径。

#### 2. 体用说：从本体功用维度区分道器
- **崔憬（唐）**：**形质为体（形下=器），妙用为用（形上=道）** → 天地以万物资始资生为道，动物以灵识为道，植物以生性为道；与老子"有之以为利，无之以为用"相通。
- **杜光庭（唐末五代）**：形而上为道之本（清虚无为），形而下为道之用（禀质流形）；又分五种体用，其中"以有为体、以无为用"近于崔憬。
- **朱熹（南宋）**：区分两种体用视角 → 从形而上看，冲漠之理为体、事物发见为用；从形而下看，事物为体、理之发见为用。
> 与象思维的融合点：体用说强调"即体即用、道器不离"，与象思维**"象中见道、道在象中"**的整体思维一致——不割裂本体与现象，而是通过具象之"象"体悟形上之"道"，是象思维非二元对立特征的体现。

#### 3. 隐显说：从主体感知维度区分道器
- **程颐（北宋）**："至微者理也，至著者象也；体用一源，显微无间" → 理微为形上，象著为形下。
- **朱熹**：以《中庸》"费而隐"解 → 费是道之用（可见），隐是道之体（非视听所及）。
- **王夫之（明清之际）**：**形而上=隐（弗见弗闻），形而下=显（可见可闻）** → 形上不能完全脱离形，要通过"形"去认识背后的隐性存在；完全脱离形的形上会堕入佛教空无。
- **陈赟评价**：隐显说的核心是**存在向主体显现的方式**，"隐"与主体知能密切相关，不是纯客观属性。
> 与象思维的融合点：隐显说引入主体视域，与象思维**"观物取象、主客交融"**的认知模式相通——象不是纯客观实体，而是主体与客体互动中生成的显现；"隐"的层面正是象思维中"大象无形"的形上之象，需通过直觉体悟而非概念分析把握。

### ⚖️ 阴阳、气、理的形上归属有哪些争论？

宋明以来**阴阳与气的形上定位**是道器之辩的核心焦点。

#### 程朱理学：理为形上，阴阳之气为形下
- **程颐**："离了阴阳更无道，所以阴阳者是道也" → 阴阳是气（形下），支配阴阳的**所以然之理**才是道（形上）；体用一源，显微无间。
- **朱熹**：继承程颐并发挥 → "所以循环者乃道"，"所以"含**动力因**意味，不仅是静态规律；理气严格分判：理是形而上之道（生物之本），气是形而下之器（生物之具）。
- **道的广狭二义**：
  - 狭义 = 形而上之理（静态）
  - 广义 = 一阴一阳流行（兼理气，动态）

#### 气学一系：阴阳、无形之气为形上
- **张载（北宋）**："一阴一阳不可以形器拘，故谓之道" → 气有两种状态：**散而无形=形上**，聚而有形=形下；气能贯通有无。
- **陆九渊（南宋）**："一阴一阳即是形而上者" → 把"一"理解为**并列对待关系**（空间性、逻辑性），阴阳是抽象的关系属性，非实体之气；朱熹批评其"昧于道器之分"。
- **明代气学思潮**：普遍反对理气二分
  - 罗钦顺、湛若水：仍以气为形下，但反对"所以然"割裂理气，强调道体流行。
  - 崔铣、王道、刘宗周：明确以阴阳、气为形上 → 王道提出"阴阳之形而上者谓之道，形而下者谓之器"，本一气而已。
- **清代**：任启运、沈起元继续主张阴阳为形上 → 沈起元区分**卦爻阴阳（形下）**与**造化之阴阳（形上）**，后者既指实体之气，也指高下、尊卑、仁义等关系属性。
> 与象思维的融合点：气学一系以"气"为形上本体，与象思维以"气-象"为世界基本构成的观念一脉相承——**气是象的质料基础，象是气的显现方式**；张载"气能一有无"正是象思维"有象无定形"的形上表达，区别于西方概念形而上学的实体化思维。

### 👁️ 神、心的形上归属有哪些分歧？

"神"与"心"的形上定位是道器之辩的延伸领域。

#### 神：造化之妙 vs 气之精英
- **主形上说**：
  - 魏晋至隋唐：引述形而上时常以"神道""神理"形容 → 《文心雕龙》"神道难摹"、《晋书·律历》"神道广大"。
  - 周敦颐、保巴、方宗诚：直接以神为形上 → "形而上者谓之神"，神与物对。
  - 张载："清通而不可象为神" → 神、化皆为形上，天地法象才是形下。
  - **朱熹晚年**：以"所以然"论神 → 神 = 理，属形而上本体。
- **主形下说**：
  - 罗钦顺：神为道之妙用，非实体 → 引朱子"神亦形而下者""神乃气之精英"为证；但作者指出罗钦顺对朱子的理解**片面**，朱子并未笼统将神归为形下。
- **鬼神的细分**：
  - 辅广、张照：鬼神为形而上（幽），礼乐为形而下（明）。
  - 王夫之：神为形上（亘生死、常伸），鬼为形下（困于形、将竭）。

#### 心：形上之性 vs 形下之觉
- **主形上说**：季本 → 心是性之所存，为气之帅，属形而上。
- **主形下说**：
  - 唐伯元：性是形而上（纯善），心是形而下（有善有恶）。
  - 高攀龙：仁是形而上，心是形而下，达则即心即仁。
  - 刘宗周："形而上者谓之性，形而下者谓之心"。
- **朱熹的中间立场**：心统性情 → 近性一面为形上，近情一面为形下，类似佛教"一心开二门"。
> 与象思维的融合点：神与心的形上之维，正是象思维**"直觉体悟、神而明之"**的认知能力基础——"神"是形上之象的妙用，"心"是观象、取象、体悟道的主体；象思维不依赖概念推理，而靠"心"的神妙作用直接把握形上之道，这是中国思维模式区别于西方逻辑形而上学的关键特征。

### 🌟 中国形上之道的总体特征是什么？

**融宇宙生化、道德价值、修身境界于一体**，重在日用践履体道。
- **道器不离**：形上之道不脱离形下器物，不是独立于现象世界的超越实体。
- **重在践履**：体道不是纯思辨活动，要在日用伦常中实践、体悟。
- **三重融合**：宇宙论（生化） + 价值论（道德） + 境界论（修身） = 统一的形上之道。
- **与西方的差异**：西方形而上学是纯思辨、概念化的第一哲学；中国形上之道是**即体即用、即静即动、即内在即超越**的。
> 与象思维的融合点：中国形上之道的三大特征，本质上都是**象思维模式**的体现：
> 1. **整体性**：道器不离 = 象思维"整体直观、不割裂本体现象"
> 2. **实践性**：日用践履体道 = 象思维"即事见理、在具体活动中悟道"
> 3. **非概念性**：融宇宙、道德、修身于一体 = 象思维"知情意统一、不做纯粹概念抽象"
>
> 说白了，中国的形而上学不是"想"出来的，是"象"出来、"做"出来的——通过观象、体象、践象，在具体生活里通达形上之道。

### 📝 补充细节
- **张载与陆九渊的差异**：两人都以阴阳为形上，但张载的阴阳与实体之气关联密切（近朱熹），陆九渊的阴阳是抽象逻辑对待关系；这一区别前人较少注意。
- **朱熹道的广狭二义**：狭义道 = 形而上之理（静态），广义道 = 一阴一阳流行（兼理气、动态）；理偏静态，道偏动态。
- **罗钦顺对朱子的误读**：罗钦顺引朱子"神亦形而下"证明神属形下，但朱子晚年已不再直接如此表述，且朱子明确以"所以然"论神时，神等同于理（形上）。
- **季本的独特立场**：以形上之理为阳、明、善、精神，以形下之气为阴、晦、恶、物质；阳刚乾健为主宰，坤顺气质为从属，近于传统形神关系的二分模式，与现代新儒家熊十力《乾坤衍》有相似处。
