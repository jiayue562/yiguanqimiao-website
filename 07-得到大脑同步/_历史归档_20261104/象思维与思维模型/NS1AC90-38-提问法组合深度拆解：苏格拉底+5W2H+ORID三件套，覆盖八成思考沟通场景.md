# 提问法组合深度拆解：苏格拉底+5W2H+ORID三件套，覆盖八成思考沟通场景

### 🏆 为什么提问法是组合练习的第一站？

提问法是**元操作**，门槛最低、迁移最快，天然适合做组合入门。
- **三大优势**：零成本（换说话方式就见效） + 天然组合型（可灵活搭配） + 内外兼用（向内自检、向外共识）。
- **三类提问法**：深度追问类（苏格拉底、五个为什么）、拓展视角类（爱因斯坦式、发散式）、结构化反思类（ORID、反思式），覆盖「往深挖—往宽拓—往回看」三个方向。
- **本篇核心三套**：苏格拉底六问（深度追问）、5W2H七维（全景检查）、ORID四层（反思落地）。

### 🔍 苏格拉底六问怎么用，才不是审问？

它是**思维检验闭环**，六类提问动态循环，不是线性走流程。
- **六大提问类型**：
  - **澄清式**：统一概念定义，消除歧义 → 解决「你说的A和我理解的A不是一回事」。
  - **探究假设式**：挖隐性前提，检验底层地基 → 你默认的「因为A所以B」真的成立吗？
  - **探究证据式**：区分主观感受与客观事实 → 别拿个例当普遍规律。
  - **探究视角式**：跳出自我中心，补思维盲区 → 换个立场看，结论可能完全反过来。
  - **探究结果式**：推演连锁后果，做压力测试 → 追问「然后呢」，挖到二阶、三阶影响。
  - **对问题的提问**：升维审视议题本身 → 别在错误的问题上狂奔。
- **标准五步组合链**：对问题的提问（破题校准） → 澄清式（统一认知） → 假设+证据（核心校验） → 视角式（突破局限） → 结果式（终极校验），可随时回溯迭代。
- **三个使用原则**：循环迭代不死板、以「为什么」为粘合剂、先聆听后提问。
- **实战效果**：同事提议「赶紧做私域」，六问转一圈后，真问题从「要不要做私域」变成「怎么向老板证明在认真经营存量」。

### 📋 5W2H七维真的能做到零遗漏吗？

它是**地毯式排查清单**，把跳跃式思考变成结构化全景，少一个维度就破一个洞。
- **七维度拆解**：
  - **What**：核心任务、交付成果、边界。
  - **Why**：核心目的、解决的痛点、不做的影响。
  - **Who**：负责人、执行人、配合方、用户。
  - **When**：启动、截止、里程碑、复盘节点。
  - **Where**：执行场景、渠道、覆盖区域。
  - **How**：执行步骤、工具、备用方案。
  - **How much**：人力/预算/时长投入、量化产出、合格标准 → 最常被漏，也最要命。
- **六大价值**：补思考漏洞、降沟通成本、生成落地计划、快速排查问题、全场景通用、培养结构化思维。
- **翻车反例**：线下沙龙漏了How much（没设预算和转化标准），为了「效果好」订五星酒店加红酒晚宴，单客成本飙升，活动热闹但亏钱。
- **极简清单**：七问贴墙，做事前扫一遍，简单事过三问（What/Why/How），复杂事全过，How much必留。

### 🔄 ORID四层怎么解决复盘流于形式？

它把**天然思考顺序**标准化成对话流程，强制全员节奏同步，从事实走到行动。
- **四层递进（严禁颠倒跳过）**：
  - **O·事实（Objective）**：纯客观记录，不带评判情绪 → 搭无争议的沟通基础。
  - **R·感受（Reflective）**：接纳所有情绪，不评判对错 → 情绪是隐藏问题的信号。
  - **I·意义（Interpretive）**：复盘根源、提炼规律 → 挖掘事件背后的价值与问题。
  - **D·行动（Decisional）**：明确责任人、截止时间、执行动作、验收标准 → 可落地可考核。
- **跨域同构**：ORID ↔ 五色光（白事实→红感受→黄价值→绿行动）；ORID ↔ 人机协同对话骨架。
- **实战效果**：线上课程项目复盘，用ORID走完四层，根因从「内容不好」变成「学伴感断得太快」，最终落地3条带标准的具体动作。

### 🎯 三套提问法怎么组合，对应不同场景？

三套是**异质互补**的：5W2H是面（空间铺展）、苏格拉底是点（纵向钻探）、ORID是线（时间流转），拼成立体思考。
- **处方一·复杂业务难题**：5W2H（铺全景） → 苏格拉底六问（挖真因） → ORID（复盘落地） → 解决「想不清—想不透—落不实」。
- **处方二·一对一深度沟通**：ORID（搭对话框架） → 苏格拉底（澄清观点、消偏差） → 爱因斯坦式提问（开新思路） → 很多人「要建议」其实是「要被问清楚」。
- **处方三·自我复盘/重大决策**：5W2H（铺七维全景） → 苏格拉底「对问题的提问」（升维质疑） → ORID（写四段落地） → 把情绪化纠结变成带timeline的行动计划。
- **完整演示·项目延期复盘会**：先用5W2H查清延期的具体环节、成本，再用苏格拉底挖透是需求变还是排期问题，最后用ORID落地「需求确认单」制度，带责任人和验收标准。
- **完整演示·跳槽决策**：5W2H列清现状与目标的差距、跳槽成本，苏格拉底挖透「没成长」的真实含义和「换环境就好」的假设，ORID最终落地「先补技能3个月再投」的行动。

### 🧘 提问法和象思维是什么关系？

西式提问**拆清楚事**，象思维**立整体之象**导航，一骨一魂，配合不散。
- **象思维四字循环 = 一套提问**：观（看到什么象） → 比（和哪些象同类） → 体（象底下的张力是什么） → 化（能不能升成更好的原象）。
- **组合用法**：
  - 用5W2H铺全景前，先浮起整体之象，再用七问核验象准不准。
  - 用苏格拉底深挖时，每挖一层问「象变了吗」，根因就在象质变的层次。
  - 用ORID复盘时，O+R是观象体感受，I是体意象，D是化原象落地。
- **实战演示·小餐厅生意不对**：先浮起「热闹的空心」之象，再用三套提问验证拆解，最终落地「团单限流+推老客储值卡」的方案。

### 🤖 给AI的提问链模板有哪些，怎么用？

AI最怕模糊指令，**组合式约束**越成体系，生成内容越能落地。
- **模板A·苏格拉底深挖链**：用于检验观点/方案，按六类提问依次追问，每步给判断。
- **模板B·5W2H全景链**：用于规划任务，按七维拆解，尤其不能漏How much。
- **模板C·ORID复盘链**：用于复盘经历，四层依次展开，不可跳过。
- **效果对比**：裸问「帮我做社群运营方案」 → AI给通用模板；用5W2H约束（目标、资源、品类） → AI给带步骤、预算、合格标准的落地方案。

### 📅 新手怎么快速上手三套提问法？

按**30天渐进路线**练习，从刻意套用变成本能。
- **第1周**：只练5W2H，接任务先默念七问，重点写How much。
- **第2周**：会议/复盘引入ORID，别跳过R（感受）层。
- **第3周**：深度讨论加苏格拉底澄清式+假设式，不追求六问全用。
- **第4周**：用「5W2H铺→苏格拉底挖→ORID收」的组合处理一个真实复杂问题。
- **速记口诀**：
  - 5W2H：做什么、为啥做、谁来做、啥时做、在哪做、怎么做、做到啥标准。
  - 苏格拉底：先问问题对不对，再问词啥意思、前提成不成立、证据够不够、换角度怎样、结果会咋样。
  - ORID：看到了啥、啥感受、啥意思、下一步咋干。
