# 曾鸣：岗位正在消失，任务登场——AI原生组织的第一张底图

### 🔍 这篇内容核心在讲什么？

**岗位**作为组织基本单元正在被**任务**取代，AI时代组织底层逻辑正在强制换代。
- **核心来源**：2026年9月张小珺对曾鸣的两个半小时访谈 + 2026年7月中信出版的《智能：人工智能时代的商业、组织与战略的本质》（曾鸣「智能三部曲」第三部）。
- **变革定位**：继生产力革命、管理革命、知识革命之后的**第四次革命——创造力革命**，人的价值从「知识拥有者」转向「认知创造者」。

### 🧠 AI时代商业价值从哪来？

曾鸣提出**三个第一性原理**，解释智能时代的价值增长逻辑。
- **智能复利**：任务越多 → 反馈越多 → 系统越强，增长同时是能力增值；传统资产越用越旧，AI系统越用越强。
  - 例子：特斯拉每辆上路车都是数据采集终端，每次行驶都在训练系统。
- **黑洞效应**：复杂任务反馈有强路径依赖，买不来也抄不走 → 高价值任务向少数领先系统聚集。
  说白了，你不是在和一家公司竞争，而是在和整个生态的流向竞争。
- **60分奇点**：跨过奇点前，AI干活、人兜底，闭环断裂；跨过之后，**AI对结果负责**，从60分到90分可能只要两周。

### 🏢 旧组织为什么不灵了？

工业时代的**认知压缩结构**前提塌了，中层功能正在被AI接管。
- 旧组织本质 = 为「规模化执行既有答案」设计的认知压缩结构，靠分工、层级、流程、控制压缩认知。
- 大模型能不断生成新解法 → 中层的信息整理、跨部门协调功能被接管 → 整套制度的前提失效。

### 🆚 岗位制和任务制差别在哪？

两者**起点完全不同**：一个从管人出发，一个从做事出发。

| 维度 | 岗位制（旧逻辑） | 任务制（新逻辑） |
| :--- | :--- | :--- |
| 起点 | 设岗招人，定汇报线和报酬 | 定义问题，拆解任务 |
| 协同方式 | 命令链 + 层级，级别高说了算 | 任务流 + 网络，谁有能力谁上 |
| 中层价值 | 信息整理 + 跨部门协调 | 无存在必要 |
| 闭环方式 | 按岗位流程推进 | 交付结果 → 形成反馈 → 沉淀系统 |
| 设计目的 | 为稳定而生 | 为生成而生 |
- **关键澄清**：科层制公司制度会衰亡，但人类分工协作不会消失，组织永远存在，只是运行方式变了。

### 🛠️ 任务制怎么落地？

核心是三件事：**分圈、分活、分钱**，对应降低不同的组织摩擦。
- **组织竞争力公式**：组织竞争力 = 人才密度 × AI杠杆 ÷ 组织摩擦
- **分圈**：围绕任务组队，而非按岗位配编 → 一个问题一个圈，圈内高内聚、圈间低耦合 → 压协调摩擦。
- **分活**：把能完整交付结果的活，整块交给「人+AI」单元 → 判据是结果能不能验证、闭环能不能形成（对应60分奇点）。
- **分钱**：按认领任务和交付结果给回报，不靠层级晋升 → 压动力摩擦。
- **未来组织形态**：曾鸣称之为「共生智能体」——创智人才 + AI智能体的协作系统，领导者从管理者转向**系统架构师**，最终是组织智能之间的竞争。

### 📋 企业该怎么启动转型？

别从「AI+」开始，**从盘点任务开始**，是三年左右的长期计划。
- **避坑提醒**：不要停留在工具叠加（给现有流程装插件、给岗位配助手），那只是旧机器的补丁。
- **两个可量化指标**：
  1. 业务里有多少比例由AI自主完成
  2. 组织里有多少岗位由智能体自主运营
  这两个数字比上了多少工具、办了多少培训更诚实。
- **一把手动作**：最早一批原生一把手，会亲自动手重写公司内部运行体系 → 先理解组织该怎么运行，再用AI实现原型。
- **核心原则**：**给上下文，而非控制**——把背景信息给足，让一线自己判断，不要层层审批。
- **节奏判断**：曾鸣把2026年比作1995年，基础设施刚就位，应用刚开场，窗口开着但远没到分胜负的时候；现在重写系统的人，三年后用自己的系统；现在只打补丁的人，三年后还用别人的系统。

### 👤 对职场人意味着什么？

岗位不再定义边界，**成长自己负责**，找工作变成认领任务。
- 变化1：没有工作描述告诉你该干什么，想解决什么问题、培养什么能力、适配什么场景，都要自己回答。
- 变化2：竞争对象多了不会累的同事 → 不用和机器比产量，要比机器给不出的东西：
  - 把复杂现实抽象成可解的问题结构
  - 在多个可能性里建立判断框架
  - 持续调整自己的认知路径
- 硅谷流行词：**主观能动性**——自己掌握自己的命运，有没有成长自己最清楚。
- 一句话总结：以后找工作找的是任务，以后立足靠的是交付。
