# 曾鸣「看十年」第三次公开课：AI原生时代的商业、组织与战略

### 🧭 这次公开课核心在讲什么？

用「看十年、想三年、干一年」的框架，系统拆解**AI原生**的商业范式、产业阶段、组织形态与战略方法。
- **课程定位**：第三次「看十年」公开课，前两次分别为2017年智能商业、2023年AI原生应用。
- **核心前提**：超级人工智能实现仍需时间，人类创造力与机器智能**互补**，人仍是主体。
- **六大模块**：智能商业、AI原生定义、AI产业化阶段、价值创造与竞争、创智组织、智能战略。

### 🏗️ AI带来的商业范式变了什么？

从「卖产品」转向**实现人的意图**，商业起点、供给方式、竞争逻辑全部重构。

#### 供给侧：从降本增效到创造新供给
- **当前局限**：多数AI应用仅替代简单重复工作，价值空间有限，出现**投入大、效果不明显**的错配。
- **真正拐点**：技术成熟到能打开过去稀缺的优质供给（好医生、好老师、专业顾问等）。
- **需求侧突破**：AI可低成本持续互动 → 发现并满足**个性化真实需求**，而非仅匹配同质化供给。

#### 商业形态：从千人一面到一人千面

| 阶段 | 核心逻辑 | 典型方式 |
| :--- | :--- | :--- |
| 工业时代 | 千人一面 | 标准化流水线，同产品服务所有人 |
| 互联网时代 | 千人千面 | 搜索+推荐，匹配已有商品内容 |
| AI时代 | 一人千面 | 动态理解不同场景意图，生成定制方案 |

#### 起点：从产品驱动到意图驱动
- **传统模式**：企业先揣测需求 → 研发产品 → 推广分销，「以客户为中心」更多是价值主张。
- **AI模式**：用户直接表达问题 → AI逐步澄清需求 → 组合方案并执行，**意图成为商业起点**。
- **关键竞争点**：谁成为用户表达真实问题的**第一站**，谁就掌握价值创造的源头。

#### 供给体系：从供应链到实时协同网络
- **传统供应链**：固定企业 → 固定流程 → 固定商品 → 规模化交付。
- **未来协同网络**：根据具体任务，**实时调用不同能力节点**，临时组合解决方案。
- **演进节奏**：数字化产品服务变化更快，物理世界产品服务变化更慢。
- **AI短剧示例**：AI提效生产 → 分人群生成版本 → 根据用户反馈实时调整内容，供给随需求动态变化。

#### 竞争：从抢时间到省时间
- **传统逻辑**：争夺用户注意力与时长，广告/品牌在搜索浏览环节发挥作用。
- **AI逻辑**：AI理解意图后直接交付结果 → 决策窗口大幅压缩 → 竞争转向**节省用户时间**。
- **创业机会**：大模型公司无法覆盖所有场景，创业公司可通过**具体场景的持续学习闭环**建立优势。

### 🤔 到底什么是AI原生？

拿掉AI后产品/业务**无法成立**，才是AI原生；仅效率下降的属于AI增强。
- **定义**：以可规模化调用的机器智能为起点，重新设计产品、工作流、组织，创造过去无法实现的客户价值。
- **演化联动**：产品改变 → 工作流改变 → 组织改变 → 商业模式重构，四者共同演化。

#### 通用技术变革的三阶段
- **第一阶段：基础设施化** → 技术变得可靠、低成本、可调用，成为社会基础能力。
- **第二阶段：原生产品服务创新** → 围绕新技术重新设计产品/流程/商业模式，分1.0到2.0演进。
- **第三阶段：社会重构** → 技术渗透全行业，改变组织、产业与社会运行方式。
- **正反馈循环**：基础设施达临界点 → 原生应用爆发 → 拉动基础设施发展 → 社会扩散重构。

#### 历史参照：电气化与互联网
- **电气化路径**：电网普及 → 福特流水线（生产端创新） → 家电陆续进入家庭 → 从「有电方便」到「无电无法生活」。
- **汽车产业探索**：早期动力、制造、销售模式百花齐放 → 福特Model T整合出大众产品 → 转向规模化竞争。
- **互联网应用爆发**：Web+浏览器降低门槛 → 门户、搜索、电商、社交等密集出现，由市场筛选主导形态。

#### 原生应用1.0 vs 2.0
- **1.0**：找到新技术的大众产品形态（如福特T型车、Yahoo门户）。
- **2.0**：形成能组织复杂供给、满足复杂需求的新系统（如通用汽车多品牌、Google搜索）。
- **Google案例**：搜索框体验 + PageRank算法 + 分布式计算基础设施 + 竞价广告闭环 = 多维度集成创新，长期占据主导。
- **关键判断**：原生不由「出生年代」决定，而由**发挥新技术根本优势的深度**决定。

### 📈 AI产业现在走到哪一步了？

通用机器智能基础设施轮廓已形成，正加速进入**原生产品密集涌现期**，重点关注2027—2028年。
- **基础设施进展**：语言/多模态/推理能力提升 + 编程/工具调用/Agent行动能力 + 算力/API/Token计费模式成形。
- **待成熟条件**：Agent开发成本进一步下降；用户能低成本表达意图、建立信任、使用Agent。
- **阶段比喻**：相当于「浏览器还没出现」的互联网早期，仍在等待标志性产品与交互突破。

#### Agent能力的三层进阶
- **第一层：能够行动** → 调用工具，完成具体任务。
- **第二层：能够主动** → 自主拆解任务，跨步骤持续执行长程复杂问题。
- **第三层：能够负责** → 稳定交付结果，交付信任依据，接受反馈并积累经验（形成学习闭环）。
- **核心门槛**：第三层是关键，只有用户愿意**托付任务**，才能形成持续学习的正向循环。

#### 从Agent Store到Agent OS
- **Agent Store**：用户发现、选择、评判、管理、使用Agent的入口（含计费、反馈机制），形态尚未确定，可能是个人助手、超级应用或新终端。
- **Agent OS**：用户仅表达目标，系统动态组织多个Agent、数据、工具和现实供给完成任务，属于**Agent原生2.0**。
- **演进顺序**：先经历应用百花齐放，再逐步形成稳定入口与系统结构，当前谈Agent OS为时过早。
- **创业者建议**：优先参与真实应用探索，找到成立的客户价值，而非等待标准确定。

### ⚔️ AI时代的竞争靠什么？

靠**智能复利**形成飞轮，跨过门槛后可能出现「黑洞效应」，强者恒强。

#### 智能复利：越用越聪明的飞轮
- **核心逻辑**：完成真实任务 → 获得反馈 → 能力提升 → 处理更复杂任务 → 更高质量反馈 → 能力再增强。
- **60分奇点**：AI终于可以**独立上岗**，是能用与不能用的关键门槛，跨越需要大量艰苦工作，不是线性增长。
- **独立上岗三条件**：
  - 端到端任务：能自主完成完整任务
  - 结果责任：直接面向结果，而非仅完成动作
  - 真实反馈闭环：行动 → 结果 → 反馈
- **早期案例**：Claude与Claude Code相互促进，更强模型支持复杂任务 → 真实任务带来反馈 → 提升研发效率 → 反哺模型与Agent改进。

#### 黑洞效应：能力差距持续放大

当系统跨过任务复杂度门槛，智能复利会转化为竞争优势的持续扩大，资源向领先者集中。
- **四个前提条件**：
  1. 学习空间足够大：任务复杂度高，仍有持续提升空间
  2. 价值差异能被感知：能力差距转化为用户可感知的价值
  3. 反馈具有路径依赖：积累的经验无法被简单复制
  4. 能力影响任务分配：更强系统获得更多、更复杂的任务
- **竞争趋势**：移动互联网是「高频打低频」，AI智能体时代是「**高维吞低维**」，智者恒强。
- **边界提醒**：通用与垂直、大场景与小场景的边界仍待研究，并非所有应用都会被同一系统覆盖。

### 👥 AI原生组织长什么样？

从岗位驱动转向**任务驱动**，人与Agent共生，形成持续进化的组织智能体。

#### 人才：从知识工作者到创智人才
- **两大核心特征**：
  - 高能动性：主动发现机会、定义问题、承担责任
  - 超强学习能力：元认知强，快速修正，从第一性原理重构问题
- **AI放大效应**：少数人 + Agent可完成过去需多岗位配合的工作，专业壁垒降低。
- **定义**：能选择方向、定义问题、创造认知，并组织人类与机器智能落地的新型创造性人才。
- **招聘案例**：创业者先用AI系统学习候选人的论文与工作，见面时直接围绕对方关心的问题深度交流，靠认知共鸣吸引人才。

#### 组织单元：从岗位部门到任务单元
- **传统逻辑**：先定义岗位 → 再把任务放进去 → 关注岗位与层级。
- **新逻辑**：先定义目标与问题 → 拆解任务明确结果 → 动态组合人+Agent+Skill+工作流+数据反馈 → 设负责人（DRI）承担最终结果。
- **管理重心转变**：管理者核心是让正确能力在正确时点以正确顺序被调用，同时让人和AI获得成长。
- **职业变化**：人不固定在一个岗位，但要对任务结果负责，高能动性者可主动认领重要问题。

#### 协作：Agent调用人，而非人用Agent
- **两种模式差异**：
  - 移交给人：Agent遇难题 → 人工接管 → 问题解决，AI没学到经验
  - 调用人的能力：Agent主导任务 → 遇难题调用人类专业能力 → 经验进入学习闭环 → 反哺Agent进化
- **关键区别**：人的贡献是否回到**Agent的学习闭环**中。
- **本质变化**：工作流从「以人为起点」转向「以AI为起点」，需重新设计权责、权限与协作机制。

#### 组织整体智能化：集体智慧的形成与应用
- **效率悖论**：个人提效不等于组织整体变聪明，部门墙和传统流程会卡住效能释放。
- **两大核心变化**：
  1. 集体智慧的形成：每个人的新发现都能改变整个组织的认知
  2. 集体智慧的应用：每个人做具体工作时都能调用组织积累的高质量认知
- **双向认知流动**：一线经验进入组织，组织整体认知支持一线，相当于CEO的全局视角与一线信息实时互通。
- **创智本质**：围绕真实任务连接人的创造力与机器智能，解决问题后沉淀为可复用组织认知，形成「价值创造—认知进化—更高质量价值创造」循环。

#### 组织OS：智能体的运转底座

组织OS是让组织智能体运转的制度、机制与技术底座，目前尚无成熟完整案例，但方向清晰。
- **四大组成部分**：
  1. 组织记忆：沉淀事实、判断、分歧、历史决策及来源，供人和AI随时调用 → 需提高工作与决策可见性，明确留痕、更新、同步机制
  2. AI学习：从不同人的思考决策中学习，形成自身认知，像新参与者一样提出观察
  3. 反馈与进化：新洞见新决策经真实结果验证，更新共同认知、Skill和下一轮决策
  4. 技术底座：身份权限、生产系统数据接入、记忆索引、执行调度、评估版本治理
- **落地路径**：已有企业不必推倒旧系统，原有SaaS可成为新系统调用的功能与数据来源，关键是接入学习过程。
- **协作变化**：从分享最终文档转向分享完整思考对话，上下文和推理过程可见，协作进入认知层面。
- **边界提醒**：组织越复杂，权限与隐私边界越重要，透明需要与信息机制、职责、技术设计配套。

#### 领导者的新职责
- **核心职责**：建设能自我进化的**人机协同系统**。
- **管理原则**：Context, not Control → 提供充分上下文（目标、背景、约束、资源），让团队自主找方案，及时反馈。
- **激励转向**：从「管控行为」转向「激发探索」，让员工被使命吸引、被难题挑战、被创造本身奖赏。
- **最终责任**：决定重大取舍，明确风险边界，承担最终责任。
- **中层变化**：信息中转、进度汇总工作减少，人才成长、能力建设、关键判断、利益协调仍重要。

#### 创智人才的内在系统

能力被AI放大的同时，情绪噪音也会被放大；团队越小，个人负面作用冲击越强。
- **判断力**：看清自己在逃避什么，更少自欺。
- **冲突直面**：不积累关系债，把冲突转化为可处理的信息。
- **抗挫能力**：把失败当系统反馈，而非自我否定，快速进入下一轮。
- **自我对话**：混乱中看清方向，焦虑时仍能行动。

### 🎯 AI时代的战略怎么做？

从一次性规划转向**愿景驱动的战略发现**，战略成为组织的日常学习闭环。

#### 传统战略的失效
- **传统模式**：五到十年规划 → 年度战略会 → 拆解目标 → KPI考核，适合稳定环境。
- **当前挑战**：颠覆性技术带来漫长不确定转型期，既有经验不够用，无法靠一次性分析完成。
- **三大变化**：
  1. 战略成为日常工作，需持续高质量决策
  2. 决策后需不断修正，环境不会停止变化
  3. 战略与产品、技术、运营深度融合，无法简单拆解传递
- **参与范围**：战略不再只是CEO/高管的事，掌握关键知识、接近真实场景的人都需参与。

#### 愿景驱动的战略发现（Vision-Driven Strategy Discovery）

**愿景—战略—行动—洞察**四步持续迭代，本质是学习闭环。
- **愿景**：在混乱中保持方向一致，提供价值基准。
- **战略**：当前理解下的行动框架，含路径、里程碑、能力积累、客户价值创新。
- **行动**：进入真实世界，获得完整反馈。
- **洞察**：解释反馈，修正愿景与战略，指导下一轮行动。
- **核心价值**：让洞察在互动、行动、反馈中持续涌现，而非靠线性分析推导。

#### 愿景为什么仍然重要？
- **复利基础**：客户理解、技术、经验、认知都需在一个方向上持续积累，频繁换方向无法形成复利。
- **判断参照**：愿景提供标尺，用来判断行动意义、能力建设优先级、反馈的解读方式。
- **动态调整**：愿景是需被现实检验的判断，不是拒绝反馈的理由；方向相对稳定，路径逐步清晰，必要时修正判断。

#### 行动的双重价值

行动不仅是执行任务，更是**产生反馈**的战略探索。
- 失败的实验可能带来高价值结构性信息，帮你理解方向为何走不通，发现新机会。
- 战略制定与执行越来越难以割裂：执行触发新思考，思考改变下一轮行动。

#### 看十年、想三年、干一年的闭环
- **看十年（Visioning）**：理解未来结构性趋势演化，逼自己看清底层驱动力与噪音的区别。
- **想三年（战略）**：以终为始，选择定位与发展路径，明确关键里程碑，是战略思考的**锚点**。
- **干一年（行动）**：落地执行，获取快速市场反馈，推动下一轮学习。
- **平衡要点**：
  - 长期太强 → 空想型公司，有远方无切口
  - 短期太强 → 追风型公司，被眼前机会牵着走
  - 中期太弱 → 愿景与行动脱节，缺少路径逻辑
- **三年目标**：不是财务线性推导的预算，而是基于业务理解的具体想象，要有牵引力也有可行性。

#### 战略生成系统：比单次战略更重要的是产出系统

用机器学习框架类比，战略生成系统也有算法、算力、数据三要素。
- **算法**：组织共同的战略方法论，统一思考框架与沟通语言，能讨论取舍、路径、长短期关系。
- **算力**：高质量人才组成的协同网络，核心是不同人的大脑真正连接，而非凑人数。
- **数据**：持续获得真实、准确、具体、丰富、及时的反馈，是学习闭环的燃料。
- **与组织OS关系**：战略生成系统是组织OS的重要组成部分，一线思考被组织吸收，共同认知支持分布式决策。
- **协作本质**：战略过程像共同拼图建模，大家把各自看到的现实拼在一起，形成更完整的理解。

#### 真正的战略共识：是推理方式的共识
- 仅对齐「走哪条路」不够，面对新情况判断仍会分歧。
- 更深的对齐：理解彼此**为什么这样思考**，依据什么做取舍，如何解释变化。
- 即使信息相同，不同人也可能得出不同结论，把判断过程放在一起讨论，才可能产生认知突破。

#### AI越重要，线下高质量互动越重要
- **反常识点**：AI承担更多基础工作后，面对面深度碰撞反而更重要。
- **常见问题**：战略会大家对着协同文档敲字，信息效率提高了，但深度争论和碰撞被削弱。
- **战略共创会价值**：通过深入互动共同创造新认知，形成战略共识，推动集体认知模式升级。
- **成功条件**：真诚、真实、开放、勇敢、深刻的文化基础；让有不同经验、掌握鲜活信息、愿意思考的人参与，而非只按岗位级别安排。
- **长期竞争**：未来战略竞争不只是「谁的战略更好」，更是「谁的**战略系统更强**」。

### 📝 结语与行动建议

全文最核心的一个词是 **Learning Loop（学习闭环）**，从个人、团队、组织到业务都需要闭环。
- **个人行动**：从自己开始用AI，使用深度决定判断深度。
- **企业节奏**：不必追每一种新工具，可等待适合自身的方案成熟，结合自身条件判断切入点。
- **升级路径**：AI增强是多数企业的必经阶段，同时要理解AI原生的长远方向，让眼前行动与未来方向建立联系。
- **核心心法**：大舍大得，大赌大赢，大拙大巧。外在能力被放大的同时，内在稳定与心力也需要同步成长。
