### **🧠 为什么新古典框架容不下企业家精神？**

新古典框架假设世界**状态完备**，企业家精神在其中**几乎无法立足**。
- **理论切口**：引入**认知视角**，将有限理性拆解为**认知的有限性、差异性、实践性**三个维度。
- **三个核心命题**：
  - 企业家精神 = **认知差异**的体现。
  - 企业 = 异质性认知**局部共识化、规模化**的组织载体。
  - 经济发展 = **“认知差异产生租金 → 模仿形成共识 → 租金消失”**的动态循环。
- **对话对象**：科斯、哈特、威廉姆森、阿尔钦与德姆塞茨、西蒙、彭罗斯、熊彼特；与**张维迎**的企业理论（关注控制权安排）互补。

### **👁️ 认知的有限性与差异性怎么理解？**

认知有限性 = **相对性**：变化超过一定比例（一般人约 **2%—3%**）才触发有意识的“慢系统”决策。
- **快慢系统**：常规范围之内 = **快系统**（无意识决策）；超出比例 = **慢系统**（有意识决策）。
- **企业家对应判断**：斯密的 skill（技巧）关乎**做得对不对**，judgement（判断）关乎**做得对不对**；企业家对应**判断**。
- **差异来源**：**了解上的差异**（信息不对称）+ **理解上的差异**（同一张K线图，有人看涨有人看跌）。
- **企业家特质**：远见洞见 + 科兹纳的**警觉（alertness）** + 勇气 + **组织能力**（熊彼特未讲怎么实施）。

### **💰 超额利润从哪来，又怎么消失？**

超额利润 = **认知差异导致的套利**，来自多数人“觉得不靠谱”。
- **道德经隐喻**：上士闻道勤而行之（如**蔡崇信**加入马云）；中士若存若亡；下士大笑之。
- **定义**：打破常规、形成**非共识判断**、谋取**超额收益**。
- **租金消散机制**：以**比特币**为例，持有人赚钱 → 大家认真研究 → 非共识变共识 → 形成新常规 → **超额收益消失**。
- **循环**：认知差异 → 租金 → 模仿 → 租金消失，构成**经济发展动态机制**。

### **🏢 企业为什么是认知共识化的载体？**

企业 = 把企业家**个人认知**转化为组织**局部共识**的载体。
- **科斯的缺口**：科斯讲企业 vs 市场的协调成本边界，但**没解释**绩优企业超额利润为何能持续（如**华为**赚钱，别人为何不能另起炉灶）。
- **不可复制的是什么**：不是规则文本或物质资产（可买到），而是老企业长期磨合形成的**成员对规则的共同理解**。
- **类比**：配合多年的**羽毛球双打组合**，不用协调就知道你前我后。理论接近**克雷普斯**的企业文化理论。
- **组织逻辑**：类似奥尔森**集体行动的逻辑**，志同道合的小团队（team）战胜一盘散沙的乌合之众（group）。

### **📉 大企业为什么会被自己发明的技术颠覆？**

**盈亏同源**：原来有效率的原因，正是现在没效率的同一个原因。
- **机制**：绩优企业把“慢系统”相机决策转化为“快系统”组织常规 → 效率高 → 但技术与市场突变时**常规难适应**。
- **案例**：**柯达**雪藏数字照相技术；**谷歌**大模型最早产生于内部却落伍（据说管理层担心影响广告收益）。
- **类比**：**刘国梁、孔令辉**在小球改大球后技术体系瞬间崩溃。
- **两种效应之争**：阿罗**替代效应**（垄断不利创新）vs 吉尔伯特与纽伯里**效率效应**（垄断者更有动力保利润）；认知层面可统一——本质是**心存侥幸、对技术没有充分理解**。
- **政策含义**：大企业做**渐进式创新**，颠覆式创新几乎都来自**小企业**；普朗克：新理论靠**老一代逝去、新一代成长**被接受。

### **🌍 企业家精神只能跟赚钱有关吗？**

不限于赚钱，**凡打破常规谋取超额收益者**皆为企业家精神。
- **分层**：经济企业家、**政治企业家**、学术企业家、军事企业家。
- **中国改革开放** = **政治企业家 + 经济企业家**互动的结果。
- **两者区别**：政治企业家目标**多元**（含光宗耀祖等），可动用**公共政策资源**（税收、土地优惠）；经济企业家即通常所讲的企业家。
- **改革机制**：**自上而下 + 自下而上**互动，两者**同等重要**。

### **📝 补充细节**
- **演讲信息**：2026年**8月22日**第二届“企业家精神：理论与实践”研讨会，作者**寇宗来**为复旦大学经济学院副院长、中国社会主义市场经济研究中心主任。
- **理论定位**：本文框架同时解释**创业成功**与**在位者失败**，并可推广到**制度变迁**层面。
- **关键边界**：科斯理论启发了新制度经济学与中国**放权让利式改革**，但未解释超额利润持续性；哈特产权理论同样未解释。
