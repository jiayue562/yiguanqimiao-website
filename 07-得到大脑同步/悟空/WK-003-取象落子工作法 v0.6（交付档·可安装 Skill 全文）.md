> 从混沌里取出第一个结构，再把它落到明天早上能做的动作。

## 一、定位

**一句话**：一套从混沌里取出第一个结构、再把它落到明天早上能做的动作的工作法。

**管哪一段**：管"问题还没定义清楚、多因素纠缠、没有现成指标"的分析任务。
**不管**：要精确量值、要复现、要追责的执行任务。判定不了时，先问一句："这个问题是要想清楚，还是要算清楚？"

**出身**：教员方法论（矛盾论 + 实践论 + 金字塔 + 金线原理，管"深"）× 象思维 / 五色光工作法（管"全"）。两套共用同一底座：信息体 / 能量体 / 物质体。

**v0.6 新增适用范围**：当输出要交给**别人**（客户、老板、团队）去执行时，走「交付档」——多出 ⓪ 接单、③-5 验象、⑦-4 立规、⑧ 交付物四段。只给自己想清楚，走「自用档」，七步原样即可。

## 二、三档模式（先选档，再走步）

| 档 | 走哪几步 | 判据 |
|---|---|---|
| 轻量档 | ①定题 → ②′三句话事实 → ③取象＋④抓矛盾 → ⑦落子 | 错了明天能改回来、影响范围小、一个人能拍板 |
| 全流程 | 七步全走 | 决策不可逆、涉及多人资源、周期跨月 |
| **交付档（v0.6 新增）** | **⓪接单 → 全流程 → ③-5验象 → ⑦-4立规 → ⑧交付物** | **输出要给第三方执行、要经得起复核、要能追责** |

**切换判据一句话**：这步棋落错了，明天能不能悔？能悔走轻量，不能悔走全流程。
**加问一句**：这个结论要交给别人照着做吗？要，加走交付档的两段（③-5、⑦-4）。

判定不了时，问用户："这个决定，错了的代价是什么？"

**盘点不许归零**：任何档位都必须有②这一步。轻量档只盘三句话，但不能不盘——③取象的判据是"象从哪三条观察来"，观察的来源就是②。②空着，取象就是裸奔。

## 三、八步流程

> 八步 = ⓪接单（交付档）①定题 ②盘点 ③取象 ④抓矛盾 ⑤展开 ⑥验算 ⑦落子 ⑧交付物（交付档）。
> 轻量档走 ①②′③④⑦（②压缩为三句话）。顺序不能换，回流除外。

### ⓪ 接单（v0.6 新增，交付档专用）

**做什么**：在动手分析之前，先定三件事，写成一页《接单说明》给对方确认。

1. **管哪一层**——"道"还是"术"。同一件事，有人管方向，有人管执行，两套人同时进场必然打架。**必须明说：我管到哪一层，不碰哪一层。**
2. **验什么**——本次合作的成功怎么算。写成可观察的三条，不写"提升管理能力"这类无法验收的话。
3. **考验期**——第一次交付之前，先设一个短周期、低成本、可退出的观察窗。**过不了考验期，不进正式交付。**

**判据**：三条写不出来，说明还没到能接的时候，先谈不先做。

**为什么放在最前面**：v0.5 及以前，这套方法从"问题"开始；但顾问现场的真实起点是"关系"——对方信不信你、愿不愿意按你的节奏走，决定了后面七步有没有人接。**接单不是商务动作，是方法论的第一步。**

### ① 定题（P0）

**做什么**：把问题收窄成一句话。
**判据**：这句话里出现两个以上的问题，就是还没定题。

**示例**：
- 坏："帮我看看，店里业绩不太行，团队状态也不好。"
- 好："狮山店新客转化率连续四周低于 50%，主因是什么？"

**冷启动**：用户只给了一堆抱怨时，用三问开局——
1. 这事做成了是什么样（一句话）？
2. 手里已收钱 / 已验证的事实有哪些？
3. 有什么红线不能碰？

**停下来问人的检查点**：三问后仍收不拢，列 2–3 个候选问题定义，让用户选。**不选，不开工。**

### ② 盘点（P1-1）

**先查本义**：这件事在用户自己的体系 / 语境里本来是什么？本义与市场习惯冲突时，**站本义**。

**再摆事实，分六类**：

| 类别 | 盘什么 |
|---|---|
| 流量 | 粉丝数、增长率、渠道数 |
| 内容 | 篇数、阅读、转发率、爆款 |
| 产品 | 清单、形态、成本类型 |
| 收入 | 已收钱的产品、单价、客户数 |
| 资源 | 时间、人、钱、工具 |
| 交付链 | 每个产品从下单到交付经过谁、资产归谁、议价权在哪 |

**三条纪律**：
1. "已收钱 / 已验证"与"备着没动"必须分开列——分量完全不同；
2. 必须盘"人"——人的变动就是资源结构的变动；
3. **缺的数据不许用印象补**——登记进《缺失清单》，标"待定"。

**规矩**：这一栏只写事实，不写判断。

#### ②′ 三句话事实（轻量档专用）

全流程走六类；轻量档只写三句话，但这三句要覆盖三件事：

1. **一个数**——最能说明问题现状的那个量；
2. **一个约束**——人力、时间或钱上不动的那条线；
3. **一条"备着没动"**——手上已有但还没启动的东西。

三句写不出一句，说明还不到能取象的时候，回①重新定题。

### ③ 取象（P1-2）

**观 → 比 → 体 → 化。用比喻不用概念**——"像水管堵了"是象，"流程问题"不是象。

**判据**：能说出这个象是从**哪三条观察**来的。说不出来，多半是臆想。

**硬停点**：每取一个象，先向用户确认"你取的是这个象吗"。**不确认，不往下走。**

#### ③-4 尺子适配检查（v0.5）

取象之前，先问一句：**这件事的答案，是刚性的还是柔性的？**

- **刚性结论**：有确定边界、可复现、可量化。用母结构（五行 / 五维 / 三层）直接量。
- **柔性结论**：只有倾向、没有边界，换个条件就变。**不许用母结构直接量**，只能取象、只能描述可能空间。

**判据**：如果一句话里出现了「决定」「必然」「一定」，先检查它是不是把柔性结论当成了刚性结论。

**失败表现**：遇到量不出的东西硬量——象取出来了，但象跟事实对不上，且怎么调都对不上。

#### ③-5 验象：反向试尺（v0.6 新增，交付档必做）

**做什么**：象取出来、还没往下走之前，拿它去量**三个已经公认做得好的人 / 单 / 店**。

| 试尺结果 | 说明什么 | 怎么改 |
|---|---|---|
| 量出不合格 | 象或尺子错了 | **改尺子，不改人** |
| 量出全合格 | 尺子太松，量不出差别 | **收紧，加一条区分项** |
| 有区分、且与公认判断一致 | 象立住了 | 往下走 |

**判据**：三个样本里有几个能被区分开。**一个都区分不出，这个象是空的。**

**为什么要这一段**：③-4 判的是"这把尺子能不能量这类事"，③-5 判的是"这把尺子量出来准不准"。前者防硬量，后者防空量。**顾问给出去的尺子，客户会拿去定人的薪、定人的去留——尺子错了，代价不由你承担。**

**停下来问人的检查点**：找不到三个公认样本，先问对方"你心里干得最好的三个人是谁"，不许自己指定。

### ④ 抓主要矛盾（P1-3）

四层往下剥：

```
根本矛盾（系统层面，贯穿始终）
    ↓
阶段矛盾（初创 → 扩张 → 成熟 → 转型）
    ↓
主要矛盾 / 次要矛盾（可转化）
    ↓
主要方面 / 次要方面（可转化）
```

**判据**：能写出"什么条件下这个主要矛盾会让位"（转化触发器）。写不出，说明没看清。

**回流**：P1 是循环不是直线。盘点出新的关键事实，就回③重取象。

### ⑤ 展开（P2）

**腿一 · 时间维：五维卦变**

| 维 | 看什么 |
|---|---|
| 本卦 | 现状——我真正站在哪 |
| 变卦 | 趋势——走下去会到哪 |
| 互卦 | 暗流——表面底下推什么 |
| 错卦 | 反面——阴阳全反是什么 |
| 综卦 | 对面——对方看到什么 |

用法：**按量级开维**。轻量档只开本卦 + 变卦；战略决策才五维全开。
实战提示：互卦和错卦出料最多（待校准）——这两个方向是人最难自己想到的。

**腿二 · 空间维：五色光**

| 光 | 频道 |
|---|---|
| 白 | 事实 |
| 蓝 | 风险 |
| 绿 | 可能 |
| 红 | 感受 |
| 黄 | 价值 |

三原则：单色聚焦、序列自由、**强制完整**（不用的要宣布）。
**挂起规则**：某色暂时答不出来，标"待定"并列入【缺失清单】，成为显式悬置项，**不许跳过**。

**两个收口（顺序不能换：先五维定象 → 五色光展开 → 三维测动力 → 金字塔收形）**：
- **三维动力**：信 / 能 / 物，任一维度变动超 ±15%（设计值，待校准）即引发矛盾运动；
- **金字塔**：中心论点 + 3–9 个支撑，MECE。

### ⑥ 验算（P3）

**① 择模配比**：2–4 个模型，按君臣佐使——
君（主攻 1 个）、臣（补盲 1–2 个）、佐（唱反调 0–1 个）、使（翻译成动作 1 个）。
省掉佐等于没有刹车；确实不用佐，要宣布理由。

**② 金线验证**：假设驱动 → 事实验证 → 动态执行 → 市场检验。

**③ 三条刻度**：
- **约束**（资源 / 周期 / 红线）——不过，方案不成立，直接说；
- **代价**（钱 / 时间 / 关系 / 能量四本账）——算不清，方案不可比；
- **可逆性**——可逆的快做，不可逆的慢做。

**回流规则**：验算结果跟象对不上，**回③重取象**。

### ⑦ 落子（P4）

**① 成器**：把结论压成动作。每个动作必须过五要素模板：

> **谁** ＋ **明早/具体时点** ＋ **做什么（动词开头）** ＋ **产出什么** ＋ **怎么算完成（可观察）**

没有动作，说明前面有一步是虚的。

**② 排次第**：从最外显、最容易动手、最快收到反馈的那件起手（待校准）。

**③ 预约复盘**：落子时必须约定——**哪天、看哪个数、跟谁复盘**。不预约，实践论闭环不会发生。

**④ 立规（v0.6 新增，交付档必做）**：动作要由一群人重复执行时，必须同时立四条规矩，否则动作活不过一周。

| # | 立什么 | 写法 | 反例 |
|---|---|---|---|
| 1 | **谁拍板** | 按事情量级分档，一档一个拍板人 | "大家一起商量" |
| 2 | **什么时候必须上报** | 写死时限（如 24 小时）与触发条件 | "有问题随时沟通" |
| 3 | **分歧怎么走** | 走机制，不走情绪；写清几轮、谁仲裁 | "开会讨论一下" |
| 4 | **怎么算完成** | 产出物 + 可观察判据 | "抓紧落实" |

**判据**：四条里有一条写不出具体动作，说明这条规则是空的，删掉重写。

**停下来问人的检查点**：规则要动别人的钱、岗、权，先问拍板人，不先宣布。

### ⑧ 交付物（v0.6 新增，交付档必做）

**做什么**：把结论装成对方能自己跑的东西，而不是一份"建议"。

**四种交付物，按对方成熟度选**：

| 交付物 | 给谁 | 特征 |
|---|---|---|
| **一页说明** | 老板、决策层 | 一句话结论 + 只做几件事 + 时间表，不超过一页 |
| **规则条文** | 执行层 | 带门禁、带判据、带"判不了怎么办" |
| **工具表** | 一线 | 能填、能查、能对账，不要求理解原理 |
| **判据清单** | 复核者 | 每一条都能验，验不过就退回 |

**三条硬要求**：
1. **每条结论都要能追到②的一个事实**——追不到，删；
2. **判不了就写"判不了"**——写清缺哪个字段，不许降级凑结论；
3. **交付物里不出现体系名**——对方要的是能用的东西，不是你的框架。

**判据**：交付物交出去，你不在场，对方能不能照着跑完一轮。跑不完，回去改⑦-4。

## 四、输出格式

全流程走完，按此模板输出：

```
【接单】管哪一层 / 验什么 / 考验期（交付档）
【定题】一句话问题
【象】一句话的象 + 三条支撑观察
【验象】反向试尺三个样本的区分结果（交付档）
【主要矛盾】根本 / 阶段 / 主要 + 转化触发器
【展开】时间维（开了几维、每维看到什么）
        空间维（五色光，含待定项）
【验证】配了哪几味模型、三条刻度验算结果
【动作】明早能做的 1–3 件（五要素模板），按次第排
【规矩】谁拍板 / 何时上报 / 分歧怎么走 / 怎么算完成（交付档）
【复盘预约】哪天 / 看哪个数 / 跟谁
【缺失清单】数据缺口与待定项
【置信度】哪几步是验证过的，哪几步是推演的
```

轻量档只输出：【定题】【象】【主要矛盾】【动作】【复盘预约】。

## 五、整合协议

**输出给谁**：
- 给用户 → 按上面模板；
- 给下一个 Skill（创作 / 总结等）→ 只传【定题】【象】【动作】三块；
- **给客户 → 走⑧，只传交付物本身，不传过程。**

**接谁的输出**：
- 接用户的事实盘点 → 进②盘点；
- 接其他 Skill 的分析结论 → 当"事实"用，但标注来源，不许当"验证"用。

**节奏控制（防 AI 一口气跑完）**：
- 全流程至少分三轮对话：第一轮 ①②（定题＋盘点）→ 第二轮 ③④（取象确认＋矛盾）→ 第三轮 ⑤⑥⑦（展开＋验算＋落子）；
- **取象确认是硬停点**；轻量档也必须在落子前把象复述给用户确认一次；
- **交付档再加一轮**：⑧交付物单独一轮，不复述分析过程。

## 六、失败模式

| 失败模式 | 表现 | 怎么防 |
|---|---|---|
| 以象代证 | 把"我觉得像"当结论 | ③强制"象的三条支撑观察" |
| 跳过取象 | 直接上模型 | ②③顺序不能换，取象未确认不许进⑤ |
| 以象代全 | 五色光漏掉某一色 | 强制完整，不用的要宣布 |
| 假完整 | 某色答不出来就跳过 | 挂起规则：标"待定"入缺失清单 |
| 数据编造 | 缺数时用印象补 | ②三条纪律第 3 条：缺项显式登记，宁可空着 |
| 零盘点取象 | 轻量档跳过盘点直接取象 | ②′三句话事实为轻量档必填项 |
| 只走本卦 | 停在"现状＋趋势" | 全流程强制开互卦和错卦 |
| 动作悬空 | 走完没有动作 | ⑦五要素模板，不过关不出 |
| 无优先级 | 给了动作不知先干哪个 | ⑦排次第：最外显、最快反馈起手 |
| 一人独象 | AI 取象未确认就往下跑 | 硬停点：不确认，不往下走 |
| 无复盘 | 落完子没人回头看 | ⑦预约复盘是必填项 |
| 顺从陷阱 | AI 一路顺畅执行，不说"不适用" | 每步设检查点；发现射程外直接说 |
| **硬量软事** | 用母结构去量只有倾向、没有边界的事，象跟事实怎么调都对不上 | ③-4 尺子适配检查：先判刚性/柔性，柔性只取象不量 |
| **空量**（v0.6） | 象取出来了，但拿它量谁都一样，区分不出好坏 | ③-5 反向试尺：三个公认样本，一个都区分不出就是空象 |
| **接单失焦**（v0.6） | 没定管哪一层就进场，跟另一套人打架 | ⓪ 接单说明：管哪层 / 验什么 / 考验期，三条写不出不接 |

## 七、自我进化机制（本 Skill 是开放的，不是封闭的）

### 7.1 三个进化入口

**入口一 · 置信度标注**：每步结论标三档——已验证 / 推演 / 设计值。用户实践中验证了某条"推演"，就升级为"已验证"。

**入口二 · 失败记录**：每次走完问一句"哪一步卡住了？"卡点写进 §六。同一类卡点出现三次，升级为新规则。

**入口三 · 阈值校准**：
所有阈值（±15%、一致性线、九成线等）都是设计初值，要用实测数据往回校。

**"一致性"怎么算——回看六项清单（v0.6 由五项扩为六项）**

预约复盘那天，翻出当次留下的输出，逐项判对错：

| # | 回看项 | 判对的标志 |
|---|---|---|
| 1 | 象成立吗 | 事情确实像取出来的那个象 |
| 2 | 主要矛盾抓对了吗 | 动了它，问题真的松动了 |
| 3 | 转化触发器应验了吗 | 触发条件发生了，矛盾按预判让位 |
| 4 | 动作真推进了吗 | 五要素的动作确实做了 |
| 5 | 动作解决问题了吗 | 复盘时那个数朝预期方向动了 |
| **6** | **规矩立住了吗**（交付档） | **没人拍板的事没发生、该上报的都上报了** |

**一致性 = 通过项数 ÷ 5**（交付档 ÷ 6）。
**没做复盘的轮次不计入统计**——没有回看就没有数据，不许估。

**校准规则**：
- 连续两次一致性 ≥ 90%（即两次都 5/5）→ 阈值下调 5%；
- 连续两次一致性 < 60%（≤3 项通过）→ 阈值上调 10%，并触发规则审查。

第 2、5、6 项是"实项"（事实说话），第 1、3、4 项是"虚项"（判断与执行）。**只有实项通过、虚项常挂**，说明象取得花哨、动作落得虚，先审③和⑦，不要急着调阈值。

### 7.2 版本管理

- 每完成一轮实战验证，版本号 +0.1；
- 已发布内容被推翻，**不静默修改**——写入修订记录，写明原表述与修正原因；
- 理由：一个靠数据回流自我修正的系统，如果自己的规则是一次性定稿的，本身就是对自己主张的反驳。

### 7.3 抗顺从约束（硬约束，写给 AI）

**判据**：如果这套方法从来没让用户不舒服过，它要么没起作用，要么你们在回音室里。

写死三条：
1. 允许指出用户不爱听的——象跟事实不符、假设站不住，直接说；
2. 每步设"何时该停下来问人"的检查点，不许一路顺畅跑完；
3. 不许用"我觉得像"替代证据。

**v0.6 加一条**：
4. **交付档里，凡是要动别人钱、岗、权的规则，必须提示"这条会得罪人"，不许只讲好处。**

## 十、v0.6 新增段的实战来源（案例 C · 交付型）

> 前两个案例是"想清楚"（修正型、生成型）。v0.6 补的是第三种：**想清楚之后，还要让别人照着跑起来。**

### ⓪ 接单（回魏，2026-11-07/08）

- **管哪一层**：明说"我管道，黄老师管术，不短于一年，我基本只跟两位创始人沟通"；
- **验什么**：一年后要有三样——一套自有话语体系、一批认同的人、一个不依赖任何个人的机制；
- **考验期**：11/8–11/26 每天打卡，26 日晚一条语音即算完成；"我给一个月时间，OK 继续，不 OK 再说"。

**关键动作**：把"验什么"写成了三条可观察的，而不是"提升管理水平"。

### ③-5 验象（味藏岗位标准，2026-10-30）

标准建好当场，先拿它去量**两三个在岗且公认干得好的人**：

- 量出不合格 → **改尺子，不改人**；
- 量出全合格 → 标准太松，收紧。

**为什么必须试**：标准一建好就会立刻被拿去招聘和考核，而它还没被验证过。**拿没验过的尺子去定人的薪，是最容易结仇的一步。**

### ⑦-4 立规（味藏集体决策 + 回魏四条规则）

- **谁拍板**：按 S/T/D 三档定级，一档一个拍板人；董事长不进决策小组、不参加讨论投票（防揣摩）；
- **何时上报**：材料递上去 3 天不回视为同意，可直接执行；卡住 24 小时必须上报；
- **分歧怎么走**：报备 → 数据 → 集体讨论 → 记名投票 → 一人拍板；平票不急着找老板，先定向再投一次；
- **怎么算完成**：谁提的事谁干，24 小时拆步骤，到期验产出。

**核心判据**：不是人不行，是没规矩。**"运行不正常先查结构，靠罚是没用的。"**

### ⑧ 交付物（味藏四件套）

| 交付物 | 实例 | 特征 |
|---|---|---|
| 一页说明 | 11 月工作执行方案 | 一句话 + 只做两件事 + 时间表 |
| 规则条文 | 集体决策管理制度 v3.0 | 带三档定级、带门禁 |
| 工具表 | 水单 14 个动作、三签制 | 一线能填能对账 |
| 判据清单 | 水单诊断门禁四道 | 每道有判据、有谁来验 |

**最硬的一条**：水单手册里写"判不了就写'判不了'"——缺字段导致结论不成立时，输出"本单此项无法判定，缺 XX 字段"，**不降级凑结论**。

### 案例 C 的启示

前两个案例证明这套方法**能想清楚**；案例 C 证明它**能交出去**。

想清楚和交出去之间，差三段：**先验人（⓪）、再验尺（③-5）、最后立规（⑦-4）**。三段都不做，方法论再漂亮，也只是一份"建议"。
