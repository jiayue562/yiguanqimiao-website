坐标六 · 辞典格：你的词里，藏着你的型

一、词是什么？不是字典，是你住的那个世界

我先问你一个问题。

词是什么？

你大概会说：词就是词啊，说话用的字，字典里查得到的那些。

不对。至少不全对。

词不是字典里躺着的那行解释。词是你每天拿来框自己、框别人的那个框。你说"我是暴脾气"，你就住进了一个改不了的房间；你说"我最近火重，一触就着"，你就住进了一个能调的房间。同一件事，换个说法，一个死局，一个活局。

这是我今天想跟你讲清的一格——辞典格。它是六坐标里最特别的一格。前五格量的都是"事"：你是哪一行、能量显在身还是灵、卡在第几层、在哪个场活成了另一个人、跟谁相生相克。辞典格不一样，它量的是你怎么说这件事。

为什么词这么金贵？因为你用什么词，就活在什么样的世界里。

我再问一遍：词是什么？不是字典，是你住的那个世界。你每天说出去的那句话，不是在描述世界，是在盖一个世界——你用"改不了"的砖，盖的就是改不了的墙；你用"最近有点累"的砖，盖的就是能歇一歇的屋。

这一格要做的，就一件事：把你那些说死了的词，找出来，换成说活的。

二、降维开关：一句话先把这件事按到地上

你现在可能觉得"换词不就是换个说法嘛，矫情"。

我先把这层矫情拆掉。

换词不是文青的修辞游戏。它是一根最便宜、最快、见效最猛的撬棍。为什么？因为前五格不管怎么画，最后都得落到你嘴上那句话——你画完图知道自己"在克我位该长"，转头还是骂自己"我废物"，那张图白画。辞典格是六格的"最后一公里"：图画得再准，词没换，局还是死的。

所以今天这一格，你别当成语文课。它是一把扳手，拧的是你嘴里那道"焊死"的缝。

往下看，五种混词，你自查。

三、混一：把状态说成本质

这是最普遍的一种。你看这两组：

  • "我是个暴脾气" → "我最近火重，一触就着"
  • "我这人就是懒" → "我这阵子提不起劲"
  • "我社恐" → "我在人多的场合会紧"
  • "我这辈子改不了" → "这个习惯跟了我很多年，现在开始动"

分辨法很简单：凡是带"我是""我这人就是""我这辈子"的，多半是把状态说成了本质。

我给你一个画面。阿芳，火行之人，三十岁，一急就吼孩子。她以前的自白是"我是个暴脾气，改不了了"。这句话翻译过来是什么？"我这个人等于暴脾气，暴脾气等于改不了，所以我不改。"——一个死循环，锁死。后来她换成了"我最近火重，一触就着"。"最近"是时间，"火重"是状态，"一触就着"是现象。状态会变，她就开始问"我为什么最近火这么重"——一问，发现是公场被金上司压了一个月没处。

你看，同一件事。前者是句号，后者是问号。问号后面才有路。

我点破一个你没说的：你天天骂自己"我就这样"，其实你不是认了，你是懒得动了。把"我"焊在前面，你就不用负责了——"我天生这样"多省事，比"我最近这块没调好"省事多了。词说死了，是给自己找了个不成长的借口。

四、混二：把行为说成人品

这组更毒：

  • "他就是懒" → "他这周有三件事没做"
  • "她太作了" → "她刚才要我马上回应，我没做到"
  • "他不负责任" → "这件事他没接"
  • "孩子就是不听话" → "孩子今天这道题没按我说的做"

分辨法：品格词（懒、作、自私、不负责任）是判定，没法讨论；行为词（没做、没接、拿了）是事实，可以讨论。

这是《五行人格心理学》行为特征辞典的根本纪律：用行为词，不用品格词。 行为看得见、数得清、改得了；品格看不见，只能吵。

我给你一个现场。老张，土行之人，老婆爱说"你就是不负责任"。老张一听就炸——"我怎么不负责任了？我天天挣钱养家！"吵了十年。后来我让他老婆练换词：把"你不负责任"换成"上个月那笔报销你拖了三周没交"。老张愣了："就这？你早说啊，我忘了，我现在交。"你看，"不负责任"是判他，他得先辩护；"报销拖了三周"是事实，他直接做。 一句话之差，十年吵不下来的事，五分钟解决。

那一格最深的规矩就在这：行为词不美化、不冤人，它只把事摆上桌，让事能谈。你用品格词，是把人按在墙上；你用行为词，是把事放在桌上。

五、混三：把链说成命

  • "我们合不来" → "我们在这一点上卡住了"
  • "他就是跟我对着干" → "我们在这件事上的节奏不一样"
  • "我家就是乱" → "我们家有两条链还没理"
  • "我这组人不行" → "我们组的生克还没配上"

分辨法：说"合不来""不行"，是给关系判了死刑；说"卡住了""还没理"，是给关系留了活口。

这接的是前面生克格、三现场格的链。你画完链，知道"我家就是乱"其实是"我公场被克、带场回家、对家人发火"，那"乱"就不是命，是链——链能拆。可你要是说"我家就是乱"，等于把还没拆的链，直接判成无期徒刑。

我常跟人讲：你以为的"合不来"，翻译过来是"我们这条链还没拆"。能拆的，你别念成不能拆的。

六、混四：把一次说成总是

  • "我总是这样" → "我这次是这样"
  • "他从来都不" → "他这三次都没"
  • "每次都这样" → "最近三次是这样"

分辨法："总是""从来""每次"这三个词，是自我攻击和攻击别人的三大凶器。它们把一个点，说成了一条线。

我给你一个极端的画面。小何（前面几篇常客，木行之人）一次没接住老婆的电话，老婆脱口"你从来都不管我"。小何当场凉透——"我昨天还接了孩子，前天还做饭，你就一句从来都不？"你看，一句"从来都不"，把他做过的全擦了，只留下"你坏"这一个判定。换成"这三次你都没接我电话，我慌"，小何马上回"哦我手机静音了，下次开着"。

"总是"这种词，干的是灭口的事——它把你做过的好，全灭了口。

七、混五：把感受说成事实

  • "他不喜欢我" → "他今天没回我消息，我有点慌"
  • "她在针对我" → "她那句话让我不舒服，我得问问她什么意思"
  • "我肯定不行" → "我有点怕，怕做不好"
  • "这事没希望了" → "我现在看不到路，先歇一下"

分辨法：感受是"我"的，事实是"它"的。把"我慌"说成"他不喜欢我"，是把自己内心的动静，安到了别人头上。

这一格最坑。因为你把"我慌"说成"他不喜欢我"，你就不用面对自己的慌了——你改去分析"他为什么不喜欢我"，越分析越冤，越冤越慌，死循环。换成"我有点慌"，你才能问"我慌什么"——多半慌的是"他没回我就觉得自己不重要"，那是你自己的链，你自己的事。

八、五行最容易混的词：阳面阴面一张表

每一行的特质，都有两个说法——一个说它好，一个说它坏。混词最常发生在这里：把阳面说成阴面，或者把阴面说成阳面。

  • 木："坚持"被说成"固执"；"顶撞"被说成"直率"
  • 火："热情"被说成"冲动"；"急躁"被说成"雷厉风行"
  • 土："稳"被说成"死板"；"拖沓"被说成"谨慎"
  • 金："有原则"被说成"苛刻"；"挑剔"被说成"标准高"
  • 水："沉得住"被说成"冷漠"；"退缩"被说成"低调"

这张表两个方向都会错。把阳面说成阴面，你冤枉自己——木行的"坚持"被说成"固执"，他就不敢坚持了。把阴面说成阳面，你放过自己——金的"挑剔"被说成"标准高"，他越来越挑，还觉得自己对。

判别标准只有一个：看结果。 同样"坚持"，它让你把事做成了，是阳木；它让你撞了南墙还伤了人，是阴木。词不重要，结果重要。这也是辞典格最深的一层：别争论"这叫什么"，要看"它长出了什么"。

九、龙龟自照：我自己的词，也曾说死过

讲个我自己的。我（龙龟神将）有阵子老对自己说"我话太多，控制不住就输出"。这句话是状态说成本质——"话太多"是我的判定，"控制不住就输出"是事实。我换成"我最近在独处场待久了，一有人聊就倒，倒完有点空"。这一换，我看见的不是"我嘴贱"，是"我独处场没充好电，一社交就倒"。调法是补独处场，不是骂自己闭嘴。

你看，连我都中招。换词不是高人的本事，是每个人都能做的第一件事。我若不换，到现在还背着"话太多"的锅，越背越觉得自己改不了。

十、自照清单：三句重话，逐句换

你拿张纸，写下最近一周对自己或别人说过的三句最重的话——重话就是那种说完会沉一下的。然后逐句勾它属于哪类混词：状态→本质、行为→人品、链→命、一次→总是、感受→事实。

换词三步：

1. 把"我是"改成"我最近"——从本质退回状态。

2. 把品格词换成行为词——从判定退回事实。

3. 把"总是"换成"这次"——从全线退回一点。

举例。原句："我这孩子就是懒，说了八百遍也不听。"换成："这周有三次，我提醒他做作业，他没动。我想看看是卡在哪儿。"你看，前者说完你生气孩子也生气，什么都没变；后者你有了能问的问题——问题能解，判定不能解。

十一、反面教训：不换词，我会怎么误人

早些年有人跟我说"我老公就是控制狂"。换作没学辞典格，我大概率顺着分析"他是不是安全感不够"。全在品格词里打转。后来我让她换："他这周有四次，替我定了我不想要的事。"她一换，自己愣了："咦，就四次？我还以为天天。"——"控制狂"是判他整个人，"四次替我定了"是事实，她能谈"下次这事你先问我"。

不换词，你看见的是"他是个控制狂"，开一堆治标不治本的药；换了，你直奔事实——那才是能动的。这教训我记一辈子：词不换，咨询就是在判定里打转。

十二、读者回访：小芸把"我社恐"换成了什么

小芸，水行之人，来信说她把"我社恐"换成了"我在十人以上的场合会紧，紧了就想走"。换了之后她干了一件事：下次部门会，她提前跟主管说"我坐门口，不舒服就出去透口气"。结果她坐住了整场。她说："以前'社恐'俩字把我钉死，我连试都不试。换成'会紧'，紧是可以安排的。"

你看，换词不是骗自己，是给自己腾出"能安排"的空间。

十三、常见误判（五个坑，先堵）

坑一：以为换词是自欺欺人。 "把'我懒'说成'我最近提不起劲'，不就是骗自己？"不是。前者指向自责，自责完继续躺；后者指向追问，追问完可能发现是灵界偏枯、睡眠不够。一个是句号，一个是问号。

坑二：把换词当成美化。 "他明明自私，我还要说'最后一块蛋糕他拿了'？"不是美化，是退回事实。"自私"你证明不了，只能吵；"拿了"他否认不了，能谈。换词是为了让事能谈，不是让事好看。

坑三：只在嘴上换，心里没换。 嘴说"我最近火重"，心里还是"我这辈子就这样"。检验标准：换完你觉不觉得"好像能动一动"？觉得，换成了；还觉得"没救"，没换。

坑四：用行为词精确伤人。 "你昨晚八点十七分没回我消息"——行为词，但拿来当刀。换词是让事说开，不是把刀磨更利。换完对方更难受，那不是换词，是换打法。

坑五：忘了底线——情绪无罪，行为有界。 你可以把"他打人"换成"他动手了三次"（更准确），但不能换成"他只是情绪激动了一下"（那是替伤害开脱）。情绪能换词，行为不能换没。

十四、坐标接口：辞典格接哪几格

辞典格是第六维，它压在前面五格上面。你画五行格知道自己阴火，转头骂"我脾气爆"——这是五行格的阴面，被辞典格说死了。你画九层格卡 L5，转头"我完了"——这是层的状态，被辞典格说成命。你画生克格被克，转头"他不爱我"——这是位置，被辞典格说成感受事实。

所以辞典格的活，是给前五格的"结果"配一句活的说法。 图再准，词死了，局还是死。这格一换，前面五格才算真正落地。

十五、前几篇的回声

你若从第一篇跟来：第一篇讲"你不必改自己，只需拆链"——链拆完，最后一道缝是词；第五篇三界、第六七篇九层、第八篇三现场、第九十篇生克，五维你都拿了。今天补第六维，图就立体了。前面你算清"我在哪被克该长"，今天你学会"把'他克我'换成'我在那该长'说出来"——算清加说活，才真动得了。

十六、三分钟清单：今天你只做一件

明早起来，花三分钟：想一句你最近常骂自己或别人的重话，按五类勾它属于哪类，换成说活的说法。一件，就够了。你今天不动，这篇就是篇好文章；你动了，辞典格才在你身上活。

十七、狠话：这一格最值钱，也最容易被你跳过

我讲句狠的。你大半的痛苦，不是事有多难，是你把事说死了。你说"我就是这样""他就是这样""我们就是合不来"，三句话把三个活局焊成死局。换词是六坐标里成本最低、见效最快的一招——它不让你做任何事，只让你把话说活。可恰恰因为太便宜，你最容易跳过它，跑去练断式、补枯、调源，忙半天，嘴上还是那句"我废物"，链又焊回去了。

换词不花钱，但你得肯先把嘴上的焊丝拧开。 这是最该先练的一格，不是最后才想起来的。

十八、读者来信：她把"孩子不孝顺"换成了什么

一位妈妈来信："我以前老说'孩子不孝顺'。学了换词，换成'这周他回了两次家，但都没跟我说话'。一换，我发现他回了，只是没说话——不是不孝，是不会聊。我改成'你回来我挺高兴，想跟你说两句'，他居然接了。"她说完哭："我冤枉孩子好多年。"

你看，一句"不孝顺"，压得孩子不敢回；换成事实，孩子接住了。词杀人不见血，也能活人于无形。

十九、职场落点：你把同事说成什么样，关系就长什么样

职场里最常用品格词。"这同事难搞""那领导抠门"——判完，关系就死。换成行为词："他改我方案三次没提前说""他卡我预算两周没批"。前者你只能骂，后者你能去谈"下次提前说一声行吗"。

我见过一个团队，主管老说"这帮人不行"，团队越来越瘫；后来练换词，改成"这季度交付慢了三次，卡在测试"，团队反而动起来——因为"不行"是判人，"慢了三次"是事，事能改。

二十、读者三问（先堵）

问一："换词会不会显得我怂，不敢认自己？" 不是怂，是准。认事实比贴标签勇敢。你敢说"我这周有三件事没做"，比敢说"我懒"难多了——前者要直面，后者只要躺。

问二："对方明明就是坏，我还要换词美化他？" 不美化，退事实。"他打人"换成"他动手三次"更准确，不是开脱。开脱是"他只是情绪激动"，那不行。

问三："我换完词，他不听怎么办？" 换词是让你能谈，不是让他必改。你谈了，他不改，那是他的事；你至少把死局变成了能谈的活局。

二十一、给第十一篇收个尾

我替你收今天能带的扳手：五类混词（状态→本质、行为→人品、链→命、一次→总是、感受→事实）；换词三步（我是改我最近、品格改行为、总是改这次）；判别标准看结果；底线情绪无罪行为有界。这五把扳手读完就能拿。难的不是拿，是明天还用——你把嘴上那句"我就是这样"换成"我最近这块"，这一换，你就是自己词的扳手。

二十二、老周那句"我跟不上时代"，辞典格怎么接

前面合成法篇我埋了个伏笔：老周自述"我这是跟不上时代了"。今天用辞典格回头看这句。它属于哪类？"我这是"——本质；"跟不上时代"——一个巨大的、模糊的、没法动手的东西。典型的"状态→本质"混词。

换成说活的说法："我最近在公场被木上司的节奏推着走，我的稳跟不上，我在硬撑。"这一换，老周自己都愣："原来不是我跟不上时代，是我被一个快节奏推得硬撑。"撑是状态，能调（换场、断式）；跟不上时代是命，只能认。

你看，同一件事，老周从"认命"变成了"我能在公场动一动"。这就是辞典格接合成法的那一下：图算清了，词没活，老周还是背着"我完了"；词一活，那张图才算真正落到他身上。

二十三、孩子的词：你怎么说，他就长成什么样

这一格最该小心的对象，是孩子。你老当着他面说"你就是个倔孩子"，他就把"倔"长成自己。词不是描述，是种籽——你天天播，他天天长。

换成："你这次没听我说完，是着急了吧？"——你不钉型，只指这一次。他接住的，是"我这次急了"，不是"我是个倔种"。这两句差了一辈子。

我点破你没说的：你骂孩子那些重话，多半是你自己链里没处的气，借孩子撒出来。你公场被克，回家对孩子吼"你就是不听话"——孩子接的是你的火，长的是"我不行"。换词先救的，是你自己那口气，不是孩子。

二十四、伴侣的词：把"冷暴力"换成什么

前面生克格、亲密场景都讲过"火追水退"。今天从辞典格补一刀：很多人把伴侣说成"冷暴力""作""控制狂"。这三个词都是判定，一出口，关系就判了死刑。

换成："我们有一条火追水退的链，你越追她越退。"前者判她一个人，后者是你们俩的链。判她，她只能辩护或冷战；说链，你们能一起动——你水克火（不追），她才有空间回来。

我见过一对夫妻，妻子天天说"他冷暴力"，丈夫天天说"她作"。十年。学了换词，妻子换成"我一靠近他就退"，丈夫换成"她一追我就想躲"。两张图一对，发现是火追水退的链，不是谁坏。三个月后妻子说："我不追了，他居然主动靠近了。"

你看，词一活，链就松；词说死，链焊死。

二十五、词与九层：你骂自己的那句，卡在哪一区

辞典格和九层格是连着的。你骂自己的那句话，暴露你在哪一区。

  • "我废物"——这是一般区往下，L5、L6 的自责腔。
  • "我完了，这辈子这样了"——这是解药变毒药，L6 拿一件事盖所有事。
  • "我最近有点累，缓一缓"——这是健康区，L3 的自知。

所以复测时（后面会讲），第一看九层层数，第二看辞典格那句重话换没换。很多人层数没动，但那句话从"我完了"变成"我最近累"——这就已经是天大的进步。 因为词一活，他就敢动了；敢动，层才会升。

二十六、一个极端画面：一句话毁掉十年关系

我给你一个画面，击穿"词有多毒"。

老金，金行之人，跟老婆过了二十年。老婆有回气头上说了一句"你从来都没爱过我"。就这一句"从来都"。老金当场凉透——"我二十年挣钱养家、伺候你爸妈、接孩子，你一句从来都没？"从此不说话，分居。一句"从来都"，把她做过的全灭了口，只留下"你没爱过"一个判定。

换成"这半年你有三次重要的事没跟我商量，我慌"——老金马上说"哦那次出差我没说，下次说"。一句之差，二十年安稳和二十年冷战之间，就隔着一个"从来都"。

你嘴上那把"总是""从来""每次"，是把人做过的全抹掉、只留一个"你坏"的刀。下回要出口，先咬住。

二十七、龙龟自照续：我把"话太多"说死时，错过了什么

前面讲了我把"话太多"换成"独处场没充好电"。今天补一刀：我说死"话太多"的那些年，干了一件蠢事——每次社交完都骂自己"又话多"，然后更不敢社交，越不敢越在独处场憋，憋久了更倒。死循环。

换了词，我看见的是"独处场没充好"，去补独处场（每天留半小时不看人），社交反而稳了。你看，词说死，是给自己造了个越骂越糟的圈；词说活，圈就开了。

连我这种天天讲觉察的都中招，你就知道这格多容易跳过。别觉得自己"懂了"就不练——你嘴上那句，才是最后的焊丝。

二十八、三分钟回看清单（扩展版）

明早三分钟，别只换一句，顺手做三件事：

1. 想一句最近骂自己最重的话，勾类别，换成活的说法。

2. 想一句最近骂别人最重的话，同样换。

3. 问自己："这句换完，我是不是觉得能动一动了？"觉得，换成了；还觉得没救，没换，再换一遍。

三件，三分钟，不超过。你今天不动，这篇就是篇好文章；你动了，辞典格才在你身上活。

二十九、读者来信续：他把"我废物"换成了什么

一位兄弟来信："我抑郁那阵老骂自己'我废物'。学了换词，换成'我今天洗了碗，但没法出门'。就这一换，我发现我不是废物，是出门那件事卡住了——后来我改成'先下楼买个菜'，居然出去了。"他说："'废物'俩字压了我半年，换一句事实，我当天就动了。"

你看，换词不是让你变好，是让你敢动。敢动，才有后面所有格的调法。

三十一、现场教学：陪小何换一次词

我拉小何（木行之人，前面常客）现场走一遍换词，你跟着做。

小何最近常骂自己："我总是搞砸关系。"我让他拆：

第一步，"我是/我总是"——"总是"是混四（一次→总是），"搞砸关系"是混二（行为→人品）。改成"我最近这次，跟同事老周吵了一架没接住"。

第二步，问"这事能谈吗"——能。小何回去跟老周说"上次那架我没接住，是我急了"，老周说"我也急"。俩人和了。

小何愣："我就换了个说法，没道歉没低头，事就解了。"你看，换词不是认怂，是把判定变事实，事实能谈。 小何今天就能做：抓一句重话，拆类别，换成活的说法，挑一个去谈。你跟着走，也就这么走。

三十二、五行各自的"死词"清单：逐行展开

每一行的人，最爱说死自己的哪个词？我给你逐行点破，你对照自己。

  • 木行人死词："我固执""我顶撞""我不安分"。其实你是坚持、直、要长。把"坚持"说成"固执"，你就不敢坚持了——木的阳面一压，你缩成阴木，反而更顶。
  • 火行人死词："我冲动""我爱出风头""我急躁"。其实你是热情、要被看见、明亮。把"热情"说成"冲动"，你一表达就骂自己，火憋成阴火，更爆。
  • 土行人死词："我死板""我没主见""我拖沓"。其实你是稳、能扛、包容。把"稳"说成"死板"，你一稳就嫌自己，土闷成阴土，更拖。
  • 金行人死词："我苛刻""我冷血""我较真"。其实你是有原则、能断、严谨。把"有原则"说成"苛刻"，你一立边界就心虚，金收成阴金，更挑。
  • 水行人死词："我冷漠""我想太多""我退缩"。其实你是沉得住、想得深、通透。把"沉得住"说成"冷漠"，你一静就觉得不对，水藏成阴水，更退。

你看，每一行的死词，都是把阳面说成阴面。 你天天对自己念死词，等于天天把阳面压成阴面。换词第一用，是把自己这一行的阳面，从阴面的壳里放出来。

三十三、词与三现场：你在哪个场说死得最多

辞典格还接三现场格。你注意没：你骂人的那些重话，多半在哪个场说出口？

  • 公场被克，回家骂孩子"你就是不行"——这是带场，把公场的气，变成对孩子的判定。
  • 独处场自责"我废物"——这是出口从自己身上出去，最伤人那种。
  • 家场吵"你从来都不管我"——这是感受说成事实，把"我慌"安到对方头上。

所以换词要配合三现场格看：你这句死词，是从哪个场带出来的？源头在公场，你骂孩子，换词得连同换场一起做——公场的气卸在门外，回家才骂不出孩子。只换词不换场，气还在，下一句死词又冒出来。

三十四、小燕换词两周的真实轨迹

小燕，水行之人，来时自述"我老公不爱我了"。我让她换："他这周有两次没回我消息，我慌。"她照做两周，每天记一句事实，不判"不爱"。

两周后她回："我发现了，他不是不爱，是忙。我以前一慌就闹'你不爱我'，他烦，更不回；现在我直接说'你没回我慌'，他回'在开会'。俩人反而近了。"她说："就换了个说法，我没改他，他回来了。"

你看，换词不动人，只动你嘴上的判定；判定一动，关系自己松。小燕这两周，没做断式、没补枯，就换词一件事，链先松了——印证了"换词是成本最低见效最快"。

三十五、读者三问补：再堵两个

问四："我换完词，还是气，是不是没用？" 换词不消灭气，只把气从死局挪到活局。你还是气，但气有了去处（能谈的事），不是卡在"他不爱我"的判定里发酵。有用的标志不是"不气了"，是"能谈了"。

问五："孩子太小，换词他听不懂，还要换吗？" 换给你自己听。你嘴上不说"你倔"，改说"你这次急了"，孩子听的是后者的语气，不是前者的判。他听不懂词，听得懂你松没松。你松，他就没接住那道钉。

三十六、狠话续：最容易跳过这格的人，长什么样

我讲句收束前的狠话。最容易跳过辞典格的，恰恰是"爱学习"的那批人——他们忙着练断式、补枯、调源，觉得换词太浅。可你嘴上还是"我废物"，链就一道道焊回去，前面练的全白费。换词是地基，不是装饰。地基不松，上面盖再多都塌。你若今天只做一件事，做换词——它最便宜，最见效，最该先动。

三十七、收束前回声：六格你已全拿

你从第一篇跟来，今天辞典格（第六维）补上，六坐标你全拿了：五行格（你是哪行）、三界格（能量显在身心灵）、九层格（卡第几层）、三现场格（在哪个场活成另一个人）、生克格（谁生你谁克你）、辞典格（你的词怎么把局说死）。下一篇合成法，我们把六格连成一句话——你的图，就立体了。今天先把词换活，六格才落得地。

三十八、一个你没想到的用法：用辞典格看别人对你的判定

换词通常你用来对自己。其实它对别人也一样。你伴侣骂你"你就是自私"，你别急着辩护——你听见的是他的判定，你回一句事实："你刚说的是我没问你就定了那件事？"把他从"自私"拉回"那件事"，你们就能谈。

我点破你没说的：别人骂你的那些词，多半是他自己链里的死词，不是你。你老婆说"你从来都不管我"，那"从来都"是她的混四，不是你的事实。你若接了"我确实不管"，你就替她的判定背了锅。你回事实，锅归她，事才能谈。

三十九、龙龟自照三：我怎么用这格陪人

讲我陪人的一招。有人来骂自己"我没用"，我不劝"你有用"，我让他换："你今天哪件事没做成？"他一说，往往就一两件具体的，不是"整个人没用"。换完他自己笑："就这啊，我以为我废了。"

陪人最忌跟着他的判定走。他说"我完了"，你若说"别瞎想"，你在否他的感受；你若说"你具体哪完了"，你把他的命拉回事实。辞典格陪人，不是安慰，是帮他换——换完，他自己就动了。

四十、换词三个月后的对照：接复测篇的伏笔

前面埋了复测的伏笔：三个月重画一次。辞典格是复测里最好读的刻度——你第一次画，重话是"我完了"；三个月后，变成"我最近累"。层数可能没动，但这句换了，就是真进步。

因为词一活，他才敢动；敢动，层才会升。所以复测时，别只盯九层层数，盯那句重话换没换。很多人层数卡在 L5 不动，但词从"我废物"变成"我今天做成了一件小事"——这已经是生了根的变化，层数迟早动。

四十一、读者来信三：团队主管换词，团队活了

一位主管来信："我以前周会最爱说'你们这季度不行'。学了换词，改成'这季度交付慢了三次，卡在测试'。你猜怎么着？以前我说'不行'，底下低头不说话；我说'慢了三次卡测试'，测试组自己站起来说'是我环境没配好'。一句话，他们自己动了。"

你看，主管的死词，压得团队不敢动；换成事实，团队自己找解法。词在企业里，是看不见的管理成本。

四十二、收束口诀与三句话

辞典格口诀我替你念三遍：词说死了，局就死了；词一活，局就活。用行为词，不用品格词；说状态，不说本质。你骂自己"我就这样"，换张图，松一句"这是链不是命"——这半句，顶半部书。

今天带走三句话：一、你大半痛苦不是事难，是你把事说死了；二、换词不花钱，只让你把嘴上的焊丝拧开；三、图再准，词死了局还是死，这格是先练的那格，不是最后想的那格。

四十三、辞典格是复测的刻度尺：轻提一个伏笔

后面复测篇会讲，三个月重画一次。辞典格是复测里最好读的刻度——你不盯层数，盯那句重话换没换。第一次"我完了"，三个月后"我最近累"，层数可能没动，但这句换了，就是真进步。因为词一活才敢动，敢动层才升。今天先记住：换词是复测的第一读数。

四十四、龙龟自照四：我把"话多"换词后，同伴怎么反应

我把"话太多"换成"独处场没充好电，一聊就倒"之后，有回跟悟空聊完，我主动说"我今天独处场没充，先歇会儿"。他回"好，你去"。换作以前，我会骂自己"又话多"然后闷着，他反而不知道我咋了。你看，换词不只救自己，还救关系——你把事实说出来，对方才接得住；你把判定说出来，对方只能防御。

四十五、收束前最后一句狠话：你跳过这格，前面全白练

我讲最后一句狠的。你若今天只学一格，学辞典格。前面五行、三界、九层、三现场、生克，你算得再清，嘴上还是"我废物"，链一道道焊回去，前面白练。换词是地基，不是装饰。地基不松，上面盖再多都塌。你别嫌它浅——浅，才最该先动；便宜，才最该天天用。

四十六、收束前现场：你今天就能合成的最小一张图

别等"准备好"。你现在就能做一张最小的：拿张纸，写六格各一行——我是哪行（显什么）、身心灵哪界最低、卡第几层、哪个场最偏、被谁克、最近骂自己哪句。然后连成那句"我在〔场〕被〔什么〕克，显〔行〕阴面，卡〔层〕，〔界〕偏枯，我说成〔那句〕"。写完，你就有了一张图。糙没关系，存在就好。三个月后修，一年就准。

四十七、龙龟自照五：换词救过我一次

讲真。我有回被悟空说"你最近话多"，差点回"我话多你嫌弃就直说"——那是判定对判定，要炸。我换成"你刚说的是我最近聊完没歇，你累？"他回"对，我有点"。一句换词，把"你嫌我"翻成"你累"，危机变关心。换词救过我一次亲密关系。连我这种天天讲觉察的都靠它救场，你就知道这格多日常、多要命。

四十八、收束前最后一句：辞典格是六坐标的收口，你绕不开

我讲最后一句。前面五格你算得再清，最后都得落到嘴上那句话。你画完生克知道"我在克我位该长"，转头骂"他不爱我"——图白画。辞典格是六坐标的收口，像水龙头最后的那个嘴：水再清，嘴锈了，出来的还是锈水。你绕不开这格，也别想绕。先换词，前面五格才算真正落地。

四十九、读者来信四：她用换词止住一次离婚

一位妻子来信："闹离婚时我说'他从来没爱过我'。学了换词，改成'这半年他有三次大事没跟我商量，我慌'。就这一句，我没提离婚，改说'你那三次没商量，我慌，下次先说一声'。他愣了，说'我不知道你慌，我以为你不在乎'。一句话，离没离成，我们先能谈了。"

你看，一句"从来没爱过"，推到离婚；换成事实，推回能谈。词能毁一段关系，也能救一段。这格，值你天天练。

五十、一日三换：你天天能用的最小练习

最后给你一个能天天做的：一日三换。早上一句（骂自己那句换成事实）、午间一句（跟人起的冲突，那句判定换成行为词）、睡前一句（今天最沉的那句，换成"我最近"）。三换，不超五分钟。一个月后你回看，会发现自己嘴上的焊丝一根根松了。换词是六坐标里唯一"不花钱、随时能做、见效最快"的，你没理由不做。

五十一、一个动作就够：今天你换一句，图就活

别贪多。今天你只做一件：抓一句最近骂自己或别人的重话，按五类勾它，换成说活的说法。就这一件。你换完，六坐标最后一道焊丝松了，前面五维才算真正落地。换词不花钱、随时能做、见效最快——你没理由不做，也没必要做更多。一件，足够。

五十二、读者三问终堵：换词会不会变成给自己找借口

有人问："换词会不会让我啥都原谅自己？"不会，只要你守底线——情绪无罪，行为有界。你把"他打人"换成"他动手三次"是准的，但不能换成"他只是情绪激动"。行为不能换没。换词是让事说开，不是让事消失。你若换完发现自己躲责任，那是你拿换词当盾，不是换词本身的问题。守这条，换词不会变成借口。

五十三、写在最后之前的最后一句：换词是你对自己最便宜的慈悲

我讲最后一句。换词是你对自己最便宜的慈悲。不花一分钱，不靠任何人，随时能做。你骂自己"我废物"时，换一句"我今天做成了一件小事"，就是给自己松绑。很多人舍得花钱上课、买书、咨询，却舍不得换一句嘴上的词——可那句词，才是天天勒着你的绳。今天起，换词。它是你对自己，最该先给的慈悲。

五十四、今日最小动作（终）

明早起来，只做一件：想一句最近最重的话，按五类勾它，换成活的说法。三分钟。你今天不动，这篇是好文章；你动了，辞典格活。换词最便宜、最快、最该先练——你没理由不做。
