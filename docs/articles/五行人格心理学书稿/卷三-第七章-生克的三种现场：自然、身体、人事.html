卷三 · 立行：五行运行论与关系论

第七章 生克的三种现场：自然、身体、人事

前面讲生克，讲的是两件事：机制（第一章 1.4 的相生相克制化乘侮胜复）和用法（第二章的四门功课与归属律、第三章的化克为生算法）。这两样都是"知道了以后怎么办"。

这一章讲第三样：生克在哪些地方发生。

同一套生克，落在三个不同的现场，长相完全不同。落在大自然里，它是草木水土火之间的循环；落在身体里，它是五脏之间的滋养与制约；落在人和人之间，它是两个人的相处里那股说不清的顺与拧。机制只有一个，现场有三个。

全书此前只讲机制与用法，没有专门讲现场。这一章补的就是这一层——它不发明任何新规律，只是把同一条规律，放回它原来被取出来的那三个地方。

全章分四段：7.1 说明本章不重复什么，7.2 到 7.4 是三个现场，7.5 收束并给出接口与待检验项。

7.2 自然界的生克：象是从生活里取来的

五行不是先有理论再去找例子，是先从生活里取下象来，再结成理论。这一节把那五环相生、五环相克的生活来历，逐条还回去。

7.2.1 相生五环的自然来历

水生木。 五行之中，唯一自带生命活力的是木。而生命要长，先得有水来润。无水之木，是一根柴，不是一棵树。所以"水生木"。

木生火。 人类最早拿到的人造火种，是钻木取火。这一条不是比喻，是技术事实：火从木里来。往深一层说，生命在于运动，生命的运动过程就是能量的释放过程，而能量释放这件事，本身就是火。所以木之生火，既是钻木取火，也是"活着就在生火"。

火生土。 "火曰炎上"说的是能量往上、往外释放。等这股能量释放殆尽，生命走到尽头，剩下的是一堆灰烬。灰烬归于土。火生土，说的是繁华之后的沉淀。

土生金。 土是中性，是向上、向外、扩张发挥到极致的那个转折点。它表面厚重，内里却蕴藏着矿藏，也蕴藏着向下、肃杀、收敛的那一股力。金属从土里挖出来，所以说"土生金"。

金生水。 这一环的解法有两说，两说都通，可以并存：

  • 其一，冷凝说。 古人在金属表面发现凝结的水珠。金属导热快，昼夜温差一大，水就在上面聚起来了。这是看得见的观察。
  • 其二，潮汐说。 月亮在天干属庚，庚属金；金配秋，配八月。古人认为潮水因月而生，尤以中秋月圆时的潮水最盛。月—金—水，这条线把金生水接到了天象上。

    • 两说各有来历，本书不作取舍，一并记录（异说并存的处置原则，见附录一）。

    7.2.2 相克五环的自然来历

    相克也一样，每一环背后都是一件古人天天在做的事。

    木克土。 大地上种树，树的根扎进土里，把土抓住。大雨来的时候，有树的坡不塌，没树的坡就流失了。木克土，说的是"用生长来固定"。

    土克水。 大雨成灾，人拿土筑墙、垒堤，把水挡在家园外面。土克水，是"用承载来止住"。

    水克火。 从前家家门口摆一口大水缸，下雨时接满，为的就是起火时能救。水克火，是"用储备来应急"——注意这一条的重点在"备"，不在"泼"。

    火克金。 要保卫家园、要煮饭生火，就得有刀枪斧头，而刀枪斧头是顽铁炼出来的。顽铁怎么化？用火。火克金，是"用高温来改变形态"。

    金克木。 生火需要柴，柴要用锯子斧头劈开。金克木，是"用锋利来裁剪"。

    五环连起来就是一条生活链：木固土 → 土挡水 → 水备火 → 火炼金 → 金劈木。 天地间的万物长出来之后，有生就要有制。水能让树木生长，也能让土质流失；而木正好按"木克土"的道理把土管住。这就是自然的循环状态。

    7.2.3 一句必须说清的话：取象不是证明

    这一节写的全是"为什么古人这么想"，不是"为什么它必然如此"。

    取象是认识的入口，不是论证的结论。 钻木取火说明"木生火"这个象取得贴切，但不能拿它去证明木行之人一定会带出火行之人的热情；金属表面凝水珠说明"金生水"这个象有观察依据，但不能拿潮汐说去支撑金行之人滋养水行之人的心理学主张。

    两头一混，就会闹出"因为古人看见水珠，所以你和某某合得来"这种笑话。

    正确的读法是：取象告诉我们这套关系的"手感"是什么，人事现场告诉我们它"长相"如何，机制告诉我们它"为什么"成立。 三样各管一段，谁也不能替代谁。这条边界，与卷一 2.5.4 讲的"象是层层发现的，不是分析推论出来的"是同一条纪律。

    7.3 身体里的生克：五脏的相生相克链

    身体是第二个现场。这一节只讲一件事：五脏之间，谁滋养谁，谁管着谁。

    （五脏与五行的对应总表见附录二，此处不重排；情志伤脏与调摄技术在卷八 7.1，以情胜情的转化技术在卷六第八章，均互引不重述。）

    7.3.1 相生链：每一个脏都在养下一个，也在被上一个养

    在相生关系里，每个脏器都滋养着另一个脏器，同时接受另一个脏器的滋养。这条链是这样的：

    环节说法白话
    肾水 → 肝木肾水滋养肝木肾精足，肝血才有源头；熬夜耗肾，第二天肝先扛不住
    肝木 → 心火肝木上济心火肝的疏泄条达，心气才顺；肝气郁住的人，心也闷
    心火 → 脾土心火温暖脾土心阳温煦，脾才运化得动；心气不足的人，吃点就堵
    脾土 → 肺金脾土生养肺气脾运化的水谷精微上输于肺，肺气才足；脾虚的人容易咳、容易喘
    肺金 → 肾水肺金滋养肾水肺主肃降，把津液往下送，肾才受得住；肺燥的人，肾水也跟着亏

    这条链是环形的，不是线性的。所以说"某一个脏虚"，不能只盯着那一个脏——它虚，可能是生它的那一环没给够。

    这是"躲到 X 上去"那条公式在身体上的版本（互引卷三 2.3）：你被克了，不要硬顶，去补你生的那一环。

    7.3.2 相克链：每一个脏都在管着一个，也被一个管着

    相克关系体现的是脏器间的相互制约，目的很朴素：防止任何一个脏器过强或过弱。

    环节说法白话
    肺金 → 肝木肺气清肃下降，抑制肝阳过亢肺的收敛管着肝的生发；肺气足的人，不容易上头上火
    肝木 → 脾土肝的疏泄，缓解脾的壅滞肝气条达，脾才不堵；肝郁的人，脾胃先出问题
    脾土 → 肾水脾的运化，制止肾水泛滥脾管着水液的代谢；脾虚的人，水湿停在身上
    肾水 → 心火肾的滋润，防止心火过旺肾水上行，心火才不浮；肾亏的人，心烦失眠
    心火 → 肺金心的阳热，制约肺的过度清肃心阳温着，肺才不至于收得太过；心阳不足的人，肺寒

    相克不是相害。 这五条制约，是五脏平衡的保障机制——正因为有它们，任何一个脏器都不会一家独大。

    一本书里讲"克"讲了这么多章，这里必须再踩一脚：克是管束，不是伤害。 身体里如果只有生没有克，那不叫健康，叫肿瘤。

    7.3.3 与识人的接口：身体是显示器

    这一节与识人有什么关系？关系在卷六 5.3 那句话：身体是心灵的显示器。

    情志—脏腑的对应（怒伤肝、喜伤心、思伤脾、忧伤肺、恐伤肾），加上这一节的两条链，就得到一个可观察的东西：一个人的情绪习惯，会在身体上留下可查的痕迹。

    比如土行之人。土主思，土行之人的毛病是想事——一遇到问题就开始想，想着想着就堵在那儿了。堵在哪儿？堵在脾胃。脾土一不通，食欲就不好。这不是玄谈，是全身的原始反应。

    反过来也成立：看到一个人长期食欲不振、脾胃失调，可以回查他的思虑模式（互引卷六 5.3"观病取五德"）。

    但要严格守住一条：这是观察线索，不是诊断结论。 身体的问题先看医生，情志的问题才归本书。把五行识人®当成听诊器用，是超范围使用（互引卷十 2.1 适用范围边界）。

    7.4 人事里的生克：十组现场

    第三个现场，也是读者最关心的一个：两个人之间，生克长什么样。

    7.4.1 先说清这一节在讲什么

    这一节讲的是"认出来"，不是"化解掉"。

    化解在卷三 2.3——那里给了"躲到 X 上去"的公式和完整的功课表。那一节不能跳过，也别和这一节混。看不懂现场，就没法用公式；只会看现场，不会用公式，就只剩下一句"我们俩相克"的宿命论。

    其次要说明：下面的十组描述，是倾向性的，不是必然性的。两个人合不合，取决于各自的阴面阳面、所处层级、当下的处境，以及他们在关系里的位置。同是土金组合，可以处得极好，也可以处得极糟——生克只说明能量的走向，不说明结果。

    最后是读法：每一组都请读成"能量的流动方向"，不要读成"这两个人合不合"。

    还有一处要分清：卷三 4.1.5 那"团队生克十句"讲的是组织——一群人在一起，五行怎么配伍、怎么补行；本节这十组讲的是两个人——能量的走向是怎么在具体相处里显形的。两处看着像，其实不是一回事，不要互相替代着读。

    还有第三处，与本节最容易混：卷八第十三章那张"五行 × 四门功课二十格"表。本节是组合视角（土生金这一对，长什么样），那一张是主型视角（我是土，面对四个方位各该修哪一门）；本节不分场，那一章专指亲密关系；本节用来"认出来"，那一章用来"认出来之后，功课落在哪一格"。先读本节认出组合，再去那一章找自己那一行。

    7.4.2 相生五组的现场

    相生的现场，共同特征是一方给的东西，恰好是另一方要的。

    组合现场为什么顺
    土生金土行之人包容，能接住金行之人的挑剔。金行之人待在土行之人身边，常觉得惬意金行之人要的是稳定与资源，土行之人恰好给得起，也给得甘心
    金生水金行之人善于指挥与规划，遇到没主见的水行之人，金行之人的能量自然流过去水行之人缺的是结构与决断，金行之人最不缺这两样
    水生木水行之人习惯关注别人、奉献自己，正好满足木行之人渴望被看见的需求木行之人要长，得先有人看见他在长
    木生火木行之人聪明、有活力，火行之人尊重知识与文化人，愿意捧着木行之人火要烧得旺，得有东西可烧；木行之人提供的正是燃料
    火生土火行之人热情、积极，能激发土行之人的活力与行动力土行之人最容易沉下去，需要有人点火

    这五组的合作价值极高：土行之人提供稳定与支持，金行之人在这个基础上做创新与发展。一个给底座，一个往上盖——互补性摆在这儿，和谐且高效。

    但相生也有相生的坏处，这一点必须同时说出来，否则会读成"生就一定好"：

  • 生过头，被生的一方会退化。 土一直给，金就懒得自己挣；金一直规划，水就越来越没主见。相生关系里，功课在生方（互引卷三 2.3 归属律），道理就在这里——给的人要管住自己。
  • 生方不给，比不生更难受。 相生关系一旦断了供，被生那一方的失落，比普通的合不来要重得多。

    • 7.4.3 相克五组的现场

    相克的现场，共同特征是一方要的东西，恰好踩在另一方的短处上。

    组合现场为什么拧
    土克水土行之人照顾所有人，追求公平；水行之人要的是一对一，于是觉得不被重视水行之人要"我是你的唯一"，土行之人给的是"我对谁都一样好"
    水克火水行之人沉、慢、绕；火行之人直来直去，碰上去觉得不适应、接不住火行之人要的是立刻的回应，水行之人给的是长久的揣摩
    火克金火行之人热情奔放、临场发挥；金行之人有条理、务实，觉得被搅乱，火行之人又觉得被管死金行之人要的是流程与边界，火行之人的能量恰恰是越界的
    金克木金行之人看现实利益，一刀切下去；木行之人追长远目标与理想，觉得被打击、被泼冷水木行之人想的是十年后，金行之人问的是这个月
    木克土木行之人聪明、反应快；土行之人跟不上节奏，且觉得自己被忽视土行之人靠稳取胜，木行之人的速度把"稳"变成了"慢"

    这五组比相生难得多。相生的功课是"别给太多"，相克的功课是"在自己的被克处长东西"。

    材料里有一句话说得极准：相克中被克的那一方，需要付出更多努力，从固有的业力模式中觉醒并超越。 换成本书的话：被克的地方，就是你最该长的地方。 这不是道德要求，是动力学——压力落在谁身上，谁手里才有改变的能量（互引卷三 2.3 归属律）。

    也正因为难，才有这句话：在亲密关系里，真爱应当让双方共同绽放，而不是陷入主从的桎梏。 如果一段相克关系长期停在"一方压着另一方"，那不是相克，那是失衡。

    7.4.4 三条读法

    看这十组现场，有三条纪律要一起给，缺一条就会用坏。

    第一条：现场描述的是能量走向，不是命运判决。

    说"你们土克水"，不等于说"你们不合适"。它说的是：在这段关系里，土行之人那个"我对谁都好"的习惯，会反复踩到水行之人"我要被单独对待"的需求上。知道了这一点，土行之人可以专门给一段单独的时间，水行之人可以练习把需求说出来。 认出来是为了改，不是为了认命。

    第二条：被克方不是受害者，是主功课方。

    这一条在卷三 2.3 讲过，这里再点一次，因为现场最容易读出委屈感。"谁难受谁改变"不是道德判断，是动力学判断。 难受的那个人手里才有能量。

    第三条：三例外——侵害性关系不适用。

    家庭暴力、职场霸凌、精神控制，第一位的动作不是做功课，是止损。这一条在卷三 2.3 的防线三里已经立过，此处重申：本章所有内容，都只处理正常人际中的能量失衡。

    7.4.5 个体视角补白：同一五行人在相生／相克环境中的阴阳显隐

    7.4.2 与 7.4.3 是关系视角——站在"两个人之间"，看能量怎么走向。这一节换一个镜头：个体视角——站在"一个人身上"，看同一个五行人放到不同环境里，阳面和阴面怎么切换。

    这换的不是话题，是落点。前面四门功课（卷三 2.2）已经立过：相生关系里，你要么在生我的位置（顺承，被滋养），要么在我生的位置（释放，去滋养）；相克关系里，你在克我的位置（臣服，被制约）。这三处位置，恰好对应一个人"顺"与"逆"的两种处境——

  • 相生环境（生我或被我生，都是滋养性关系）：能量通畅，阳面自然显。
  • 克我环境（被制约，制约性关系）：能量受阻，阴面容易露。

    • 一句话：环境是那面镜子，照出你这一行此刻的成色。 顺境里你长出的，未必是你"本来就有"，是关系把你那一面的功能激活了；逆境里你漏出的，也未必是"你这个人"，是压力把你那一面的过度表现逼出来了。认清这一点，顺逆都不再是判语，而是线索。

    7.5 一条贯穿三域的观察：生是给，克是管

    三个现场看完，可以收成一句话。

    生，是给出去；克，是管得住。

    自然是这么安排的：木给水固定住，水给火留着备用，火给金改形状，金给木裁长短，土给水挡住去路。给的目的是让它长，管的目的是让它别长疯。

    身体也是这么安排的：肾水养肝木，肺金管肝木；脾土养肺金，心火管肺金。养和管，永远成对出现，从来不是二选一。

    人事还是这么安排的：土给金稳定，木给火燃料；土管着水的泛滥，金管着木的扩张。一段关系里，如果只有生没有克，会养成依赖；如果只有克没有生，会磨成消耗。

    所以判断一段关系好不好，不要问"我们相生还是相克"，要问：生和克配不配得上。 有生有克，且都在适度区间，就是活的；只有一头，就是死的。

    这与卷三 1.4 的"制化"是同一件事的不同说法——制化讲机制，这一句讲现象。机制在第一章，现象在这一章。

    本章收束

    这一章做的事，说到底是把生克从公式里请出来，放回它原来待着的地方。

    公式是抽象的，现场是具体的。 你知道"土克水"，和你在一个土行之人身上看见"我对谁都一样好"、在一个水行之人身上看见"他需要被单独对待"，是完全不同的两件事。前者是知识，后者是眼力。

    五行识人®要练的是后者。

    再退一步说，三个现场其实是同一个现场。自然是身体的外化，身体是人事的底座，人事是自然的重演。 古人从草木水土里取下的象，之所以能用来讲人，不是因为人和草木相似，是因为它们的运行方式同构——都有生有克，都要有给有管，都在动态平衡里才活得下去。

    平衡不是静止，是流动。 这一句放到下一句里才完整：流动的是象。 象一僵，生克就变成了标签；象一流，标签就重新变回活人。
