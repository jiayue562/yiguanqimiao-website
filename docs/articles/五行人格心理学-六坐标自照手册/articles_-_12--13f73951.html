第十二章 · 调法库

图看清了，链画出来了，接下来就是调。

这一章是整本手册的工具箱。它给四法、两张速查表、一个动作库，随用随翻。

一、四法总纲

链有四个环节（源、势、式、场），对应四个调法：

法动的是问的话治本吗难度见效
调源源头这股劲儿最初从哪来？能在这处理吗？治本难慢
断式反应模式我每次到这儿，重复的是什么动作？能插一杠吗？治标易快
换场出口这股劲儿从哪出去了？能换个地方出吗？治标易最快
补枯最枯的那一界三界里哪界最低？能补吗？治本中中，撬动力最大

四法不是四选一，是四个入口。 选哪个，取决于你当前的状态。

二、调源

原理

链的头。能量从这儿进来，所以在这儿处理，最治本。

老周的源在公场——上司的节奏（木）压着他的稳（土）。在源头处理，就是把节奏这件事本身谈开。

怎么操作

第一步：认出源。 问自己："这股劲儿，最初是从哪儿进来的？"身体会紧一下的那个，就是。

第二步：问一句"这事儿能谈吗"。

  • 能谈——就去谈。谈的方式：说事实 + 说影响 + 说请求，不讲品格、不讲感受的判定。
  • ❌ "你天天瞎折腾"（品格词）
  • ✅ "三个月换了四个方向（事实），我跟不上，做出来的东西反复返工（影响），能不能先定一个，做完再换（请求）？"
  • 不能谈（比如对方是上级、是父母、是已经发生的事）——那就换一个思路：调整你接的方式。 老周不能让上司慢下来，但他可以问"哪件事先停"。

    • 第三步：接受"源可能动不了"。

    这是调源最需要有的心理准备。很多源头是动不了的——你换不了上司，改不了过去，控制不了别人。

    源动不了，不代表没路。那就动式、动场。 调源治本，但它不是唯一的路，也不总是最该先走的路。

    什么时候用

  • 你有能力、也有空间去动那个源头。
  • 或者，那条链反复发作，你受够了，愿意花力气在根本上。

    • 什么时候别用

  • 你现在已经很累（L5 往下）——先断式、换场，攒点力气再说。
  • 源头涉及侵害性关系（家暴、霸凌、精神控制）——不是调源，是止损。

    • 三、断式

    原理

    式，是你那个固定的反应模式。每次到这一步，你就重复同一个动作。

    老周的式是"钻牛角尖、往坏处想、拖沓"。每次被推，他就往里闷。

    断式，就是在这个动作刚起来的时候，插一杠，把它打断。

    它不治本——源头的推力还在。但它最快、最省、最容易上手，而且能让链松一口气。链一松，你才有力气去动源头。

    什么时候用

  • 新手请永远从断式开始。
  • 你现在已经很累，动不了源头。
  • 你需要一个"立刻能做"的动作。

    • 五行断式对照表

    每一行的阴面，断法不一样。 找对你那一行：

    行阴面起来时的样子断式动作为什么这么断
    阴木顶撞、抗上、僵住、对着干先答应，再想。 说"我听到了"，然后离开现场走几步木往上顶，先让那股劲儿有个出口（回应），再动身体破僵
    阴火急躁、抢话、爆发、管控喝口水。 或者数三下、离开现场三分钟水克火。物理意义上的水，也能压一压
    阴土钻牛角尖、往坏处想、拖沓、闷起身，做一件五分钟能完成的小事。 倒垃圾、回个消息、洗个杯子土往里闷，用一件"做完了"的小事破掉那个闷
    阴金挑剔、苛刻、计较、非要赢先找三个好的。 或者把你的标准写下来，看看是不是过线了金的问题是"裁"过度，先让它看见好的，收一收刀
    阴水退缩、回避、多疑、不敢信人说一句最小的话。 哪怕只是"我在"水往里藏，用最小的表达破那个藏

    断式的三个要点

    要点一：早。 在阴面刚起来的时候断，最容易。等到爆发了，断不动了。

    要点二：物理。 断式最好是身体的动作——喝水、起身、走几步、洗个手。纯靠"想"来断，很难。身体一动，那个模式就断了。

    要点三：重复。 一次断不掉是正常的。断十次，链松一分。 断式的价值不在一次的效果，在重复中把老模式磨薄。

    要点四：小。 动作要小到几乎零成本。靠"打起精神"撑行为是靠不住的——今天有劲做、明天没劲就断，链永远松不了。小到顺手就做、不做都觉得可惜，它才长得住。断式之所以从"喝口水""走几步"开始，就是因为小。

    四、换场

    原理

    场是出口。能量从哪儿出去，决定了它伤谁。

    老周的气从家场出去（对家人发火）、从独处场出去（"我跟不上时代了"）——两个出口都在伤他最在乎的东西。

    换场，就是把出口挪个地方。

    怎么操作

    第一步：认出现在的出口。 这股劲儿，现在从谁身上出去？从什么事上出去？从什么自我攻击上出去？

    第二步：选一个新的出口。 新出口要满足两个条件：不伤人、真能出。

    现在从哪出换成从哪出
    对家人发火回家前在楼下／车里坐十分钟；或者去走二十分钟
    对孩子吼先离开那个房间，喝口水，回来说"我刚才急了"
    喝酒、暴食、刷手机到凌晨换成一件有消耗但无害的事：快走、洗澡、写三行字
    自我攻击（"我废物"）换成一句具体的话："我今天做成了______"（哪怕只是洗了碗）

    第三步：在 A、B 之间插一个缓冲。

    带场链（A 场被克 → B 场发作）最有效的换场，是在两个场之间插十分钟。

    回家前十分钟，坐在车里、走在路上、站在楼下——做一件有仪式感的小事（换双鞋、洗把脸、听一首歌），告诉自己："公场的事，留在门外。"

    在两个场之间插的这十分钟，就是给"不把气带回家"这个新规安的触发点——新习惯得有个固定的钩子才挂得住，不然一累就滑回老样子。

    什么时候用

  • 你的链是带场链（A 场被克，B 场发作）——换场是特效药。
  • 你需要立刻见效的。
  • 源头暂时动不了。

    • 换场的判断标准

    换完之后，你是松了，还是更空了？

  • 松了，能回来继续做该做的事——换对了。
  • 更空了，回来更不想面对——那是逃避，不是换场。

    • 换场是"出去加个油再回来"，不是"跑了不回来"。

    五、补枯

    原理

    三界里分数最低的那一界，是撬动全局的支点。

    老周灵界 4 分（三界里最低）。他自己说不清为什么而做，于是只能从别人的认可里找存在感（L5 外求认可）。灵界一活，外求就松了。

    怎么操作

    哪一界枯，补哪一界：

    枯的是怎么补最小动作
    身界睡、吃、动早睡半小时，或每天走二十分钟。先只做一样。
    心界让情绪有出口每天写三行（不用成文），或找一个能说话的人
    灵界立一个小小的志找一件"不问结果也愿意做"的事，每周做一次

    补灵界，是最容易被忽略、也最撬动力的一招

    "没劲"多半不是懒，是灵界偏枯。

    很多人以为自己需要休息（身界）、需要调节情绪（心界），其实他是没方向。

    补灵界不需要想通人生意义。 反过来——开始做了，意义才会慢慢显出来。

    这正是不靠动机的改法：不是想通了才做，是做着做着想通了。很多人卡在"我得先想明白"上，结果一辈子没动；先动最小的一步，路是走出来的，不是想出来的。

    找一个小的、具体的、不问回报的事：带两个年轻人、每周写一页东西、养一盆植物、陪一个老人聊会儿天。做着做着，那个"为什么"就出来了。

    什么时候用

  • 你的三界里有一界明显低于其他两界。
  • 你"说不上哪里不对，就是没劲"。
  • 你的链是外求链（求认可 → 求不到 → 更求）。

    • 六、生克调法速查

    被克了，怎么办：化克为生三步

    核心原理：被克了，不要硬顶，去补你"生"的那一环。

    举个例子。金克木——金讲现实利益，木讲长远理想。木被金泼冷水。

  • 硬顶：跟金吵"理想很重要" → 输，而且更被泼。
  • 化：木不去顶金，木去生火——把你的理想，变成一次有感染力的表达、一个能点燃人的方案。火克金，金那把刀就被暖过来了。

    • 三步算法：

    步做什么例（金克木）
    第一步认出谁克你金克我（木）
    第二步不去顶不跟他吵理想
    第三步去生你生的那一环木生火 → 把理想变成能点燃人的东西 → 火克金 → 平衡回来

    两个环，先记牢：

    相生环：木生火 → 火生土 → 土生金 → 金生水 → 水生木（回到木）
    相克环：木克土 → 土克水 → 水克火 → 火克金 → 金克木（回到木）

    用法：谁克你，你就去生下一个——你生的那个，会去克他。

    谁克我我不顶我去生结果
    木克土不跟木比快土生金（定标准、划边界）金克木
    土克水不跟土要公平水生木（长出自己的事）木克土
    水克火不催水回应火生土（做点实在的事）土克水
    火克金不跟火抢节奏金生水（沉下来想清楚）水克火
    金克木不跟金争木生火（点燃、表达）火克金

    这张表的逻辑是闭死的：被 X 克 → 去生我生的那一环 → 我生的那一环恰好克 X。无论你被哪一行克，都走得通。

    生过头了，怎么办

    相生关系里，功课在生方。

    如果你发现某段关系里你一直在给：

  • 1. 停一停。 不是不给，是少给一点，看对方会不会自己动。
  • 2. 把"给"换成"陪"。 替他做 → 改成在旁边看着他做。
  • 3. 允许对方不长。 这是最难的——你看着他在那儿卡着，忍住不伸手。不伸手，他才长得出自己的力气。

    • 被克方：那块地方正是我要长的

    重复一遍第八章那句：

    被克的地方，就是你最该长的地方。

    木被金克——金问这个月，木想十年后。木的毛病恰恰是落不了地。 金那把刀砍下来的，正是木最该长的地方。

    克你的人，常常是你最需要的那个人。

    七、调法怎么选

    给一张选择表，直接照着挑：

    你现在的状态先动哪个
    第一次用，不知道从哪开始断式（最容易，立刻能做）
    链是带场链（A 场被克，B 场发作）换场（特效药）
    很累，动不了大的断式 + 换场（先松一口气）
    三界里有一界明显最低补枯（撬动力最大）
    链反复发作，我受够了调源（治本，但先确保你有力气）
    L5 及以下别自己扛，请专业的人来（见第十四章）
    涉及伤害止损，不是调（见第十四章）

    总原则：先易后难，先标后本。

    想让一个新习惯真正长出来，记住三件事同时备齐：动作够小（做得起）、有个固定的提醒（挂得住）、不跟自己较劲（别硬来）。少一样，它都落不了地；三样齐了，它自己会扎根。

    链一松，你才有力气去动源头。 所以别一上来就挑最难的。

    八、最小动作库

    最后给一张随手可查的表。每一格，只做一个动作。

    卡在哪最小动作
    我要炸了喝口水
    我在钻牛角尖起身，做一件五分钟能完成的小事
    我想顶回去先说"我听到了"，然后走开几步
    我在挑刺先找出三个好的
    我想躲说一句最小的话（哪怕只是"我在"）
    我要把气带回家回家前十分钟，在楼下坐一坐
    我骂自己了换成一句具体的："我今天做成了______"
    我拖着不动只做第一步（比如只打开文档，不写）
    我不知道我要什么找一件小事，不问结果地做一次
    我睡不着泡脚，早卧半小时
    我累但说不出为什么看三界：哪界最低，补哪一界
    我不知道从哪下手先只动一个环节，观察两周

    这张表的用法：卡住的时候，扫一眼，挑一个做。做完就够，不用多做。

    这些动作的共同点：小到不需要你"有状态"就能做。没劲的时候，恰恰是该用它们的时刻——因为有劲时你本就用不着。

    一章口诀

    调源治本，断式最快，换场特效，补枯最撬；先易后难，先标后本。

    再短一点：

    一次只动一个环节，动完观察两周。

    *（本章所有调法为日用觉察与关系调整方法，非医疗手段、非心理治疗。若涉及持续功能受损或伤害行为，请直接翻到第十四章，寻求专业帮助。）*
