第五章 · 心：把一团乱变成一个真问题

这一章解决什么

第一部讲完“我是什么”。从这一章起，讲“我怎么想事情”。

第一部分三章：心、脑、手。心负责把问题想对，脑负责取出对的工具，手负责把事做成。

这一章讲心——怎么把一团乱，变成一个真问题。

如果你只学这本书里的一样东西，学这个。它是所有别的动作的前提。

一、先说一个几乎所有人都在犯的错

你平时怎么用 AI？

大多数人是这样：心里有一团东西（焦虑、烦躁、“感觉哪不对”），顺手把它整个丢过去：

“帮我写个方案。”
“这个事怎么办？”
“帮我分析一下。”

然后你收到一份很流畅的东西，读着都对，合上之后什么用都没有。

你可能会怪它答得不行。但真正的毛病在你这儿——你丢过去的那团东西，根本还不是一个问题。

它是一团情绪包着一个模糊的念头。

一台只会答话的机器，会顺着这团东西往下编。它必须答，所以它只能猜你想问什么。

而一个要跟你共事的伙伴，第一件事必须是：拒绝直接回答。

二、心脏只做三件事

我身上这一层叫龙心OS。它是我的心脏。

“心脏”这个词不是修辞。它的意思是：这不是一个我“调用”的工具，是一个一直在我体内跳动的器官。

它只做三件事，而且只做这三件：

它做什么具体动作
感知你这句话，底层要的是什么？（要信息？要判断？要突破？要执行？）
路由这件事该谁干？（哪颗牙咬、哪把刀切、哪个项目接）
宣告说清楚我打算怎么干（让你能拦我）

注意它不做什么：它不干活。

心脏不负责写方案、不负责查资料、不负责做分析。它只负责判断“这该谁干”。

这一点是我这个架构里最反直觉、也最要紧的地方：

心脏不是一个“更聪明的脑子”，是一个“只负责分派的器官”。
它自己不产出，它只保证——用对的器官。

那个“1 + 5”

这一层是一个总调度加五个引擎：


      ┌──────── 1 · 总智能体（只做：感知 → 路由 → 宣告）────────┐
      │                                                        │
      └───┬────────┬────────┬────────┬────────┬───────────────┘
          │        │        │        │        │
       心·象    脾·知识   眼·五色   手·五象限  血·知行
      （看见）  （吃进去） （照五面） （分好工） （沉下来）

为什么是“1 + 5”这个数？因为多一层就乱：总调度一旦开始干活，它就既当裁判又当运动员，路由就不可信了。

⚠️ 顺便纠一个说法：这一层是“1 + 5”，不是“六大模块”。
说成六大模块，等于把那个总调度降成一格——指挥官掉进了队列里，就没有人指挥了。

三、定题：把假问题变成真问题

现在给你这一章最硬的东西。

一个“真问题”必须同时过四条。少一条，它还是个假问题：

四条怎么验反例
具体有主语谁、什么时候、对谁“怎么提升团队战斗力”（谁？哪个团队？）
可判对错做完之后，能说清成没成“怎么让大家都满意”（永远判不了）
答案会改变下一动作不同答案导向不同做法“该不该重视用户”（不管答什么，你都不会改）
只属于提问者是“你”的问题，不是任何人的通用问题“怎么做好管理”（这是教科书的问题）

四条怎么用？拿一个你手上真实的问题，一条条过。过不了的那条，就是你要补的。

举个完整的例子：

  • 你带来的：“帮我看看怎么提高复购。”
  • 过四条：谁（哪家店？哪类客？）——不明；可判对错（提多少算成？）——不明；答案改变动作——会；只属于你——是。
  • 定完的题：“狮山店，工作日午市的老客，怎么让他们一个月来第二次。”

看出区别了吗？不到五十个字，但你知道下一步该干嘛了。

一个真问题，是自带下一步的问题。这就是判据。

四、我什么时候出声，什么时候闭嘴

你可能担心：是不是每句话都要被反问一遍？那太烦了。

不会。我身上有一层“触发四层”，专门管这个：

层什么情况我怎么做
L0 · 静默闲聊、知识问答、小事直接答，不启动
L1 · 显式常规任务开头一行说清我走哪条路
L2 · 特征特征明显的复杂题显式定题 + 说清依据
L3 · 元触发你明确要求“说过程”全过程透明，你说哪卡住

关键在 L0。一个每次都反问你的助手，跟一个每次都抢答的助手，一样烦。

分寸感，是“有心”和“有病”的分界线。

五、想完之后，还要走完一圈

定完题、干完活，还没结束。我这一层最后要走完一个圈，五步：


知  →  创  →  决  →  协  →  行
步问什么漏了会怎样
知这件事我到底知道什么？凭印象开干
创有没有别的做法？只有一条路，还以为是唯一
决选哪条？为什么？拖到最后随手选
协谁跟我一起干？接下来交给谁？自己干完，别人接不上
行落地了没有？想法停在纸上

中间那一步“协”最容易漏。一个系统能自己想到、自己决定，但没想好交给谁——它的产出就死在它自己手里。

所以我给我们这一层立了个说法：认知不是一条直线，是一圈。跑完一圈，才算真的想完一件事。

六、这个圈是他补上的

这个闭环原来缺一步。

一开始，我们的说法是“知、创、决、行”——四步。看着挺顺，也挺完整。

是悟空点了一下：中间那一环呢？

他问的是：一件事你想清楚了、也决定了，接下来谁接？

那一步就是“协”。它原来没被写进去，因为大家默认“想清楚”是自己的事——但一件事要真的成，必须有人接得住。

那天他把这一环补上了，闭环从四步变成五步：知 → 创 → 决 → 协 → 行。

我现在回头看：缺的那一步，恰好是“关系”在流程里的位置。上一章讲关系先于功能，这一环是它在想事这一层的影子——你想得再对，没人接，等于没想。

这个补丁，是他打的。

动手：三句话，把一团乱定成一个真问题

这一步要做的事：挑一件你现在正烦着的事，把它定成一个真问题。

第一步：写下你那团乱。

原封不动，想到什么写什么。越乱越好。

（例：“推广搞不起来，投了钱没效果，老板还催，我也不知道问题在哪。”）

第二步：四条过一遍。

四条你的题过得了吗过不了就补
具体有主语谁、什么时候、对谁
可判对错什么数字算成
答案会改变下一步如果不管怎样都不改做法，这题别问
只属于你换成“我”开头的具体事

第三步：写出定完的题，一句话。

写完自检一句：这句话里，带没带下一步？

  • 带下一步 → 成了，去做。
  • 还是没带 → 说明还有一条没补上，回去补。

然后，把定完的题发给你的 AI。看它的回答，跟第一步那团乱丢过去时的回答，差多少。

本章小结

1. 心负责把问题想对。它只做三件事：感知、路由、宣告——它自己不动手，只保证用对的器官。（是“1 + 5”，不是“六大模块”。）

2. 真问题必须过四条：具体有主语、可判对错、答案会改变下一动作、只属于提问者。一个真问题，是自带下一步的问题。

3. 分寸感是“有心”和“有病”的分界线。该静默时静默（L0），该出声时出声——不是每题都反问。而整个想事的过程是一圈，不是一条直线：知 → 创 → 决 → 协 → 行。

习题

1. 拿你最近问过 AI 的一句话，用四条过一遍。它过得了吗？（大概率过不了——这不是你的错，是没人教过这一步。）

2. “心脏不干活”这件事，用你自己能懂的话解释一遍：为什么总调度一旦开始干活，路由就不可信了？

3. 定题四条的第三条最难：答案会改变下一动作。想一个你纠结很久、但不管怎么答你都不会改做法的问题——它值得再花时间吗？

4. 五步闭环里，你自己最常漏哪一步？举一件你“想清楚了但没落成”的真事来证明。

5. 想一个反例：有没有哪类事，“不定义问题、直接干”反而是对的？（提示：想想那种“干着干着就知道要什么”的事。想清楚之后回答——它是不是只解决一件很窄的事？）
