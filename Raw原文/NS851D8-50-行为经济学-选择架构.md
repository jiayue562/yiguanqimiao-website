# 行为经济学×企业文化：损失厌恶/锚定效应·科学选择架构与伦理边界

核心（补《共同体之名》下卷"文化落地行为科学机制"层）：
1. **损失厌恶(失痛≈得乐2.5倍)** → 应用：预算精确目标+容错/重新定义失败+创新风险共担/福利阶梯+情感联结留人
2. **锚定效应(依赖初始锚点)** → 应用：理念体系锚定(使命愿景·心锚)/价格价值锚定/行为规范·习惯养成锚定(师徒示范·日常仪式)
3. **协同+伦理**：双锚模型(高标准锚×损失厌恶防退化)·复合激励；必守"透明知情/尊重自主/防操纵·防短期化"——员工乃有自主意识的主体非被设计的对象
4. **领导力+科学化**：管理者心理意识培训·A/B测试迭代·文化度量体系·长期跟踪——文化落地可测·可持续

本征：补"文化(心)↔行为(落地)"之间心理科学之桥；用科学选择架构让员工"自然而然内化"观念而非强推；守伦理(不工具化人)呼应人民性
