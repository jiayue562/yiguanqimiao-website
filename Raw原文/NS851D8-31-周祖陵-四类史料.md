# 陇东庆阳周祖陵与岐黄故里（从实物遗存看多元一体）

核心原象：
1. **四类史料分层（方法升级）**：考古实物 / 先秦原始文献 / 后世层累增补叙事 / 近现代当代建构——严守"不能拿后世叙事当上古史实"
   - 落到三样本：周祖陵=纪念记忆载体(非已证王陵)·岐伯庆阳籍贯=宋代地方叙事·千家碑林=2011当代金石工程
2. **破除"中原-边疆"后设视角**：上古满天星斗(南佐5100年区域王权中心)·多中心互动·中心边缘动态流动(周起陇东-关中/商在豫北)——"老少边穷"是唐宋后环境变迁+重心东移的后设观念
3. 两类"进入边地"模式：战败被驱逐(退入) vs 失势主动西迁(带内核融入)——周祖=第二种
4. 一体内核边地保存可等崛起：周人陇东存农耕内核→东进灭商建周(一体/多元辩证)

岐黄故里=宋后地方建构元典(一体)地方转化(多元)；千家碑林=当代金石创造转化
