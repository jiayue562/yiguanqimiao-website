# 从西北研学遗存看中华民族多元一体格局的历史生成（阶段性总结）

核心原象：多元一体历史生成的体系总图
- 多元=满天星斗本然(多区域独立原生文明·非晚出) + 互动持续(非孤岛·新石器起交流) + 延续(纳入共同体后地域特质仍在)
- 一体=动态生成的三层命运联结：①共享价值内核(非单向中原输出) ②共建历史记忆(层累建构·共祖符号) ③休戚与共命运联结(滚雪球式扩张)
- 辩证：多元是基础·一体是结果 / 一体不消解多元·多元不破坏一体 / 演化=滚雪球非积木
- 破后设视角：满天星斗多中心·"中原-边疆"是后世固化·西北也创造者非接收端

四类史料分层(呼应周祖陵)：考古实物/先秦文献/后世层累/当代建构——不拿后世叙事当史实

实证收拢：周人(庆阳存核待崛起)·西夏(断流反例·多元延续)·寺院(法脉同源形态多元)·岐黄(元典地方转化)
