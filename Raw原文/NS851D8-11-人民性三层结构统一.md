# 心性本源、社会关系与人民性的统一建构（马克思人学×费孝通差序×大圆满心性）

核心原象：
1. 四层递进统一框架：心性本体层 → 个体认知层 → 社会现实层 → 实践价值层
2. 人民性获得"内在心性本源"：纯粹平等觉知本心=自愿利他/不工具化的内生根基
3. 差序格局：本土认知过渡模型，需经"心性修持+社会实践"双重扬弃升华为共同体人民性
4. 内外双向：外在马克思实践(制度)·内在大圆满平等心性(自觉) → 完整人民性双维

关键边界（学术严谨）：本心≠社会本质；唯物改造自我≠佛法修心；差序圈层≠人民性——已厘清
企业落地：三维人民性→四层文化架构(心性共识/人际认知/客观制度/实践落地)→内外双层筛选→去中心化传承

风险提示（诚实，成书须守）："心性本源支撑人民性"涉及唯物×心性关系，成书表述须始终以"社会实践为物质根基、心性为内在动机补充"为纲，避免被误读为唯心主义。
