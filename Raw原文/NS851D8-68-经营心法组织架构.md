# 经营心法(12层面)+组织架构(差序设计)+《资治通鉴·三家分晋》管理秩序

核心（补《共同体名》下卷"经营心法/组织架构/管理秩序"层）：
1. **经营心法12层面**：使命(使是责任·命是生命·三维利他/未来/心灵)/愿景目标(实现使命路径·XX集团创世界级餐饮案例)/价值观(实现愿景保障·利他)/产品理念(禅食一味·药食同源·天人合一·24节气养生)/组织架构/核心能力/根本特征/人员发展/企业发展/思维方式/工作方法/格言——全面系统构建经营之道
2. **组织架构(据差序格局设计)**：核心层(师徒·家规传承·拜师礼)/紧密层(部门·礼法并重·项目茶礼)/外围层(伙伴·契约治理·诚信公约)；差序(中国水波纹/血缘地缘业缘/孝悌忠信)vs团体(西方一捆柴/契约信仰/博爱)对照
3. **《三家分晋》管理秩序哲学(极正·中国式治理)**：
   - ①组织最重要=维护秩序(天子之职莫大于礼·礼=纪纲/分=君臣/名=公侯卿大夫)
   - ②管理体系=不可违背的"礼"(管理制度·一把手最重要·先于战略用人找钱·系统改勿因人废制)
   - ③汇报线=不能逾越的"分"(职级职等定岗定编·谁向谁汇报·非极端勿越)
   - ④职位待遇=珍惜的"名"(名器不乱·繁缨/正名·防微杜渐)
   - ⑤宁做守成CEO不作死(心存敬畏/无为/不开绿灯·庸才非最大破坏者)
   - ⑥新人合理跟随(尽量避免越级汇报·公平制衡·副手上一级指派·业绩不向辛苦低头·价值观不向业绩低头)
4. 本征:实操书"从文化到经营"落点,极正(资治通鉴=中国式治理智慧·无敏感);把"礼治→现代管理制度-汇报线-职位待遇"三层
