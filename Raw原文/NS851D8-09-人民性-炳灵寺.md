# 人民性：文化存续的顶层根本标尺（炳灵寺汉藏多元文明遗存实证）

核心原象：人民性 = 文化存续的充要条件（最硬实证）
- 实物铁证（炳灵寺）：服务贵族的盛唐大型主窟 → 随王朝衰败断层；服务百姓的17-47盛唐民间浅龛 → 33座千年不断、民间自发保护
- 132窟三层叠加：北魏汉窟+明代藏密+民间关公 → 政权多次更替而文化不断，因锚定各族百姓共同诉求
- 正面：扎根百姓→千年永续；反面：服务贵族贵族→断层消亡

企业落地：三维人民性(员工/客户/社会) → 双层筛选(人民性总标尺+核心价值观细则) → 三层载体(顶层标杆/中层传导/基层特色) → 去中心化传承(不依附创始人)
学术要点：人民性=顶层本源总纲；核心价值观=当代实操细则；二者同源辩证，须协同表述
