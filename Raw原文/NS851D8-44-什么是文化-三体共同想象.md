# 什么是文化：心文化·组织三体论·共同想象凝聚大规模合作

核心（补《共同体之名》上卷"文化本体/组织三体"一层）：
1. **心文化=企业文化之魂**；四要素(语言/文字/思想/生活习惯)承载文化与企业家精神之扩散
2. **组织三体论**：企业如人=信息体(使命愿景/企业家精神认知)+能量体(关系氛围/动能)+物质体(流程成果)；三体互为、企业家精神经三体全面赋能
3. 三藏修为：世间法(套利·循规则利用规则)/道法(创新·内在修为求真理)/不二教法(冒险·超越恐惧执着)
4. **赫拉利"认知革命→虚构故事→大规模合作"**：文化的本质=能凝聚大量陌生人的"共同想象"(公司/品牌/商标皆想象现实)；企业核心竞争力=突破现实的共同故事/想象之凝聚力

去敏感处理：赫拉利宗教/国家/政治例→只留"共同想象凝聚合作"的通用企业之理
本征：企业非冷机器而="三体活体"；文化非装饰而是凝聚千人万店为一致行动的"共同心文化/共同故事"
