# 02 第一部分：西方"天人对立"观念的历史演进与哲学内涵

## 一、核心定义
**天人对立**：西方现代性的主导世界观，将人与自然、主体与客体、精神与物质二元划分，强调人类对自然客体的认识、征服与控制。它推动科技与工业文明，也埋下生态危机、意义危机与组织异化的种子。

## 二、详细内容

### 1.1 起源与核心特征
- 哲学根基：古希腊"主客二分"传统，文艺复兴与启蒙运动系统化。
- 对比："跟西方主客二分、天人对立相对照，中国的文化传统是主客交融、天人合一。"
- 自然被客体化、数学化 → 失去内在价值与神圣性，沦为满足人类欲望的工具。

### 1.2 哥白尼·人类中心主义的第一次祛魅
"哥白尼的日心说：人类不是宇宙的中心。" 地心说（地球为上帝焦点）支撑人类中心宇宙观；日心说表明地球只是普通行星，太阳亦非宇宙中心。
- 双重祛魅：去除地球中心地位 + 开启科学理性对传统宇宙观的解构。
- 意义：将人类从宇宙中心"放逐"，以客观外在视角审视自身 → 主客二分强化，是天人对立深化的关键一步。

### 1.3 达尔文·人类神圣性的进一步消解
"达尔文的进化论：人类不是上帝创造的，人是进化而来的。"
- 人类从"上帝选民"还原为自然界普通一员，与猿类共祖，无不可逾越鸿沟。
- 但进化论揭示"物竞天择，适者生存"的残酷竞争法则 → 导向另一种"对立"：自然是需要征服的对手。
- 渗透社会 → 社会达尔文主义，为殖民主义、种族主义、自由竞争资本主义提供"科学"依据；企业领域表现为"你死我活"零和博弈。

### 1.4 弗洛伊德·人类理性的最后祛魅
"弗洛伊德建立的精神分析：人跟动物一样，都受力比多驱动。"
- 理性意识下存在广阔无意识领域（本能冲动、被压抑欲望、童年创伤），人类行为多受无意识驱动，理性常为本能找合理化借口。
- "人也是有基本的动物的本能驱动的，有生殖本能、死本能"——泛性论。
- 意义：从内部瓦解人类作为理性主体的自信；内在不确定感反而强化对外在控制（技术/组织）的渴望 → 现代企业机械系统不断强化的心理动因。

### 1.5 天人对立在企业机械系统中的体现（五维度）
| 维度 | 机械系统表现 |
|------|------|
| 人与自然 | 自然=资源库+垃圾场，最大化利用最小化责任 |
| 人与社会 | 社会=市场+监管，交易而非共生，责任形式化 |
| 人与组织 | 员工=人力资源+生产要素，泰勒科学管理将劳动简化为标准机械动作 |
| 组织与组织 | 竞争对手=敌人，商场如战场，零和博弈 |
| 内部结构 | 严密科层制+分工，追求可预测与控制（韦伯典范） |

> 草原对比："草原上的人天亮起、天黑息、无手机信号，正儿八经跟天地合一；机械生命则按24小时、上班8小时的人为时间过生命。"——机械系统按人为时间规则运转，造成人的异化与生态破坏。
