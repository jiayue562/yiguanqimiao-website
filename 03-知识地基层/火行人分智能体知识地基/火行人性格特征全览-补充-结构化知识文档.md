## 三、动态转化模型

**支持性环境**（被看见+被尊重+有舞台）：
```
热情感染力 → 明察洞见 → 明辨守礼 → 高效推动 → 温暖关爱
（整合人格：感染力 + 智慧 + 品格 + 行动力 + 温度）
```

**受挫性环境**（被忽视+被否定+无舞台）：
```
炫耀虚荣 → 主观武断 → 嗔恨批判 → 冲动浮躁 → 索取控制
（防御人格：表演 + 偏执 + 攻击 + 混乱 + 控制）
```
