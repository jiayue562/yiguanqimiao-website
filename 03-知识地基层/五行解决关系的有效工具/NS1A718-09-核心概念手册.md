## 二、五行关系属性速查
```
木：生发·条达·仁爱 → 关系:成长/创新/正直(固执/抗上) → 关注:自我成长/理想
火：炎上·光明·礼仪 → 关系:热情/主动/表达(急躁/冲动) → 关注:情感连接/价值认可
土：承载·包容·信义 → 关系:稳定/协调/支持(犹豫/固执) → 关注:安全感/和谐稳定
金：收敛·肃杀·决断 → 关系:秩序/公正/义气(挑剔/冷漠) → 关注:规则标准/目标达成
水：润下·智慧·变通 → 关系:适应/包容/智慧(逃避/消极) → 关注:情感深度/内在需求
```

## 三、五伦↔五行 映射速查
```
父子：父母(木)生发 ↔ 子女(水)智慧    健康:水生木(子女成就滋养父母)
君臣：上级(金)决断 ↔ 下级(木)执行    理想:金生水(决策支持下级智慧)
夫妇：火↔水 / 金↔木 等组合           和谐:水火既济(互补) vs 火水未济(冲突)
兄弟：关系同辈相生相克
朋友：信义(土)为基·互通有无
        ↑ 相克僵持 → 通关法(引入第三方能量)
```
