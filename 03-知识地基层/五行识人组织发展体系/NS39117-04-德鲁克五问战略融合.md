# 四、德鲁克"经典五问"与五行识人模型的战略融合

整合《德鲁克"经典五问"与五行识人模型的战略融合》，用五行框架解码德鲁克战略五问。

## 4.1 德鲁克五问 × 五行映射

| 德鲁克五问 | 五行维度 | 五行识人解码 |
|-----------|---------|------------|
| 我们的使命是什么？ | 灵界(原象)·土/水 | 使命=组织的"土行承载+水行长期储备"，是稳定与远见的统一 |
| 我们的顾客是谁？ | 火行(连接)·水行(精细) | 顾客=火行需连接影响、水行需精细适配需求 |
| 顾客看重的价值是什么？ | 水行(适配)·火行(服务) | 价值=水行精准满足+火行情感连接 |
| 我们的成果是什么？ | 金行(效率)·木行(创新) | 成果=金行量化结果+木行创新增量 |
| 我们的计划是什么？ | 木行(生发)·土行(承载) | 计划=木行战略生发+土行务实落地 |

## 4.2 五行事业理论：使命-顾客-价值-成果-计划的能量闭环

```
使命(土水·灵界)
  │ 界定组织能量方向
  ▼
顾客(火水·连接精细)
  │ 明确能量作用对象
  ▼
价值(水火·适配服务)
  │ 能量转化的衡量标准
  ▼
成果(金木·效率创新)
  │ 能量产出的验证
  ▼
计划(木土·生发承载)
  │ 能量落地的路径
  ▼
回归使命(动态平衡)
```

## 4.3 战略诊断的五行视角

- 使命模糊 = 灵界原象扭曲（阴土疑/阴水痴）→ 需用阳土信、阳水智重塑。
- 顾客错位 = 火水配比失衡 → 补火行连接或水行精细。
- 成果失真 = 金行过亢(唯KPI)或木行不足(无创新) → 化克为生。
