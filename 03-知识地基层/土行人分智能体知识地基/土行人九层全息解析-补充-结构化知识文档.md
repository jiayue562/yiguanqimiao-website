## 一、核心定义

**土行人九层发展层级**：基于"一心三界五行九层"全息发展理论，土行能量的"承载性"与"稳定性"从阳土（信实、包容、厚德载物）到阴土（疑忌、固执、壅滞沉沦）的完整演变光谱。九层模型描绘了从健康整合到病态分裂的连续心理地形图，既是诊断当前状态的"坐标仪"，也是反向修炼的"路线图"。

**核心公式**：层级升降 = 阴土能量（疑/怨/僵/控）与阳土能量（信/思/容/稳）的比例变化 + 三界协同度

**三大区间**：①健康状态(1-3层)·阳土主导·三界协同 ②一般状态(4-6层)·阴阳交战·三界失衡 ③不健康状态(7-9层)·阴土固化·三界扭曲

```
一心（承载觉知：土行=承载性+稳定性）
  ↓ 显化
三界（灵界=信/疑·心界=思/怨·身界=稳/僵）
  ↓ 遵循
五行（火生土/土生金/木克土/土克水）
  ↓ 量化
九层（实虚阶梯：从阳土信实到阴土疑滞的完整光谱）
```

**核心公式**：层级升降 = 阴土(疑/怨/僵/控)与阳土(信/思/容/稳)的比例变化 + 三界从协同到失衡的动态过程

## 三、健康区间（第1-3层）

### 第1层·解放层级——厚德载物，无为而化

| 维度 | 详述 |
|:----|:------|
| **①意向** | "至诚无息，寂然不动，感而遂通"。无分别地包容承载万物，信德非刻意守之而是本然状态 |
| **②性格** | 宽厚诚信，无丝毫固执猜忌。情绪极度稳定源于深层存在性安全感。思维开阔能整合多元观点 |
| **③行为** | 无为而化，稳重可靠有担当。滋养万物而不居功，是团队凝聚力的绝对核心 |
| **④三界** | **高度和合**。灵界→心界→身界完美协同。五行阳性能量纯熟流畅：戊己合圭、中黄直透 |
| **⑤拔阴取阳** | 维持"保任"——意诚心正，平息后天妄念让先天元神主宰。行"呼"字诀养脾静土，站桩意守中宫 |

---

### 第2层·心理能力层级——中流砥柱，主动承载

| 维度 | 详述 |
|:----|:------|
| **①意向** | "致中和，天地位焉"。从纯粹承载转向主动整合维系和谐，有了"我应该维持和谐"的责任框架 |
| **②性格** | 坚韧不拔务实稳健，极强耐力包容心。天然协调者和支持者。已初显"过度负责"苗头 |
| **③行为** | 沉稳应对善于补位，执行力强。主动维护系统稳定，承担繁琐持久任务。可靠但已有"努力维持"痕迹 |
| **④三界** | **基本协同但有轻微波动**。五行土生金旺盛，但对水(变化)的克制初显 |
| **⑤拔阴取阳** | "阴土忧转阳土思"：担忧时转为系统性思考"我的应对预案是什么？"练习授权信任他人 |

### 第3层·社会价值层级——成就认可，稳定大局

| 维度 | 详述 |
|:----|:------|

| **④三界** | **协同但张力初显**。木克土矛盾浮现：对变革的抗拒。需防土气壅滞导致消化不良 |
| **⑤拔阴取阳** | "苟日新日日新"——主动拥抱微小变革。"运"字功运动导引，引入木性活动用生机疏通板结 |

## 四、一般区间（第4-6层）

### 第4层·失衡层级⚠️——固执己见，拒绝变通

| 维度 | 详述 |
|:----|:------|
| **①意向** | "维持现状，抗拒变化"。从积极承载退缩为消极维持。信沦为对旧模式的盲目忠诚 |
| **②性格** | 呆板无趣爱较真固执保守。心界被忧思主导，对未来不安，思维僵化缺乏弹性 |
| **③行为** | 墨守成规难以突破。以"责任"和"可靠"名义行控制之实，阻碍必要创新 |
| **④三界** | **轻度失衡**。灵界固执→心界忧思→身界僵化形成恶性循环。阴土初显，木克土关系紧张 |
| **⑤拔阴取阳** | **核心"通"字诀**："信的真实是顺应天道变化而非固守不变"。小冒险打破日常routine，引入火行愿景思考变化的好处。嘘字(疏肝木)+呼字(健脾土)结合 |

### 第5层·人际控制层级🔥🔥——多疑敏感，操控求安

**定位：最常见困境·拔阴取阳主战场**

| 维度 | 详述 |
|:----|:------|
| **①意向** | **被"恐惧失控"驱使**。必须被需要必须掌控一切才能安全。信彻底扭曲为对控制权的执着 |
| **②性格** | 多疑算计固执己见，缺乏安全感。用"责任""承诺"道德捆绑他人。情绪沉闷压抑易生怨气 |
| **③行为** | **操控性**。制造他人依赖感/内疚感/利用规则操控人际关系。被动攻击——答应拖延不做 |
| **④三界** | **失衡链条固化**：灵界控制→心界疑惧→身界操控。阴土主导，土克水过度(压抑智慧变通) |
| **⑤拔阴取阳** | **核心"怨转思"**：怨猜疑时→暂停→"对方的动机可能是什么？我的安全感一定要来自控制吗？"授权实验：从小事开始授权不干预。呼字诀健脾祛湿+呵字诀养心火 |

## 七、核心金句

1. 真正的稳定不是固守疆界，而是内心如大地般无分别的承载觉知。
2. 第4层是分水岭——在这里，你选择"通"还是"堵"，决定了是向上还是向下。
3. 第5层的"怨转思"不是压抑情绪，而是把板结的能量疏通为活水。
4. 从"固守疆界的僵土"到"滋养万物的沃土"——九层修炼的终极指向。
5. 健康不是没有阴土，而是阳土的承载足够厚实，使阴土的疑滞自然消融。
