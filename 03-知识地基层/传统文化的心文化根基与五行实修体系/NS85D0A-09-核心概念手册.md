## 二、五重五行映射速查（同一五行在不同层面的显化）
```
五行    宇宙法则(易)   生命系统(医)   伦理德能(儒)   宇宙图景(道)   心性障碍(禅)
木  →   生发/曲直      肝/怒         仁/直          青龙/春        贪/执着(⚠️另说火行人)
火  →   炎上/光明      心/喜         礼/明          朱雀/夏        嗔/对抗(⚠️另说木行人)
土  →   稼穑/承载      脾/思         信/稳          勾陈/长夏      痴/无明(⚠️另说水行人)
金  →   从革/收敛      肺/忧         义/决          白虎/秋        慢/傲慢(共识)
水  →   润下/藏纳      肾/恐         智/深          玄武/冬        疑/不信(⚠️另说土行人)
```
> ⚠️ 五毒列"另说"指《五毒自解》节点映射(贪=火/嗔=木/痴=水/慢=金/疑=土)，与本篇不同。详见 [[03-知识地基层/传统文化的心文化根基与五行实修体系/NS85D0A-10-知识图谱]] 联系M。

## 三、五常↔五行 映射速查
```
仁(木)：生发仁爱 → 人际关系关怀包容 → 阳面:仁心 / 阴面:固执抗上
义(金)：收敛决断 → 人际关系公正担当 → 阳面:义气 / 阴面:刻薄挑剔
礼(火)：炎上光明 → 人际关系尊重表达 → 阳面:礼心 / 阴面:虚伪急躁
智(水)：润下藏纳 → 人际关系明辨变通 → 阳面:智心 / 阴面:狡诈逃避
信(土)：承载稳定 → 人际关系诚实可靠 → 阳面:信心 / 阴面:固执不化
        ↑ 拔阴取阳:阴面转阳面(联系I)
```
