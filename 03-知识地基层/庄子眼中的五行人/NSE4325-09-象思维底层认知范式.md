# 九、象思维：五行识人的底层认知范式

## 9.1 象思维与《庄子》思想的同构性

- **认知层次同构**：物象→意象→原象 = 观物→体物→体道
- **核心特质同构**：动态整体直观 = 顺应自然、不执不滞

## 9.2 六非特征 ↔ 庄子顺应自然

| 象思维六非 | 《庄子》对应 |
|-----------|-----------|
| 非实体性 | 「物无非彼，物无非是」(万物流动无固定实体) |
| 非对象性 | 「天地与我并生，而万物与我为一」(主客同源) |
| 非现成性 | 「物有常然，理有固然」(规律动态需顺应) |
| 整体直观性 | 「听之以气」(整体感知能量本质) |

| 阶段 | 五行识人体现 | 《庄子》对应 |
|------|-----------|-----------|
