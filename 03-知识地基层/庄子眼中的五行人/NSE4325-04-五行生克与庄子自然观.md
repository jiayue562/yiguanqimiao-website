# 四、五行：三界能量运行的底层逻辑与《庄子》自然观

## 4.1 核心规律：相生相克 = 阴阳相照

五行生克非人为设定，是对自然能量流动规律的提炼，与《庄子》「阴阳相照，相盖相治」自然观完全一致。

## 4.2 相生：能量的自然滋养 = 生而不有

| 相生 | 《庄子》印证 | 陈鼓应注 |
|------|-----------|---------|
| 木生火 | 「木与木相摩则然(燃)」 | 自然能量自然转化，无外在强制 |
| 火生土 | 「天地之气，莫大于和」 | 火温热与土寒凉调和孕育万物 |
| 土生金 | 「大块载我以形，劳我以生」 | 大地承载金属生成，自然孕育 |
| 金生水 | 「水行莫如用舟…」 | 金属凝实能凝聚水汽，规律自然显现 |
| 水生木 | 「水之积也不厚，则其负大舟也无力」 | 水滋养树木是自然的本能 |

## 4.3 相克：能量的自然制约 = 物壮则老

相克(木克土/土克水/水克火/火克金/金克木)本质避免单一能量过亢，对应《庄子》「物壮则老，谓之不道，不道早已」（庄子继承老子）。

| 相克 | 《庄子》印证 |
|------|-----------|
| 木克土 | 「播糠眯目，则天地四方易位」——木创新破土僵化 |
| 土克水 | 「秋水时至，百川灌河」——土规则规范水泛滥 |
| 水克火 | 「轻用民死，民不聊生」——水沉静平复火躁亢 |
| 火克金 | 「强者，累之以形」——火包容软化金刚愎 |
| 金克木 | 「德有所长而形有所忘」——金收敛克制木傲慢 |

> 相克的「克」不是对抗，而是「适度制约」，即《庄子》「和而不同」平衡智慧。

## 4.4 实践口诀（一）：拔阴取阳 = 去伪存真

口诀：「欲生真水，必认不是；欲生真金，必找好处；欲生真土，必信因果；欲生真火，必达天时。水金土火，通透豁达；仁德阳木，自然而生。」
- 认不是 ↔ 齐物论「彼亦一是非，此亦一是非」(放下是非执着)
- 找好处 ↔ 「善人者，不善人之师」(发现他人本性)
- 信因果 ↔ 「死生，命也；其有夜旦之常，天也」(信自然规律)
- 达天时 ↔ 「当其时，顺其俗者，谓之义徒」(顺应时机)

> **隐秘同构 Z-I**：拔阴取阳=去伪存真 = [[五行化性通关点_00-总索引]] —— 阴面=不精不诚的造作，阳面=精诚本真，与五行化性「拔阴取阳」完全一致。

## 4.5 实践口诀（二）：化克为生 = 顺势而为

口诀：「木克土，胃发堵；土生金，木畏金。土克水，常后悔；水生木，土畏木。水克火，急窝火；火生土，水畏土。火克金，人不亲；金生水，火畏水。金克木，气不舒；木生火，金畏火。」
- 木克土(胃发堵)→土生金(强化土承载、滋养金收敛)制约木过度造作 ↔ 「缘督以为经」
- 土克水(常后悔)→水生木(智慧滋养创新)打破土固执 ↔ 「播糠眯目」
- 水克火(急窝火)→火生土(热情滋养信心)打破水消极 ↔ 「鸿蒙…心养」
- 火克金(人不亲)→金生水(自省滋养智慧)打破火急躁 ↔ 「无听之以耳…听之以气」
- 金克木(气不舒)→木生火(成长滋养包容)打破金狭隘 ↔ 「登高不慄，入水不濡」

> **隐秘同构 Z-J**：化克为生=顺势而为 = [[五行化克为生理论体系_00-总索引]] —— 「顺物自然而无容私焉」，将阻滞转化为平衡，与化克为生核心逻辑同构。
