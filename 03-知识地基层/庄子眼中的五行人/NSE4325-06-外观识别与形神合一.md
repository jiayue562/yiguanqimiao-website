# 六、外观识别口诀：融合象思维与《庄子》「形神关系」的外在显化

## 6.1 总口诀及象理解析

> 木瘦金方水必肥，上尖下阔为真火，土行背厚晃如龟，朝中方白属金行。

本质「形神合一」：外在形态(形)是内在精神(神)的自然显化，与《庄子·德充符》「形骸有亏而精神充盈」一致——形是神的显化，神是形的主宰。

## 6.3 分五行外观特征（形神合一深化）

1. **木行人**：取象树木修长 → 三瘦(长)：身直(正直豁达)、肢长(舒展无拘)、形瘦(专注内敛)
2. **火行人**：取象火焰炎上 → 三尖(突)：上尖(突破欲)、形突(V字体型肩宽)、轮廓锐(明辨是非)
3. **土行人**：取象大地厚重 → 三厚(短)：身厚(负重)、肉厚(温润包容)、形敦(稳定坚定)
4. **金行人**：取象金属方正 → 三方(薄)：脸方(原则坚定)、唇薄(言语精炼)、质薄(通透纯粹)
5. **水行人**：取象水流圆润 → 三肥(圆)：身圆(A字臀)、肤松(从容不迫)、形垂(沉潜内敛)
