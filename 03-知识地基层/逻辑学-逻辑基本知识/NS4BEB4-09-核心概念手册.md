## 一、思维形式三要素（全书地基）

- **概念** → 思维的最小单位，反映事物本质属性，通过语词表达。见[[NS4BEB4-03-第三章-定义与划分|定义与划分]]、[[03-知识地基层/逻辑学-逻辑基本知识/NS4BEB4-01-第一章-绪论|思维与语言]]。
- **判断** → 对事物情况有所断定的思维形式（肯定/否定；全称/特称/单称）。见[[03-知识地基层/逻辑学-逻辑基本知识/NS4BEB4-01-第一章-绪论|思维与语言]]。
- **推理** → 由已知判断推出新判断的思维形式，是思维的最高层级。见[[03-知识地基层/逻辑学-逻辑基本知识/NS4BEB4-01-第一章-绪论|思维与语言]]、[[NS4BEB4-04-第四章-演绎推理|演绎推理]]、[[NS4BEB4-05-第五章-归纳推理|归纳推理]]。

## 二、逻辑形式与语言（第一、二章）

- **逻辑** → 音译自希腊语"逻各斯（λογος）"，日常有四义：①客观事物规律 ②理论观点 ③思维规律规则 ④逻辑学本身。见[[03-知识地基层/逻辑学-逻辑基本知识/NS4BEB4-01-第一章-绪论|逻辑四义]]。
- **思维** → 人脑对客观事物的概括和间接反映；语言是思维的物质外壳。见[[03-知识地基层/逻辑学-逻辑基本知识/NS4BEB4-01-第一章-绪论|思维与语言]]。
- **逻辑形式** → 表达思维内容的联结方式（如"所有S都是P"），由常项+变项构成。见[[03-知识地基层/逻辑学-逻辑基本知识/NS4BEB4-01-第一章-绪论|思维形式与内容]]。
- **常项** → 逻辑形式中决定性质的部分（如"所有""都是"）。见[[03-知识地基层/逻辑学-逻辑基本知识/NS4BEB4-01-第一章-绪论|常项与变项]]。
- **变项** → 逻辑形式中可代入不同概念/命题的符号（S、P、p、q）。见[[03-知识地基层/逻辑学-逻辑基本知识/NS4BEB4-01-第一章-绪论|常项与变项]]。
- **命题** → 可判断真假的陈述句；疑问句、祈使句不表达命题。见[[03-知识地基层/逻辑学-逻辑基本知识/NS4BEB4-01-第一章-绪论|命题形式与真值]]。
- **真值** → 命题的真假属性；经典逻辑仅有"真/假"二值。见[[03-知识地基层/逻辑学-逻辑基本知识/NS4BEB4-01-第一章-绪论|命题形式与真值]]。
- **形式逻辑** → 以思维形式及其规律为研究对象，要求满足四律。见[[03-知识地基层/逻辑学-逻辑基本知识/NS4BEB4-01-第一章-绪论|形式/非形式逻辑]]。
- **非形式逻辑** → 研究日常语境中的实际论证，不依赖人工符号。见[[03-知识地基层/逻辑学-逻辑基本知识/NS4BEB4-01-第一章-绪论|形式/非形式逻辑]]。
- **演绎逻辑** → 前提必然推出结论（前提真+形式有效→结论必真）。见[[03-知识地基层/逻辑学-逻辑基本知识/NS4BEB4-01-第一章-绪论|演绎/归纳逻辑]]、[[NS4BEB4-04-第四章-演绎推理|演绎推理]]。
- **归纳逻辑** → 个别→一般，结论超出前提、具或然性。见[[03-知识地基层/逻辑学-逻辑基本知识/NS4BEB4-01-第一章-绪论|演绎/归纳逻辑]]、[[NS4BEB4-05-第五章-归纳推理|归纳推理]]。
- **现代逻辑** → 19世纪中叶后在数理逻辑基础上发展，核心是形式化（符号化/公理化/形式证明）。见[[03-知识地基层/逻辑学-逻辑基本知识/NS4BEB4-01-第一章-绪论|现代逻辑]]。
- **莱布尼茨** → 现代逻辑奠基人，首倡用数学方法处理演绎逻辑、把推理变成逻辑演算。见[[03-知识地基层/逻辑学-逻辑基本知识/NS4BEB4-01-第一章-绪论|现代逻辑名称]]。
- **名辩学** → 中国先秦逻辑（名学+辩学），与古希腊逻辑、古印度因明并称三大起源；墨家"辩、类、故""三表"为早期体系。见[[03-知识地基层/逻辑学-逻辑基本知识/NS4BEB4-01-第一章-绪论|逻辑起源]]。
- **语言三职能** → 交流思想、表达感情、指使行为；前两者及指使行为需严格合逻辑。见[[NS4BEB4-02-第二章-逻辑与语言|语言职能]]。
- **自然语言** → 生活中形成的语言（汉语/英语等），灵活但有歧义。见[[NS4BEB4-02-第二章-逻辑与语言|自然语言vs人工语言]]。
- **人工语言** → 为精确创造的符号系统（逻辑符号/数学/编程），无歧义但脱离日常。见[[NS4BEB4-02-第二章-逻辑与语言|自然语言vs人工语言]]。
- **语言形式** → 语句的语法结构（主谓宾等）。见[[NS4BEB4-02-第二章-逻辑与语言|语言形式vs逻辑形式]]。
- **预设** → 语句成立的隐含前提（"你何时戒烟"预设"你抽过烟"）。见[[NS4BEB4-02-第二章-逻辑与语言|预设与语境]]。
- **语境** → 语句所处的语言环境（上下文/时间/地点/说话人）。见[[NS4BEB4-02-第二章-逻辑与语言|预设与语境]]。
- **对象语言** → 被分析文本自身的语言（如《放下包袱》原文）。见[[NS4BEB4-02-第二章-逻辑与语言|对象/元语言]]。
- **元语言** → 描述对象语言的语言（逻辑术语、分析语句）。见[[NS4BEB4-02-第二章-逻辑与语言|对象/元语言]]。

## 三、概念明确（第三章·定义与划分）

- **内涵** → 概念所反映事物的本质属性。见[[NS4BEB4-03-第三章-定义与划分|内涵与外延]]。
- **外延** → 概念所包含事物的范围。见[[NS4BEB4-03-第三章-定义与划分|内涵与外延]]。
- **反变关系** → 内涵越多则外延越小，反之亦然。见[[NS4BEB4-03-第三章-定义与划分|内涵与外延]]。
- **指称论** → 意义理论之一：语词意义=所指对象。见[[NS4BEB4-03-第三章-定义与划分|意义理论]]。
- **观念论** → 意义理论之一：语词意义=所引发观念。见[[NS4BEB4-03-第三章-定义与划分|意义理论]]。
- **功用论** → 意义理论之一：语词意义=实际使用中的作用。见[[NS4BEB4-03-第三章-定义与划分|意义理论]]。
- **同音词** → 语音同但意义无关（"室"/"试"）。见[[NS4BEB4-03-第三章-定义与划分|概念关系]]。
- **同义词** → 意义相同或相近（"父亲"/"爸爸"）。见[[NS4BEB4-03-第三章-定义与划分|概念关系]]。
- **多义词** → 同一语词多义（古汉语"足"=脚/足够），易生歧义。见[[NS4BEB4-03-第三章-定义与划分|概念关系]]。
- **上位词** → 外延更大的概念（"水果"）。见[[NS4BEB4-03-第三章-定义与划分|概念关系]]。
- **下义词** → 外延更小、内涵更多的概念（"苹果"）。见[[NS4BEB4-03-第三章-定义与划分|概念关系]]。
- **反义词** → 意义相反（"真"/"假"），是矛盾/反对关系的基础。见[[NS4BEB4-03-第三章-定义与划分|概念关系]]。
- **定义** → 通过明确内涵来明确概念的方法。见[[NS4BEB4-03-第三章-定义与划分|定义目的与种类]]。
- **外延定义** → 通过明确外延下定义（适合外延小的概念）。见[[NS4BEB4-03-第三章-定义与划分|定义种类]]。
- **内涵定义** → 通过明确内涵下定义，最常用"属加种差"。见[[NS4BEB4-03-第三章-定义与划分|定义种类]]。
- **属加种差** → 被定义项=种差+邻近属概念（如"正方形=有一个直角且四边相等的平行四边形"）。见[[NS4BEB4-03-第三章-定义与划分|属加种差]]。

## 四、推理（第四、五章）

- **三段论** → 大前提+小前提+结论；中项M至少周延一次。见[[NS4BEB4-04-第四章-演绎推理|三段论]]。
- **周延** → 概念在命题中断定了全部外延；前提不周延的项结论不得周延。见[[NS4BEB4-04-第四章-演绎推理|三段论规则]]。
- **复合命题** → 简单命题+联结词（联言/选言/假言/负）。见[[NS4BEB4-04-第四章-演绎推理|复合命题]]。
- **联言命题** → "p且q"，全真才真、一假则假。见[[NS4BEB4-04-第四章-演绎推理|复合命题]]。
- **选言命题** → "p或q"（相容）/"要么p要么q"（不相容）。见[[NS4BEB4-04-第四章-演绎推理|选言推理]]。
- **假言命题** → 充分条件/必要条件/充要条件三种条件关系。见[[NS4BEB4-04-第四章-演绎推理|假言推理]]。
- **充分条件** → "如果p那么q"；规则：肯前必肯后、否后必否前。见[[NS4BEB4-04-第四章-演绎推理|假言推理]]。
- **必要条件** → "只有p才q"；规则：否前必否后、肯后必肯前。见[[NS4BEB4-04-第四章-演绎推理|假言推理]]。
- **充要条件** → "当且仅当p才q"，前后互推。见[[NS4BEB4-04-第四章-演绎推理|假言推理]]。
- **负命题** → 否定某命题，真值与原命题相反。见[[NS4BEB4-04-第四章-演绎推理|复合命题]]。
- **二难推理** → 两假言+一选言前提，令对方进退两难；选言须穷尽，否则"假二难"。见[[NS4BEB4-04-第四章-演绎推理|二难推理]]。
- **完全归纳** → 考察全部对象后推一般，前提真则结论必真（必然）。见[[NS4BEB4-05-第五章-归纳推理|完全/不完全归纳]]。
- **简单枚举归纳** → 部分对象无反例即推一般，易证伪（或然）。见[[NS4BEB4-05-第五章-归纳推理|不完全归纳]]。
- **科学归纳** → 结合因果分析，可靠性高于简单枚举。见[[NS4BEB4-05-第五章-归纳推理|不完全归纳]]。
- **穆勒五法** → 求同/求异/求同求异并用/共变/剩余。见[[NS4BEB4-05-第五章-归纳推理|穆勒五法]]。
- **求同法** → 异中求同，多场合唯一共同点即原因。见[[NS4BEB4-05-第五章-归纳推理|穆勒五法]]。
- **求异法** → 同中求异，两场合唯一不同点即原因。见[[NS4BEB4-05-第五章-归纳推理|穆勒五法]]。
- **求同求异并用法** → 正反场合群对比确定因果。见[[NS4BEB4-05-第五章-归纳推理|穆勒五法]]。
- **共变法** → 因果共变，一现象随另一现象变化而变化。见[[NS4BEB4-05-第五章-归纳推理|穆勒五法]]。
- **剩余法** → 从余果推余因（居里夫人发现镭）。见[[NS4BEB4-05-第五章-归纳推理|穆勒五法]]。
- **类比推理** → 两对象部分属性同→其他属性同；或然性高。见[[NS4BEB4-05-第五章-归纳推理|类比推理]]、[[NS4BEB4-08-附录-课文逻辑分析|《订鬼》类比]]。

## 五、思维四律（第六章）

- **同一律** → 同一思维过程中概念/命题须保持同一（A是A）；违则"偷换概念/转移论题"。见[[NS4BEB4-06-第六章-思维的基本规律|同一律]]。
- **不矛盾律** → 矛盾/反对命题不能同真、必有一假（A不是非A）；违则"自相矛盾"。见[[NS4BEB4-06-第六章-思维的基本规律|不矛盾律]]。
- **排中律** → 矛盾命题不能同假、必有一真（要么A要么非A）；违则"两不可"；只适用于矛盾命题。见[[NS4BEB4-06-第六章-思维的基本规律|排中律]]。
- **充足理由律** → 论证中确定判断为真须有充足理由（B真且B推A）；属"论证的基本规律"，与前三律不同层次。见[[NS4BEB4-06-第六章-思维的基本规律|充足理由律]]。
- **矛盾命题** → 不能同真也不能同假，必有一真一假。见[[NS4BEB4-06-第六章-思维的基本规律|矛盾/反对辨析]]。
- **反对命题** → 不能同真但可同假（如"全及格"与"全没及格"）。见[[NS4BEB4-06-第六章-思维的基本规律|矛盾/反对辨析]]。

## 六、谬误（第七章·三大类）

- **语形谬误** → 因语法结构/词序导致的逻辑错误。见[[NS4BEB4-07-第七章-谬误|语形谬误]]。
- **句义含混** → 结构歧义致多解（"父在母先亡""三个学校的领导"）。见[[NS4BEB4-07-第七章-谬误|句义含混]]。
- **复杂问句** → 隐含未证实预设的问句（"你何时戒烟""你为何杀人"）。见[[NS4BEB4-07-第七章-谬误|复杂问句]]。
- **断章取义** → 脱离语境截取局部歪曲原意（"维民所止"文字狱）。见[[NS4BEB4-07-第七章-谬误|断章取义]]。
- **语义谬误** → 因语词/语句意义误用导致的错误。见[[NS4BEB4-07-第七章-谬误|语义谬误]]。
- **歧义谬误** → 多义词特定语境两解（"夔一足"）。见[[NS4BEB4-07-第七章-谬误|歧义]]。
- **混义谬误** → 同一语词先后用不同含义（"运动"混用）。见[[NS4BEB4-07-第七章-谬误|混义]]。
- **语义不明** → 语词模糊无法理解（"未来的金属"）。见[[NS4BEB4-07-第七章-谬误|语义不明]]。
- **重点强调不当** → 过度强调个别词忽略整体（"不要对邻居做假证"）。见[[NS4BEB4-07-第七章-谬误|重点强调不当]]。
- **偷换概念** → 不保持概念同一性（"鲁迅的著作"集合/非集合混用）。见[[NS4BEB4-07-第七章-谬误|偷换概念]]。
- **同语反复** → 定义项直接含被定义项（"乐观者=乐观对待生活的人"）。见[[NS4BEB4-07-第七章-谬误|同语反复与循环定义]]。
- **循环定义** → 概念相互定义绕圈子（"丈夫=妻子的爱人"）。见[[NS4BEB4-07-第七章-谬误|同语反复与循环定义]]。
- **语用谬误** → 交际语境中产生的逻辑错误。见[[NS4BEB4-07-第七章-谬误|语用谬误]]。
- **语境混淆** → 不顾语境差异滥用语句（"你真行"表贬）。见[[NS4BEB4-07-第七章-谬误|语境混淆]]。
- **预设错误** → 语句预设不成立（"你停止打老婆了吗"）。见[[NS4BEB4-07-第七章-谬误|预设错误]]。
- **人身攻击** → 不反驳观点而攻人格身份（"你犯过罪没资格谈哲学"）。见[[NS4BEB4-07-第七章-谬误|人身攻击]]。
- **诉诸权威** → 仅以权威言论支撑论点而无据（整篇引名言无事实）。见[[NS4BEB4-07-第七章-谬误|诉诸权威]]。
- **滑坡谬误** → 夸大连锁反应必然性阻止A（"用手机→玩游戏→考不上大学"）。见[[NS4BEB4-07-第七章-谬误|滑坡谬误]]。
