# 时空全息论 · 五、时空一体：时空全息的核心

> **五行属性**：水（流动不二，时空互摄）｜ **关联**：[[总索引-时空全息论]] ｜ [[时空全息论-03-空间全息：立体空间模型]] ｜ [[时空全息论-04-时间全息：三际贯通]]

## 核心定义

**时空一体**：空间与时间并非两个独立维度，而是一体不二。宇（空间）即宙（时间），方位即时辰。这是时空全息论的**核心**。

## 详细内容

### 1. 宇与宙：中国传统的时空一体观
- 《尸子》："**上下四方曰宇，往古来今曰宙。**"
- 宇 = 空间的全部；宙 = 时间的全部。
- 宇宙 = 时空全息的总名。无空间则时间无所依，无时间则空间无所变。

### 2. 后天八卦与地支：时空一体的经典模型
| 方位 | 后天八卦 | 十二地支 | 时空意义 |
|------|---------|---------|---------|
| 正北 | 坎 | 子 | 水·冬·午夜·阴极阳生 |
| 东北 | 艮 | 丑、寅 | 土·冬春之交·黎明前 |
| 正东 | 震 | 卯 | 木·春·日出·阳气升发 |
| 东南 | 巽 | 辰、巳 | 木·春夏之交·日升 |
| 正南 | 离 | 午 | 火·夏·日中·阳极阴生 |
| 西南 | 坤 | 未、申 | 土·夏秋之交·日昃 |
| 西北 | 乾 | 戌、亥 | 金·秋冬之交·夜 |

**空间即时间，时间即空间**：
- 子时在正北——午夜、冬至，阴极阳生；
- 卯时在正东——日出、春分，阳气升发；
- 午时在正南——日中、夏至，阳极阴生；
- 酉时在正西——日落、秋分，阳气收敛。
**方位即时辰，空间即时间，时空不二。**

### 3. 时空一体的内在逻辑
- **空间是时间的凝固**：定格一瞬间，空间格局便是那个时刻的"切片"。建筑、化石、地貌，都是过去时间的空间留存。
- **时间是空间的流动**：万物变化、空间移位转化生灭，便是时间在显现。流水、四季、花开，都是空间在时间中的演化。
- **王夫之《思问录》**："天地之化，日新而不已。其不已者，非以空间为体，以时间为用；乃**时统空间，空间即时间之所现也**。"——时间统摄空间，空间是时间的显现。

### 4. 观象中的时空一体
- 观"春"：既是时间（春季），也是空间（东风、草木、温润之气）。春时与春位一体。
- 观"离卦"：既是空间结构（中空、附丽），也是时间动态（火需续薪，不止则灭）。
- 观"水"：既是空间形态（流动、润下），也是时间过程（源头活水、逝者如斯）。
**空间即时间，时间即空间。时空本是一体，观象即是观时空一体。**

## 隐秘知识联系

1. **时空一体 ↔ 相对论时空观**：爱因斯坦"时空连续统（spacetime）"——时间与空间不可分割，质量弯曲时空。本文"无空间则时间无所依，无时间则空间无所变"与相对论不谋而合，且早两千年。
2. **王夫之"时统空间" ↔ 过程哲学**：怀特海过程哲学"实在即过程"与"时统空间"共振——存在是生成之流。
3. **方位即时辰 ↔ 中医子午流注**：针灸"子时胆经、午时心经"正是地支时空一体在人体的应用，证明该模型具实操科学价值。
4. **"空间是时间的凝固" ↔ 化石学/地质学**：岩层是时间的空间切片——古人直觉与现代地层学一致。
