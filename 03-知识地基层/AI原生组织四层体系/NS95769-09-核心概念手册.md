# AI原生组织四层体系 · 核心概念手册

> 全体系术语卡片，每条含「定义 + 所在文件 + 关联概念 [[链接]]」。跨链标注指向龙心OS/五行/复杂系统等外部体系（落实"发隐秘知识联系"要求）。

## 一、哲学底层概念（见 [[NS95769-01-马克思视野下的个人哲学]]）

- **元公式（合于道→自然显化）** → AI原生组织统一校准公式：AI承担并行执行协调，人守不可替代判断责任，二者在数据层统一校准下运转；逆用显化指标反向印证"合道"。所在：[[NS95769-01-马克思视野下的个人哲学]]§3.4、[[03-知识地基层/AI原生组织四层体系/NS95769-02-AI原生组织顶层设计]]§4.1。跨链：↔ [[知行合一]]（表示空间→压缩→泛化，同一元操作）；↔ 龙心OS"起手即全息"。
- **一元统摄** → 马哲（辩证唯物+历史唯物+科学实践观）为永恒不变唯一一元本体/分析标尺，传统文化居从属被转化资源，非平等融合。所在：[[NS95769-01-马克思视野下的个人哲学]]§1.2/§3.1。跨链：↔ 龙心OS规则体系（骨架不可改）。
- **双维赋能** → 客观实践维（马哲管事成事辨势）+ 主观精神维（传统文化安心修身立德），统一隶属马哲一元。所在：[[NS95769-01-马克思视野下的个人哲学]]§1.2/§3.3。跨链：↔ [[五色光思维]]（双维≡分色管理）；↔ 双轨审计。
- **碳硅合一** → "人类CEO，AI员工"人机共生，碳基心性与硅基算力在马哲框架内化学反应融合。所在：[[NS95769-01-马克思视野下的个人哲学]]§1.2。跨链：↔ 凤爪OS/龙龟神将（人+AI共生）。
- **两个结合** → 马克思主义基本原理同中国具体实际结合、同中华优秀传统文化结合，本文魂脉根脉依据。所在：[[NS95769-01-马克思视野下的个人哲学]]摘要。
- **蒸汽机谬误** → 仅把AI当工具加在旧流程上（如蒸汽机仅抽水驱动水车），非真AI原生。所在：[[NS95769-01-马克思视野下的个人哲学]]§1.1。跨链：↔ [[知行合一]]（伪落地=未完成三阶转化）。
- **认知算法化** → 马哲方法论（矛盾分析/量变质变/实践认识论）工程转译为AI注意力机制/阈值触发/执行即训练闭环。所在：[[NS95769-01-马克思视野下的个人哲学]]§5.1。
- **心性反算法化** → 儒道义利之辨/阴阳平衡/心性修养作AI对齐锚点与抗算法异化精神防御。所在：[[NS95769-01-马克思视野下的个人哲学]]§5.2。
- **五大红线** → 不置换本体/不复古/不离实践/不教条/数据不替人决（红线五为AI专用）。所在：[[NS95769-01-马克思视野下的个人哲学]]§3.5。跨链：↔ 龙心OS规则一~九（P0/P1硬边界）。

## 二、组织总纲概念（见 [[03-知识地基层/AI原生组织四层体系/NS95769-02-AI原生组织顶层设计]]）

- **三层结构** → 决策层(5人+AI)/数据层(AI全自动·赋能层并入)/执行层(N超级个体)，是"职能切片"非"权力层级"。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-02-AI原生组织顶层设计]]§4。跨链：↔ [[00-索引与导航/AI统一索引/AI-总索引|龙心OS]]（1+5总智能体+五子智能体，同为非上下级职能网络）。
- **超级个体** → "1人+一组AI功能聚合"的最小组织单元，无级别差异只有功能包差异，人做AI干不了的5%判断域。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-02-AI原生组织顶层设计]]§7.2。跨链：↔ 凤爪OS（人+AI识别共生）。
- **品牌定位（数据起点）** → 三重核心身份（东方健康烹饪/技术领先/老字号高端）决定数据采集范围与优先级；强制"无品牌定位不出方案"。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-02-AI原生组织顶层设计]]§1。
- **A/B/C三级权力** → A战略级(董事长终决)/B业务级(总经理)/C执行级(创业单元总)，匹配业务等级即时行动。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-02-AI原生组织顶层设计]]§5.2。
- **实时决策五步闭环** → 感知→分级路由→决策者判断→指令执行→效果回流。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-02-AI原生组织顶层设计]]§10、[[03-知识地基层/AI原生组织四层体系/NS95769-03-AI原生组织数据结构与业务流顶层设计]]§6.1。
- **数据层组织OS** → 数据层从"支持部门"升为"组织操作系统"，实时驱动三层协同。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-02-AI原生组织顶层设计]]§6.7。跨链：↔ [[00-索引与导航/AI统一索引/AI-总索引|龙心OS]]（认知OS，同为底册调度中枢）。
- **金枪鱼数据链** → 以金枪鱼为最小切口验证全链路数据（7节点+身份证号贯通）。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-02-AI原生组织顶层设计]]§9、[[03-知识地基层/AI原生组织四层体系/NS95769-03-AI原生组织数据结构与业务流顶层设计]]§4。
- **楔子化** → 人嵌入岗位像楔子卡住关键责任点，系统正常人静默，边界外异常人介入（对应API化）。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-02-AI原生组织顶层设计]]§8.2。跨链：↔ 道家阴阳平衡（保留人工冗余容错）。
- **信息租金/认知差** → 中层权力源于信息不对称（信息租金），数据层消除之；价值创造从信息差转移到认知差（超级个体护城河）。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-02-AI原生组织顶层设计]]§4.7。
- **无层之层** → 终极演进：三层消融为自由态责任承担者+数字神经液+战略意图节点，走向无结构流体网络。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-02-AI原生组织顶层设计]]§16。跨链：↔ 复杂系统（流态化网络/涌现）。
- **约束即创造力** → 柳总方法论：清晰约束让AI创造力在边界内爆发。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-02-AI原生组织顶层设计]]附章。跨链：↔ 龙心OS规则八（输出质量P0）。
- **房屋建设法** → 先画架构再填充，不在第一版追求完美。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-02-AI原生组织顶层设计]]附章。跨链：↔ 知识学习金字塔原理+象思维结构全息。

## 三、数据执行概念（见 [[03-知识地基层/AI原生组织四层体系/NS95769-03-AI原生组织数据结构与业务流顶层设计]]）

- **六元组** → 食材周期节点+业务渠道+数据值+时间戳+7S映射+责任锚点，每条数据标准。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-03-AI原生组织数据结构与业务流顶层设计]]§2.1。跨链：↔ 知识笔记frontmatter（title/tags/五行/层级/links，同构MECE+责任锚定）。
- **七节点标准模型** → 选品→采购→入库→分割→储存→销售调度→超期，食材全生命周期。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-03-AI原生组织数据结构与业务流顶层设计]]§4.2。跨链：↔ [[象思维]]（物象流转→原象）；↔ 易经卦变（本卦→变卦）。
- **三色预警（红/橙/黄）** → A红(董事长/总·分钟级)/B橙(单元总·1h)/C黄(店长·2h)，阈值触发。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-03-AI原生组织数据结构与业务流顶层设计]]§6.2。跨链：↔ [[五色光思维]]（蓝风险+白事实的落地）。
- **四级闭环（日/周/月/年）** → HB1-HB7(日)/W1-W4(周)/M1-M4(月)/年度，复盘反哺业务。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-03-AI原生组织数据结构与业务流顶层设计]]§7。
- **三频推送** → 日反馈+异常预警+周期报表，从事后到实时。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-03-AI原生组织数据结构与业务流顶层设计]]§6.5。
- **七信息交会点** → 食材验收/员工状态/岗位达标/当日策略/问题分级/客户反馈/组长报告，全量汇聚。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-03-AI原生组织数据结构与业务流顶层设计]]§6.4。
- **七S管理框架** → 战略(S1)/结构(S2)/制度(S3)/人员(S4)/作风(S5)/技能(S6)/价值观(S7)，数据值映射考核维度。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-03-AI原生组织数据结构与业务流顶层设计]]§2.1。跨链：↔ 五行（七S五档系数≡五行五档）。
- **28%成本红线** → 食材成本率26%预警/28%红线(A级一票否决)。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-03-AI原生组织数据结构与业务流顶层设计]]§8.1。
- **全员数据裁定员** → 每个环节人都是数据裁定员（含洗碗阿姨），AI才能调度。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-03-AI原生组织数据结构与业务流顶层设计]]§9.2。
- **ABCD客户分层** → D钻石/P铂金/G金卡/S银卡，基于RFM AI自动分层。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-03-AI原生组织数据结构与业务流顶层设计]]§2.5.4。
- **客户流转增长闭环** → 引流→储值→提升→裂变，储值会员为核心枢纽。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-03-AI原生组织数据结构与业务流顶层设计]]§2.5.3。
- **双系统认知模型** → System2(理性←AI) + System1(直觉←人)，共振点=决策时刻。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-03-AI原生组织数据结构与业务流顶层设计]]§1.7。

## 四、人才执行概念（见 [[03-知识地基层/AI原生组织四层体系/NS95769-04-AI原生组织人才顶层设计]]）

- **L1-L4四阶晋升** → 学徒(用眼学)→师傅(用手做)→储干(用嘴教)→店储(用脑管)。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-04-AI原生组织人才顶层设计]]§5。跨链：↔ 知识学习五层认知操作（金→火→水→木+土）。
- **ABCD角梯队** → A角(直接接班人)+A1/A2+B角+B1/B2，每店3×6=18人储备。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-04-AI原生组织人才顶层设计]]§3.3。
- **三驾马车** → 店长(堂食)/前厅经理(酒水)/料理长(外卖)，兼具创业单元在店执行人+门店管理者双重身份。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-04-AI原生组织人才顶层设计]]§2.3。
- **跑3单元轮岗** → 强制轮值堂食/酒水/外卖+跨店轮转，不走"店长→区域总"行政线。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-04-AI原生组织人才顶层设计]]§4。跨链：↔ 五行相生循环（避免偏科≡阴阳平衡）。
- **招培一体化** → 招×培×训×检×闭，终局"自己长出人"。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-04-AI原生组织人才顶层设计]]§1.3/§8。跨链：↔ [[知行合一]]（表示空间→泛化实践）。
- **师徒制** → 唯一贯穿L1-L4骨架，1对1/2，师傅KPI=徒弟多快出师。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-04-AI原生组织人才顶层设计]]§8.7。跨链：↔ 儒家"己欲立而立人"。
- **7S五档系数** → S×1.2/A×1.0/B×0.8/C×0.6/D×0，只做减法。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-04-AI原生组织人才顶层设计]]§7.2。
- **铁三角56件** → 每阶5培训+4认证+5制度=14件×4阶=56件产出。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-04-AI原生组织人才顶层设计]]§1.7。
- **双签字制度** → 有记录没做好罚个人，没记录罚管理者。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-04-AI原生组织人才顶层设计]]§8.4。
- **3:10储备法则** → 每开10店储备3套班子(12人)，储备率≥90%方可扩张。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-04-AI原生组织人才顶层设计]]§4.7。
- **559型干部** → 5基础+5核心+9行为特质干部标准。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-04-AI原生组织人才顶层设计]]§4.8。
- **两大基本素养** → 禅食一味(后厨)/禅礼一味(前厅)，L1-L4度量衡。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-04-AI原生组织人才顶层设计]]§6。
- **GROW五步** → 目标/现状/方案/行动/跟踪，闭模块。所在：[[03-知识地基层/AI原生组织四层体系/NS95769-04-AI原生组织人才顶层设计]]§8.6。

## 五、跨体系审计概念（见 [[03-知识地基层/AI原生组织四层体系/NS95769-00-总索引]] 第五节）

- **双轨审计 / 红线熔断** → 每季客观轨(马哲效率)+主观轨(心性心力)双审；主观跌破阈值→暂停AI恢复人工。所在：[[NS95769-01-马克思视野下的个人哲学]]§6.5.5、[[03-知识地基层/AI原生组织四层体系/NS95769-02-AI原生组织顶层设计]]§15.4。跨链：↔ 双维赋能（显式同构）。
