## 二、五毒→五智转化速查
```
贪 → 妙观察智(红)
嗔 → 大圆镜智(白)
痴 → 法界体性智(蓝)
慢 → 平等性智(黄)
疑 → 成所作智(绿)
        ↑ 能量自然升华 = 拔阴取阳(念头层)
```
