## 一、核心定义

**金行人外观识别体系**：基于"象思维"哲学——金属"方正刚硬、薄而坚、光泽洁净"之自然本象，以"三方（薄）"为总纲的金行能量外在显化特征系统。

**核心口诀**：`木瘦金方水必肥，上尖下阔为真火，土行背厚晃如龟，朝中方白属金行`

**三方（薄）体系**：
| 三薄 | 特征 | 象理 |
|:----|:----|:----|
| **脸方** | 国字脸/方形轮廓/下颌角明显 | 原则、边界、坚定 |
| **唇薄** | 嘴唇偏薄/唇线清晰如刀刻 | 言语精炼、果断干脆 |
| **质薄** | 皮下脂肪少/手背青筋显/眼皮单薄 | 去芜存菁、纯粹精炼 |

---

## 二、象思维根基

金行取象于"金属"，自然之象四要素：
- **方正刚硬**：原则、边界、不可弯曲的坚定性
- **薄而坚**：精炼、纯粹、去芜存菁
- **光泽洁净**：正直、清廉、品性高洁
- **可锻可铸**："从革"之性——坚守本质的同时具备变革潜能

## 三、静态特征详解

### 3.1 总体体型

| 特征 | 描述 |
|:----|:-----|
| **方正匀称** | 身材刚正硬朗，骨架刚正硬朗 |
| **肩背** | 小肩背，紧凑内收，背部挺直有刚硬感 |
| **躯干** | 长方形轮廓，腰线不明显或偏直 |
| **四肢** | 修长匀称，骨骼线条明显，肌肉呈条状 |
| **小手足** | 骨架小巧但形态方正，指节分明 |
| **足跟坚厚** | 核心特征——全身清瘦但足跟结实有力 |

### 3.2 头面特征

| 部位 | 阳金特征 | 阴金特征 |
|:----|:--------|:--------|
| **脸型** | 国字脸/方型轮廓/下颌角明显 | 瘦削尖刻/颧骨突兀 |
| **额头** | 宽阔方正/发际线平直 | 狭窄 |
| **眉毛** | 眉浓/眉形清晰有棱角（剑眉/平直眉） | 稀疏或散乱 |
| **眼睛** | 大眼睛/内双或单眼皮/眼神锐利清澈 | 眼神逼人多疑/冷峻 |
| **鼻子** | 鼻梁高挺笔直/鼻头适中/线条清晰 | 鼻梁尖削 |
| **嘴唇** | 唇薄/唇线清晰如刀刻/唇色偏淡 | 唇色青白/嘴角下撇 |
| **肤色** | 白而润泽（白玉/凝脂） | 惨白无华/青白晦暗 |

### 3.3 手部特征

- **手型**：方正，长宽比例协调
- **手背**：皮肤薄，青色血管（青筋）清晰可见
- **手指**：修长，骨节分明突出，刚劲有力
- **指甲**：偏方正，甲床红润

## 四、动态特征

### 4.1 声音与语言

| 维度 | 特征 |
|:----|:-----|
| **音质** | 清亮、明亮、有金属质感（如钟磬），穿透力强 |
| **语调** | "高调起低调落"——开口音调高，句末收尾干净 |
| **发音** | 唇音清晰有力（与薄唇呼应） |
| **内容** | 言简意赅，逻辑清晰，直击核心 |
| **常用词** | "我是这么想的""我认为""我觉得" |

### 4.2 步态与动作

- **步态**："行走轻快，走路带风"，背部挺直，步伐频率高
- **动作**：干净利落，不冗余，目的性强，完成度高
- **落脚**：扎实轻快，有节奏感（得益于足跟坚厚）

### 4.3 神态与表情

- **常态**：严肃、专注、冷静，眼神呈观察/审视状
- **笑容**：不频繁，多为微笑/轻笑，大笑较少
- **生气时**："发脾气时好冷笑，面色煞白"——向内收敛，冷暴力式

### 4.4 着装风格

| 维度 | 特征 |
|:----|:-----|
| **款式** | 简洁、大方、沉稳、合身利落（西装/衬衫/直筒裤） |
| **色彩** | 纯色：黑/白/灰/藏蓝/米色等中性冷色调 |
| **材质** | 挺括、光滑、高级面料 |
| **动机** | "给别人看"——建立权威、彰显专业、体现秩序 |

## 七、四步识别法

| 步骤 | 时间 | 观察要点 |
|:----|:----|:--------|
| **①整体观形** | 3-5秒 | 体型是否方正匀称、骨架清晰、干净利落 |
| **②细部察特征** | 10-15秒 | 验证三方：脸方？唇薄？手背薄青筋显？眼皮薄眼神锐？ |
| **③动态观神态** | 持续 | 听声音清亮简洁？观步态轻快挺直？察神情严肃专注？ |
| **④综合判能量** | 整合 | 阳金(温和润泽) vs 阴金(刻薄僵硬) |
