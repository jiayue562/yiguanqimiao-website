## 一、核心定义

**金行人生克规律**：金行能量在五行动态网络中与木、火、土、水四行之间的相生相克关系。金行处于"从革"能量定位：**土生金**（根基滋养）、**金生水**（智慧变通）、**火克金**（核心平衡）、**金克木**（规范引导）。

**核心口诀**：
- `土生金：信实承载生养义理决断`
- `金生水：义理精炼生发智慧变通`
- `火克金：热情礼明软化冰冷刚硬`
- `金克木：收敛规则约束生发散漫`

## 二、四组核心生克关系

### 2.1 土生金：根基与滋养

| 状态 | 表现 | 调适 |
|:----|:----|:----|
| **健康**（土厚生金足） | 原则建立在扎实数据和事实之上，自信而不狂妄 | 维持积累习惯 |
| **失衡**（土虚金弱） | 原则飘忽，决策优柔，空谈无法落地 | **补土固本**：建立知识库+微承诺+寻求稳定支持 |
| **失衡**（土壅金滞） | 过度保守被体制束缚，创新被压制 | **疏土生金**：梳理精简+引入木克土疏浚 |

### 2.2 金生水：创造与流淌

| 状态 | 表现 | 调适 |
|:----|:----|:----|
| **健康**（金温水生智） | 不仅逻辑清晰且洞察深刻，原则有温度，沟通圆融 | 维持沟通练习 |
| **失衡**（金燥不生水） | 只知批判切割，言语尖刻，人际关系紧张 | **润金生水**："我理解"前置+深度复盘+非暴力沟通 |
| **失衡**（水泛金沉） | 过度妥协丧失原则，规则形同虚设 | **固金导水**：明确核心底线+框架内变通 |

### 2.3 火克金：锤炼与熔铸（核心平衡课题⚡）

| 状态 | 表现 | 调适 |
|:----|:----|:----|
| **健康**（火暖金辉） | 既有热情又有原则，既冷静又有使命感 | 愿景链接原则 |
| **失衡**（火弱金寒） | 冷漠无情，不近人情，生活枯燥 | **引火暖金**：培养爱好+设定目标+练习表达赞赏 |
| **失衡**（火旺金融） | 心烦意乱无法专注，原则动摇易妥协 | **培土泄火生金**：恼转行+固金仪式 |

### 2.4 金克木：规范与修剪

| 状态 | 表现 | 调适 |
|:----|:----|:----|
| **健康**（金锋木秀） | 欣赏创意但能用标准帮其优化落地 | 维持赋能心态 |
| **失衡**（金强木折） | 过度严苛压制创意，团队活力丧失 | **化克为生：金生水→水生木** |
| **失衡**（木亢金缺） | 规则缺失，目标涣散，效率低下 | **强金制木**：明确坚守核心底线 |

## 三、核心技术

### 3.1 拔阴取阳口诀

| 阴→阳 | 口诀 | 操作 |
|:------|:----|:-----|
| 阴金贪→**阳金义** | **"贪转义"** | 计较固守时→自问"是出于义理还是占有？"→回归更大价值 |
| 阴金恼→**阳金行** | **"恼转行"** | 烦躁批判时→"我现在能做什么具体事？"→批评转建设行动 |

### 3.2 化克为生

**火克金转化**（金生水，火畏水）：
```
火（压力/热情）→克→金（烦躁/原则动摇）
  → 金生水（柔和沟通/变通理解）
  → 水克火（以柔克刚降温）
  → 同时火生土（做出稳定承诺）→土生金（稳固自身）
```

**金克木转化**（木生火，金畏火）：
```
金（规则/批评）→克→木（创意/活力受压抑）
  → 帮助木生火（将创意转化为成果）
  → 成果的影响力软化金的固执
  → 同时金生水（理解包容支持）
```

### 3.3 标准化诊断流程

1. **症状收集**（观三界之象）：身界（僵硬/呼吸/皮肤）→心界（恼/恨/悲）→灵界（控制/义理）
2. **关系映射**（辨五行之克）：烦躁→火克金；胸闷→金克木；优柔→土虚金弱；冷漠→金不生水
3. **情境回溯**（找现实之因）：回顾近期失衡事件
