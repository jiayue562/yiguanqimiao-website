## 一、核心定义

**金行人×福格行为模型（B=MAP）整合体系**：将金行人五维度人格特质（坚固/收敛/锋利/光洁/沉降）与福格行为模型B=M×A×P相结合，为金行人的"阴面逆境特质"向"阳面顺境特质"转化提供系统化的行为诊断与设计系统。

**核心公式**：`B（行为）= M（动机）× A（能力）× P（提示）`

**核心理念**：精炼而非否定——引导金行人的秩序与精炼能量以更圆融的方式表达。

## 二、B=MAP×金行五维度微习惯速查表

| 维度 | 阴面→阳面 | 微行为(B) | 动机增强(M) | 能力优化(A) | 提示锚点(P) |
|:----|:---------|:---------|:-----------|:-----------|:-----------|
| **坚固** | 好胜→刚毅 | 10秒黄金沉默+找一个对方合理点 | 真正强者能整合资源创共赢 | 极小思维动作打断反驳链 | 想反驳时→启动沉默 |
| **收敛** | 狭隘→含蓄 | 每日一微分享（转发文章附点评） | 开放分享是建立权威的最高效方式 | 极小动作，几乎不占资源 | 下班前→执行微分享 |
| **锋利** | 严苛→公正 | "缓冲-聚焦"句式：关于X我看到Y | 批评目的是帮人不是发泄情绪 | 简单语言模板可调用 | 想批评时→套用句式 |
| **光洁** | 自负→智慧 | "事实+归因"成就谦述法 | 真正大家虚怀若谷 | 填空式结构降低难度 | 介绍成果后→谦述 |
| **沉降** | 焦虑→沉稳 | 1分钟焦虑快照：焦虑主题+强度+小行动 | 真正冷静是在风险前清晰思考 | 模糊担忧→具体小步骤 | 焦虑反刍时→做快照 |

## 三、五维度B=MAP诊断方案

### 3.1 坚固（刚毅坚强⇄好胜计较）

| 要素 | 设计 |
|:----|:-----|
| **微行为** | 想反驳时启动"10秒黄金沉默"，同时找一个对方观点的合理之处 |
| **动机** | 阳面：真正强大是整合资源创共赢；阴面：好胜导致孤立 |
| **能力** | 极小思维动作，打断自动化反驳链 |
| **提示** | 内部：血压升高/语速加快时 |

### 3.2 收敛（含蓄持重⇄小气狭隘）

| 要素 | 设计 |
|:----|:-----|
| **微行为** | 每日一微分享：转发文章附一句点评/花5分钟解答问题 |
| **动机** | 阳面：开放是最佳权威建立方式；阴面：封闭导致网络萎缩 |
| **能力** | 极小可控动作，几乎不占核心资源 |
| **提示** | 锚点：每天关闭电脑前执行微分享 |

### 3.3 锋利（公正锋利⇄严苛无情）

| 要素 | 设计 |
|:----|:-----|
| **微行为** | "缓冲-聚焦"句式："关于[具体事]，我看到这里可以做得更好" |
| **动机** | 阳面：批评目的是帮人；阴面：严苛导致士气低落 |
| **能力** | 简单语言模板，如程序般可调用 |
| **提示** | 内部：发现错误怒火上涌时 |

### 3.4 光洁（智慧权威⇄虚荣自负）

| 要素 | 设计 |
|:----|:-----|
| **微行为** | "事实+归因"成就谦述法："项目取得X成果，得益于团队协作" |
| **动机** | 阳面：真正的大家虚怀若谷；阴面：虚荣导致固步自封 |
| **能力** | 填空式结构降低谦逊表达的认知难度 |
| **提示** | 锚点：介绍成果后→主动询问"你有什么建议？" |

### 3.5 沉降（沉稳冷静⇄焦虑多疑）

| 要素 | 设计 |
|:----|:-----|
| **微行为** | 1分钟焦虑快照：主题+强度(0-10)+最小行动 |
| **动机** | 阳面：真正冷静是在风险前清晰思考 |
| **能力** | 模糊担忧→具体可操作小步骤，打破瘫痪 |
| **提示** | 内部：开始反复担心"万一怎么办"时 |

| 步骤 | 操作 | 金行要点 |

| **②探索选项** | 结构化头脑风暴 | 先求全面，不急着批判 |
| **③匹配黄金行为** | 焦点地图评估 | 选高影响+高可行 |
| **④从微习惯开始** | 简化为不会失败 | 抵抗"要么完美要么不做" |
| **⑤找到对提示** | 锚点提示优先 | 利用计划敏感性+内部信号转化 |

| **⑦排除/重复/扩展** | B=MAP诊断+迭代 | 失败=数据反馈，非性格缺陷 |

## 五、核心金句

1. "精炼而非否定——行为改变的目标不是否定金行人追求秩序的本性，而是引导其以更圆融的方式表达"
2. "微习惯是最高战略——在最固执、最焦虑、最封闭的日子里也能完成的行为，才是可持续的"
3. "庆祝不是幼稚的自我表扬，而是行为系统的正向强化信号——对金行人，庆祝=确认流程执行正确"

5. "核心是理性的自我优化：引导金行人将其追求精炼的智慧，首先用于精炼自身的行为系统"
