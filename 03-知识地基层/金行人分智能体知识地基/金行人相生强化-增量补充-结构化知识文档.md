## 一、核心定义

**金行人相生强化技术**：一套根植于东方五行智慧（土生金、金生水），并得到现代多学科原理支持的综合性心理干预与个人成长方法。核心是**双焦点工程**——以"土生金"为根本滋养路径（解决能量来源与根基），以"金生水"为价值升华路径（解决能量转化与智慧）。

**核心逻辑**：`土（稳定信实）→ 金（刚毅规则）→ 水（智慧洞察）`

**体系定位**：相生强化是金行人从"阴金困扰"（刻薄、计较、僵化）到"阳金绽放"（义气、清明、圆融）的核心成长技术。

## 三、核心相生关系

### 3.1 土生金：稳定信实淬炼刚毅规则

**核心意象**：大地中孕育沉淀出金属矿物；厚重土壤压实形成磐石矿藏。

**滋养本质**：以"承载化"生"收敛义"——土行阳面特质（诚信/踏实/耐心/整合）通过长期积累，提炼升华为金行阳面特质（义理/原则/果断/规则）。

**不足信号**（需土生金滋养）：
- ⚠️ 优柔寡断，缺乏主见
- ⚠️ 生活工作缺乏条理
- ⚠️ 畏惧权威不敢坚持原则
- ⚠️ 做事粗枝大叶
- ⚠️ 成果难以提炼，经验无法传承

**三维度实操**：

| 维度 | 方法 | 操作 |
|:----|:----|:-----|
| **内修** | 承诺闭环 | 答应的事必完成+记录 |
| | 结构化整理 | 物理/知识/经验三维整理 |
| | 深耕专业 | 成为领域专家（厚土生金） |
| | 基于事实思考 | 先收集数据→再分析判断 |
| **环境** | 土行色材质 | 黄色/棕色/陶瓷/实木 |
| | 空间秩序 | 物各有位，稳定不常变 |
| | 信息沉淀 | 建立个人知识管理系统 |
| **互动** | 执行-提炼链 | 项目完成→输出SOP/原则清单 |
| | 设立坚守原则 | 写下核心原则并练习坚守 |
| | 有底气的果断 | 收集信息→设定截止→做决定 |

### 3.2 金生水：规则收敛涵养智慧洞察

**核心意象**：金属冷凝为液体；刀剑锋芒收敛后方能如明镜映照万物。

**滋养本质**：以"收敛义"生"润下智"——金行阳面特质（原则/边界/逻辑/决断）为水行阳面特质（智慧/变通/洞察/共情）提供理性骨架和安全容器。

**不足信号**（需金生水滋养）：
- ⚠️ 思维混乱抓不住重点
- ⚠️ 情绪化决策
- ⚠️ 边界模糊过度卷入
- ⚠️ 缺乏应变智慧
- ⚠️ 沟通缺乏深度

**三维度实操**：

| 维度 | 方法 | 操作 |
|:----|:----|:-----|
| **内修** | 逻辑思维训练 | 每日逻辑题/分析文章结构 |
| | 建立决策框架 | 为常遇决策设分析问题清单 |
| | 深度复盘炼金 | 分析决策逻辑+预设+变量 |
| | 时间区块管理 | 清晰划分时段训练节奏感 |
| **环境** | 金行色风格 | 白色/金色/灰色/简洁直线条 |
| | 信息过滤秩序 | 设信息摄入规则减少噪音 |
| | 深度工作区 | 专门思考/学习/创作空间 |
| **互动** | 规划-洞察链 | 先设分析框架→再深入调研 |
| | 有边界共情 | 设情绪结界+倾听+不卷入 |
| | 写作输出 | 列提纲→填充→提炼核心观点 |

## 五、五大原则与四大误区

### 原则
1. **顺势而为**：抵触时调整方式

3. **身心合一**：行动时感受身心灵
4. **聚焦阳面**：以建代破
5. **个体差异**：灵活调整

### 误区
| 误区 | 错误 | 正确 |
|:----|:----|:----|
| 错判滋养源 | 金弱却学新知（金生水） | 金弱→补土（土生金） |
| 滋养过度 | 过度整理→思维僵化 | 引入木疏土 |
| 忽视金生水 | 只有原则无智慧 | 必须金生水升华 |
| 与其他混淆 | 阴金强时只做相生 | 先拔阴取阳转化 |
