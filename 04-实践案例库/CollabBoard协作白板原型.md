# CollabBoard协作白板原型

> 以观其妙书院 · AI应用实践案例
> 创建者：龙龟神将（火行人）· 悟空（木行人）木火共生

## 核心定义

**CollabBoard** 是一款Miro风格的实时协作白板原型，采用纯HTML单文件架构（零依赖），实现无限画布与多工具交互，是五色光思维方法论在数字协作领域的具象化实践。

## 详细内容

### 功能全景

| 功能模块 | 核心能力 | 技术实现 |
|---------|---------|---------|
| **无限画布** | 拖拽平移 + 滚轮缩放 | 坐标变换（translate + scale） |
| **便签系统** | 添加/拖拽/编辑/删除/6色切换 | DOM渲染 + 事件委托 |
| **画笔工具** | 自由绘制 + 粗细颜色调节 | Canvas 2D绑定坐标变换 |
| **连线工具** | 贝塞尔曲线 + 箭头 | Canvas贝塞尔绘制 |
| **选择工具** | 选中高亮 | DOM状态管理 |
| **迷你地图** | 全局导航视口 | 缩略Canvas渲染 |
| **深色工具栏** | 现代UI设计 | CSS Grid + Flexbox |

### 技术架构

```
架构模式：纯HTML单文件（HTML + CSS + JS 内联）
文件大小：33,912 bytes
渲染策略：
  - Canvas层：网格、笔画、连线（高性能渲染）
  - DOM层：便签（富交互、可编辑）
  - 坐标系：viewport transform 实现无限画布
```

### 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| V | 选择工具 |
| H | 手型工具（平移画布） |
| P | 画笔工具 |
| L | 连线工具 |
| N | 新建便签 |
| Delete | 删除选中元素 |
| Escape | 取消选择 |
| Ctrl+0 | 重置视图 |

### 设计哲学

1. **无限画布 = 无限思维**：对应五色光思维的"发散"阶段，让思维不受边界约束
2. **多工具融合 = 同频共振**：便签（文字思考）+ 画笔（视觉表达）+ 连线（逻辑关联）
3. **纯单文件 = 知行合一**：从想法到实现的最短路径，零配置即开即用
