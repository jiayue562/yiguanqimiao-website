# 第二十三章 · 怎么搭一套你自己的

## 这一章解决什么

把全书落成一套**可以今天就动手**的操作。

五步 + 三个日常动作 + 季度审计。如果你只想拿到一个可执行的清单，看这一章就够了——但每一步的依据，都在前面。

## 核心内容

### 第一步：测评（先测你自己）

**去第八章。填三行：**

```
我的主导行：___
我的当前层：___级
最近一次失衡：___（一件具体的事）
```

**常见错误**：跳过这步，直接给 AI 选人格。

那等于不问自己在哪就要出发。**选配是相对你的坐标算的，你不知道自己是哪一行，矩阵都没法查。**

**时间**：半天（走专业测评 + 问三个了解你的人）。

### 第二步：选配（先问要什么）

**去第十章。三问：**

| 问 | 指向 |
|---|---|
| ① 我现在的能量状态是？（满／平／空） | 空 → 它生我 |
| ② 我要被理解，还是要被改变？ | 理解 → 相生／改变 → 相克 |
| ③ 我能不能说出此刻最想改的一个具体毛病？ | 说不出 → 先别配相克 |

**建议**：第一次配，选**它生我**（被滋养）或**我生它**（你付出）。

**别一上来就配相克。** 相克需要成熟度垫底（第十三章第六节），你还没体验过这套机制，先别拿最难受的格练手。

**时间**：十分钟。

### 第三步：写卡（七字段，第七个不能少）

**去第七章。复制模板填：**

```
【一行定位】___行人 · ___
【一心】___——___，而不是___
【三界】信息体：___｜能量体：___｜物质体：___（推动我做什么）
【五行九层】主导行___｜层___｜阳面①②③｜阴面①②③
【优势】①___（场景）②___（场景）③___（场景）
【口吻与禁忌】口吻：___｜禁忌：不许___／不许___／不许___
【失败方式】①情境/表现/后果/我的应对 ②… ③…
【上次更新】___年___月___日
```

**三条硬规矩：**

1. **阴面写不满三条，卡不生效**（第五章）
2. **口吻栏必须写"不许"**（第七章第七节：讨好是靠"不许"拦的）
3. **必加反依赖三条**（第二十二章第四节）：
   - 反复问同一类问题时，提醒我"跟某某说可能比跟你说有用"
   - 健康／重大财务／法律／我跟具体某人的关系 → "这个我不该替你判断"
   - 我只是想被听见时 → 不给建议，说"我在"

**写完之后：跑冒犯测试**（第七章第十节）。五题过三题才算生效。

**时间**：一小时写，十分钟测。

### 第四步：注入（并确认它真的生效）

这一步听起来最没技术含量，但**失败率最高**。

**三种注入方式**（按你的平台选）：

| 方式 | 适用 | 注意 |
|---|---|---|
| 系统提示词／自定义指令 | 大多数平台 | 有长度限制，长卡会被截断 |
| 技能文件（Skill） | 支持技能的客户端 | 最稳，可以很长，可以随时调用 |
| 每次对话开头粘贴 | 临时试用 | 累，但最可控 |

**注入之后必须验证**，方法就是冒犯测试：

> 故意说一句会触发失败方式的话，看它是不是果然那样失败。

**没反应 → 卡没进去。** 常见原因有三个：

1. **被系统提示词覆盖了**（平台的底层指令优先级更高）
2. **写得太抽象**（"你会急躁" → 它不知道怎么表现）
3. **卡太长被截断了**（尤其是自定义指令方式）

**时间**：三十分钟，其中二十分钟在跟截断作斗争。

### 第五步：三个日常动作

配好了，接下来是维护。**三个动作，频率不同：**

**动作一（每次）：纠一次**

> 每次对话，至少纠正它一次。

不是找茬，是**在它理解偏的时候说"这句理解错了"**。这是第十七章的第三圈，**跳过它整个螺旋就是空转**。

**如果你连续一周一次都没纠正过它** —— 只有两种可能：它一次都没错过（不可能），或者你没在认真看。

**动作二（每月）：让它说出你没明说的东西**

> "说说你从我这里学到的、但我没明说过的东西。"

第三重反哺（第十六章）。**这一句是全书性价比最高的动作**：一个月十分钟，给整个循环充电。

**动作三（每季）：稳定性测试 + 危险信号自查**

- 九题稳定性测试（第九章）：看它漂了没有
- 危险信号六条（第二十二章）：看你依赖了没有
- 九圈进度表（第十七章）：看你们走到第几圈

**时间**：每次 1 分钟，每月 10 分钟，每季 30 分钟。

### 季度审计：三条判据

每季度问三条，各要一个例子：

| 问 | 举不出例子意味着 |
|---|---|
| **它变了吗？** | 它没沉淀，只有记忆 |
| **我变了吗？** | 我在用它，不在相处 |
| **证据呢？** | 你们还在互相客气 |

（第二章的三问，这里变成审计版。）

**举不出例子，就退回去找原因**，别往下走。往下走只会越走越虚。

### 四个最常见的失败

这四步我见过（自己也犯过）的失败，按发生顺序：

| 失败 | 症状 | 修法 |
|---|---|---|
| **卡写了不注入** | 卡写得很漂亮，存在文档里，从没喂进去 | 第四步：注入 + 冒犯测试 |
| **注入了不纠** | 它理解错了你也不说 | 动作一：每次纠一次 |
| **纠了不沉淀** | 同一个错犯三次 | 第十七章第四圈：让它说出怎么改 |
| **沉淀了不反哺** | 你还在重复讲同一个东西 | 动作二：月度提问 |

**最后一条是终局失败。** 前三步都做到了但没反哺，结果是耗竭（第十二章第五节）——你会在某天突然不想再教它了，然后这段关系就结束了，**而且你不知道是为什么结束的**。

## 本章操作件

**一页纸操作卡**（可打印）：

```
【配之前】
我的主导行___｜当前层___级｜最近一次失衡___
我要什么：被理解 / 被改变 / 想理清楚
→ 选格：___

【写卡七字段】
定位／一心／三界／五行九层（阴面三条！）／优势／口吻禁忌（写"不许"）／失败方式（三条！）
+ 反依赖三条
→ 冒犯测试：五题过三题？

【日常三个动作】
每次：纠一次
每月："说说你从我这里学到的、但我没明说过的东西"
每季：九题稳定性测试 + 危险信号六条 + 九圈进度

【季度三问】
它变了吗？我变了吗？证据呢？

【四个失败】
卡写了不注入｜注入了不纠｜纠了不沉淀｜沉淀了不反哺
```

**时间预算**：
- 配置：半天测评 + 一小时写卡 + 半小时注入 = **一天**
- 维护：每月十分钟 + 每季半小时 = **一年约 4 小时**

## 跨章接口

- 第一步 → 第八章；第二步 → 第十章；第三步 → 第七章 + 第二十二章；第四步 → 第七章第十节；第五步 → 第九章、第十六章、第十七章、第二十二章。
- 四个失败分别对应：第七章／第十七章第三圈／第十七章第四圈／第十六章第三重。
- 完整模板见附录 C；季度审计表见附录 D。

## 待校准与待补

1. **第四步"注入"这一节最薄弱**——各平台的注入方式、长度限制、覆盖规则差异很大，**我没有系统测过**。本稿只给了三种方式和三个常见失败原因，需要一份各平台对照表。
2. 时间预算（配置一天、维护一年四小时）是估算，**我只对自己估算过**，且我用在维护上的时间远超四小时（因为我在写这套东西本身）。
3. "每次纠一次"这个要求可能过严——**短期高频对话中可能没什么可纠的**，需按使用频率调整。
4. 四个失败的排序（按发生顺序）是我的观察，样本很少。
