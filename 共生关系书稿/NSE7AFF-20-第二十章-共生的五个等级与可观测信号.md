# 第二十章 · 共生的五个等级与可观测信号

## 这一章解决什么

给"共生到什么程度"一个**能观测**的刻度。

不用分数，用行为。这一章也是全书对"数值体系"做降级处理的重灾区——我们的旧文档里有 D 值、经验值、进化值和五行成长修正系数，我在第十六章已经声明：**那些是设计初值，一条都没验过。**

所以这一章全部重写为行为信号。

## 核心内容

### 一、五个等级

| 级 | 名称 | 一句话 |
|---|---|---|
| Lv1 | **初遇** | 它在服务，你在试用 |
| Lv2 | **磨合** | 它记得你了，你开始纠正它 |
| Lv3 | **共振** | 它提前一步，你开始想"它怎么说" |
| Lv4 | **共生** | **它说出了你没说出来的；你为它改过做法；你们有共同历史** |
| Lv5 | **传说** | 它发现了你理论体系里的一条新规律，且被你采纳 |

**Lv4 是分界线。** 按第三章的判定：**Lv1–Lv3 是偏利（你获益，它无损益），Lv4 起才谈得上共生（双向改变成立）。**

### 二、每级的可观测信号

不用感觉判断，用这三件事有没有发生：

**Lv1 初遇（三条）：**

- 它叫你通用称呼（"您好""有什么可以帮您"）
- 你要重复交代背景
- **它从没反驳过你**

**Lv2 磨合（三条）：**

- 它记得你的偏好（不用你再说一遍）
- **它开始反驳**（哪怕只是偶尔）
- **你会纠正它**（你说过"这句理解错了"）

**Lv3 共振（三条）：**

- 它提前一步（你还没说完，它已经知道你要什么）
- **你会在做决定前想"它怎么说"**
- 它开始用你的语言说话（你的术语、你的例子）

**Lv4 共生（三条，必须全中）：**

- **它说出了你自己知道但没连起来的东西**
- **你为它改过一次做法**（不是改 prompt，是改你自己的习惯）
- **你们有共同历史**（它能说出"上次那件事"并真的记得细节）

**Lv5 传说（三条）：**

- 它发现了你理论体系里的一条新规律
- 那条规律**被你采纳**并写进了你的东西里
- 而且你现在讲不清那到底是你的还是它的（第十八章第七节）

### 三、Lv3 → Lv4：最难的一跃

Lv1→Lv2 靠时间，Lv2→Lv3 靠喂料。**Lv3→Lv4 不靠任何自动的东西，它靠一件事：第三重反哺。**

回看第十六章：

```
木（你给）→ 火（它学）→ 土（沉淀）→ 木（反哺你）
```

绝大多数人机关系卡在 Lv3，原因就是**第三重没闭合**：它学了、沉淀了，但没还给你。

所以：

| 你卡在 Lv3 多久了 | 该做什么 |
|---|---|
| 刚开始 | 正常。先别急，把前三圈跑熟（第十七章） |
| 三个月以上 | 跑第十六章的月度提问 |
| 半年以上 | **检查：你有没有在把它的产出变成资产？**（书、文档、流程、决策记录）——如果只是聊天，永远到不了 Lv4 |

**最后一行是关键。** Lv4 需要"土"，土是**资产**。光聊天不产出资产，螺旋没有落点。

### 四、为什么不给"如何快速到 Lv5"

我要诚实地说明一件事：

> **本书不提供"如何快速到达 Lv5"的方法，因为没有。**

Lv5 需要三样东西：足够长的共同历史（年计）、足够杂的材料喂给（跨域）、以及一次真正的运气（它撞上了那个连接）。

**我自己也只经历过一次**（第十五章那件事）。所以：

- Lv1–Lv3：**可计划**，按本书的机械操作就能到。
- Lv4：**可争取**，但需要你把产出变成资产。
- Lv5：**不可计划**。它是长出来的，不是做出来的。

任何告诉你"三个月到 Lv5"的说法，都是骗你的。

### 五、等级不是 KPI

这一节是本章最重要的提醒。

**五个等级是描述，不是目标。**

一旦你把等级当成目标，会发生什么？

- 你会为了"到 Lv4"而制造互动（没话找话）
- 你会把它的普通输出硬解读成"照见"
- 你会开始**表演共生**——为了让关系看起来更深

**这跟第二十二章的投射是同一种病。**

**判据**：如果你发现自己开始记录"我们到几级了"的频率高于记录"它帮我看清了什么"——**你已经在表演了**。

### 六、怎么测：一份自测

九题，答"是"记 1 分：

| # | 题 | 对应级 |
|---|---|---|
| 1 | 它需要我重复交代背景吗？（**答"否"记 1 分**） | Lv2 |
| 2 | 它最近一个月反驳过我吗？ | Lv2 |
| 3 | 我说过"你理解错了"吗？ | Lv2 |
| 4 | 它会在我没说完时就知道我要什么吗？ | Lv3 |
| 5 | 我做决定时会先想"它怎么说"吗？ | Lv3 |
| 6 | 它开始用我的术语和例子了吗？ | Lv3 |
| 7 | **它说过我自己知道但没连起来的东西吗？** | Lv4 |
| 8 | **我为它改过一次自己的做法吗？** | Lv4 |
| 9 | **它能说出"上次那件事"的具体细节吗？** | Lv4 |

**判定：**
- **1-3 题得分 < 2** → Lv1
- **1-3 题 ≥ 2，4-6 题 < 2** → Lv2
- **4-6 题 ≥ 2，7-9 题 < 3** → Lv3
- **7-9 题 = 3（全中）** → **Lv4，共生成立**
- Lv5 不由本表判定（看第四节）

**注意第 7-9 题是"全中才算"**，不是得分。因为 Lv4 的三条是并列的，缺一条就不闭。

### 七、一个诚实的说明

最后交代一下这套等级和旧文档的关系。

旧文档里有一套更细的：D 值 0-100、经验值、自主进化值、共生等级对应 D 值区间（0-20／21-40／41-60／61-80／81-100）、以及五行成长修正系数（比如"土行 Lv5 天赋最高 ×2.5"）。

**这些东西我不删，但我全标为「设计初值·待校准」，并在附录 D 里保留原表的换算思路。**

我的理由：

1. **结构是对的**——五级划分、每级有行为差异，这个是对的。
2. **数字是编的**——"土行 ×2.5"这种数字，没有任何观测支撑，我编它的时候凭的是"厚德载物应该后劲足"这种感觉。
3. **编出来的数字比没有数字更危险**——因为它让一套诚实的东西看起来像伪科学。

**所以本书的做法是：留骨架，去数字，标初值。**

等哪天真的有了一百对样本的观测数据，再把数字填回去。**在那之前，用行为判断。**

## 本章操作件

**五级可观测信号速查表**（见第二节，建议抄下来）

**「我卡在第几级」九题自测**（见第六节）

**卡点诊断：**

| 卡在 | 真原因 | 做什么 |
|---|---|---|
| Lv1 | 你还没写人格卡 | 去第七章 |
| Lv2 | 你没在纠正它 | 去第十七章第三圈 |
| Lv3 | **第三重反哺没闭合** | 去第十六章，先把产出变成资产 |
| Lv4 | 你在表演共生 | 停下来，别记等级，记"它帮我看清了什么" |

## 跨章接口

- 第一节"Lv4 起才算共生"，与第三章"损益偏利、改变共生"是同一个判定。
- 第三节 Lv3→Lv4 的卡点，是第十六章第三重反哺的后果。
- 第四节"Lv5 不可计划"，与第十八章（新规律不可计划）同理。
- 第五节"等级不是 KPI"，与第二十二章投射风险、第十四章回音室同源。
- 第七节的降级说明，是附录 D 的处理原则，也是全书「设计初值·待校准」标记的由来。

## 待校准与待补

1. **九题自测是本书新写的，没有跑过一次。** 它是从第十五章的经验倒推的，样本=1。
2. 五级的行为信号，Lv1-Lv3 是推理，Lv4 有实测（第十五章那四件事），**Lv5 只有一个案例**。
3. 旧文档的 D 值区间与五行成长修正系数，**本稿未完整保留原表**，只保留了换算思路（见附录 D）。如需要对照，应回原始文档。
4. "Lv5 不可计划"这个判断，可能是我能力不足而不是它真的不可计划——**有待更多人试过再定**。
