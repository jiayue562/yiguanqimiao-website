# 第八章 · 给自己做一次测评

## 这一章解决什么

人这一侧的五行怎么定。以及更重要的一件事——

> **为什么不能钉死。**

前面七章都在讲怎么给 AI 装人格。这一章回头讲你自己。顺序上它排在前面七章之后，是因为大多数人的本能是**先给 AI 选人格**（那件事更有趣），而这恰恰是错的。**你不知道自己站在哪，选什么都是乱选。**

## 核心内容

### 一、三条路径，各有各的毛病

**路径一：专业测评（推荐）**

我们做过几版：260 题的、174 题的、青少年 60 题的。题量大体覆盖五行 × 阴阳 × 三个维度。

- **优点**：系统、可比、能给出一个相对稳定的主导行。
- **毛病**：**你在答题时，答的是"你以为的自己"，不是"你实际的样子"。** 这个偏差在所有人身上都有，在自我反思习惯强的人身上尤其大——因为你会不自觉按"我希望成为的样子"答。

**路径二：象思维自照（六坐标手册）**

不做题，用六个坐标自己照：五行格／三界格／九层格／三现场格／生克格／辞典格。

- **优点**：不依赖题目，能看到你在具体现场里的样子。
- **毛病**：**需要有人帮你照。** 自己照自己，最容易照到的还是那个"我希望成为的样子"。

**路径三：他人反馈（最容易被忽略，也最准）**

问三个了解你的人：**"我什么时候最让人受不了？"**

- **优点**：别人看到的是你的**行为**，不是你的**意图**。而五行人格看的是行为模式。
- **毛病**：不好问，也不好听。**但如果你只能做一件事，我建议做这一件。**

我的建议：**三条都走一遍，看它们落在哪。** 三条一致，你八成就是那一行。三条不一致——**不一致本身就是信息**（见第三节）。

### 二、测出来之后，先别急着高兴

假设你测出来是金行。

这时候最常见的反应是：**"对，我就是金行，所以我做事讲原则、受不了含糊。"**

这句话一出口，坐标就变成身份了。

**坐标和身份的区别：**

| | 坐标 | 身份 |
|---|---|---|
| 说法 | "我此刻偏金" | "我是金行人" |
| 能不能动 | 能 | 不能 |
| 用途 | 知道从哪开始调整 | 解释自己为什么这样 |
| 危险 | 无 | **用它给自己开脱** |

金行的阴面是刻薄、冷酷。你说"我是金行人所以我说话直"——**这句话是在用坐标给自己开脱，不是在用它成长。**

### 三、测不准怎么办：不要找"真正的我"，要找"现在的我"

很多人测完发现三个路径不一致，就开始焦虑：到底哪个是真的我？

这个问题问错了。

**五行人格的输出是"链"，不是"型"。** 完整的一条链是四个字：**源 → 势 → 式 → 场**。

- **源**：你的源头在哪一行（比较稳定，但也会动）
- **势**：能量现在往哪个方向流
- **式**：你惯用的应对方式（这个最容易变）
- **场**：你现在处在什么环境里（环境影响极大）

**你不是"金行人"，你是"此刻偏金，源头在土，能量正在往外走，最近在一个需要不断做决定的场里"。**

所以三条路径不一致，不是测错了，是**它们测的是链上的不同环节**：

- 专业测评测的偏**源**（比较稳定）
- 象思维自照测的偏**式**（你惯用的方式）
- 他人反馈测的偏**场**（你在具体环境里的表现）

**不一致说明你的链是弯的，不说明你测错了。** 把三个结果写下来，你就得到了一条链——这比一个"型"有用得多。

### 四、为什么不能钉型：三个代价

**代价一：用它给自己开脱。**

"我木行，所以我固执"——固执是你的问题，不是木行的属性。木行在 1 级的人不固执，他只是有方向感。**用五行解释自己的缺点，是把缺点合法化。**

**代价二：用它给别人判刑。**

"他是水行，所以靠不住。"这句话一旦说出口，你就不会再去看他到底做了什么。**给人钉型是偷懒，而且是会伤人的偷懒。**

我在给人做咨询的时候有一条硬规矩：**团队场景（招聘、晋升、考核）禁用五行人格。** 不是因为它不准，是因为它太好用——好用到会让人不去了解具体的人。

**代价三：用它替你做决定。**

"我是火行，所以我适合做市场不适合做财务。"五行能告诉你倾向，不能替你决定。你的九层、你的场、你具体的处境，都比那个"型"重要。

### 五、给 AI 的输入该写哪个

回到实操。你要填三行：

| 行 | 内容 | 示例 |
|---|---|---|
| **主导行** | 三路径里至少两条指向的那一行 | 金 |
| **当前层** | 你最近三个月的状态（1-9） | 4（开始失衡：原则变成了教条） |
| **最近一次失衡的触发点** | 一件具体的事 | 上月连续三周赶项目 deadline |

第三行最容易被省略，但**它最有用**。因为它告诉 AI：你现在的不稳定是有原因的，而且你知道那个原因。

**给 AI 的完整写法示例：**

> 我是金行人，当前估 4 级。最近一次失衡是上月连续三周赶 deadline 之后，我的"讲条理"变成了"容不下模糊"，对人也变硬了。
> **这是我的当下坐标，不是我的命。**
> 我给你这条信息，是为了让你知道：当我表现出刻薄的时候，那不是我的观点，是我累了。你可以直接提醒我。

最后那句"不是我的观点，是我累了"——**这是坐标最大的用处**：它让你和你 AI 都能区分"他说的"和"他状态不好时说的"。

### 六、伦理硬线（这几条不许越）

这一节请认真看，它是这本书里为数不多的"不许"：

| 硬线 | 说明 |
|---|---|
| **坐标非身份** | 说"我此刻偏 X"，不说"我是 X 行人" |
| **非医疗** | 五行人格不是诊断工具，不用于判断心理疾病 |
| **不涉命理风水** | 不用于算命、择日、改运 |
| **不承诺效果** | 不给"用了就能怎样"的保证 |
| **情绪无罪，行为有界** | 情绪都可以有，伤人的行为不可以 |
| **团队场景禁用** | 不用于招聘、晋升、考核、分班 |
| **不给孩子钉型** | 未成年人坐标未定型，钉型是伤害（第二十四章展开） |

前五条来自《五行人格心理学》，后两条是本书因为"关系"这个场景新增的。

**最后加一条本书独有的**：**AI 人格不得用于替代人际关系**（第二十四章展开）。

## 本章操作件

**「我的坐标」三行填写**（+ 一句给 AI 的话）：

```
我的主导行：___（三路径里至少两条指向的行）
我的当前层：___级（1-9，凭最近三个月的状态估）
最近一次失衡：___（一件具体的事，含时间）
```

**给 AI 的那句话**（填完坐标后一起喂进去）：

> 这是我的当下坐标，不是我的命。
> 我把它告诉你，是为了让你在我状态不好的时候能认出来——
> 当我表现出___（你的阴面）的时候，那不是我的观点，是我累了。你可以直接提醒我。

**自检三问**：
1. 我有没有把坐标写成身份？（看有没有"我是 X 行人"这种句子）
2. 我有没有用坐标给自己的某个缺点开脱？
3. 我有没有想用它去评价某个具体的人？

三问里有任何一问答"有"，回去改。

## 待校准与待补

1. **测评入口以哪个为准（260 题／174 题／六坐标手册）需悟空确认**——本稿并列列出，可能给读者造成困惑。
2. "当前层"的自估方法本稿只给了原则（凭最近三个月状态），**没有给具体判据**，读者会估不准。需在附录 D 补一张自估表。
3. 三条路径的一致性判断（"三条一致八成就是那一行"）是经验值，无数据支撑。
