# 第十三章 · 复测与轨迹

## 图是照片，轨迹是电影

前面所有章节画的，都是**一张图**。

一张图很有用，但它有一个根本的局限：**它只是某一刻的你。**

你今天画的图，代表你今天。三个月后，你可能往上走了一层，也可能掉下去两层。**只有一张图，你既看不出自己在走，也看不出自己在掉。**

所以这一章要做的事是：**把很多张图，连成一条线。**

> **图是照片，轨迹是电影。别拿一张照片当一辈子。**

轨迹比单点有用得多，因为：

- 单点告诉你"你在哪"——这是事实。
- 轨迹告诉你"你在往哪走"——**这是趋势，而趋势是可以被改变的。**

---

## 为什么是三个月

建议的复测节律是：**每三个月重画一次。**

为什么是三个月？两个原因：

**第一，三个月足以让一次有意识的调整显出痕迹。** 你开始断式、开始换场，两周可能只觉得"好像好了一点"，三个月就能在图上看出层数的移动。

**第二，三个月足以预警一次下滑。** 从 L4 掉到 L5 通常很慢，但一旦开始下滑，它是**加速的**（见第三章）。三个月一次，能在加速之前抓住。

**特殊时期可以加密**：遇到大的变动（换工作、搬家、亲人离世、重病、关系破裂），可以一个月画一次，密切观察。

## 复测怎么做

**三个动作，二十分钟。**

### 动作一：重画六格（10 分钟）

用第九章的自测画法，把六格重填一遍。

**注意：不要翻上一次的图。** 先凭此刻的感觉填完，再拿出来对比。翻着上次的填，你会不自觉地"保持一致"。

### 动作二：逐格对比（5 分钟）

把这一次的六格和上一次的并排，逐格看：

| 格 | 上次 | 这次 | 变化 |
|---|---|---|---|
| 五行格（主导行/阴阳） | | | |
| 三界格（身/心/灵/平衡度） | | | |
| 九层格（区/层/走向） | | | |
| 三现场格（各场分数/最偏场） | | | |
| 生克格（最卡的一势/位置） | | | |
| 辞典格（重话/换成什么） | | | |

**重点看三处：**

1. **九层格的层数**——这是最直观的升降，也是"我到底变没变"的第一证据。如果你只问一个问题，就问它：三个月前我在第几层，现在在第几层？**数字往 L1 挪了多少，你就向本源走近了多少；这正是"我进步了"的硬证明。**（比如从 L5 到 L4，不是"降了一层"的好运，是状态向本源回收了一层。）

**更重要的是：你从 L5 挪到 L4，挪的是"相"、是"阶"；那个能挪、能知"我在进步"的，一直是同一个一心。** 进步是相的回收，不是体的增减——你从来没有"多出来"一个更好的自己，只是显出来的位置，向本源收回了一层。这正合十六字骨架里的"一心为体"：体从未动过，动的一直是它显出来的相。
2. **三界格的平衡度**——这是最根本的底层指标。（层数最直观、平衡度最底层：一个看升降幅度，一个看状态底座，两者一起读，不冲突。）
3. **辞典格的重话**——你最近骂自己的那句，换了吗？**这一格最容易看出真变化**：很多人层数没动，但那句话从"我这辈子完了"变成了"我最近有点累"——**这就已经是很大的进步。**

### 动作三：连成轨迹（5 分钟）

把每次复测的九层位置，标在一条时间轴上，连起来。

```
九层轨迹图

L1 ┤
L2 ┤
L3 ┤           ●
L4 ┤     ●           ●
L5 ┤ ●                   ●
L6 ┤
L7 ┤
L8 ┤
L9 ┤
   └────┴────┴────┴────┴────┴────┴
    1月   4月   7月  10月  1月   4月
```

**在图旁边记两个东西：**

1. **这个区间发生了什么**（换了工作、开始锻炼、家里出事、开始做某件事）。
2. **这个区间我做了什么调整**（开始断式、换了场、补了灵界）。

这两条记下来，你就能看出**什么对你有用**——这是任何人都替不了你的、只属于你的数据。

## 怎么读轨迹

### 四种基本形态

**形态一 · 上升轨迹**（如 L6 → L4 → L3）

说明阳面转化生效、调整得力。

**该做的**：保持，别停。**最容易犯的错是"好了就停"**——到了 L3 就松懈，然后又掉回去。

**形态二 · 下降轨迹**（如 L4 → L5 → L7）

**预警信号。** 提示环境或心态出了偏差，需要及时干预。

**该做的**：
- L4 → L5：找关系。第五层缺的是一份不需要挣的安全感，不是道理。
- L5 → L6：**请专业的人来。** 第六层是一般区的后墙，再往后就是不健康区。
- 到了 L7：**立即转介**（见第十四章）。

**形态三 · 长期持平**

不见得是坏事。稳定在 L3、L4，是很好的状态。

**但要问一句**：是"稳住了"，还是"卡住了"？

- 稳住了：能量通顺，日子过得下去，还在往前走。
- 卡住了：看起来没事，但你知道自己在原地踏步，而且有点闷。

**卡住的信号通常出现在辞典格**——你的重话一直没换过。

**形态四 · 剧烈波动**

这季 L3，下季 L6，再下季 L4。

**先看是不是外部原因**（换了工作、家里出事）。如果不是，可能说明**你的调整方法不稳定**——一阵子很用力，一阵子完全放下。

**该做的**：不求大步，求**小步不停**。与其三个月猛调然后停三个月，不如每天做一件五分钟的事。

小步要生根，得有个固定的钩子——同一时间、同一地点做，新习惯才挂得住，不会一阵子用力、一阵子全放下。这叫"挂"住，不是"逼"住。

## 影响轨迹的四股力量

同一个人的坐标会随时间流动，动力来自四股力量。**理解它们，你就不会把正常的波动当成失败。**

### 一、年龄

生命阶段带来五行能量的此消彼长。

年轻时木火旺（要长、要闯），中年土金渐显（要稳、要收），老年水气渐深（要藏、要养）。

**这是正常的，不是退步。** 一个五十岁的人不再像二十岁那样横冲直撞，那不叫"没冲劲了"，那叫**换了季节**。

### 二、季节

四时之气与五行相应。

- **春（木）**：生发的季节。适合开始新事，也容易躁动。
- **夏（火）**：释放的季节。适合表达、社交，也容易耗散。
- **长夏（土）**：承载的季节。适合消化、整理，也容易闷。
- **秋（金）**：收敛的季节。适合收尾、决断，也容易苛。
- **冬（水）**：沉潜的季节。适合休息、复盘，也容易沉。

**应用**：如果你的图在秋天总是往下走一点（金气主收），那不必惊慌——**顺着季节安排事情**，秋收冬藏，春天再动。

### 三、境遇

顺逆境遇会激发阳面或阴面。

**同一个五行人，在相生的环境里显阳面，在被克的环境里显阴面**（见坐标一、坐标五）。所以**环境一换，图就变**——这不是你退步了，是场换了。

**应用**：看图的时候，先记下"这段时间我处在什么环境"。不然你会把环境的影响，算到自己头上。

### 四、修习

觉知训练与拔阴取阳，直接推动层级跃迁。

这是四股力量里**唯一完全由你做主的**。年龄、季节、境遇，你都控制不了；**只有修习，是你说了算的。**

**应用**：不要小看每天五分钟。轨迹图上看得最清楚——**那些持续做小事的区间，线是往上走的。**

## 年度复盘：一年四次

三个月一次是常规，一年可以做一次大复盘。

**年度四问：**

1. **这一年，我的层数动了吗？往哪边？**
2. **三界里，哪一界变化最大？为什么？**
3. **我最卡的那条链，拆掉了几个环节？**
4. **我骂自己的那句话，换成了什么？**

**再问一句最关键的：**

> **这一年，我有没有做过一件"不问结果也愿意做"的事？**

如果有，你的灵界多半是活的。如果没有，明年先补这一条。

## 常见错误

### 错误一 · 不复测

最常见的错误，没有之一。

很多人画完第一张图，觉得"我知道自己了"，然后就放下了。**三个月后他还是那个他，只是他不知道自己在哪。**

**解决办法**：在图卡上直接写下下次复测的日期。写下来，才会做。

### 错误二 · 复测时照抄上次

翻着上次的图填，结果每次都一样。

**先凭此刻的感觉填完，再拿出来对比。**

### 错误三 · 因为一次下滑就觉得自己失败

轨迹往下走一段，是很正常的。

**看轨迹，不要看单点。** 一年里有两季往下，另外两季往上——那是活的，那是正常的。

**只有一种情况需要警觉**：连续两次都在往下，而且没有明显的外因。

### 错误四 · 把轨迹当成成绩单

轨迹不是用来比的——不跟别人比，也不跟过去的自己较劲。

**它的唯一用途是：让你看见趋势，然后决定要不要动、动哪里。**

轨迹往下，不是"我失败了"，是"该调整了"。**就像体检报告上的箭头，它不是判决书，是提醒。**

## 一章口诀

> **三个月复测一次，一年连成一条线；看趋势，不看单点。**

再短一点：

> **图是照片，轨迹是电影。**
