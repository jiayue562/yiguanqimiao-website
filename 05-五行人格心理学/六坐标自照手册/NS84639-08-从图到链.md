# 第八章 · 从图到链

## 图是六个点，链是一条线

上一章我们把六格合成了一句话。那句话还是**静态**的——它告诉你"你现在站在哪"。

这一章要做的是：**让这句话动起来。**

方法很简单：在六个点之间，画上箭头。

> **点告诉你"你在哪"，箭头告诉你"你怎么到这儿的"。**

有了箭头，你就知道该从哪儿下手——**链上任何一个环节动了，整条链就松。** 这就是"你不必改自己，只需拆链"的意思。

---

## 链的四要素

一条链，由四个东西构成：

| 要素 | 是什么 | 问的话 |
|---|---|---|
| **源** | 能量**进来**的地方。链的头。 | 这股劲儿，最初是从哪儿进来的？ |
| **势** | 能量流动的**方向**。 | 它是往上走还是往下沉？往外放还是往内收？ |
| **式** | 你那个**固定的反应模式**。 | 每次到这儿，我都在重复什么动作？ |
| **场（出口）** | 能量**出去**的地方。 | 这股劲儿，最后从谁身上、从哪儿出去了？ |

**链上三个可动点对应三法；另有补枯一法对应三界最枯界，合为四调法：**

- **调源**——在源头处理（最治本，也最难）
- **断式**——在反应模式上插一杠（最省力，最容易上手）
- **换场**——把出口挪个地方（最快见效）

（四调法的完整操作，见第十二章调法库。）

---

## 画链三步

### 第一步 · 找源

问自己：**"这股劲儿，最初是从哪儿进来的？"**

源通常落在三现场格的某一场上。老周的源在公场。你的可能是家场（跟伴侣的关系）、独处场（夜里睡不好）、学校场（孩子）。

**找源的检验标准**：你一想到它，身体会紧一下。

### 第二步 · 找势

问自己：**"这股劲儿进来以后，是往哪儿走的？"**

看五行格——它显出了哪一行的阴面？那就是势的形状：

- 显**阴木**：往上顶、往外对抗（顶撞、抗上、对着干）
- 显**阴火**：往上冲、往外爆发（急躁、管控、抢话）
- 显**阴土**：往里闷、往下沉（钻牛角尖、拖沓、往坏处想）
- 显**阴金**：往内收、往外裁（挑剔、苛刻、计较）
- 显**阴水**：往下退、往里藏（退缩、回避、不敢信人）

看九层格——它把你推到了第几层？那就是势的深度。

### 第三步 · 找出口

问自己：**"这股劲儿，最后从哪儿出去了？"**

出口有三种，都要查：

1. **从人身上出去**——你把它发在了谁身上？（伴侣、孩子、下属、同事、路人）
2. **从事上出去**——你把它转成了什么行为？（喝酒、刷手机、暴食、疯狂工作）
3. **从自己身上出去**——你把它变成了什么自我攻击？（"我废物""我改不了""我这辈子完了"）

**第三种出口最容易被忽略，也最伤人。** 因为它不闹，但一直在。

## 老周的链（贯穿演示）

把第七章老周的六格，连成一条链。

### 画出来

```
【源】公场：上司木克土（节奏推着我，我要的稳被说成慢）
   │
   │  势：能量往内收、往下沉
   ▼
【式】土阴显形：钻牛角尖、往坏处想、拖沓
   │  → 事情更做不好
   │  → 更想"做得更漂亮让上面看见"（L5 外求认可）
   │  → 灵界更枯（4 分，说不清为什么而做）
   │
   │  带场：公场 → 家场
   ▼
【出口】家场：对家人发了不该发的火
   │     独处场：深夜自语"我跟不上时代了"
   │
   │  循环
   └────→ 第二天更累，公场更扛不住 ──→ 回到【源】
```

### 这条链告诉老周什么

**第一，他的僵化不是本性，是势的形状。** 土被木推，只能往里闷。他不是在"变顽固"，他是在硬撑。

**第二，他的 L5 外求认可，根源在灵界那 4 分。** 他自己说不清为什么而做，就只能从别人的认可里找存在感。灵界是这条链的撬动点。

**第三，他真正的出口错了。** 气从家人身上出去、从自我攻击出去——这两个出口都在伤他最在乎的东西。

**第四，链是闭合的。** 出口的能量又回到了源（第二天更累），所以它会一直转。**转的链，光靠忍是断不了的，得从某个环节插进去。**

### 这条链上，老周能动的四个点

| 环节 | 动作 | 难度 |
|---|---|---|
| **调源** | 在公场把节奏问题谈开；或调整自己接任务的方式（先要"哪件事先停"，别硬接四个方向） | 难，但治本 |
| **断式** | 发现自己开始钻牛角尖时，起身倒杯水、走两步——把"往里闷"打断 | 易，立刻能做 |
| **换场** | 回家前在车里／楼下坐十分钟，把公场的气卸在门外 | 易，见效快 |
| **补最枯的那一界** | 灵界 4 分——立一个小小的志（比如带两个年轻人出来），给日子装个方向 | 中，但撬动力最大 |

**老周只需要选一个先做。** 选最容易的那个，先让链松动一下。

## 四种常见链型

大多数人的链，逃不出下面四种。看看你的是哪一种。

### 链型一 · 带场链（最常见）

```
A 场被克 ──→ 带着这股劲儿 ──→ B 场发作 ──→ 自责 ──→ 第二天更累
```

**典型台词**："我白天在单位憋了一天，回家就对孩子发了火。发完我又后悔。"

**断点**：**换场**——在 A、B 之间插一个缓冲（回家前十分钟）。这是见效最快的一招。

### 链型二 · 外求链

```
灵界偏枯 ──→ 不知道为什么而做 ──→ 去求别人的认可 ──→ 求不到或求不够
   ↑                                                        │
   └──────────────── 更枯 ←── 更求 ←──────────────────────┘
```

**典型台词**："我也不知道我图什么，就是想让人认可我。得到了也高兴不了两天。"

**断点**：**补灵界**。这一型靠"更努力表现"是解不开的——表现是这条链的燃料，不是解药。要往源头走：给自己找一件不问结果也愿意做的事。

### 链型三 · 压抑链

```
一直忍 ──→ 累积 ──→ 一次爆发 ──→ 爆发后自责 ──→ 发誓下次不这样 ──→ 继续忍
   ▲                                                                    │
   └──────────────────────────────────────────────────────────────────┘
```

**典型台词**："我能忍，但忍到最后一定会炸一次，炸完我又特别后悔。"

**断点**：**断式**——在"累积"阶段就放气，而不是等到"爆发"。忍不是德行，是把压力存起来，利息很高。

**关键认知**：这条链的问题不在"爆发"，在"一直忍"。你要改的不是脾气，是**允许自己在小事上说不**。

### 链型四 · 补偿链

```
某处不足（或某处空） ──→ 拿另一件事盖住 ──→ 越盖越累 ──→ 那处还是空
   ▲                                                          │
   └────────────────────────────────────────────────────────┘
```

**典型台词**："我工作特别拼，其实我也知道，是因为家里那摊事我不想面对。"

**断点**：**调源**——去面对那个被盖住的东西。补偿链的特点是：你越努力，那个空洞越大，因为你所有的力气都用在盖它，而不是填它。

## 从"命"到"链"：这一章真正要给你的

回头看老周那句话。

**画链之前**："我这是跟不上时代了。"

这句话里有三个"死"：

1. **"我"**——问题在我身上。
2. **"这是"**——它是一个事实。
3. **"跟不上时代"**——一个巨大的、模糊的、无法动手的东西。

**画链之后**："我在公场被木克，土显阴面，灵界偏枯，气从家场出去，第二天回到原点。"

这句话里有六个"活"：场、势、行、层、界、词——**每一个都能动。**

> **你以为的"命"，画出来就是一条链；链能拆，命不能拆。**

这就是这套工具的全部意义。它不让你变成一个更好的人——它只是让你看见：**你从来不需要变成另一个人，你只需要拆掉那条链。**

## 常见错误

### 错误一 · 把链画成一条直线

真实的链多半是**循环的**——出口连回源头。

画成直线，你会以为"解决了源头就完了"。画成环，你才知道**它是会自己转的**，必须在某个环节持续地插进去。

### 错误二 · 想在源头一步解决

调源治本，但最难，也最慢。

**新手请从"断式"或"换场"开始。** 这两招不治本，但它们能立刻让链松一点。**链一松，你才有力气去动源头。**

### 错误三 · 一次想断所有环节

链上有四个环节，你一次只动一个。

动完一个，观察两周，看链松没松。松了，再动下一个。**一次全动，你不知道是哪个起了作用，也坚持不下去。**

### 错误四 · 把自责也画进链里

"我发完火又自责，自责完更累"——自责确实是链的一部分。

但请注意：**画它是为了看见它，不是为了多一个东西骂自己。** 看见"我在自责"，自责就已经松动了——因为你从"我在自责"里分出了一个"看见自责的我"。

---

## 收束 · 你画的，是一心在观它自己的运行

这一章你做的全部动作——找源、找势、找出口、画箭头、拆链——看起来是在"分析自己"。

其实不是。你分析的那个人，是六坐标显出来的"相"；那个能分析、能看的，是同一个"一心"。

> **你画链的整个过程，是一心在照见它自己的运行；六坐标是它显出来的相，不是它自己。**

所以"拆链"不是把"我"修掉，是让一心从它卡住的那个相里，松出来一点。链松了，不是你变成了另一个人，是那个能知的源头，重新看见了通路。这整本手册从头到尾都是这一个动作——不是要你成为谁，是要你认出：能看的，一直是那个一心。

---

## 一章口诀

> **点告诉你站在哪，箭头告诉你怎么来的；链能拆，命不能拆。**

再短一点：

> **你不必改自己，只需拆链。**
