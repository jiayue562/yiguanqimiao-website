# 坐标一 · 五行格

## 这一格量什么

**一句话**：五行格量的是你的**能量底色**——你最常显出哪一种运行方式。

五行不是五种人，是**五种运行的样子**：

- **木**——往上、往外长。像春天的树，要突破、要伸展、要往前走。
- **火**——往上、往外放。像夏天的火，要热烈、要点燃、要被看见。
- **土**——往中间、往下托。像长夏的地，要承载、要稳定、要兜住。
- **金**——往内、往下收。像秋天的刀，要清晰、要边界、要裁剪。
- **水**——往下、往里藏。像冬天的水，要沉潜、要通透、要养着。

这五种运行方式，每个人都有，只是配比不同、显隐不同。五行格要找的，是你**最常显的那一行**（主导行）和**次常显的那一行**（辅行）。

**注意两个词：常显、此刻。**

"常显"说的是它不是某一瞬间的情绪，是你一贯的默认反应；"此刻"说的是它会变——逆境里你可能显出平时不显的那一行。所以这一格填的是"最近三个月，我最常显哪一行"。

---

## 速查表一：五行五维度

每一行都不是一个点，是五个侧面。先看清楚这二十五个侧面，再判断自己偏哪一行。

| 行 | 五维度 | 白话 |
|---|---|---|
| **木** | 曲直、生发、舒畅腾上、调达柔和、内在成长 | 能屈能伸、要生长、要舒畅、要变通、要长进 |
| **火** | 炎上、明亮、炽烈、发散、迅疾 | 要向上、要照亮、要热烈、要扩散、要快 |
| **土** | 承载、适应、容纳、运化、稳定 | 能扛事、能随遇、能包容、能消化、能稳住 |
| **金** | 坚固、收敛、锋利、光洁、变革 | 有原则、能收束、能决断、要干净、敢改变 |
| **水** | 润下、通透、沉潜、静藏、养物 | 往低处走、看得透、沉得住、藏得住、能养人 |

读法：不要一行一行地"对号入座"，要**横着读**——把五行都看一遍，看哪一行的五个侧面，你中得最多。

---

## 速查表二：五行的阳面与阴面

**这是五行格最关键的一张表。**

每一行都有两面。阳面是这一行"通"的时候的样子，阴面是这一行"堵"的时候的样子。

**同是木行，走阳面则"曲直向上"，走阴面则"曲而扭曲"。**

| 行 | 阳面（通） | 阴面（堵） |
|---|---|---|
| **木** | 仁德、宽容、进取、有担当、能屈能伸 | 傲慢、固执、嫉妒、顶撞、抗上孤僻 |
| **火** | 礼德、温暖、明亮、有感染力、能点燃人 | 急躁、虚荣、争理、管控强加、记恨 |
| **土** | 信德、包容、可靠、能托底、坚韧不拔 | 多疑、僵化、抱怨、死板迟缓、黏着依赖 |
| **金** | 义德、严谨、利落、有边界、能断 | 苛刻、冷漠、计较、挑剔、执拗不化 |
| **水** | 智德、变通、沉静、通透、能养物 | 恐惧、贪婪、退缩、多疑、消沉委靡 |

**这一张表要特别留意三件事：**

**第一，阴面不是"坏人"，是"堵住了"。** 木行的傲慢，是生发的能量出不去了，憋成了顶撞；火行的急躁，是要照亮的心没被接住，憋成了管控。阴面是阳面走了岔路，不是另一种本性。

**第二，得分高不等于好。** 一个人木行得分很高，可能是阳木（仁德宽容），也可能是阴木（傲慢嫉妒）。**看阳面还是阴面，比看高不高更重要。**

**第三，阴面自己看不见。** 这是最麻烦的一点。你身上阳面的部分，你清楚；阴面的部分，往往是别人先看见。所以后面第九章讲"关系镜"——请一个亲近的人帮你照，就是在补这个盲区。

## 自照清单（打勾）

凭第一反应勾，不斟酌。勾完看哪一行最多。

### A 卷 · 认主行（五行各三题）

| 行 | 自照题（符合就打 √） |
|---|---|
| **木** | ①我天生往上走，遇事想突破、想生长<br>②我直来直去，讨厌绕弯子<br>③不顺心时我容易顶、容易僵 |
| **火** | ①我热情外放，喜欢成为人群的中心<br>②我反应快、点子多，但也可能忽冷忽热<br>③急躁起来我会抢话、会发火 |
| **土** | ①我是大家的"底盘"，习惯包容、托住别人<br>②我慢热但可靠，厌恶变动<br>③固执起来我听不进、认死理 |
| **金** | ①我讲规则、重标准，看不得凑合<br>②我干脆利落，该断就断<br>③苛刻起来我挑剔人、不近人情 |
| **水** | ①我沉静通透，喜欢往深处想<br>②我善藏善忍，不轻易亮底牌<br>③多疑起来我退缩、回避、不敢信人 |

**判读**：哪一行 √ 最多，即疑似主导行。若两行接近（比如都是 2 个），那是**双主行**的信号——这很常见，不必强行选一个。

### B 卷 · 照阴面（五行各选，勾"我最近有"的）

| 行 | 阴面表现（最近一个月有过的，打 √） |
|---|---|
| **阴木** | □ 顶撞、抗上、不服管<br>□ 冷淡、退缩到自己的世界里<br>□ 敏感、觉得别人针对我<br>□ 逃避、嘴上逞能实际不做<br>□ 消极、对着干 |
| **阴火** | □ 怨亲、急躁、一点就着<br>□ 争理、记恨、翻旧账<br>□ 管控、强加、要别人听我的<br>□ 虚荣、浮夸、要面子<br>□ 贪求、溺爱、边界不清 |
| **阴土** | □ 愚闷、固执、钻牛角尖<br>□ 抱怨、多疑、往坏处想<br>□ 死板、迟缓、不肯变通<br>□ 黏着、依赖、不敢自己做决定<br>□ 呆板、闷着不动 |
| **阴金** | □ 苛刻、挑剔、看什么都不顺眼<br>□ 冷漠、自私、别人的事与我无关<br>□ 计较、争锋、一定要赢<br>□ 刻薄、说话伤人<br>□ 执拗、认死理、不肯转弯 |
| **阴水** | □ 退缩、逃避、能躲就躲<br>□ 多疑、恐惧、总觉得要出事<br>□ 沉溺幻想、活在脑子里<br>□ 拖沓、懒散、提不起劲<br>□ 怨天尤人、都是别人的错 |

**判读**：哪一行勾得最多，这一行就是你**当下最需要先拔的阴面**。

注意 A 卷和 B 卷可能不一致——比如 A 卷你木最多，B 卷你火勾得最多。这不矛盾：**A 卷是你的底色（木），B 卷是你此刻堵住的地方（火）。** 底色一时半会儿不变，堵住的地方才是你当下要动的。

## 填格

把上面的结果，填进这一格：

```
五行格
  主导行：_______（木／火／土／金／水）
  辅　行：_______（可空着，若双主行就填两行）
  当前显：□ 阳面   □ 阴面   □ 阴阳交织
  最需拔的阴面：_______行（B卷勾得最多的那一行）
```

**填格的三条提醒：**

1. **不要选"我想要的"，要选"我实际的"。** 很多人想成为水（沉静通透），实际是火（急躁外放）。填你实际的，不填你向往的。
2. **最近三个月为准，不是一辈子。** 你五年前可能显金，现在显火，都正常。填最近。
3. **填不出来就空着。** 空着也是一种真实的信息——它通常意味着"我最近没在留意自己"。这时候跳到第九章，用日记画法，记一周就出来了。

## 常见误判

### 误判一 · 把"此刻的状态"当成"本来的行"

这是最常见的错误。

一个人连着三个月高压加班，变得急躁、易怒、控制欲强。他一填，火。但其实他的底色是土——只是土被压久了，憋出了火的形状。

**怎么分辨**：问自己一句——"我十八岁以前，是什么样子？" 那时候的状态，通常更接近底色。或者问一句——"我放松的时候，是什么样子？" 放松时的你，比紧绷时的你更像你。

### 误判二 · 以为一个人只能有一行

不是。五行人人都有，只是配比不同。

**有辅行是正常的，双主行也是正常的。** 有人木火双显（又要长又要亮），有人土金双显（又稳又利落）。强行把自己塞进"一行"，是把自己削掉一块。

### 误判三 · 把阴面当成本性

"我就是脾气差"——这句话是把阴火当成了本性。

阴面不是本性，是**堵住的阳面**。火的本性是照亮，堵住了才变成急躁。你把堵的地方疏通，火还是那股火，但它烧的方向变了。

**这一条极重要**：如果你认定阴面是自己的本性，你就不会去动它了——"我天生如此"是最有效的一句自我放弃。

### 误判四 · 以为五行有高下

没有。木不比水高级，金不比土低级。

五行是五种运行方式，不是五种等级。**每一行都有它的阳面和阴面，每一行的阳面都好，每一行的阴面都不好。** 判别标准只有一个：走阳面还是走阴面。

### 误判五 · 用五行给别人定罪

"他是阴金，所以苛刻"——这是把工具用反了。

你看出他是阴金，用途只有一个：**知道怎么跟他处**（比如给他清晰的边界和流程，他就不苛刻了）。不是"他这个人就是苛刻"。

## 一格口诀

> **五行是底色，不是牢笼；阴面是堵住，不是本性。**

再短一点：

> **认主行，照阴面；阴不是性，堵才是病。**
