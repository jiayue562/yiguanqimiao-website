# 坐标三 · 九层格

## 这一格量什么

**一句话**：九层格量的是你的**生命状态**——你此刻站在发展的第几层。

前两格说的是"你是什么"：五行格说你的底色，三界格说你的落点。这一格说的是"**你现在怎么样**"。

这两个问题必须分开问。**"你是木行"说的是本性，"你在第几层"说的是此刻的状态。** 本性相对恒定，状态一直在动。

这是一个极重要的区分。一个处在第二层的木行人和一个处在第六层的木行人，五行得分可能差不多，生命状态却天差地别：

- 第二层的木：仁德宽容，能屈能伸，遇挫能自己回来。
- 第六层的木：傲慢固执，顶撞抗上，出了问题全是别人的错。

**同是木行，一个在往上长，一个在往下掉。**

所以这一格，是六坐标里最关键的一格。它不只告诉你"你在哪"，还告诉你"你在往哪走"。

## 速查表一：九层光谱

| 层 | 名称 | 三界平衡度 | 能量状态 | 典型表现 |
|---|---|---|---|---|
| **L1** | 解放层 | ~95% | 阳面圆满 | 不必努力就合上节奏，情绪来了不留下 |
| **L2** | 心理能力层 | ≈90% | 阳面主导 | 波动了能自己回来，而且回得越来越快 |
| **L3** | 社会价值层 | ~85% | 阳面稳定 | 在人群里发光，做事有价值感 |
| **L4** | 失衡层 | ~75% | 阴阳博弈 | 有一处"不像我了"，但还能自己调 |
| **L5** | 人际控制层 | ≈60% | 阴面渐显 | 开始要别人的反应，需要被确认 |
| **L6** | 过度补偿层 | ≈50% | 阴面强化 | 拿一件事盖住所有事，停不下来 |
| **L7** | 侵害层 | ~35% | 阴面主导 | 开始伤人伤己，失边界 |
| **L8** | 妄想强迫层 | ~20% | 阴面固化 | 认不出世界了，现实检验能力丧失 |
| **L9** | 病态破坏层 | ＜20% | 阴面爆发 | 撑不住了，功能全面崩溃 |

九层分三个区：

- **健康区（L1–L3）**：阳面主导，三界平衡。这一区不需要"治"，需要的是**继续往上走，以及把手里有的给出去**。
- **一般区（L4–L6）**：阴阳交战，还有来回。**这一区是窗口期**——往上还是往下，取决于这一区怎么过。
- **不健康区（L7–L9）**：阴面固化，需要专业干预。这一区**不能谈成长，不能谈转化，更不能谈修行**。先稳定，再治疗。

## 速查表二：三区怎么分辨

**总分定位用三界平衡度，具体落层用下面这张表。**

### 健康区：怎么看出来

| | L1 解放层 | L2 心理能力层 | L3 社会价值层 |
|---|---|---|---|
| **一句话** | 不必努力 | 努力了能回来 | 在人群里发光 |
| **主观感受** | 没什么要处理的 | "我刚才急了一下，现在好了" | "我做的这些是有价值的" |
| **遇到挫折** | 挫折不构成问题 | 波动后自行回稳 | 需要关系与意义来消化 |
| **风险点** | 执着于"我已放下" | 停留在"我修得好" | 价值感绑在社会认可上 |
| **怎么看出来** | **他不需要被看见** | **他能看见自己** | **他能被很多人看见** |

最后一行最管用。你去观察一个人：**他需不需要被看见？**

第三层的人需要被看见，而且值得被看见。第二层的人不需要被看见，但他能清楚地看见自己——他能说出"我刚才急了，现在已经好了"。第一层的人既不需要被看见，也不特别在意自己——你跟他在一起觉得他没什么存在感，但你离开时会觉得少了点什么。

### 一般区：怎么看出来

| | L4 失衡层 | L5 人际控制层 | L6 过度补偿层 |
|---|---|---|---|
| **一句话** | 有一处不对劲 | 需要别人来确认我 | 拿一件事盖住所有事 |
| **范围** | **局部**：一处失衡，其余正常 | **关系**：把别人卷进来 | **整体**：三行以上阴面凸显 |
| **主观感受** | "我这是怎么了" | "他们怎么看我" | "我必须做点什么" |
| **自调能力** | 尚存 | 减弱 | **显著下降** |
| **怎么看出来** | **他哪里"不像他了"** | **他开始要反应** | **他停不下来** |

**L6 的判断要点**：看的不是他做了什么，是**他停不停得下来**。

一个人加班到深夜，你让他先回去睡，他能站起来走人——那不是 L6，那只是忙。怎么劝都不走、不走又做不下去、坐在那里熬——这才是。

L6 和 L2 是镜像的：**L2 是"我能自己调回来"，L6 是"我调不回来了，而且我不承认我调不回来"。**

### 不健康区：怎么看出来

| | L7 侵害层 | L8 妄想强迫层 | L9 病态破坏层 |
|---|---|---|---|
| **一句话** | 开始伤人 | 认不出世界 | 撑不住了 |
| **分界线** | 行为失控，**但还认得现实** | **现实检验能力丧失** | 心理功能全面崩溃 |
| **社会功能** | 严重受损 | 需要他人照顾 | 完全丧失 |
| **第一位的事** | **止损与安全** | 精神科介入 | 紧急住院与危机干预 |

**到了 L7 及以上，本体系不作诊断，也不作治疗。一律转介。**（详见第十四章）

## 速查表三：五行各型的九层光谱（判断"我这一行"现在在哪一层）

前面两张表是不带行别的"通用刻度"——它告诉你落在哪一区、大概第几层。但要**精确判断"我是木行／火行……此刻在第几层"**，必须按自己的行别看。

> 同样的第五层：木行顶上去、火行压下去、土行拴住人、金行挑毛病、水行退开。**层数一样，长相完全不同。**

所以完整的自照永远是两句话：**我是哪一行，我在第几层。** 缺一句都不算定位。

**用法（顺序不能反）**：
1. 先用坐标二的三界平衡度定区（A 卷）——你在健康区／一般区／不健康区；
2. 再确认你的行别（坐标一五行格）；
3. 去下表找**你这一行**在那一区的层，逐条对"样子"，对得上才算数。

> 称号是**验证**不是**猜**：先有三界的读数，再用称号去对一遍。看见自己"争强好胜"就定第五层——第三层的木也争，他争的是事不是输赢；看见自己"安静退缩"就定不健康区——第一层的水本来就安静。**行为定不了层，行为底下躲着什么才定层。**

### 先记住每行的"怕与求"（定位自己的轴）

同一行，从第一层到第九层，怕与求的内容**从来不变**，变的是这个怕对你的控制权大小：

| 行 | 怕（一直在躲的） | 求（一直在奔的） |
|---|---|---|
| 木 | 无用、无能、长不出来 | 能干（自己行） |
| 火 | 被控制、被伤害 | 保护、独立 |
| 土 | 失去支持与指导 | 被支持 |
| 金 | 堕落、不完美、不干净 | 正直、做个好人 |
| 水 | 得不到爱、没人真要 | 被爱 |

怕与求有三态：**健康区是睡着的怕**（推着你往前走）；**一般区是醒着的怕**（牵着你绕圈）；**不健康区是疯了的怕**（拖着你往下坠）。同一个木行：第一层做事是因为该做，第五层做事是因为不做就证明他不行，第九层做事是因为那件能毁的事就在眼前。**事情可能一样，底下的那一点完全不同。**

### 每行怎么判断"自己"在哪一层（主轴 + 一个最易误判自己的点）

- **木行 · 主轴：生发 → 证明 → 毁灭。** 易误判：把"抗上"当骨气——第二层抗上是因为事，第五层抗上是因为输赢；木行真正想通的样子是能笑出来，安静下来通常不是想通，是攒下一轮火或开始消极抵抗。
- **火行 · 主轴：照亮 → 控制 → 焚毁。** 易误判：把"急躁"当高效——第四层以后的快是不敢慢；火行说"我没事"往往是有事，他真有事的样子常常是突然安静。
- **土行 · 主轴：承载 → 拴住 → 坍塌。** 易误判：把"付出"当无私——第四层往下付出开始带钩子（每份好都让你背上一点债）；他说"都行"的时候，通常已经不行了。
- **金行 · 主轴：分明 → 挑错 → 肃杀。** 易误判：把"严谨"当美德全部——严谨到不容一点错，已经是怕不是严谨；金行的冷静底下常常是冷的，他不是不动怒，是把怒冻起来了。
- **水行 · 主轴：润泽 → 示弱 → 沉溺。** 易误判：把"随和"当通达——第四层往下的随和是不敢有立场；水行往下掉时往往越来越安静，那是危险信号，他真正好转的样子是开始提要求、说"我不愿意"。

> **不健康区（L7+）一律转介**（详见第十四章）：到了这一层，本体系不作诊断、不作治疗。若你对照上表发现自己停在 L7 及以上，或身边人如此，请寻求专业帮助，不要自行处理。

## 自照清单

### A 卷 · 先定区（用三界平衡度）

把坐标二算出的三界平衡度拿过来，对着看落在哪一区：

| 三界平衡度 | 落在 |
|---|---|
| 80% 以上 | **健康区**（L1–L3） |
| 50% – 79% | **一般区**（L4–L6） |
| 50% 以下 | **不健康区**（L7–L9）→ **请直接翻到第十四章** |

### B 卷 · 再定层（逐条对照，勾"最近一个月符合"的）

> **先确认你的行别**（坐标一五行格），再按速查表三里**你这一行**的光谱逐条对照勾选。上面的通用描述是参考，分行描述才是你该对的那一列——同层不同行，长相完全不同。

**健康区**——

□ **L1 解放层**：我不需要刻意努力，就能合上事情的节奏；情绪来了走一遍就走了，不留在心里；我不太在意"我做得好不好"
□ **L2 心理能力层**：我会波动，但能自己回来，而且回来的时间越来越短；想法跟我不同的人，我听得进去
□ **L3 社会价值层**：我在人群里是舒服的，人群跟我在一起也舒服；我给予的时候，自己也在长

**一般区**——

□ **L4 失衡层**：我有一块地方"不像我了"，但其他地方还正常；只要意识到，多半能自己缓过来
□ **L5 人际控制层**：我开始在意别人怎么看我；我需要别人的反应才能确认自己；我缺的是一份不需要挣的安全感
□ **L6 过度补偿层**：我拿一件事盖住所有事；我停不下来；别人劝我停，我不听，但我自己也做不下去

**不健康区**（勾选即请转介，不要自照）——

□ **L7 侵害层**：我做了伤害自己或别人的事；我不在乎别人怎么看了
□ **L8 妄想强迫层**：我分不清哪些是我想出来的、哪些是真的
□ **L9 病态破坏层**：我撑不住了；我需要紧急帮助

### C 卷 · 下滑通道自查

一般区三层不是并列的，是一条通道：

> **L4（一处失衡）→ L5（把别人卷进来）→ L6（停不下来）**

这条通道有两个特点，值得记牢：

**第一，它是加速的。** 从 L4 到 L5 通常很慢，可能拖上几年；从 L5 到 L6 往往快得多。因为一旦开始外求，一个人就失去了内在的刹车——他需要的外界反馈越来越多，而外界反馈给得越来越少，于是他加码，加码又让身边的人退得更多。**这是一个自我加速的循环。**

**第二，每一层的"解药"，在下一次会变成"毒药"。**

- L4 靠"自我调整"能缓过来，于是他学会了**压**——压住情绪，装作没事。这办法在 L4 管用，到 L5 就成了问题：压住的那些东西会变成对认可的渴求，从后门跑出来。
- L5 靠"得到认可"能缓过来，于是他学会了**表现**——做得更好、说得更漂亮。这办法在 L5 管用，到 L6 就成了问题：要维持的表现越来越多，撑不住的那天就是过度补偿的开始。

> **所以转化的关键不在于"用对办法"，在于"在办法还管用的时候就换掉它"。**

这句话是一般区最值钱的一句，也是最难做到的一句——**人总是等到办法彻底失效才肯换。**

自查三问：

1. 我现在还在用的那个"让自己好起来"的办法，是什么？
2. 这个办法，最近是不是越来越费劲？
3. 如果它快不管用了，我准备换什么？

## 常见误判

### 误判一 · 把层级当人品

**层级不是人品，是状态。**

一个人在第六层，不代表他是个坏人，只代表他此刻堵得厉害、停不下来。同样，一个人在第三层，也不代表他是个圣人，只代表他此刻能量通顺、在社会上有位置。

**层级会动，人品是另一回事。** 拿层级评判人，是把状态当成了身份。

### 误判二 · 把自己往高了填

自评最常见的偏差，是给自己偏高。

尤其 L1，被误填的概率极高。判断 L1 有一个简单的检验：**一个人如果还能说出"我已经放下了"，他多半还没放下。** L1 不是"什么都做到了"，是"什么都不必做了"——这两句看起来像，实地上差着十万八千里。

**填低不填高。** 把自己填在第四层，你还有往上走的空间和动力；把自己填在第一层，你就什么都不用做了——这恰恰是最危险的。

### 误判三 · 以为一般区是"没问题"

L4–L6 叫"一般区"，但这个"一般"不是"还行"的意思，是**"还来得及"**的意思。

一般区是窗口期，但窗口不是一直开着的。三层的可干预性差别很大：

- **L4：自己能调。** 只要意识到"我这块不对劲"，多半能缓过来。这个阶段最有效的帮助是**点一下**——让他看见那个"不像他"的地方。一句就够。
- **L5：需要关系。** 他的失衡已经绑在别人身上了，靠自己想通很难。这个阶段有效的帮助不是讲道理，是**给一个不依赖表现的关系**——让他体验到"你什么都没做，我也照样在这儿"。第五层的人缺的从来不是认可，是一份不需要挣的安全感。
- **L6：需要专业帮助了。** 自我调节能力显著下降，防御性强，寻常的劝解已经进不去。**第六层是一般区，但它是一般区的后墙**——再往后一步，就是不健康区。

> **一句话记住：第四层点一下，第五层陪一段，第六层请专业的人来。手法错了，代价是他继续往下走。**

### 误判四 · 给别人定层

这一条要说得重一点：**不要替别人定层，尤其不要替别人定 L5 以下。**

层级是极难观察的，你看到的只是行为，看不到别人内心的挣扎。你说某人在 L6（停不下来），可能人家只是最近项目紧。

**给别人定层，是这套工具最容易伤人的用法。**

若你真担心一个人，正确做法不是"他是第六层"，而是"他最近停不下来，我陪他聊聊"。前者是判定，后者是关心。

### 误判五 · 在不健康区谈修行

L7 及以上，第一位的动作是**止损与安全**，不是做功课、不是拔阴取阳、不是向内看。

一个人都站不稳的时候，你给他方向没有用。**先稳定，再治疗。**
