# 第七章 · 六格合成法

## 六格不是六个答案

六格填完，你手上有六个结果。但如果只是把它们并排摆着，那还不是图——那是六张纸条。

**合成，是把六格变成一个结构。**

先说一个铁律，免得后面混：

> **五行格（坐标一）是你的身份底色，恒定不变——你永远是哪一行，在任何场里都是那一行。九层格（坐标三）是你此刻的层级，它会动：向 L1（数字减小、靠近本源）是进步，向 L9（数字增大、滑向表层）是退步。这两格里，只有五行格是身份，九层格是状态。**

六格合成法说的"主格"，**不是身份，是情境**——

> **六格里，有一格是"情境主格"；其他五格，都在解释它为什么现在这样。**

情境主格是你当前最紧的那一格——就是你一看就觉得"唉，就是这个"的那一格。它说的是"我现在先动哪一点"，**永远不替换你的五行底色**。

有时候情境主格是三现场格（"就是那个破单位"），有时候是九层格（"我最近整个人都不对"），有时候是生克格（"就是被他克住了"）。即便主格落在五行阴面上（"我就是火，太急了"），那也是"我这个火行人的阴面被激活了"，不是"我改行了"。

**情境主格会变。** 这一季度是场的问题，下个季度可能是层级的问题。所以每次重画，都要重新找主格——但你的五行底色，重画一万次还是那一行。

---

## 合成三步

### 第一步 · 填完六格

不做这一步，后面都是空的。若某格填不出，用那一格的日记画法（见第九章），记一周就出来了。

### 第二步 · 找主格

看六格，问自己一句：**"哪一张，是我一看就叹气的？"**

那就是主格。在它旁边画个圈。

如果分不出来，用这个笨办法——把六格两两对比，看哪两格之间有明显的**因果**（比如"因为公场被克，所以火重"）。有因果的那一对里，**"因"的那一格通常就是主格**。

### 第三步 · 连成一句话

把六格合成一句话。格式如下，填空即可：

> **我在〔　场　〕被〔　什么　〕克（或：缺〔　什么　〕），显出〔　哪一行　〕的〔 阴面 〕，卡在第〔　几　〕层，〔 哪一界 〕偏枯，我把它说成了〔　那句话　〕。**

这句话，就是你的图。

**它比六张纸条有用得多**——因为它是一条链的形状，而不是六个点。

## 完整样例：老周的图

贯穿这一章，我们用一个人把合成过程演一遍。

**老周，四十五岁，技术部门主管。**

他的自述是："我这是跟不上时代了。"

### 他的六格

**坐标一 · 五行格**
```
主导行：土    辅行：金
当前显：阴面（多疑、僵化、拖沓）
最需拔的阴面：土
```
自照时他 A 卷土行三条全中（我是大家的底盘／慢热但可靠，厌恶变动／固执起来听不进），B 卷阴土勾了三条（钻牛角尖／往坏处想／不肯变通）。

**坐标二 · 三界格**
```
身界：7    心界：5    灵界：4
三界平衡度：53%
活跃界：身界    偏枯界：灵界
```
他自己说："身体还行，就是心里烦，也说不清为了什么。"

**坐标三 · 九层格**
```
所在区：一般区    当前层：L5 人际控制层
近三个月走向：往下
"让自己好起来"的办法：把事情做得更漂亮，让上面看见
```
他勾中了 L5 那条："我开始在意别人怎么看我。"

**坐标四 · 三现场格**
```
公场：-3    家场：+1    独处场：-2
最偏的场：公场    充电的场：家场
有无带场：有（公场 → 家场）
```
带场自查他勾了三条，其中有"我在单位憋了一天，回家对家人发了不该发的火"。

**坐标五 · 生克格**
```
最卡的那一势：我和上司之间
我在的位置：克我位
这股势是：只有克，没有生
```
他上司是木行的——反应快、要突破、三天一个新想法。老周是土——要稳、要落地。木克土：上司的速度，把老周的"稳"变成了"慢"。

**坐标六 · 辞典格**
```
最近最常对自己说的一句重话："我这是跟不上时代了。"
这句话属于：状态→本质
换成说活的说法："我最近在公场被推着走，我的节奏跟不上，我在硬撑。"
评价上司最常用的品格词："瞎折腾" → 换成行为词："三个月换了四个方向"
```

### 找主格

老周看六格，一眼叹气的是**坐标四 · 三现场格**："就是那个破单位。"

主格 = 三现场格（公场）。

### 连成一句话

> **我在〔公场〕被〔上司的节奏〕克，显出〔土〕行的〔阴面：僵化、拖沓、往坏处想〕，卡在第〔五〕层，〔灵〕界偏枯，我把它说成了〔"我跟不上时代了"〕。**

这一句，就是老周的图。

注意：老周的五行底色就是**土**，这里"显出土行"，是被克住的土，不是换了行。如果主格落在生克格（被木克），那个"木"是**上司的行**，不是老周的行——别把"被谁克"读成"我是谁"。

**对比一下他原来的自述**："我这是跟不上时代了。"

- 原版是**身份判定**——"我跟不上"，是一个关于"我"的结论。结论不能改，只能认。
- 图版是**结构描述**——场、势、行、层、界、词，六个可动的点。每一点都能动。

这就是合成的价值：**把你以为的"我"，拆成了一张可以动的图。**

---

## 直答一个常见问题

有人会问："如果主格是场、是势，那我到底什么行人？"

答：**你是什么行人，永远以坐标一·五行格为准。** 老周是土行人，重画一万次还是土行人。

六格合成法不重新定义你。它做的是另一件事：**在你恒定底色之上，标出当下最该调的那一点。** 底色是"你是谁"，主格是"你现在先动哪儿"。

所以回到那个问题——老周问"我到底是什么行人"，你答"土行人"；他若追问"那我怎么现在这样"，你才把图展开：被木克、显阴、卡 L5、灵界偏枯。前者是身份，后者是当下呈现。两句话，不打架。

---

## 合成之后：先看懂"哪个是因，哪个是果"

合成完之后，还要做一件事：**分清因果。**

老周的六格里，有因果关系的至少两组：

1. **公场被克（因）→ 土显阴面（果）**。不是他僵化，是被推得只能僵住。
2. **灵界偏枯（因）→ L5 外求认可（果）**。他自己说不清为什么而做，于是只能从别人的认可里找存在感。

**分清因果，才知道从哪儿下手。**

- 若你只盯"土显阴面"，你会去"改自己的僵化"——费力，而且改不动，因为源头还在推。
- 若你看到"公场被克是因"，你会去处理源头——**调源**。

这就是下一章"从图到链"要做的：把图上的六个点，连成一条有方向的线。

## 常见合成错误

### 错误一 · 六格都是"我不好"

很多人填完之后，六格全指向"我这个人不行"——五行阴面、灵界偏枯、L6、公场最耗、只在克位、词全说死了。

**这不是图，这是自我攻击穿上了工具的衣服。**

如果六格全负，先别急着调。回到坐标六，把词换活；再回到坐标二，找出分数最高的那一界（哪怕只有 5 分），先保住它。

**图是给你用的，不是给你判刑的。**

### 错误二 · 六格之间没有联系，各说各的

五行火、灵界偏枯、L4、独处场最耗、生位、词没问题——六个答案对不上。

这通常意味着：**某一格填错了，或者某一格填的是"我想要的"而不是"我实际的"。**

回去重填，重点检查五行格和九层格——这两格最容易填成"我向往的样子"。

### 错误三 · 一次就想填完美

第一张图，填得粗糙是正常的。

**这套工具的用法不是"填一次，用一辈子"，是"先填一张糙的，三个月后修一次，一年后就很准了"。**

第一张图唯一的任务是：**存在。** 有了第一张，你才有得改。

### 错误四 · 拿六格去给别人"合成"

"我给你合成一下：你在公场被克，显阴火，卡在 L5……"

不要这样。给别人画图，只能画到"看清怎么跟他处"为止，不能画到"你就是这样的"。

**你画的不是他的图，是你眼里的他。** 这两件事差得很远。

> **五行是底色、恒定；主格是情境、可变；六格连成一句话，句号就变成了链。**
