# 坐标四 · 三现场格（处）

## 这一格量什么

**一句话**：三现场格量的是**场**——你在哪些场里活着，哪个场最耗你，哪个场最养你，以及你是怎么把一个场的能量，带到另一个场去的。

前面三格都量的是"你这个人"：你的底色、你的落点、你的层级。这一格开始量**你所处的位置**。

为什么必须量场？因为**同样一个人，在不同的场里，会显出完全不同的样子。**

一个人在单位是出了名的好脾气——稳、能扛、谁都不得罪。回到家，孩子一道题做错，他拍桌子。

你说他到底是好脾气还是坏脾气？都不是。**他在公场显土（承载），在家场显阴火（急躁）。**

这就是场的作用：**环境是那面镜子，照出你这一行此刻的成色。** 顺境里你长出的，未必是你本来的样子，是那个场把你这一面激活了；逆境里你漏出的，也未必是你这个人，是压力把你那一面逼出来了。

换个说法：场不是装着你的容器，是你和环境一起"长"出来的——你创造了场的一部分，场也反过来塑造了你。这正应了那句老理：我们感知到的从不是"孤立的我"，而是"我与环境的互动中的我"。

所以这一格，是六坐标里**最解冤的一格**。

很多人一辈子背着一个"我是暴脾气""我就是懒""我性格不好"的包袱，画到这一格才发现：**不是你不好，是那个场在推你。**

---

## 术语说明（重要）

《五行人格心理学》正书卷三第七章另有一处"三现场"，指的是**生克发生的三个领域**——自然、身体、人事。

本手册这一格的"三现场"，指的是**人所处的三个场域**——公场、家场、独处场。

**两者同名，所指不同，各司其职，不相互替代：**

| | 正书卷三第七章的"三现场" | 本手册的"三现场格" |
|---|---|---|
| **问的是** | 生克在哪些领域发生？ | 人在哪些场里活着？ |
| **答的是** | 自然、身体、人事 | 公场、家场、独处场 |
| **用来** | 认出生克的样态 | 找出哪个场在推我 |

自照时以本手册口径为准；研读正书时按正书口径。两者互不冲突，一起用反而更完整——**先在本格找出"哪个场在推我"，再去正书卷三第七章看"这个场里的生克长什么样"。**

## 速查表：三个基本场

| 场 | 包含 | 这个场的主课题 | 通畅时的样子 | 堵塞时的样子 |
|---|---|---|---|---|
| **公场** | 职场、学校、社会、一切有评价与竞争的地方 | 做事、被评价、争取资源 | 有位置、被需要、能发挥 | 被压、被卡、被否定、被无视 |
| **家场** | 亲密关系、亲子、原生家庭 | 被爱、被看见、归属 | 松弛、能说真话、被接住 | 被要求、被忽视、要演、要忍 |
| **独处场** | 一个人时的一切 | 与自己相处 | 能静下来、能充电、不空 | 空、慌、停不下来、自我攻击 |

三个场之外，若你的生活里有特别重要的场（比如"学校场"对孩子、"社群场"对某些人），可以自行加格。**工具是为你服务的，不必拘泥于三。**

## 核心机制：带场

这一格最重要的内容，不是"哪个场耗你"，而是**带场**。

**带场，就是把一个场里没消化掉的能量，原封不动地带到另一个场去。**

最典型的一条路径：

> **在公场被克 → 带着这股气回家 → 去克家里更弱的人 → 克完自己更难受 → 独自消化（或消化不了）**

这不是脾气问题，这是一条**能量的传递链**。

你在公场被领导压了一整天（被克），你不敢还嘴（那股能量没出去），你带着它回家。孩子一道题做错——**你炸了。** 你炸的量，远远超过那道错题应得的量。你炸的是白天那口气，孩子只是赶上了。

炸完你后悔，你自责"我怎么又这样"，你躲进厕所（独处场），在水里泡着，或者刷手机到凌晨。第二天起来，更累，公场更扛不住。**链闭合，循环开始。**

**看懂带场，是这套工具最能解冤的一刻。**

因为你终于知道：不是你脾气差，不是你不爱孩子，不是你改不了——**是你有一股能量，在公场进来了，没出去，从家场出去了。**

出口挪对了地方，这股能量就不用从孩子身上走。

为什么链会闭合？因为长期被同一个场"克"着，你的注意力会被锁死在一种样态里——你不是不想变、不是看不出别的路，是那一刻你的眼睛只看得见那一种线索。看懂这一点，你就从"我脾气差"的归因里彻底松绑了。

### 常见的带场路径

| 路径 | 现场 | 被带走的是什么 |
|---|---|---|
| 公场 → 家场 | 白天受的气，晚上对家人发 | 被压的火、被否定的憋 |
| 家场 → 公场 | 早上吵的架，白天对同事冷 | 没被接住的委屈 |
| 家场 → 亲子 | 夫妻之间的冷，转成了对孩子的严 | 关系里缺的暖，变成对孩子的要求 |
| 独处场 → 全场 | 夜里没睡好，第二天全场都扛不住 | 没充上的电 |
| 公场 → 独处场 | 白天没做成的事，夜里在脑子里重放 | 没被认可的价值感 |

## 自照清单

> **画场前，先扫身体（身体觉察入口）**：落笔打分前，花两分钟闭眼扫一下自己——肩是紧还是松？呼吸是浅还是沉？坐姿是蜷还是展？你身体的这些信号，就是你此刻"带着哪个场"的第一个线索。身体比脑子先知道你在哪个场里。

### A 卷 · 三个场的耗养打分

给每个场打分：**正数表示这个场在养你，负数表示这个场在耗你。**（从 -5 到 +5）

```
公　场：（　　　）分　　▁▁▁▁▁ 耗    ▏   养 ▁▁▁▁▁
家　场：（　　　）分　　▁▁▁▁▁ 耗    ▏   养 ▁▁▁▁▁
独处场：（　　　）分　　▁▁▁▁▁ 耗    ▏   养 ▁▁▁▁▁
其他场（　　　）：（　　　）分
```

**判读**：

- 分数**最低**的那个场，就是你当前**最偏的场**——它最耗你，也是你那张图上最该被看见的地方。
- 分数**最高**的那个场，是你的**充电场**——它养你，是你资源的来源。

**这两个都要记下来。** 最耗的场要处理，最养的场要主动多待——很多人不是没有充电场，是从来没把它当回事。

### B 卷 · 带场自查

在你最近一个月有过的情形前打 √：

□ 在单位／学校憋了一天，回家对家人发了不该发的火
□ 和家人／伴侣闹了别扭，第二天对同事或同学态度明显变差
□ 白天的事没做成，晚上在脑子里一遍遍重放
□ 夜里没睡好，第二天整个人像被抽空
□ 明明是 A 的事，我却对 B 发了脾气
□ 我在某个场里特别能忍，回到另一个场就完全忍不住
□ 我回家前需要"缓一缓"才敢进门（或进门后明显感觉自己要炸）
□ 我在独处时会反复想某个场里发生的事

**勾中三条以上，说明你身上有明显的带场。** 这时候不要急着"改脾气"，先去做第八章的"画链"——把那条链画出来，看它从哪个场进、从哪个场出。

### C 卷 · 场的阴阳自查

同一个五行人，放到不同性质的环境里，阳面和阴面会切换：

| 五行 | 在相生的环境里（阳面显） | 在被克的环境里（阴面露） |
|---|---|---|
| **木** | 逻辑清醒、决断落地、仁德共情、能统筹、敢创新 | 空谈不落地、散漫、对抗挑衅、情感抽离、决策瘫痪 |
| **火** | 有活力、有感染力、能点燃人、包容而有领导感 | 挑剔苛责、冲动说教、攻击与退缩来回摆、方向迷失 |
| **土** | 可靠、能扛、顾大局、善解人意、坚韧 | 顽固迟钝、拖延逃避、患得患失、刻板封闭、拖沓埋怨 |
| **金** | 高效有条理、开放创新、乐观赋能 | 悲观埋怨、自我否定与执守拉扯、规避责任 |
| **水** | 无我利他、沉潜有智慧、能凝聚人、外柔内刚 | 推卸责任、情绪操控、圆滑虚伪、散漫、半途而废 |

场显出的样态，就是你与这个场共造的"样子"，它既由你创造，也反过来作为背景限制你当下的选择——所以换场，常常不是你变了，是样子换了。

**这一张表的用法**：先看你在**哪个场**里，再看你在这个场里是**被生还是被克**，然后对照上表——你会发现，你以为的"我这个人就是这样"，其实只是"我在这个场里被克了"。

**这张表也是六坐标里最能给人松绑的一张。** 它说明：你不是变了，是场换了。

## 常见误判

### 误判一 · 以为场是客观固定的

不是。场和人互相塑造——这正是"场与人双向塑造"的核心：场不是装着你的客观空间，是你与环境共同创造的产物，二者互相雕塑。

同一个单位，有人觉得是被压的公场，有人觉得是发挥的公场。差别不在单位，在**你在这个场里的位置**——你是被生还是被克，你有没有出口。

所以改善场有两条路：**换场，或者换你在场里的位置。** 后者往往比前者可行——换工作难，换你在工作里的姿态，相对不难。

### 误判二 · 只盯着最耗的那个场

最耗的场要看，最养的场也要看。

很多人一头扎进"我公场太耗了"，却没发现自己其实有个很养的家场或独处场。这时候最有效的动作，往往不是去改造公场，而是**主动增加充电场的时间**——电量足了，公场的消耗就没那么致命。

### 误判三 · 把"换场"当成逃避

换场是三调法之一（见第十二章），它有正经的用途，也有被滥用的可能。

**判断标准**：换场之后，你是松了，还是更空了？

- 松了，能回来继续做该做的事——这是换对了。
- 更空了，回来更不想面对——这是逃避，不是换场。

换场是"出去加个油再回来"，不是"跑了不回来"。

### 误判四 · 拿"带场"给自己的发作开脱

"我白天被压了，所以晚上对孩子发火是合理的"——不是。

**看懂带场，是为了让出口挪对地方，不是为了给发作找理由。**

情绪无罪，行为有界。你那股气无罪，但它从孩子身上出去，就越界了。看懂链，是为了断链，不是为了继续。

### 误判五 · 以为独处场不重要

独处场是三个场里最容易被忽略的，但它是**充电与消化的地方**。

很多人公场家场都在耗，独处场又用来刷手机、熬夜、自我攻击——那他就没有充电的地方了。**三个场全负，人必然垮。**

如果你三个场都是负分，请优先处理独处场：**先给自己造一个能充电的角落。** 哪怕只有半小时。

## 场即疗愈现场 · 象操作练习

这一格不只是"看清场"，它本身就是**能疗愈的地方**。

你受伤，往往不是伤在当下，是伤在"那个场"里留下了一个没走完的旧象——当时你做错了、或者你被伤了，那个画面卡在那里，之后每次回到类似的场，旧象就自动播放。

疗愈的做法，不用向外求，就在象里完成：**回到那个场，用象思维演绎一个成功的象，把对的做一遍。**

四步：

1. **回到那个场（旧象）**：闭上眼，把自己放回当初受伤或被卡住的那个现场——不是回想剧情，是让那个旧象重新在场里立起来。
2. **回到那个场（象思维在场）**：用象思维把"我"重新放进现场，让身体记起当时的紧、当时的堵，但不陷进去，只是"在"那里。
3. **演绎成功的象**：在同一个场里，重新走一遍——这一次，把对的做一遍。不是压抑旧象，是在旧象的原位上，长出一个新的、成功的象。你原来做错的，现在做对了；你原来被伤的，现在被接住了。
4. **松绑·新象落地**：让这个新象在身体里落定。旧象没有消失，但它不再是唯一的版本——你在这个场里，已经有了"对的那个"可以调取。

这不是"想开了"，是**在场的原位上，把那条链重新走通**。原先我们做错了，回到那个场把正确的做一遍，我们就松绑了；原先我们被伤了，回到那个场演绎一个被接住的象，那道伤口就不再自动裂开。

> 说明：象操作是自用调节练习，不是临床治疗，不承诺疗愈效果。若你长期被困在创伤里、自己走不通，请转介专业帮助（参照 L7+ 转介纪律）。场是环境的描述，也是回归的路径——但不是替代专业支持的路径。
