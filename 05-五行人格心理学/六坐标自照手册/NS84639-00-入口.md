# 五行人格心理学·六坐标自照手册（入口）

> 以观其妙书院 出品 · 《五行人格心理学》配套工具书
> 全书 16 章 / 约 6.8 万字 / 49 表。定位：正书讲"人怎么运行"，手册讲"我从哪开始看清自己"。

## 为什么需要这本手册
正文书（117 篇）讲理论与体系，这本手册把你直接带进"画自己"的现场。它不测评你、不贴标签，只给你一张图卡和一套"链"——你照着画，就能看见自己此刻的能量流向，并知道从哪一环下手调。

## 四条工具独特性（务必先读）
1. **六坐标是坐标系，不是六个测评**。横向=象，纵向=层，深度=阶，处所=场，势能=势，用词=词。
2. **自照，不是被测评**。画的人是你，看的也是你；输出归你，不动用他人。
3. **输出是"链"不是"型"**——链可拆、可改、可追踪，型不可拆。你不必改自己，只需拆链。
4. **默认可移**。三个月复测一次；图是照片，轨迹是电影。

## 生克基准（全文统一）
- 相生：木生火 → 火生土 → 土生金 → 金生水 → 水生木
- 相克：木克土 → 土克水 → 水克火 → 火克金 → 金克木
- 最易记反：水克火（非火克水）、火克金（非火克木）；火不克木——木生火，火是木生出来的。
