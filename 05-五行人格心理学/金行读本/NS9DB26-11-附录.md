## 附录一　金行金句卡（专场收尾每人认领一句）

1. 金曰从革——金行的力量不是硬，是"顺天理而敢断"。
2. 金行的底色是"断"：断得清明是义，断得伤人是从革走了阴。
3. 金行的功课只有一句：**把量别人的尺子，拿回来量自己。**
4. 挑剔的尺度，正是自我苛责的尺度——放过家人之前，先放过自己。
5. 金行最怕的不是得罪人，是怕自己不干净。
6. 他能接受失败，不能接受"不干净的成功"。
7. 能忍住不轻易出手的义，才是真义；忍不住出手的，多半是借着义行"我对"的瘾。
8. 金行修行，不是修"更有原则"，是修"原则不再用来撑自己"。
9. 找好处，是金的功课——真看见别人的长处，才有真判断。
10. 恼是挑别人，行是做自己；把"他怎么这样"换成"我来做对"。
11. 金行认怂不是失败，是续命；金行认错不丢人，端着才伤人。
12. 最硬的金属，最后碎得最彻底；能弯的金，才用得最久。
13. 金行最性感的时刻，是承认"这条规矩，我自己也没守住"的那一刻。
14. 你那一句"我这是为你好"，若让孩子心里长出"我永远不够好"，请在这一代停住。
15. 镜子照自己是修行，镜子照别人是挑剔——怎么用这套体系，本身就是金行的功课。

## 附录三　术语速查（对外与书写统一用）

| 项目 | 标准写法 |
|---|---|
| 指称一型人格 | 金行之人（禁"金型""金行行人"，旧称"金型"只在引旧语料时注明） |
| 五行的"病" | 金行——恼（王凤仪体系怒恨怨恼烦之"恼"） |
| 五行的"德" | 金行——义 |
| 五行的五维 | 坚固、收敛、锋利、光洁、变革 |
| 相生（铁律） | 木→火→土→金→水→木 |
| 相克（铁律） | 木克土、土克水、水克火、火克金、金克木 |
| 金行的生克位置 | 生我者土，我生者水；克我者火，我克者木 |
| 金行对应 | 西方、秋季、白色（银色）、商音、肺与大肠 |
| 判型说法 | 判型／诊断／识别（不写"五行识人"当动词混用） |
| 与九型关系 | 同构非等同（只借镜，不混用） |

**复核口诀（易记反处重点圈出）**：相生是"土生金、金生水"；相克是"火克金、金克木"——**水克火不是火克水，火克金不是金克火，火不克木（木生火）**。凡写生克，先背这张口诀。
