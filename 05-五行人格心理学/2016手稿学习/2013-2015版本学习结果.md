**核心公式**：特质 = 意象 + 五行

## 三、核心内容

### 3.1 五行理论基础

#### 3.1.1 五行生克

**相生**（顺生）：木生火 → 火生土 → 土生金 → 金生水 → 水生木
**相克**（逆克）：木克土 → 土克水 → 水克火 → 火克金 → 金克木

**相制相化**：通过相生来制服克我之物
**相侮**：被克者太强，反克克者

#### 3.1.2 五行与阴阳

- 金木是一对阴阳
- 水火是一对阴阳
- 土是半对阴阳

### 3.2 五行人识别方法

#### 3.2.1 形体口诀

**木瘦金方水必肥，上尖下阔为真火，土行背厚晃如龟，朝中方白属金行。**

**三长/三尖/三厚/三薄/三肥**：
- **木**：三长——脸长、身材四肢长、手指长
- **火**：三尖——头顶尖、鼻头尖、下颚尖
- **土**：三厚——身材厚（敦实）、胸背厚、手背厚
- **金**：三薄——嘴唇薄、眼皮薄、手背薄
- **水**：三肥——眼皮肥（多层）、下巴肥、手背肥

#### 3.2.2 五行歌诀

**木形歌**：面长露骨色微青，背耸肩宽步履平。试听语音直而短，偶观筋项识真形。
**火形歌**：上尖下阔面丰盈，毛发枯焦黄且疏。声破音尖行动急，轻浮暴躁少涵容。
**土形歌**：背隆腰厚面平方，朴拙无文颜色黄。言语鼾宏行重浊，硁狭跼促好猜疑。
**金形歌**：薄唇齿利面团方，俏俊形容半带狂。令色巧言音响亮，对人不肯道行藏。
**水形歌**：体貌丰肥面下宽，眉粗目大发齐肩。音低唇厚行迟缓，抑郁终身不肯前。

#### 3.2.3 声音判断

- **木声**：高唱，直而短，齿音（正直）
- **火声**：焦烈，尖而破，舌音（急躁）
- **土声**：深厚，鼻音重（稳重）
- **金声**：和润，响亮，唇音（肃杀）
- **水声**：缓急，慢长而低，喉音（慢性子）

### 3.3 五行人特点（20141125版定型）

#### 木行人
- **关键词**：感觉（对目标任务追求度低，对关系情感热情低，分析型）
- **优势**：才气独特、创新成长、正直不屈、仁德善良
- **劣势**：傲慢孤僻、抗上不服、偏执顶撞、忧愁善变
- **管理风格**：高精确型，有条理的领导者（猫头鹰）
- **最胜任工作**：策划人
- **五行运转建议**：谦虚，低位思考，练习微笑

#### 火行人
- **关键词**：准则（对目标任务和关系情感追求度均高，高度驱动型）
- **优势**：推动提升、明辨守礼、热情自信、主动影响
- **劣势**：急躁争斗、炫耀虚荣、自卑夸张、情绪多变
- **管理风格**：高表达型，社交能力强（孔雀）
- **最胜任工作**：宣传公关
- **五行运转建议**：让自己退让，变慢，练习深呼吸

#### 土行人
- **关键词**：信念（对目标任务追求度低，习惯领域固定）
- **优势**：信实可靠、耐力持久、宽宏厚道、支持担当
- **劣势**：呆板无趣、迟钝缓慢、沉闷埋怨、固执不化
- **管理风格**：高耐力型，友善的合作者（树袋熊）
- **最胜任工作**：财务经理
- **五行运转建议**：相信因果，活泼畅言，多做运动

#### 金行人
- **关键词**：目标（对目标任务追求度高，对关系情感投入度低，高支配型）
- **优势**：刚毅坚强、含蓄持重、仗义果断、权威出众
- **劣势**：好胜计较、小气狭隘、尖酸刻薄、自负嫉妒
- **管理风格**：高支配型，权威的领导风格（老虎）
- **最胜任工作**：业务经理
- **五行运转建议**：找他人的好处，常布施，不执着，学会感恩

#### 水行人
- **关键词**：和谐（对目标任务追求度低，对关系情感投入度高，高协调型）
- **优势**：滋润祥和、智慧亲和、外柔内刚、善解人意
- **劣势**：消极放任、圆滑世故、忧虑多疑、散漫无序
- **管理风格**：高适应型，综合考虑者（变色龙）
- **最胜任工作**：人事经理
- **五行运转建议**：认不是，生敬畏心，学作计划

### 3.5 五行生克在人际关系中的应用

### 3.6 转运改命之道

**一转改运**：在基本人格范围内，负面能量向正面能量转化（阴木→阳木），通过后天有意识的学习和训练改变负面影响，包括从事上改、从理上改、从心上改。

**二转改命**：以五行相生顺序转化自己的人格属性（阳木→阳火→阳土→阳金→阳水），成为五行流通之人，只有通过修心开智才能改变。

**五行化性方法**：
- **木**：仁，能忍辱养仁德木 → 戒杀
- **火**：礼，不抱屈生明理火 → 戒淫
- **土**：信，不怨人生信实土 → 戒妄
- **金**：义，找好处生响亮金 → 戒盗
- **水**：智，认不是生智慧水 → 戒酒

**五行精髓**（王凤仪）：
- 欲生真水必认不是
- 欲生真金必找好处
- 欲生真土必认因果
- 欲生真火必达天时
- 以上四样都达透了，才能生出仁德而达全体的阳木
- 最后达到"五行攒簇"，浑然一体，不分五行

- **火性病**：恨人伤心 → 心热心跳、失眠颠狂
- **土性病**：怨人伤脾 → 膨闷胀饱、腹痛吐泻
- **金性病**：恼人伤肺 → 气喘咳嗽、肺痨咳血
- **水性病**：烦人伤肾 → 腰腿病痛、遗精阳萎

### 4.2 五行关系专题

#### 4.2.1 自身五行相克（内在关系）

详见3.5节。核心是：阴面相克导致疾病，通过拨阴取阳转化为相生。

#### 4.2.2 人我之间的五行相克（人际关系）

详见3.5节。核心是：了解对方五行属性，通过"躲"到相生位置化解相克。

#### 4.2.3 五行相乘与相侮（2013版第三章）

**相乘**（克得太过）：
- 自然生命：自信→感恩→忏悔→忍辱→技巧→自信
- 社会生命：信用→富有→精进→宽容→博学→信用
- 精神生命：信仰→布施→敬畏→仁慈→静虑→信仰

**相侮**（反克）：
- 自然生命：自信侮技巧、技巧侮忍辱、忍辱侮忏悔、忏悔侮感恩、感恩侮自信
- 社会生命：信用侮博学、博学侮宽容、宽容侮精进、精进侮富有、富有侮信用
- 精神生命：信仰侮静虑、静虑侮仁慈、仁慈侮敬畏、敬畏侮布施、布施侮信仰

### 4.3 象思维专题

**核心定义**：象思维是以"象"为核心，具有创新联想性，归结为悟性对于僵化事物和观念之不断超越以达到与动态整体之天道相通的思维方式。

**与西方概念思维对比**：

| 维度 | 西学—概念思维 | 国学—象思维 |
|------|---------------|-------------|
| 最高本体 | 外在（上帝） | 内在（儒道禅） |
| 特征 | 实体性 | 非实体性 |
| 对象性 | 二元对立 | 天人合一 |
| 载体 | 语言、概念 | 象（物象、意象、体悟之象） |
| 表述 | 言以尽意 | 象以尽意 |
| 位置 | 左脑（思维） | 右脑（感觉） |
| 判断方法 | 理智、客观逐一分析 | 直觉、主观整体感受 |

**观象修炼**：洗心→养心→正心→静心→明心

### 4.4 五行互藏专题（201503版新增）

**定义**：五行中任何一行皆包含有其他四行。如土中有木（木赖土以植）、土中有火（火赖土以荣）、土中有金（金赖土以藏）、土中有水（水赖土以固）。

**提出者**：明代医家张介宾（张景岳）《类经图翼·五行统论》

**意义**：五行互藏作为能包容人与自然以及人体组织之间关系的五行框架，不仅有各行之间的平面联系，更有一定的层次结构。
