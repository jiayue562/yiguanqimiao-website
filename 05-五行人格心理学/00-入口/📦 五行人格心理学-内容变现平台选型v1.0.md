## 〇、一句话结论

**主力用「小报童」，社群用「知识星球」，高价训练营上「私域自建」，抖音／小红书不要碰。**

理由不是费率，是**合规**：2026 年各大平台正在严打"借传统文化之名的玄学变现"，五行人格天然处于这条红线的最边缘。选平台的第一个筛子不是"能赚多少"，是"会不会被封号"。

## 三、推荐组合：三级火箭

```
第一级 · 小报童专栏（低价 · 9.9–199 元）
       ↓  引流 + 建立"这个人讲得真"的信任
第二级 · 知识星球社群（中价 · 数百元/年）
       ↓  互动 + 提问 + 案例拆解（陪跑属性）
第三级 · 私域训练营 / 企业陪跑（高价 · 千元至万元）
         小鹅通或千聊承接，对应产品体系 P4/P5/P8
```

**对应到我们已定的产品编号**：
- 小报童 → 势层**内容底座**（今天是★☆☆☆☆，专栏是补它的最短路径）+ P1/P2 轻量测评的内容入口
- 知识星球 → P4「拔阴取阳 30 日营」、P5「化克为生关系课」的社群载体
- 私域 → P8「金行人陪跑」的 B 端样板间（味藏已在跑，直接沉淀）

**三条执行建议**：
1. **专栏价格先低后高**。首期定价建议 9.9–39 元买断或年订，把订阅量跑起来；内容量攒到 30 篇以上再调价。
2. **分销比例开到 40%–50%**（小报童允许最高 60%，且分销收入平台不抽成）——这是我们唯一能低成本撬动传播的杠杆。
3. **不要一稿多平台同价同内容**。小报童与知识星球必须内容分层：专栏给"结论"，社群给"过程与答疑"，否则读者没有理由两头付费。

## 四、★合规红线（本节最重要，其余都可商量）

### 4.1 三条硬规（违反即账号风险）

| 条 | 内容 | 依据 |
|---|---|---|
| **① 不碰诊断** | 精神障碍诊断只能由**精神科执业医师**完成（《精神卫生法》第 29 条）；心理咨询人员不得从事心理治疗与精神障碍诊断（国家卫健委口径）。我们只能写"人格特质评估""自我探索参考"，**禁止任何"测出你是否抑郁/焦虑/人格障碍"式表述** | A（法规／官方） |
| **② 不做诱导式消费** | "免费答题 → 付费解锁报告"已被《法治日报》《人民日报》等点名为**诱导式消费**（违反《广告法》）。★**这条直接命中我们的 P3 商业模式**——必须改为**明码标价在前**：先写明报告价格与包含什么，再让用户决定是否答题 | A（官媒批评口径） |
| **③ 不碰玄学词** | 抖音：算命／算卦／八字／看相／占卜／转运／旺运／开运／化解／化煞／辟邪 等为最高级违规，**无申诉空间**；小红书：封建迷信、算命占卜属违规，严重封禁 | B（平台违禁词清单，各平台基本一致） |

### 4.2 ★术语安全替换表（对外内容统一执行）

| ⛔ 禁用 | ✅ 替换 | 为什么 |
|---|---|---|
| 算命、看命、命格、命盘 | **人格底色、主导能量、行为倾向** | 命理与心理学的分水岭就在"先天的命" |
| 缺什么五行、补五行 | **五行偏重、失衡侧** | "补"会滑向改运 |
| 转运、开运、旺运 | **转化、调整、提升** | 平台违禁词 |
| 化解小人、化煞 | **转克为生、化消耗为滋养** | ⚠️ 我们的"**化克为生**"与"化煞/化解"**字形相近**，在抖音机器审核中可能被连带误伤，建议对外统一写"**把相克转成相生**" |
| 你是金行人（定性） | **你的主导能量偏向金行，当前处在第 X 层** | 定性 = 宿命；加"当前位置" = 可改变 |
| 测一测你是什么人 | **测一测你现在在哪里** | ★**与我们的对立定位完全一致** |

### 4.3 ★一个意外收获：我们的定位本身就是合规护身符

今天定的对立定位——

> **我们测的是你现在在哪一层，不是你天生是什么命。**

这句话在**市场层面**是差异化（竞品讲"底色恒定不变"，我们讲"可以往上走"），在**合规层面**则是**免责声明**：它明确否认宿命论、承认人格可改变。

**建议把这句话写进专栏首页、测评说明页、每份报告的第一屏。** 一句话同时解决"和竞品划界限"与"和监管划界限"两件事。

### 4.4 其他必做

- 报告显著位置加：**"本测评为自我探索工具，结果基于你当前的自我报告，不构成心理诊断，不能替代专业医疗与心理服务。"**
- 中央网信办"清朗"专项行动重点整治**制造、贩卖焦虑**的内容——我们的转化叙事必须是"你有一条路可以走"，不能是"你再不改就完了"。
- B 端内容**禁止出现"用于招聘筛选"**字样（就业歧视风险）。
