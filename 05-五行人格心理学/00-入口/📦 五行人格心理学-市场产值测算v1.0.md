## 二 ★可测算：我们的 SAM

### 2.1 C 端

**基数**：2026E 自测用户 **1.48 亿人次**（B）
**〔假设·待验证〕** 独立用户 ≈ 人次 × 40% ≈ **5900 万人**（用户会复测，此系数无数据支撑）

| 付费率 | 付费人数 | 客单 ¥300 | 客单 ¥1000 |
|---|---|---|---|
| 0.5% | 29.5 万 | **0.9 亿** | 3.0 亿 |
| **1%** | 59 万 | **1.8 亿** | **5.9 亿** |
| 3% | 177 万 | **5.3 亿** | 17.7 亿 |
| 5% | 295 万 | **8.9 亿** | 29.5 亿 |

### 2.2 B 端

**基数**：中小企业 **6348.7 万户**（截至 2025-09，CNNIC）；2025 年底超 6300 万户，占经营主体 95%+；其中 **98.1% 为小微型**
**〔假设·待验证〕** 20–500 人规模、有管理培训预算者 ≈ 1% ≈ **63 万家**

| 渗透率 | 企业数 | 客单 ¥3 万 | 客单 ¥10 万 |
|---|---|---|---|
| 0.01% | 63 家 | 189 万 | 630 万 |
| **0.1%** | 630 家 | **1890 万** | **6300 万** |
| 1% | 6300 家 | 1.9 亿 | 6.3 亿 |
| 5% | 3.15 万家 | 9.5 亿 | 31.5 亿 |

> ★**B 端的算术很不一样**：做到 **630 家企业**（0.1% 渗透）就是 **1890 万–6300 万**。单子少，但一个顶 C 端几千单。这印证了「B 端从陪跑切、不从测评切」。

### 2.3 专业端

- 行业实况：中国心理咨询师持证人员中，**接受过系统学历教育的不到 10%**；国家**尚无**统一执业资格标准（2017 年已取消资格证）
- 无独立产值数据
> ★这对我们是**机会也是雷**：认证市场有真实需求（从业者缺系统训练），但国家无资格标准 → **我们的认证只能做"能力认证"，绝不能暗示"执业资格"**。

## 三 三条由产值数据回推的判断

**判断一：测评不赚钱，改变才赚钱。**
盘子 1 有 1.48 亿人次却无产值；盘子 4（命理人格）有 300–600 亿产值。差别在于——后者卖的是**解释与指引**，不是分数。**P3 是枢纽，但不是收银台。**

**判断二：B 端的产值密度远高于 C 端。**
C 端做到 1% 付费率（59 万人）≈ 1.8–5.9 亿；B 端做到 0.1% 渗透（630 家企业）≈ 0.2–0.6 亿。看似 C 端大，但 **B 端只需 630 个客户**，且客单是 C 端的 30–100 倍。**在获客能力有限时，先做 B 端。**

**判断三：这个行业没有被认真统计过。**
企业培训 1.3 万亿 vs 4069.5 亿（差 3 倍）；心理咨询 104 亿 vs 1450 亿（差 14 倍）。
> 双重含义：① 对外讲故事时**没有权威口径能否我们**；② 也意味着**不能拿这些数字去融资**——尽调一查就穿。
