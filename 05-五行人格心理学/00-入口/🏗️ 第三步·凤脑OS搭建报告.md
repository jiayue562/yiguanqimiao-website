- `🌐 知识图谱.md`：从凤脑OS 技能 `references/跨域联系网络.md`（干净源）重建为 UTF-8，保留 **联系9–130（122条核心跨域联系）**，与 L7 清单编号一致
- `📚 五行人格心理学总索引.md`：全新综合为 v2.0 导航枢纽（三层架构 + 四大分类 + 17篇L7进度 + 跨域联系统计 + 七步标准）

### ② 建立规范文件夹结构（Step3 spec 要求）
创建 4 个规范文件夹，将 235 个根级松散文件 + 13 个主题目录归类：

```

├── 00-入口/        （总索引 + 知识图谱 + 共创文档）
```

### ③ 链接完整性保障（专业关键决策）
- 预检发现 Obsidian 混用 `[[名称]]` 与 `[[文件夹/文件]]` 两种链接
- 搬迁前扫描：指向被移动文件的 path-style 链接 = **0** → 安全搬迁
- 搬迁后校验：**无重名笔记、无新增未解析链接**（2763 个"未解析"是 Obsidian 正常的概念占位链接，非断裂）
- 修复 2 处真实重名（`🌐 知识图谱`、`📚 总索引` 各有旧副本）→ 重命名消歧
- 修复旧 📊 总索引中 6 个指向 `知识图谱/` 的 path 链接

### ④ MVP 验证（spec 要求·每5篇一次）
**测试样例**：「请分析一个经常抱怨、爱猜疑的人是什么五行状态？」

## 三、MVP 验证答案（知识库可调用性证明）

> 基于凤脑OS 知识地基（土行人完整体系 / 九层发展阶梯 / 运象三法）的分析：

**① 五行定位：阴土**
- "抱怨"对应阴土之"怨（怨恨不满）"；"爱猜疑"对应阴土之"疑（疑虑不信）"
- 土行人文档明确：阴土失衡时心界"情绪以怨恨、疑虑、担忧为主"，灵界"价值观扭曲为疑——不信任他人"

**② 三界扫描**
- 灵界：缺乏信任感与安全感，"信"转为"疑"，使命从"承载滋养"扭曲为"控制固守"
- 心界：情绪外投（抱怨），思维保守固执、消极归因
- 身界：黏着、反复确认、身体紧绷

**③ 九层定位**
- 阴土显化于**一般区~不健康区**（约 4–6 层，正是拔阴取阳核心应用区）

**④ 转化方案（运象三法）**
- 拔阴取阳：怨 → 信（阴土怨转阳土信·感恩包容）；疑 → 信（建立信任·信实笃定）
- 化克为生：木克土（思虑过度/猜疑）→ 木生火、火生土，将"被克"张力转为滋养
- 相生强化：滋养阳土特质（诚信、包容、承载）

**⑤ B=MAP 落地**
- 动机：想改善关系与内在安定
- 能力：觉察"阴土升起"的瞬间
- 提示：遇事先问"这是事实，还是我的猜疑？"

→ 证明：凤脑OS 知识地基能为凤心OS 慢思考层提供**精准的概念引用与转化路径**。
