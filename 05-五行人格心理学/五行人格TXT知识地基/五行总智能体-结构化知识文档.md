## 一、核心架构：一心三界五行九层象思维体

五行人格心理学的核心架构可概括为 **"一心三界五行九层象思维体"**：

| 要素 | 对应 | 功能 |
|:----|:----|:----|
| **一心** | 纯粹觉知·本体 | 人格的本体与源头 |
| **三界** | 身语意/精气神/信息能量物质 | 生命存在的三个维度 |
| **五行** | 木火土金水 | 五种生命能量运行模式 |
| **九层** | 1-3健康·4-6一般·7-9不健康 | 人格发展的纵向坐标 |
| **象思维** | 观象→取象→运象 | 贯穿体系的认知工具 |

> **核心金句**："体(一心)相(三界)用(五行)"的圆融统一——横向五行生克构成动态平衡，纵向九层展示能量梯度，深度三界揭示身心灵立体结构

## 二、一心：纯粹觉知——人格的本体基石

| 层面 | 描述 | 修行方法 |
|:----|:----|:--------|
| **本质** | 超越二元对立的纯粹觉知=意识的源头 | 观照练习：日常生活中保持"知道"的心，知道自己在生气(木)/思考(火)/恐惧(水) |
| **人格关系** | 觉知如银幕，人格如影像。迷失=认同于影像，修行=回归观察者 | 静心技术：深呼吸/冥想/持咒平息大脑噪音 |
| **量子视角** | 意识可能是物质世界的基础，观察者通过意识参与现实构建 | 臣服技术/自省技术的高级阶段=将小我消融于纯粹觉知 |

|:---:|:----:|:----|:----|

| | 2·心理 | 特质高度整合 | 灵活运用五行优势，良好人际关系 |
| | 3·社会 | 适应规范 | 各领域发挥作用，偶有执着但能调节 |
| **一般** | 4·平衡 | 阴阳交战区 | 压力下出现负面情绪 |
| | 5·控制 | 开始控制 | 试图控制环境与他人维持安全感 |

## 六、生克规律：人际互动的底层逻辑

### 相生（滋养与支持）

```
🌿木 → 🔥火 → 🌏土 → ⚔️金 → 💧水 → 🌿木
木生火(创造点燃热情)→火生土(热情带来成果)→土生金(稳定支持规则)→金生水(规则激发智慧)→水生木(智慧滋养成长)
```

### 相克（制约与冲突）

| 克局 | 冲突本质 | 修行方向 |
|:----|:--------|:--------|
| **木克土** | 木嫌土慢·土嫌木急 | 木需尊重土节奏·土需学习木进取 |
| **土克水** | 土嫌水滑·水嫌土堵 | 土需学会放手·水需学会承担 |
| **水克火** | 水嫌火躁·火嫌水冷 | 水需欣赏火温暖·火需学习水冷静 |
| **火克金** | 火嫌金冷·金嫌火乱 | 火需尊重金秩序·金需学习火灵活 |
| **金克木** | 金嫌木乱·木嫌金狠 | 金需欣赏木生机·木需学习金修剪 |

> **核心金句**：相克关系往往是修行的道场。亲密关系是最真实的道场——我们往往被相克的人吸引，因为对方拥有我们缺失的特质，却又在相处中痛苦。
