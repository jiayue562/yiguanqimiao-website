## 一、木行五维度×B=MAP完整映射

### 1.1 曲直（才气独特↔傲慢孤僻）

| B=MAP要素 | 设计 | 木行要点 |
|:---------|:-----|:--------|
| **行为B** | 微行为：团队讨论时先以"我有一个初步想法，供大家参考"开场 | 仅改变一句话的开头 |
| **动机M** | 阳面连接："独特创意被完善和采纳才有价值"；阴面预警："孤立导致创意枯竭" | 用利他替代自我证明 |
| **能力A** | 非暴力沟通模板、选择平等尊重的讨论环境 | 降低社交脑力消耗 |
| **提示P** | 内部提示："我的想法最独特"苗头时触发；锚点提示："每次参加讨论第一次发言时" | 将傲慢感转为行动信号 |
| **庆祝** | 完成分享后内心说"好，我迈出一步了" | 强化分享~愉悦连接 |

### 1.2 生发（创新成长↔抗上不服）

| B=MAP要素 | 设计 |
|:---------|:-----|
| **行为B** | 微行为：收到不认同的指令→暂停→写两栏笔记(三点反对+两点理解) |
| **动机M** | 阳面："建设性提案者比批判者更有影响力"；阴面："抗上导致失去平台" |
| **能力A** | 写下是简单的记录任务，为情绪争取缓冲时间 |
| **提示P** | 内部提示：内心升起"这不对"时；锚点：每次收到不悦邮件/指令时 |
| **庆祝** | 完成笔记后心里说"理性战胜了冲动" |

### 1.3 舒畅腾上（正直不屈↔偏执顶撞）

| B=MAP要素 | 设计 |
|:---------|:-----|
| **行为B** | 微行为：争论中强制10秒生理暂停(闭口+深呼吸+感受脚踩地面) |
| **动机M** | 阳面："圆融实现正义比固执赢辩论更有价值"；阴面："正直初衷被方式掩盖" |
| **能力A** | 深呼吸是任何人都能完成的极小动作 |
| **提示P** | 内部提示：面颊发热/心跳加速/非黑即白时；环境提示：办公桌放"冷静石" |
| **庆祝** | 完成暂停后内心肯定"停得好" |

### 1.4 调达柔和（仁德善良↔忧愁善变）

| B=MAP要素 | 设计 |
|:---------|:-----|
| **行为B** | 微行为：感到情绪低落时→立刻起身喝一杯温水或到窗边数三种颜色 |
| **动机M** | 阳面："自身稳定是有效关爱的前提"；阴面："情绪不稳反而让关系沉重" |
| **能力A** | 喝水/看窗外几乎零成本、零技能要求 |
| **提示P** | 内部提示：情绪无缘由低沉时；锚点：感到情绪"开始下沉"时 |
| **庆祝** | 完成后对自己说"我照顾了自己一下" |

### 1.5 内在成长（安静内向↔疏远冷淡）

## 二、四个高频场景完整方案

### 2.1 拖延写作/创意启动难

```
B=打开文档写下标题和第一句（每天）
M=连接："完成比完美更重要"；预警："拖延导致灵感消散"
A=使用番茄钟25分钟只写不停；写作模板降低启动脑力
P=锚点：每天早晨第一口咖啡后
```

### 2.2 人际关系疏离

```
B=每周一次15分钟咖啡邀约
M=连接："深度连接是灵感来源"；预警："孤立导致思维僵化"
A=提前准备开放式问题清单；选择能量较高时段
P=日历固定预约；内部提示："当感到一周过于安静时"
```

### 2.3 易怒与偏执情绪

```
B=微行为：愤怒时做一次缓慢深呼吸(4-2-6呼吸)
M=连接："冷静让我智慧捍卫正确"；预警："发怒削弱说服力"
A=练习"情绪标记"快速说出"我很愤怒"
P=内部提示：身体发热/心跳加速时；环境：办公桌放"冷静石"
```

### 2.4 抗上不服导致职业困境

```
B=微行为：收到不认同指令时先写两栏笔记
M=连接："建设性提案者比批判者更有影响力"
A=学习"向上管理"话术模板
P=锚点：每次点开令我不悦的邮件时
```
