# 第95讲｜伦理分级：拿图看干预的尺子怎么量

> 一百讲·第95讲 / 共100讲

## 一、先说最重要的一句

第94讲画了一条边界：AI 进得了人的身，学得会人的情绪，进不了那个"知道"。

那一讲回答的是"**机器能拿你多少**"。

这一讲换个方向，问一个更贴身的问题——不问你跟机器，问你跟人：

> **当一个人带着自己的五行议题来找你，你到底能在哪一层动手、哪一层必须停手、哪一层得把人交出去？**

这个问题，是每一个学过一点五行人格的人都会撞上的。

学了判型，朋友会拿自己来问你；学了沟通，同事会找你倾诉；学了亲子，家长会来讨方法。

你手里有了一套"好像挺有用"的工具。然后你发现，工具越有用，你越不敢乱用——

因为你不清楚：**哪一层我能帮，哪一层我不能碰。**

这一讲就给这把尺子。

先立总口诀，它是全讲的骨：

> **总口诀：同样是帮人，尺子不一样——**
> **成长区里可以陪，治疗区外必须停；**
> **不诊断、不处方、不越级；**
> **拿不准，就转介——转介不是推卸，是守住"不伤害"。**

后面所有的展开，都是在解释这把尺子怎么量。

### 先分清两件事：边界和分级

书稿里有个区分，是整个伦理骨架的起点，必须先立住：

**边界**，管的是"体系对外不越权"——整套体系整体上在哪儿止步，那是第94讲和第90讲、92讲反复画过的线。

**分级**，管的是"体系对内不越级"——在体系允许的范围之内，按严重度，把干预分成"可以自己做的"和"必须转介的"。

打个比方：

边界是围墙——墙外不是你的院子，别出去。
分级是院内的台阶——台阶以下你随便走，台阶以上是危房，别上去。

**两条线合起来，才是完整的伦理骨架。**

这一讲专讲分级这条线。

## 二、先看那张图：三区九层，一轴到底

讲分级，先得有刻度。

我们这套体系里，人的心理状态有一条统一的刻度轴，叫**九层发展光谱**。它从低到高，把一个人的状态分成九层，再归成三区：

| 区 | 层 | 名称 | 性质 |
|---|---|---|---|
| **成长区** | L1 | 提升 | 健康人群的正常成长 |
| | L2 | 精进 | 同上 |
| | L3 | 奉献 | 同上 |
| **成长区** | L4 | 觉察 | 健康人群的转化诉求 |
| | L5 | 转化 | 同上 |
| | L6 | 贯通 | 同上 |
| **治疗区** | L7 | 治疗 | 超出自我调节范围 |
| | L8 | 稳定 | 涉及病理层级 |
| | L9 | 康复 | 涉及病理层级 |

看清楚这张表的分水岭在哪儿：

**L6 和 L7 之间，隔着一条不能随便跨的线。**

L1–L6，叫**心理成长区**；
L7–L9，叫**专业治疗区**。

这一讲所有的分级规矩，都是围绕这条线展开的。

### 这一讲的三层递进

**第一层：成长区里，你能做什么**——L1–L6 哪些议题可以自我干预、同伴支持、教练式引导。

**第二层：治疗区外，你必须停什么**——L7 以上为什么必须转介，转介的操作纪律是什么。

**第三层：无论哪一层，都要守什么**——知情同意，和四条底线原则。

三层走完，你手里那把尺子就刻好了。

## 三、成长区（L1–L6）：可自我干预与同伴支持

先讲好消息：这一区间的绝大多数事，你不仅能做，而且该做。

### 分级陈述

L1–L3（提升与奉献）与 L4–L6（觉察与转化）属于**心理成长区**。

这一区间的议题是这些：

- 自我认知的拓展——"我到底是个什么样的人"；
- 习惯的微调——"我总熬夜/总拖延/总急躁，怎么改"；
- 关系的改善——"我跟伴侣/孩子/同事，怎么好好说话"；
- 情志的疏导——"我最近很怨/很怕/很躁，怎么办"。

这类议题，在本体系权限之内，可以通过**自评、同伴支持、教练式引导**来进行，**不要求临床资质**。

### 为什么划在这条线

因为 L1–L6 对应的，是"**健康人群在正常生活里的成长诉求**"，不是病理状态。

一个人想更通透、想少点儿怨、想跟孩子好好说话——

**这些是人人都有的修行，不是病。**

本体系在这层有大量可给的东西：口诀、行功、生克四功课、判型工具，都是为这一层设计的。

第1讲到第90讲我们讲的所有东西——五行原象、九层光谱、象思维、拔阴取阳、五色光、生克功课——默认的使用场景，都是这一层。

### 但要守三条伦理要求

即便在成长区，也不是想怎么帮就怎么帮。三条：

**第一条：知情同意。**

任何引导式干预，须让对方知道三件事：我们在做什么、依据什么、可能有什么波动。

尤其 L4–L6 区间——觉察与转化——转化过程可能**短期放大情绪**。书稿里专门有个词，叫"涨落放大假说"，意思是：一个人开始向内看的时候，原本压着的情绪可能会先冒出来一阵，看起来像"越做越糟"，其实是在过那道坎。

所以必须**提前告知**："波动会来、会回落。"

不让人误以为"越做越糟"。

这一条太重要了。多少好心办坏事，都是因为没打这个招呼——对方一波动，双方都慌了，一个以为自己做错了，一个以为对方更严重了。

**第二条：自愿。**

五行转化是**活法**，不是任务。

任何人可随时停。停的权利，不可被"为你好"剥夺。

这一条要刻进骨子里：你觉得对方"再坚持一下就好了"，但那是你觉得。对方说停，就停。

**第三条：不替代专业。**

即便在成长区，若对方同时透露临床级信号（见下一节），成长区干预**立即让位**，转入转介流程。

这三条不是束缚，是保护——保护对方，也保护你自己。

### 成长区的四样工具，怎么用才不越界

本体系在成长区主要给四样东西：**口诀、行功、功课、判型工具**。它们各有各的用法边界，用错了就会从"成长工具"变成"越界凶器"。逐个说。

**口诀，是用来"提点"的，不是用来"压人"的。**

"火行的人别急着发火"——这话自己对自己说，是提醒；对正在气头上的人说，就是指责。同样一句口诀，方向不同，性质完全不同。成长区里，口诀的第一使用人是你自己；给别人用，要等对方来求教，且语气永远是"我有个说法，你看看有没有用"，不是"你该这样做"。

**行功，是用来"练自己"的，不是用来"治别人"的。**

闭目养木、少言养火、静坐养土——这些行功的默认对象是自己。你可以带别人一起练，但"一起练"和"我练给你治病"是两回事。前者是同伴，后者是越界。

**功课，是用来"照见"的，不是用来"考核"的。**

生克四功课、认不是、找好处——这些是让人看见自己的模式，不是让人交作业。一旦功课变成"你做了没""你怎么又没做到"，它就从一个自我照见的工具，变成了一把衡量别人的尺子——那就背离了它的本意。

**判型工具，是用来"参考"的，不是用来"定论"的。**

判型给出的是一个当下的侧面，不是一个人的全部。第1讲到第90讲反复强调反标签——任何分型结果落到"你就是这种人"的句式里，就已经越界了。

记住一个总原则：**这四样工具，全部是"自助优先、助人其次"。** 先把自己练明白，再去陪别人；陪的时候，对方永远有说"不"的权利。

## 四、治疗区（L7–L9）：明确转介声明

现在讲那条线的另一边。这一节是全讲最重的一节。

### 分级陈述

L7 以上（治疗与稳定区间）涉及**病理层级**，超出本体系非临床干预的权限范围。

凡判型落在此区间，或干预过程中议题滑入此区间，**必须转介**有资质的临床心理或精神科专业。

**本体系内容在该状况下不适用。**

### 这一条为什么没有回旋余地

书稿里给了一个非常重的词：

> **L7 以上不是"更深层的成长"，是另一个性质的事。**

它可能伴随真实的功能损害、风险行为与诊断阈值。

拿非临床的口诀和行功去"处理"它，不是大胆，是**失职**。

这句话，请读三遍。

我们手里这套东西再好用，它也是**非临床的成长与文化修养体系**。我们不持有诊断权，不持有处方权，也不声称能处理病理。

这不是谦虚，是边界。边界不是限制我们帮人，是防止我们**用好心把人帮到沟里去**。

### 为什么 L7 是那条线

看九层刻度的定义：L7 是"治疗与稳定"的起点。

意思很明白：到此层，议题已不是自我调节能覆盖，需要专业治疗介入。

就像一个人骨折了，你给他再好的营养餐、再贴心的陪伴，都不如送他去骨科。营养餐和陪伴没错，错的是把它们当成治疗方案。

**本体系在 L7 以上主动止步**，理由和整套体系的适用范围边界同源——我们不越权，是因为我们真的在乎人。

### 转介的操作纪律：三条

书稿给了三条操作纪律，一条都不能省：

**第一条：判型即声明。**

凡诊断报告显示某维度落 L7 以上，报告须附转介声明——不隐藏、不淡化。

我们第92讲讲过，专业场景出报告要有五步可读结构。现在补一条：报告里若出现 L7 以上的信号，那一页必须同时出现转介声明。这不是吓人，是规矩。

**第二条：过程滑层即停。**

原本在成长区工作，过程中若出现病理信号——自伤/伤人风险、现实检验受损、急性症状——**立即停手并转介**。

五行转化练习在该状况下不适用。

这一条要特别注意"过程中"三个字。很多人是聊着聊着才发现不对的。发现的那一刻，不是"再聊聊看"，是立刻停。

**第三条：不混淆权限。**

本体系从业者不得借"五行"之名行诊断、处方之实。

转介不是推卸，是守住"不伤害"的底线。

## 五、知情同意：那把尺子的刻度

讲完两级分区，讲无论哪一层都要守的东西。

知情同意，是现代伦理里最被低估的一个词。听起来像走流程，其实是整个伦理的地基。

### 什么叫真正的知情同意

不是让人签个字。

是让对方在**信息充分、自愿、可退出**的前提下，决定要不要跟你走这一段。

书稿把它拆成三块：

**第一块：他知道你在做什么。**

"我们接下来会用五行人格的框架，帮你看看你现在的状态。这属于自我探索，不是医疗。"

**第二块：他知道依据什么。**

"我会用判型工具和观察跟你一起看，不会给你下诊断，也不会给你开方子。"

**第三块：他知道可能有什么波动。**

"探索过程中，有些情绪可能会浮上来，这是正常的，会回落。任何时候你想停，我们就停。"

这三句话讲完，对方才算是"知情"了。

### 为什么它这么重要

因为**探索自我这件事，是有力量的，而力量需要方向**。

一个不知道自己会经历什么的人，被带进一场可能掀起情绪的探索，就像没系安全带坐过山车——不是不能坐，是得先知道。

知情同意，就是那个安全带。

它同时保护两方：

保护来访者——他不会被突如其来的波动吓到，也不会被"为你好"绑架着走完他不愿走的路；
保护助人者——你尽到了告知义务，万一对方出现波动，你不是那个"没打招呼就动手"的人。

## 六、四条底线原则：整卷的伦理地基

书稿把分级落到日常，靠的是四条谁都该记牢的底线原则。

它们不是某一章的规矩，是**整卷的伦理地基**。我一条一条讲。

### 第一条：不伤害（首要原则）

任何干预的第一检验是：**会不会伤人。**

当不确定时，宁可保守、宁可转介，不拿人试。

这一条为什么是"首要"？因为其他原则都建立在它之上。一个"有用但伤人"的方法，再有用也不能用。

医学里那句老话——"首先，不要伤害"——在这里同样成立。

### 第二条：自愿与自主

对方是**主体**，不是对象。

任何转化须对方知情同意、可随时退出。

五行分型结果不得用于剥夺他人自主权——这一条和反标签化是同源的：分型是用来照见自己的镜子，不是用来贴在人身上的判决书。

### 第三条：能力边界声明

从业者须清楚声明：我能做什么、不能做什么。

能做的做到位，不能做的老实转介，**不扮全能**。

这一条对热心人特别难。热心人看到别人难受，第一反应是"我来"。但"我来"之前，得先问一句："这事在我能力范围内吗？"

不在，就转介。转介不是冷漠，是另一种负责。

### 第四条：保密与边界

成长区与专业转介过程中的信息，须按相应规范保密。

师徒、教练、同伴关系中的越界——如利用信任做操控——**一律禁止**。

这一条和"去功利化"原则同根：关系是用来照见彼此的，不是用来获取什么的。

### 危机红线：最后一条，也是最快的一条

当来访者处于危机状态——自伤/伤人风险、精神病性症状、急性失能——**立即转介，不拖延、不自行处理**。

这一条没有讨论余地。

那种状况下该做的不是这些转化，是**稳定与安全**。

把这条红线放在心里最显眼的位置。它平时用不上，一旦用上，就是人命关天的事。

### 底线与底线打架时，谁优先

有人会问：四条底线都是底线，万一互相打架怎么办？

比如：对方求你保密，但他有伤人风险——保密原则和不伤害原则冲突了，听谁的？

书稿给过一个清晰的排序逻辑，我把它讲透。

**第一优先：不伤害。**

当保密的内容涉及对他人或自己的现实危险时，保密让位给安全。这不是违背保密，是保密的应有之义——保密是为了保护人，不是为了保护秘密本身。

**第二优先：危机红线。**

自伤、伤人、急性失能——这三类情况一旦出现，优先级高于一切成长目标、高于关系维护、高于"他会不会不高兴"。宁可对方一时怨你，不可让他陷在危险里。

**第三优先：自愿与自主。**

在安全的前提下，对方的意愿最大。他不愿意继续，就停；他愿意走多远，由他定。

**第四优先：能力边界与保密。**

以上都守住之后，再谈"我能做什么、什么该守口如瓶"。

记住一句话：**底线不是用来束缚你的，是用来在紧急时刻替你省掉犹豫的。** 平时把排序想清楚，事到临头才不慌。

## 七、分级背后的统一逻辑

现在把整把尺子的逻辑收一下。

**第94讲讲边界时说**：体系在严重度轴上，止步于临床门前。
**这一讲讲分级时说**：体系在严重度轴之内，到 L7 也必须止步。

两条线共用一条根据：

> **本体系是非临床的成长与文化修养体系，不持有诊断权与处方权。**

一句话，把墙和台阶都解释清楚了。

### 分级不是把人推开，是把人放到对的位置

这一句是整章最要紧的视角转换。

一个在 L3 纠结"怎么少怨"的人，你给他口诀和行功——**是对的位置**。

一个在 L8 带着真实病理的人，你把他转介出去——**也是对的位轩**。而且是对他更负责的位置。

很多人不敢转介，是怕显得自己"帮不了"。

但你想过没有：一个骨折的人，你非要给他按摩，他感恩你吗？他只会更疼。

**转介，是把人从你够不着的地方，送到够得着的人手里。这不是放弃，这是接力。**

## 八、读者常问·十二问

**问一：我怎么判断对方在 L6 还是 L7？我不是专业人士。**
你不需要精确判断。你只需要记住一条模糊但管用的界线：如果对方的议题已经明显影响吃饭、睡觉、工作、人际这些基本功能，或者你隐隐觉得"这不像普通的不开心"——那就往 L7 以上想，宁可转介。

**问二：转介会不会伤了对方，让他觉得我在推开他？**
话术很重要。不说"你有病我处理不了"，说"你现在的状态，已经超出了我能稳妥陪伴的范围，我认识的更专业的人能更好地陪你走这一段，我陪你一起去"。转介不是抛弃，是换一个更合适的陪伴者。

**问三：朋友找我倾诉，我也要搞"知情同意"吗？那多生分。**
朋友间的日常倾诉不需要走流程。但一旦你要"用工具"——要给他判型、带他做功课、引导他向内看——就需要打一声招呼："我可以用我学的框架帮你看看，但这不是诊断，你想停随时停。"一句就够，不生分，反而专业。

**问四：对方说想自杀，我该怎么办？**
立即转介，同时陪伴。先稳住当下、确保安全，联系专业危机干预或医疗机构，通知可信任的家人，不让他独处。不要试图用五行功课"处理"危机——那一刻要的不是转化，是安全。

**问五：那这套体系是不是就没什么大用了？只能管管"不开心"？**
恰恰相反。它管的是人一生最大的基本面——健康人的成长。绝大多数人一生都在 L1–L6 里打转：怎么认识自己、怎么处关系、怎么养习惯、怎么活通透。这些做好了，很多 L7 以下的问题根本不会发生。**上工治未病，这才是大用。**

**问六：我给员工做团队盘点，算不算"干预"？**
算。所以组织场景的规矩更严：团队盘点可以做（看搭配、看角色），但不得用于招聘、晋升、淘汰等决策，也不得给个人贴"你有问题"的标签。组织场景的尺子，第92讲量过，这一讲再重申一遍。

**问七：我自己给自己判型、做功课，也要知情同意吗？**
对自己也要温柔。自己探索时，提前告诉自己："波动会来、会回落，我可以随时停。"很多人对自己比对外人还狠——逼着自己"必须面对"，那不是转化，是另一种暴力。

**问八：同行里有人拿五行给人"治病"，我怎么看？**
那是越界。你阻止不了别人，但你可以守住自己，并且在你能力范围内提醒对方那条线。**体系的名声，靠每一个守线的人撑着。**

**问九：成长区到底能不能收费？**
能不能收费是市场问题，怎么收费是伦理问题。核心一条：收费不能改变关系的性质——收了费，你更不能越界，因为对方付了钱就更信任你，信任越大，责任越大。

**问十：如果对方坚持说"我就是想让你帮我看看，不用转介"，我该怎么办？**
温柔而坚定。你可以说："我理解你信任我，我很珍惜这份信任。正因为我珍惜，我才不能在你最需要专业支持的时候，只用我的业余能力硬撑。"真正的尊重，不是顺着对方，是护住对方。

**问十一：学了这一讲，我是不是以后都不敢帮人了？**
恰恰相反。这一讲是让你帮得更久、帮得更稳。知道界限在哪里的人，才敢放手去帮——因为他知道哪里该停，所以哪里都能去。真正危险的是不知界限的热心。

**问十二：最该记住哪一句？**
**"成长区里可以陪，治疗区外必须停；拿不准，就转介——转介不是推卸，是守住不伤害。"**

## 九、贯穿长案：一位妈妈的两次求助

讲一个我亲历的案子，它让我对这把尺子有了实感。

### 第一次：成长区

一位妈妈来找我，说儿子上初中，脾气大，一回家就摔门，跟她没话说。

她学了点五行，自己判断儿子是"木旺"，问我怎么"克"他。

我先把她的问题正过来："你不是要克他，是要听懂他。"

我们做了三件事：教她用"我信息"开口（"我等你等到很担心"而不是"你怎么又这么晚"）；带她看木行的孩子要什么（要空间、要方向、要被看见努力）；给她一套行功，让她先管住自己的火——孩子一摔门，她先停三秒。

这是标准的 L3–L4 议题：关系改善、情志疏导。在成长区里，口诀、行功、功课，全部用得上。

三个月后她来说：儿子还是摔门，但摔完会出来了。她说："至少他知道我在门口等着。"

这就是成长区能给的——**不是把问题变没，是把人接住。**

### 第二次：滑层

又过了半年，她半夜给我打电话，声音是抖的。

她说儿子最近把自己关在屋里，不肯上学，说"活着没意思"，还拿美工刀划过手腕。

我听完，做了三件事：

第一，让她立刻收走屋里所有利器，确保当下安全；
第二，让她现在、马上联系学校的心理老师，并预约儿童精神科或心理科；
第三，我说："从这一刻起，我不再是教你功课的人，我是陪你找专业的人。他现在的状态，不是我们这套功课能处理的。"

她愣了一下，说："我以为你会教我怎么做功课。"

我说："正因为我会，我才更要停。"

后来那个孩子确诊是抑郁发作，经过专业治疗，一年后慢慢恢复。那位妈妈后来跟我说了一句话：

> **"谢谢你当时没教我'怎么做功课'。你要是教了，我会以为那是我没做好的事，然后更拼命地错下去。"**

这个案子，就是这一讲的全部注脚：

成长区的功课，她学得越用力，越是把孩子往更深处推——因为她把"情绪问题"当"行为问题"在治。

而转介的那一晚，才是她真正帮到孩子的开始。

### 补一个组织场景的对照

有人会问：成长区那套"别越界"的规矩，在组织里是不是更松——毕竟公司要管人，哪能那么客气？

恰恰相反。组织场景的分级，比个人场景更严，因为组织手里的权力更大。

个人场景里，你越界，伤的是一段关系；组织场景里，你越界，伤的是一个人的生计和尊严。

所以同样是 L1–L6 的议题，在公司里做，要多加三道闸：

**第一道：目的闸。** 你带团队做五行工作坊，目的是帮大家照见自己的模式、改善协作，不是"摸清每个人的底，好用人之"。目的不对，工具越精致越危险。

**第二道：用途闸。** 第92讲讲过：团队盘点可以做，招聘、晋升、淘汰不能用。这一讲的 L 分级给这道闸补了理论依据——因为一旦评估结果被用于"决定一个人的去留"，它就事实上变成了一种"处理人的工具"，而这超出了成长体系的权限。

**第三道：告知闸。** 员工参与任何判型、测评、工作坊，必须知情且自愿。领导安排的和自己愿意的，是两回事。员工有权拒绝，且拒绝不应被记在心里。

组织里的管理者，最容易犯的错不是坏，是**把"为你好"当成通行证**。这一讲的尺子告诉你：为你好，也要在界线内为好。界线外的"为好"，是另一种伤害。

## 十、接回九层、三界、易与观其妙

**接九层。**

这一讲的 L1–L9，就是九层发展光谱本身。九层既是"往高处走的阶梯"，也是"往低处看的尺子"——同一个刻度，一个用来成长，一个用来守线。

所以记住：**九层不是用来给人分高低的，是用来给人定位的。** 定位到成长区，好好陪；定位到治疗区，好好转。

**接三界。**

身界的行为问题，多在成长区可调；心界的情志波动，一半在成长区、一半要警惕；灵界的价值与觉知议题，是成长区的纵深。

但无论哪一界，一旦出现功能损害与风险信号，就跨过了分级的线——因为三界是通的，身会影响到心，心会影响到灵。

**接易。**

《易》讲"**知止而后有定**"的前身——《大学》里说"知止而后有定，定而后能静"。

这一讲的转介，就是"知止"。

知道在哪里停手，心才定得下来；心定得下来，才能真正帮到人。一个不知道"止"的助人者，是危险的——他的热心没有刹车。

**接观其妙。**

观其妙讲"**常无欲以观其妙**"。

"无欲"二字，放在助人场景里，就是四条底线里的"去功利化"——帮人的时候，心里没有"我要证明我有用""我要你谢我"的欲，才能看清对方真正需要什么。

有时候对方真正需要的，恰恰是你说一句："这个我帮不了，我陪你去能帮的人那里。"

那一句，也是观其妙。

## 十一、再深一层：为什么我们总想跨过那条线

讲完所有规矩，往深走一步。

规矩大家都懂：L7 以上要转介。但为什么现实中，总有人跨线？

### 表面原因：分不清

很多人是真的分不清 L6 和 L7。这情有可原——所以尺子要常备，拿不准就往保守走。

### 深层原因：舍不得

这是更普遍的原因。

一个人跟你倾诉了三个月，你们有了信任。这时候他状态滑下去，你要转介——你舍不得：舍不得这段关系，舍不得"我好像能帮到他"的感觉，也怕转介之后他不再找你。

**这个"舍不得"，就是越界的温床。**

多少"我再陪陪他""再聊聊应该没事"，都是舍不得在说话。

### 最深层原因：我们误以为"帮到底"才是爱

最深的一层在这里。

我们从小被教育：爱一个人，就是为他做一切能做的事。

但真正的爱，有时候恰恰是**承认自己做不到**，然后把他交到能做到的人手里。

一个妈妈最爱的时刻，不是孩子生病时她硬撑着当医生，是她抱着孩子去医院。

**助人也是一样。转介不是爱的终止，是爱的升级——从"我帮你"升级到"我为你找到最好的帮助"。**

这一层想通了，那条线就不再是束缚，而是你爱人的方式里，最成熟的那一部分。

## 十四、文化根

中国人讲"医者仁心"，也讲"医不叩门"。

"医不叩门"的意思是：再高明的医者，也不主动上门说"你有病，我来治"。

这句话常被误解为"医者架子大"。其实它的真意是两条：

一是**不越界**——对方没求你，你别闯进人家的生命里指手画脚；
二是**不贴标签**——你凭什么断定人家"有病"？也许人家只是活得跟你不一样。

把这两条放到这一讲里，正好对上：

"不叩门"，就是成长区里不主动给人贴标签、不越界干预；
"有求才应、应而有度"，就是对方来了，你在能力范围内好好帮，超出范围老实转介。

**仁心不是什么都敢做，是知道什么不该做。**

两千年前的医家懂这个道理。今天，每一个拿五行帮人的人，也该懂。

## 十五、一心为体

L1–L9，是一条刻度。

刻度本身是死的，用刻度的那颗心是活的。

同样是"帮人"两个字，心里装着"我要证明我有用"的人，会忍不住跨线；心里装着"我要他好"的人，会在该停的地方稳稳停住。

**尺子不在纸上，在心上。**

这一讲教了你刻度，但真正让你守住刻度的，是那个"不忍心伤他"的觉知。

守住它，你手里的每一句口诀、每一套行功，才都是善用。
