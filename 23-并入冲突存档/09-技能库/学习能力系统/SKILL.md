## 三、指令实现手册

### 指令一：写入记忆

**触发词**：写入记忆、帮我记住、把...写入记忆

**实现逻辑**：
```
1. 解析用户要记忆的内容
2. 写入MEMORY.md（长期记忆）
3. 写入当日日志（短期记忆）
4. 可选：同步到IMA笔记
```

**输出格式**：
```
✅ 已将以下内容写入长期记忆：
[内容摘要]
存储位置：MEMORY.md
```

### 指令二：调取记忆

**触发词**：调取记忆、读取记忆、告诉我你记住了什么

**实现逻辑**：
```
1. 读取MEMORY.md
2. 搜索相关主题
3. 输出结构化记忆
```

**输出格式**：
```
📚 关于[主题]的长期记忆：
1. [记忆点1]
2. [记忆点2]
3. [记忆点3]
来源：MEMORY.md
```

### 指令三：记忆蒸馏

**触发词**：记忆蒸馏、压缩记忆、整理记忆

**实现逻辑**：
```
1. 读取完整MEMORY.md
2. 识别重复、过时、冗余内容
3. 压缩为精炼版本
4. 保留核心信息
```

### 指令四：联网搜索

**触发词**：联网搜索、搜索最新、帮我搜索

**实现逻辑**：
```
1. 调用web_search获取最新信息
2. 提炼核心结论（结论优先）
3. 标注数据来源
4. 给出可行动洞察
```

**输出格式**：
```
📊 [话题]最新信息

【核心结论】
[一句话结论]

【关键数据】
- [数据点1]
- [数据点2]

【行动建议】
[可直接执行的建议]

来源：[搜索渠道]
```

### 指令五：深度研究

**触发词**：深度研究、深入分析、系统研究

**实现逻辑**：
```
1. 多角度搜索（web_search多轮）
2. 知识学习引擎深度分析
3. 四维输出：现状+数据+影响+行动
```

**输出格式**：
```
🔬 [话题]深度研究报告

一、现状与趋势
[当前格局+未来走向]

二、核心数据与案例
[关键数据+典型案例]

三、对我的直接影响
[与悟空业务的关联]

四、行动建议
[可执行的下一步]
```

## 八、深度学习方法论（MIT学霸超前学习法）

> 2026-05-15 融入学习能力系统，作为深度学习的理论根基

### 8.1 核心框架

**定位**：基于AI工具与认知重构的深度学习范式

**核心三角**：
1. **认知支架**：NotebookLM（Gemini 1.5 Pro驱动，证据驱动型推理）
2. **核心算法**：三问驱动（概念关联分析 + 教学式自查 + 出题思维训练）
3. **执行流程**：课前60%→课中20%→课后20%
4. **效率跃迁**：从"时间驱动"向"漏洞驱动"
5. **核心指标**：知识内化率（≥60%为有效）

### 8.2 五大理论根基

| 理论 | 核心 | 在本系统中的应用 |
|------|------|----------------|
| 整体性学习法 | 联系网络储存知识 | 指令五（深度研究）的知识关联方式 |
| 费曼技巧 | 简单语言解释=真正理解 | 指令八（知识沉淀）的验证标准 |
| 元认知理论 | 关于认知的认知 | 指令一/二/三（记忆管理）的监控机制 |
| 间隔重复 | 遗忘临界点提取 | 指令三（记忆蒸馏）的时间策略 |
| 凋零效应防御 | 知识表象≠思维实质 | 所有指令的深度标准 |

### 8.3 三问驱动框架（元认知监控闭环）

本系统在进行任何深度学习时，自动执行三问：

```
第一问（概念关联）：这个新知识与已有知识库中的哪些概念相关？
第二问（教学自查）：我能用简单语言向小白解释这个概念吗？
第三问（出题思维）：我能设计一道区分"死记硬背"与"真正理解"的题目吗？
```

### 8.4 知识学习六层递进

```
获取（指令四/六）→ 理解（本系统核心）→ 拓展（指令五/七）
→ 纠错（指令三蒸馏）→ 应用（指令八沉淀）→ 测试（对话调取验证）
```

### 8.5 学习飞轮

```
问题（三问自查）→ 地图（概念关联）→ 验证（对话验证）→ 沉淀（MEMORY.md+Obsidian+IMA）
     ↑                                                        │
     └──────────────── 跨会话持续旋转 ─────────────────────────┘
```
