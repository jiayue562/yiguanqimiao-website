# 输入输出规范化

## 输入规范

### 必需输入
- **学习内容**：理论文档、对话记录、项目复盘
- **应用场景**：个人成长/商业实践/知识生产/修行文化
- **知识类型**：概念/方法/模型/框架

### 可选输入
- **触发关键词**：用户期望的激活词汇
- **预期输出格式**：SKILL.md/完整包/测试用例

## 处理逻辑

1. **表示空间处理**：
   - 标签化拆解（概念/方法/工具/资源）
   - 识别语义单元（C1-C6）
   - 建立语义关联网络

2. **压缩处理**：
   - 核心优势识别（帕累托原则）
   - 价值密度评估（信息增益计算）
   - 符号化表达（一句话+象征符号）

3. **泛化处理**：
   - 场景适配（结构映射）
   - 跨场景验证（3个场景测试）
   - 系统进化建议（龙心OS升级点）

## 输出规范

### 标准输出
- **输出类型**：知行合一沉淀卡
- **错误输出**：触发条件不满足、知识关联缺失

### 输出格式模板

### 标准输出
```yaml
本次引擎：[引擎组合·配方名]
核心洞察：[一句话·不超过30字]
象征符号：[1个词或意象]
泛化场景：
  ① [具体场景一]
  ② [具体场景二]
  ③ [具体场景三]
系统进化：[具体升级点或"暂无"]
存入Obsidian：[是·路径] / [否]
```

### 错误输出
```yaml
错误类型：[类型]
错误描述：[具体说明]
解决建议：[如何处理]
```
