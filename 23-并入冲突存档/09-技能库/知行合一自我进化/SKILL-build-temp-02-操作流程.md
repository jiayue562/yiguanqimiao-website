# 可执行操作流程识别

## 操作步骤数
**三阶段（表示空间→压缩→泛化）**

## 步骤清单
1. **表示空间（标签化拆解）**
   - 描述：观察完整经验，记录发生了什么，识别核心标签
   - 输入：任务/对话/学习经历
   - 输出：标签化语义单元

2. **压缩（核心化提炼）**
   - 描述：从全量标签中提炼核心优势，形成一句话洞察和象征符号
   - 输入：全量标签集合
   - 输出：核心洞察 + 象征符号 + 龙心OS连接

3. **泛化（场景化落地）**
   - 描述：将核心优势扩展应用到新场景，形成具体行动方案
   - 输入：核心洞察 + 目标场景
   - 输出：3个具体场景 + 系统进化建议

## 逻辑依赖
**表示空间→压缩→泛化**（顺序依赖，不可跳转）

## 检验结果
**每步都能用自然语言描述：是** ✅
