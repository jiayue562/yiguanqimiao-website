# 数据结构与业务流顶层设计（执行层·数据维）

> **核心金句**：数据结构不再是IT部门的附庸，而是整个组织由"人治"向"系统治"跃迁的操作系统。

## 一、核心定义

以**食材全生命周期**与**7S管理框架**为底座的数据结构与业务流顶层设计。核心命题：建立两条全链路——**业务流全链路**（引流→交付→留存→供应链）回答"业务怎么跑"；**数据流全链路**（采集→清洗→存储→分析→推送→回流）回答"数据怎么用"。业务流是载体，数据流是驱动。

## 二、详细内容（逐章透视）

### 2.1 总纲与四条数据设计规则
- 规则1：每条数据必须含**六元组**（食材周期节点+业务渠道+数据值+时间戳+7S映射+责任锚点）。
- 规则2：节点(物理状态变化)与渠道(业务动作)是父子关系不混层。
- 规则3：销售行为贯穿多节点，不单设"销售"节点。
- 规则4：时间戳精确到分钟（实时监测可行）。
- 四大战略目标：食材利用率≥95% / 食材成本率≤27%(28%红线) / 损耗率≤5% / 净利率≥15%。
- 人机分工：AI做95%(收集/趋势/模式/方案)，人做5%(战略/文化/例外/拍板)。
- **双系统认知模型**：System2(慢思考/理性←AI) + System1(快思考/直觉←人) 在"决策时刻"共振——AI把可能性空间压缩到最小，人做最后选择。

### 2.2 客户流转增长闭环（v3.5新增核心）
- 总营业额=堂食+酒水+外卖。堂食=客流量×翻台率×人均；酒水=用餐人数×渗透率×客单价(利润杠杆：渗透率每+5%净利润+2.5%)；外卖=有效订单量×客单价(坚持200-250元高客单)。
- 客户流转：①引流获客→②储值沉淀→③交叉提升→④转介绍裂变。
- **ABCD客户四级分层**(RFM)：D钻石(R≤7天/F≥4/M≥1000) / P铂金(R≤15/F≥2/M≥500) / G金卡(R≤30/F≥1/M≥300) / S银卡(R≤60/M≥150)，AI自动分层无需人工标注。
- **三大工具协同**：战术层(销售漏斗：流量×转化×客单×复购) → 战役层(营业额公式) → 战略层(客户流转图)，数据贯穿始终。储值会员是核心枢纽。

### 2.3 数据结构：六元组标准
- 六字段定义+示例表（选品/采购/入库/分割/储存/超期 各映射到 7S维度+责任锚点）。
- **数据全链路六层闭环**：采集层(95%自动)→清洗分析层(→7S得分)→推送层(三频)→决策回流层(回写时间戳更新7S)。

### 2.4 业务流全链路（四大业务流+三驾马车）
- 业务流1引流获客(漏斗顶端) / 业务流2门店交付变现(三驾马车协同) / 业务流3客户留存裂变(全生命周期) / 业务流4后端供应链(金枪鱼最小切口)。
- 每环节标注关键指标+数据节点+7S映射，体现"业务动作产生数据→AI归因→行动指令→回业务端"。

### 2.5 金枪鱼7节点标准模型（最小切口）
- 选品→采购→入库→分割(开鱼)→储存→销售调度→超期。单场开鱼秀影响5-10万业绩；12%历史损耗率严重侵蚀毛利。
- 销售渠道比率：预售10% / 开鱼21% / 热度36% / 收尾32%。老饕认定3条件(认可理念+3月≥2次且单≥500+主动传播)。

### 2.6 数据层与三层结构对接
- 决策层权力匹配表(A/B/C/D级)；执行层超级个体矩阵(采购/厨师长/前厅/市场/店长 + AI功能包80% + 楔子责任20%)。
- 组织变革四本质区别复述（经验→数据/事后→实时/部门→超级个体/满足→创造）。

### 2.7 实时决策引擎（五步闭环+三级预警）
- 五步：实时感知→自动分级路由→【F6边界守护插入：AI不指定具体行动/须附置信度/标记"AI预处理·最终判断由决策者做出"】→决策者即时判断→指令下达执行→效果跟踪回流。
- **三色预警**：红(A级·董事长/总经理·分钟级) / 橙(B级·创业单元总·1小时) / 黄(C级·店长·2小时)。
- **关键阈值总表**（采购成本≤25%黄/25-28%橙/>28%红一票否决；出成率≥70%绿/<65%红；损耗率≤5%绿/>8%红；等14项）。
- 完整实时决策示例：Tuna-0723-01 全生命周期闭环验证。

### 2.8 四级闭环（日周月年）
- 日反馈HB1-HB7(七步心跳)；周复盘W1-W4(趋势归因)；月度M1-M4(战略校准+7S五档)；年度(战略/7S总评/3:10储备/招培验收)。

### 2.9 利润模型与28%红线
- 总营业额=堂食+酒水+外卖，AI归因定位不达标根因。
- **成本率红线**：累计成本÷累计营收，26%预警/28%红线(A级升级)。
- 损耗率=(储存损耗+超期损耗)/总购入量，日损>2%预警，连续3日→B级。

### 2.10 全员数据裁定员矩阵
- 采集原则升级：人工填报→API化采集(95%自动)；人角色→楔子化核验；采集时机→SOP内嵌。
- 各岗位采集矩阵(洗碗阿姨/服务员/切配/储存/外卖/直播/采购/店长)，每条数据有反馈闭环。

### 2.11 全品类与全业务线复刻
- 通用模板：业务物理状态流转×数据生命周期×7S考核 三维交汇。金枪鱼P0(验证通过)/和牛·松叶蟹·鹅肝P1/P2/会员储值/门店拓张/人才培养。

### 2.12 三阶段过渡 & 附则
- 阶段一功能数字化→阶段二数据层独立→阶段三超级个体成型。
- 数据层与26智能体对接：六元组字段→对应智能体(P-01/DU-DS等)。
- 三店差异化数据策略：金月湾(采样密度最高) / 狮山(标准化最高) / 松山湖(维度最宽)。
