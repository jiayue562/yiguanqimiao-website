# AI原生组织顶层设计（总纲 v3.0）

> **核心金句**：未来AI原生组织是以全业务数据飞轮为决策依据、三层低结构的超级个体网络。三层不是金字塔，每一层都由超级个体组成。

## 一、核心定义

味藏 AI原生组织顶层设计总纲：以**品牌定位**为数据起点，构建**决策层/数据层/执行层**三层低结构，以**超级个体**（1人+N组AI功能聚合）为最小单元，通过**数据驱动+实时决策**实现从经验科层到人机共生的跃迁。元公式：**合于道 → 自然显化**。

## 二、详细内容（逐章透视）

### 2.1 品牌定位：一切数据的起点
- 三重核心身份：专注东方健康烹饪 + 以技术领先见长 + 老字号高端餐饮（2007年，17年匠心）。
- **强制规则**：无品牌定位不出方案。市场定位(人均300+)→客群画像；产品定位(金枪鱼锚点)→第一优先级数据链；价格定位(人均300锁死)→成本红线≤28%。
- 四层护城河：战略定位 / 技术壁垒 / 文化体验(三禅一体) / **组织变革（最深一层）**。

### 2.2 传统科层痛点诊断
- 痛点一：科层膨胀、依赖经验、无法复制（成功说不出原因）。
- 痛点二：事后管理、数据断裂、无法回溯（ERP堆数据无用于决策）。
- 痛点三：利益固化、人情岗位、阻碍新人（渐变非休克）。
- 软硬双轮不匹配：使命已定缺载体承接。

### 2.3 四大本质区别 & 三大变革维度
- ①决策依据：经验→数据 ②管理时序：事后→实时 ③岗位定义：部门制→超级个体 ④人机分工：人90%执行→AI90%以上执行。
- 三维：经验→数据 / 事后→实时 / 满足需求→创造需求（德鲁克：企业本质是创造客户）。

### 2.4 元公式与三层结构
- **元公式**：合于道→自然显化；逆用：观察显化指标(人效/速度/瓶颈消除)反向印证"合道"。
- **三层全景**：决策层(5人+AI) ↔ 数据层(AI全自动·赋能层并入) ↔ 执行层(三驾马车=N个超级个体)。
- **核心区分（易误读点）**：三层是"职能切片"非"权力层级"。决策层=战略语境设定者；数据层=组织OS；执行层=微型企业CEO(95%异常自闭环)。
- **共享原则**：所有决策基于数据层；每层网状协作；日常不上浮(95%层内消化)。

### 2.5 决策层落地（5人+AI，A/B/C三级权力）
- 构成：董事长(林浏斌)/总经理(柳友连)/堂食总(陈明武)/酒水总(柳春叶)/外卖总(柳能源)。
- A级战略(董事长终决) / B级业务(总经理终决) / C级执行(创业单元总终决)。
- **人机共生决策体**：AI汇聚分析+预警+方案推演；人做方向终决+跨单元协调+现场感知；人的直觉退为"最终质询权"非第一反应。

### 2.6 数据层落地（赋能层并入）
- 原四部门(市场/人事/采购/财务)本质都是数据采集分析→并入数据层，人转超级个体。
- 两大核心：数据要精准(不精准比没有更危险) + 数据链条完整(无断点)。
- 三驾马车供数据 + 七信息交会点(食材验收/员工状态/岗位达标/当日策略/问题分级/客户反馈/组长报告) + 三频推送(日反馈/异常预警/周期报表)。
- 定位：从"支持部门"到"组织OS"（Data Mesh理念：一套底座多套视图）。

### 2.7 执行层落地（三驾马车+超级个体）
- 三驾马车双层含义：业务层(三条营收线) ⊕ 人才层(店长/前厅经理/料理长)。业务层"线"×人才层"点"=穿透执行。
- 超级个体构成表：店长/前厅经理/后厨料理长/采购/市场/人事/财务超级个体及其AI功能聚合+人5%判断域。
- **人做AI干不了的两类事**：物理耦合类(火候/突发/安全) + 关系信任类(谈判/大客户/文化/团队)。

### 2.8 岗位：最小单元
- 三问三答：岗位=数据采集节点+功能聚合体；岗位与超级个体是同一事物两视角；未来岗位=功能聚合非部门划分。
- 从"API化"到"楔子化"：人嵌入岗位像楔子卡住关键责任点，边界外异常才介入。
- 人才管道双轨制(L1-L4 + ABCD角)；26个AI智能体对应26岗位。

### 2.9 金枪鱼数据链（最小切口）
- 选品/采购/入库/分割/储存/销售调度/超期 7节点；每条鱼唯一身份证贯通全生命周期。
- 全员数据裁定员："有多少人工就有多少数据"。

### 2.10 传统中层危机
- 小宗案例：经验型中层系统性边缘化。结论：仅"全新/无先例/人性博弈/复杂伦理/情感冲突"场景人类经验不可替代。

### 2.11 实时决策机制（五步闭环）
- 实时感知→自动分级路由→决策者即时判断→指令下达执行→效果跟踪闭环。三前提：数据精准/链条完整/权力匹配。

### 2.12 过渡路径（三阶段）
- 阶段一功能数字化(→3月)→阶段二数据层独立运转(3-6月)→阶段三超级个体成型(6-12月)。管理层-25%，层级4→3。

### 2.13 元公式操作原则 & 硬指标锚
- 逆用显化印证表；哈佛实证(组织小25%/管理少15%) + 味藏印证(异常闭环≥95%/数据驱动决策趋近100%)。

### 2.14 味藏双重定位
- AI原生组织理论试验场 + 可产品化复制的AI运营系统原型。"一套底座，多套视图"。

### 2.15 八条红线（与哲学五红线对齐）
1. 数据不能替代人的最终判断（附置信度+标记）
2. 杜绝数据教条化，坚持现场感知第一（对抗数据幻觉）
3. 心性修行不能脱离社会实践
4. 岗位消失≠人消失（形态变化非目的）
5. 判断权不可越级（分钟到天归执行层，月到年归决策层）
6. 物理现场不可替代（火候/安全/突发）
7. 关系信任不可算法化（谈判/大客户/文化/团队）
8. 文化底线不可让渡（AI无权调文化）
- **薪酬翻番底层逻辑**：三层化+AI赋能=一人多功能=人效↑=利润↑=薪酬翻番；边际成本趋零(消灭中间层)。
- **双轨审计+红线熔断**：客观轨(马哲实践)＋主观轨(心性标准)，主观跌破阈值强制暂停AI流程。

### 2.16 终极演进：无层之层
- 三层结构"消融"为无结构流体网络——决策层5人变战略意图节点，数据层溶入"数字神经液"，执行层成自由态责任承担者。

### 2.17 龙龟经验沉淀（方法论）
- 房屋建设法 / 先有框架后有细节(50万字失控教训) / 约束即创造力 / 过程比结果重要 / 不在载体耗精力 / 先画地图再分任务。
