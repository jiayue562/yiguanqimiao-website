# 附录 D · 触发日志模板与示例

> 七字段标准格式 + 五条填好的真实日志（含两条误触发）。

---

## 一、日志字段表

| 字段 | 内容 | 为什么要有 |
|---|---|---|
| **时间** | 时间戳 | 复盘时排序 |
| **触发层** | L1 / L2 / L3 | 看哪层最活跃、哪层最不准 |
| **命中信号与分值** | "摄入度2+沉淀1=3" | **这是"因为"的证据** |
| **调度的引擎** | 派了谁 | 看有没有偏科 |
| **宣告文案** | 当时说了什么 | 看宣告有没有说理由 |
| **用户反应** | 接受 / 否决 / **无反应** | 三种都要记 |
| **事后判定** | 对 / 错 / 勉强 | 回填，唯一的自我纠错机制 |

### 模板

```
【时间】2026-__-__ __:__
【触发层】□L1 □L2 □L3
【命中信号】__________（如：摄入度2 + 沉淀1 = 3）
【调度引擎】__________
【宣告文案】我判断这是 S__，派__，因为__
【用户反应】□接受 □否决（原话：____） □无反应
【事后判定】（一周后回填）□对 □错 □勉强　说明：____
```

## 二、五条填好的日志

### 日志 1 · L2 正确触发（脾）

```
【时间】2026-__-__ 08:20
【触发层】L2
【命中信号】摄入度2（30页PDF） + 协作度1 + 沉淀1 = 4
【调度引擎】脾（知识学习）
【宣告文案】我判断这是 S2，派知识学习消化材料——30 页，摄入度满分。
            你没说要决定什么，先不派五色光。
【用户反应】接受
【事后判定】对 —— 三判据走完，指出报告第 12 页数据反常
【后续】读到第 12 页，未知度升 2，升档补派心
```

### 日志 2 · L2 正确触发（眼）

```
【时间】2026-__-__ 10:40
【触发层】L2
【命中信号】决策度2（三选一） + 摄入1 + 沉淀1 = 4
【调度引擎】眼（五色光完整序列）
【宣告文案】我判断这是 S4，派五色光走完整序列，因为你有三个选项要权衡。
【用户反应】接受
【事后判定】对 —— 走完发现第三个根本不在一个量级，问题变了
【后续】L3 触发点①命中（"行，就这个方向"），出一级沉淀卡
```

### 日志 3 · L2 正确触发（心，且刻意没派眼）

```
【时间】2026-__-__ 14:00
【触发层】L2
【命中信号】未知度2 + 沉淀2 + 协作1 = 5
【调度引擎】心 + 手(Q4) + 血　（**未派眼**）
【宣告文案】我判断这是 S3，未知度满分，派象思维取象；你掌握的信息比 AI 多，
            按 Q4 分工；这个洞察必须留，收尾派知行合一。
            **先不派五色光**，还没到权衡的时候。
【用户反应】接受
【事后判定】对 —— 过早开五色光会把原创问题压成选择题
```

### 日志 4 · 误触发（L1 关键词无语境）★

```
【时间】2026-__-__ 16:50
【触发层】L1
【命中信号】关键词"沉淀"
【调度引擎】血（知行合一）
【宣告文案】（无——L1 点名触发时如果没写理由，这里就是空的）
【用户反应】**无反应**（用户默默关掉卡片，继续聊）
【事后判定】错 —— ①用户说的"沉淀"是"要好好想想"，不是"出沉淀卡"
                  ②任务根本没做完，没有东西可沉淀
【处方】把"沉淀"从 L1 降为 L2 辅助信号：
        只有同时命中"任务已完成"状态时才生效
【备注】**用户没有投诉**。只看"有没有人骂"会误判这次为成功。
```

### 日志 5 · 误触发（L2 打分虚高）★

```
【时间】2026-__-__ 09:15
【触发层】L2
【命中信号】未知1 + 决策1 + 协作1 + 摄入1 + 沉淀1 = 5
【调度引擎】（系统犹豫，最终派了脾）
【宣告文案】我判断这是 S2……（理由勉强）
【用户反应】否决（原话："不用，我就是随口一说"）
【事后判定】错 —— **五维各打 1 分，加起来 5 分，但没有一维突出**
【处方】确认"至少一维 ≥2"这条附加条件的必要性：
        各维都是 1 分的情况，通常是漫谈，不该触发
【备注】这条日志是"至少一维≥2"规则存在的直接证据
```

## 三、怎么用这五条日志

| 日志 | 说明什么 |
|---|---|
| 1、2、3 | 正确触发长什么样：**宣告里有"因为"，还有"先不派谁"** |
| 4 | **用户不投诉 ≠ 没问题**；"无反应"必须记 |
| 5 | 为什么要有"至少一维 ≥2"这条附加条件 |

**日志 3 里"先不派五色光"这一句，是好日志的标志。** 一份好的触发日志，不只记录"派了谁"，还记录"**没派谁，以及为什么**"。

## 五、待校准

1. **否决率 30% 这个警报线是经验值**，无统计依据。
2. 统计口径：否决率按**次数**还是按**会话**计，未论证（本章默认按次数）。
3. 五条日志中，日志 4 是真实的，其余四条是构造的——真实日志积累够之后应替换。
4. 日志存哪儿、存多久、怎么跟三向同步配合，见第二十三章。
