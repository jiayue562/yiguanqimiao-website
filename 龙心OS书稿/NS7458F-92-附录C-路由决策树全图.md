## 二、四问速判分支（手动版）

```
① 答案在不在已有知识里？
     ├─ 不在 → 🐉 心（取象）      → S3 / Q5
     └─ 在   → 📚 脾（消化）      → S1 / S2

② 要不要做决定、有没有多面？
     └─ 要   → 🌈 眼（五色光）    → S4 / S5

③ 要不要 AI 参与、谁掌握信息？
     └─ 要   → 🤝 手（分象限）    → S6 / S7
                （Q1–Q4 分派，Q5 转心）

④ 做完了要不要留下资产？
     └─ 要   → 🔄 血（沉淀）      → S9 / 任何收尾

【四问全否】 → 不启动任何引擎（L0）
【四问并联】 → 命中几条派几条（不是串联）
```

## 四、组合与顺序规则

### 三条排序原则

1. **取象在前** —— 象没定，后面全在模糊基础上做
2. **决策在后** —— 信息不全就决策，是最大的浪费
3. **血在最后** —— S9 例外（血在最前）

### 撞车消解（按顺序用）

| 招 | 什么时候用 |
|---|---|
| **降级** | 两个都要但资源不够 → 各走浅层 |
| **串行** | 有依赖关系 → 排队，先出产出 |
| **仲裁** | 结论直接冲突 → **交给人拍板** |

### 最小可用原则

> 能用两个引擎，就不要上三个。

## 六、降级路径

```
L1（点名）──确定──→ 执行
   └─点名了但特征明显不符 ──→ 退回 L0，问一句

L2（特征）──≥阈值──→ 执行
   └─2~3 分之间（差一点）──→ 退回 L0，不硬猜

引擎调用失败 ──→ 按备选映射降级
龙脑OS 不可用 ──→ 用内置基础模型兜底（5 个）
龙爪OS 不可用 ──→ 跳过执行，直接输出推荐
全部失败 ──→ "处理失败，建议人工介入" + **附上已收集的部分结果**
```

## 七、待校准

1. 主决策树中"2~3 分之间"这个模糊带的边界未定。
2. L1 覆盖负向信号的具体条件未细化（所有点名都覆盖？还是只覆盖部分否决项？）。
3. Q3（共创伙伴）在决策树里的位置偏弱——它通常不是独立终点，而是过渡态。
4. S5 全系统配方的内部顺序（心→眼→手→血）未实测。
