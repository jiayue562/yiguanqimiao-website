# 附录 B · 场景识别矩阵全表

> S0–S9 × 五维特征 × 引擎候选 × 典型输入。
> 五维定义见第十章，打分规则见第十六章。

---

## 一、五维定义（复习用）

| 维度 | 0 分 | 1 分 | 2 分 | 指向 |
|---|---|---|---|---|
| **未知度** | 答案已在已有知识里 | 有一部分现成的 | 谁都不知道 | 🐉 心 |
| **决策度** | 只需执行 | 有选择但不大 | 要在多面中取舍 | 🌈 眼 |
| **协作度** | 人独立完成 | AI 帮忙查查 | 需 AI 深度参与 | 🤝 手 |
| **摄入度** | 不用看新材料 | 要看一点 | 有一大份材料要消化 | 📚 脾 |
| **沉淀价值** | 用完即弃 | 可能有用 | 值得留下 | 🔄 血 |

**阈值**：合计 ≥3 且有一维 ≥2 → 触发；≥5 → 触发并组合；<3 → L0 不启动。

## 二、场景全表

### S0 极简问答

| 项 | 内容 |
|---|---|
| **识别特征** | 单句直接问题、闲聊、确认 |
| **五维典型** | 全 0（或只有 1 个 1 分） |
| **自动路由** | 不启动引擎，直接回答 |
| **声明方式** | **静默** |
| **典型输入** | "今天几号""这个字怎么读""你说呢" |
| **备注** | 这是默认值，不是异常 |

### S1 信息查询

| 项 | 内容 |
|---|---|
| **识别特征** | "是什么""告诉我"、定义查询 |
| **五维典型** | 摄入度 0–1，其余 0 |
| **自动路由** | 脾（浅层） |
| **声明方式** | **静默** |
| **典型输入** | "知行合一是什么意思""MECE 是什么" |
| **备注** | 浅层＝只走前两层，不做完整十项指令 |

### S2 深度理解

| 项 | 内容 |
|---|---|
| **识别特征** | 提供文章、要求深入理解 |
| **五维典型** | 摄入度 2、沉淀 1–2、协作 1 → 合计 4–5 |
| **自动路由** | 脾 → 心 → 血 |
| **声明方式** | **声明** |
| **典型输入** | "帮我把这份报告吃透""这本书讲了什么，我要讲给团队" |
| **备注** | 说"要讲给别人听"时，血必派 |

### S3 创新突破

| 项 | 内容 |
|---|---|
| **识别特征** | 全新问题、0→1 需求 |
| **五维典型** | 未知度 2、沉淀 2、协作 1 → 合计 5 |
| **自动路由** | 心 主导（+ 手 Q4 + 血） |
| **声明方式** | **声明** |
| **典型输入** | "我想做一件市场上没有的东西""这个难题没人解过" |
| **备注** | **不派眼**（还没到权衡的时候） |

### S4 分析决策

| 项 | 内容 |
|---|---|
| **识别特征** | 多选项、需权衡 |
| **五维典型** | 决策度 2、摄入 1、沉淀 1 → 合计 4 |
| **自动路由** | 眼（五色光完整序列）+ 血 |
| **声明方式** | **声明** |
| **典型输入** | "三个供应商选哪个""要不要做这件事" |
| **备注** | 完整序列＝至少五色 + 主持人整合 |

### S5 重大决策

| 项 | 内容 |
|---|---|
| **识别特征** | 战略级、影响深远 |
| **五维典型** | 决策 2、未知 1、协作 1、摄入 1、沉淀 2 → 合计 7 |
| **自动路由** | 全系统（心 → 眼 → 手 → 血） |
| **声明方式** | **声明** |
| **典型输入** | "我们要不要进入这个市场""这个业务要不要砍掉" |
| **备注** | 唯一适合"全员出动"的场景；走之前先定题 |

### S6 任务执行

| 项 | 内容 |
|---|---|
| **识别特征** | 明确指令、直接执行 |
| **五维典型** | 协作度 2，其余 0–1 |
| **自动路由** | 手（五象限） |
| **声明方式** | **静默** |
| **典型输入** | "帮我把这些文件按日期排一下""生成一份表格" |
| **备注** | 静默是因为分工是常识性的，说出来啰嗦 |

### S7 系统规划

| 项 | 内容 |
|---|---|
| **识别特征** | 项目规划、任务分工 |
| **五维典型** | 协作 2、决策 1、摄入 1、沉淀 2 → 合计 6 |
| **自动路由** | 心 → 手 → 眼 → 血 |
| **声明方式** | **声明** |
| **典型输入** | "这个项目怎么排""这几个人怎么分工" |
| **备注** | 先取象（这事到底是什么），再分工 |

### S8 修行文化

| 项 | 内容 |
|---|---|
| **识别特征** | 心文化、传统智慧、修养类话题 |
| **五维典型** | 未知 1–2、摄入 1、沉淀 2 |
| **自动路由** | 心 + 脾（溯源）→ 血 |
| **声明方式** | **声明** |
| **典型输入** | "怎么理解'致良知'""这个境界是什么意思" |
| **备注** | 脾走"溯源"层（追概念的来路），不走完整五层 |

### S9 系统进化

| 项 | 内容 |
|---|---|
| **识别特征** | 龙心OS 自身的升级、复盘、调阈值 |
| **五维典型** | 沉淀 2、未知 1 |
| **自动路由** | **血 → 心 → 眼 → 落地更新** |
| **声明方式** | **声明** |
| **典型输入** | "我们这套系统要不要调一下""最近的触发准不准" |
| **备注** | **唯一一个血在最前的配方**（因为要先翻旧账） |

## 三、S0–S9 一页速查

| 场景 | 典型五维 | 路由 | 声明 |
|---|---|---|---|
| S0 极简 | 全 0 | 不启动 | 静默 |
| S1 查询 | 摄入 0–1 | 脾（浅） | 静默 |
| S2 深读 | 摄入 2 + 沉淀 1–2 | 脾→心→血 | 声明 |
| S3 创新 | 未知 2 + 沉淀 2 | 心（+手+血） | 声明 |
| S4 决策 | 决策 2 | 眼（+血） | 声明 |
| S5 重大 | 决策 2 + 沉淀 2 + 未知 1 | 全系统 | 声明 |
| S6 执行 | 协作 2 | 手 | 静默 |
| S7 规划 | 协作 2 + 沉淀 2 | 心→手→眼→血 | 声明 |
| S8 文化 | 未知 1–2 + 沉淀 2 | 心+脾(溯源)→血 | 声明 |
| S9 进化 | 沉淀 2 | **血→心→眼→更新** | 声明 |

## 四、负向信号（否决项）

任一命中 → 不启动，除非用户点名（L1）：

| 信号 | 例子 |
|---|---|
| 闲聊语气 | "今天好累""你说呢" |
| 明确要快 | "快点""一两句说完" |
| 单次问答 | 问完就走 |
| 同一引擎刚触发过且无新信息 | 五分钟前刚消化过同一份材料 |

---

## 五、待校准

1. S0–S9 与五维打分的映射关系**需逐格人工核定**——表中若干格是推断值。
2. 阈值 3 和 5 是设计初值，未经实测。
3. "摄入度"与"未知度"容易同时偏高，区分度待确认。
4. S8 的"修行文化"场景五维特征最难量化，表中数值最不可靠。
