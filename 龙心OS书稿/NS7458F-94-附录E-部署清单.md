## 二、五个 SKILL.md 最小字段

每个引擎的 SKILL.md 必须写这六块：

| # | 字段 | 内容 | 缺了会怎样 |
|---|---|---|---|
| 1 | **核心定位** | 一句话：它管哪一段 | 中枢不知道该不该派它 |
| 2 | **触发规则** | 什么信号下启动 | 只能靠手动 |
| 3 | **操作流程** | 分几步，每步干什么 | 产出不稳定 |
| 4 | **输出格式** | 固定模板 | 结果没法被下一环接 |
| 5 | **整合协议** | 输出给谁、接谁的输出 | **接缝处全漏** |
| 6 | **失败模式** | 什么情况下会出错 | 错了不知道 |

**第 5 条最容易漏，也最关键**——它是"流水线 vs 工具箱"的分界线。
**第 6 条是本书特别加的**——不敢写失败模式的 Skill，用起来危险。

### 中枢 SKILL.md 额外要写

| 字段 | 内容 |
|---|---|
| 职责边界 | **只做感知·识别·路由·宣告，不干活** |
| 宣告义务 | 每次调度必须说"派了谁、因为什么" |
| 分层动员 | 轻载/标准/深度的判定标准 |
| 降级映射 | 引擎失败时切谁 |
| 越界禁止 | **不产出内容、不评判对错、不替人决定** |

## 三、上线自检 12 项

装完之后逐项打勾。**有"否"就别上线。**

| # | 检查项 | 是/否 |
|---|---|---|
| 1 | 五个引擎各自能单独跑通吗？ | ☐ |
| 2 | 中枢派活之后，引擎真的接住了吗？ | ☐ |
| 3 | **L0 真的是默认吗？**（闲聊时它会不会乱动） | ☐ |
| 4 | L2 打分能跑出来吗？（分数对不对） | ☐ |
| 5 | **L3 真的是默认吗？**（任务做完会不会自动沉淀） | ☐ |
| 6 | 每次触发都有宣告吗？ | ☐ |
| 7 | 宣告里有没有"因为"？ | ☐ |
| 8 | 日志真的在写吗？（**去翻文件确认，别看它说**） | ☐ |
| 9 | 用户说"不用"，它真的停了吗？ | ☐ |
| 10 | 那个"不用"被记下来了吗？ | ☐ |
| 11 | 沉淀卡真的入库了吗？（去 Obsidian 里看一眼） | ☐ |
| 12 | 三向同步真的通了吗？（三端各查一次） | ☐ |

**重点盯 3、5、8、11 项**——这四项最容易"以为做了其实没做"。

## 四、四层学习能力 · 九条指令

| 层 | 能力 | 指令 |
|---|---|---|
| **一** | 持久记忆 | ① 写入记忆　② 调取记忆　③ 记忆蒸馏（**每月一次**） |
| **二** | 实时获取 | ④ 联网搜索（单话题）　⑤ 深度研究（多角度） |
| **三** | 文件与知识库读取 | ⑥ 读取本地文件　⑦ 批量读取知识库 |
| **四** | 自主进化 | ⑧ 每日知识沉淀　⑨ 设置定时学习任务 |

### 九条指令速查

| 想干什么 | 指令 |
|---|---|
| 让它记住 | ① 写入记忆 |
| 验证它记没记住 | ② 调取记忆 |
| 记忆太臃肿 | ③ 记忆蒸馏（每月） |
| 查个新东西 | ④ 联网搜索 |
| 系统研究一个领域 | ⑤ 深度研究 |
| 读本地文件 | ⑥ 读取本地文件 |
| 读整个知识库 | ⑦ 批量读取知识库 |
| 今天做个了结 | ⑧ 每日知识沉淀 |
| 让它自己跑 | ⑨ 定时学习任务 |

**第 ③ 条（记忆蒸馏）最容易被忽略**。不蒸馏，三个月后记忆库变垃圾场，检索慢且互相矛盾。

**第 ⑨ 条是"系统在你不用它时也在工作"的实现。**

## 五、三向同步配置

| 端 | 角色 | 存什么 |
|---|---|---|
| **Obsidian** | 主知识库 | 完整沉淀卡、进化日志、双向链接 |
| **WorkBuddy** | 工作记忆 | 每日日志（append-only）、长期记忆、项目状态 |
| **IMA** | 移动端 | 一句话洞察 + 象征符号（手机能看） |

**验收方法**：三端各查一次，确认同一张卡在三处都能找到。

## 六、三种常见失败

| 失败 | 表现 | 根因 |
|---|---|---|
| **一次建六个** | 中枢和五个引擎同时上，哪里错了都不知道 | 没有实测 |
| **只建引擎不建中枢** | 五个都好用，但得自己记什么时候用哪个 | **这是工具箱，不是有机体** |
| **建了中枢但中枢亲自干活** | 中枢开始大段大段写内容 | 越界（第九章） |

## 七、标签与命名规范

| 项 | 规范 |
|---|---|
| 引擎符号 | 🐉 心 / 📚 脾 / 🌈 眼 / 🤝 手 / 🔄 血 |
| 场景编号 | S0–S9（**不重编**，重编会废掉历史日志） |
| 触发层 | L0/L1/L2/L3 |
| 象限 | Q1–Q5（配名称：高效助理/学习伙伴/共创伙伴/共创导师/未知探索域） |
| 沉淀卡 | 七字段固定格式（见第八章） |
| 三记号 | [AI] / [人] / [⇄] |

**禁用表述**："六大模块"（1+5 不是六个平级）、"自动触发"（单独使用太含糊，要写清 L 几）。
