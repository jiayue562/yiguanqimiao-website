# 第十一章 · 路由四问与决策树

## 这一章解决什么

给你一个不用背矩阵也能用的路由方法。

上一章的五维打分很准，但它有个问题：**你没法在心里面打五个数再决定**。真到用的时候，人需要的是几句能默念的话。

这一章给四问。问完，该派谁就出来了。

## 核心内容

### 一、路由四问

| # | 问 | 答"是" → 派谁 | 答"否" → |
|---|---|---|---|
| ① | 答案在不在已有知识里？ | **不在** → 🐉 心·象思维<br>**在** → 📚 脾·知识学习 | — |
| ② | 要不要做决定、有没有多面？ | **要** → 🌈 眼·五色光 | 跳过 |
| ③ | 要不要 AI 参与、谁掌握信息？ | **要** → 🤝 手·五象限 | 跳过 |
| ④ | 做完了要不要留下资产？ | **要** → 🔄 血·知行合一 | 跳过 |

**四问是并联，不是串联。** 这是最容易搞错的地方。

不是"问完第一问再问第二问"，是**四个问题同时问，命中哪个派哪个**。一次对话可能同时命中两个、三个，命中几个就派几个。

### 二、四问与四个引擎的对应

注意：四问对应的是**四个**引擎，不是五个。

第一问是双向的（在/不在 → 脾/心），所以实际上覆盖了五个引擎：

```
                  ┌─ 不在 → 🐉 心（取象）
① 知识在不在？───┤
                  └─ 在   → 📚 脾（消化）
② 要做决定吗？────── 要  → 🌈 眼（五光扫面）
③ 要 AI 参与吗？──── 要  → 🤝 手（分象限）
④ 要留下吗？──────── 要  → 🔄 血（沉淀）
```

**为什么"要留下吗"也要问？**

因为它不是默认"要"的。有很多事做完就完了，不值得沉淀——比如"帮我改个错别字"。硬要给这种事做沉淀卡，是在制造垃圾。

但反过来，第十七章会讲：**有一类情况，不管你答不答"要"，系统都会默认留下**（L3 元触发）。这是两套机制的衔接点，别在这里搞混——四问是**你手动判断**用的，元触发是**系统自动执行**用的。

### 三、完整决策树

```
输入进来
  │
  ├─ 五维全 0？ ── 是 ──→ 【L0 静默】直接回答，不启动引擎
  │
  └─ 否
      │
      ├─ ① 知识在不在已有里？
      │     ├─ 不在 → 🐉 心（S3 创新突破 / Q5）
      │     └─ 在   → 📚 脾（S1 查询 / S2 深度理解）
      │
      ├─ ② 要做决定、有多面？
      │     └─ 要   → 🌈 眼（S4 分析 / S5 重大）
      │
      ├─ ③ 要 AI 参与？
      │     └─ 要   → 🤝 手（S6 执行 / S7 规划）
      │
      └─ ④ 做完要留下？
            └─ 要   → 🔄 血（S9 进化 / 任何场景收尾）
```

**四条分支可以并行命中。** 命中两条以上，按顺序原则排队（第十三章）。

### 四、兜底规则：四问全否 → 不启动

这条规则比四问本身更重要。

**四问全否，说明这件事不需要引擎。** 它是闲聊、是简单查询、是一次性动作。这时候启动任何引擎都是浪费，而且是骚扰。

这就是为什么第十四章要把 **L0 静默定为默认值**——系统的默认状态是"什么都不做"，只有被证据推动了才动。

**宁可少触发，不可乱触发。**

### 五、三个判例

#### 判例一：一句话查询

> "知行合一是什么意思？"

① 在已有知识里 → 脾（浅层）；② 不做决定 → 否；③ 要 AI 参与？边缘；④ 不用留下 → 否。
**结论**：脾浅层回答，静默执行，不声明。

#### 判例二：一份材料

> "帮我看看这份三十页的行业报告。"

① 在（材料里）→ 脾；② 暂时不做决定 → 否；③ 要 AI 参与 → 手（Q2 学习伙伴：它读得快你来审）；④ 值得留下 → 血。
**结论**：脾 + 手 + 血。声明："我判断这是 S2，派知识学习消化材料，人机协同按'学习伙伴'象限分工——我读你审，最后留一张卡。"

#### 判例三：一个没见过的问题

> "我想做一件现在市场上没有的东西，不知道从哪下手。"

① **不在**已有知识里 → 心（取象）；② 还不到做决定 → 否（别急）；③ 要 AI 参与，但**你不知道的比它多** → 手（Q4 共创导师：你说经验它结构化）；④ 要留下 → 血。
**结论**：心 + 手(Q4) + 血。**注意这里没有眼**——还没到权衡的时候，过早开五色光会把一个原创问题压成一个选择题。

第三个判例是全书最重要的一处的伏笔：**顺序错了，比没做更糟。** 第十三章讲这个。
