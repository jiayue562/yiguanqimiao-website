## 🐉 心 · 象思维

| 项 | 内容 |
|---|---|
| **器官位** | 心（主神明） |
| **管哪一段** | 无 → 有 |
| **一句话** | 在谁都不知道的地方，看出这件事"像什么" |
| **内部构造** | 三层次（物象→意象→原象）／六非两核心／四步法（观物取象→立象尽意→取象比类→观象制器） |
| **必用它的时候** | Q5 未知探索域；被卡住反复打转；跨域原创 |
| **触发信号** | "全新的""没见过的""不知道从哪下手" |
| **最小操作** | 问一句"它像什么"，然后追问"这个'像'背后的本质是什么" |
| **及格线** | 取出的象能导出一个具体做法 |
| **失败模式** | 把意象当原象／把取象当结论／故意求象／装玄 |
| **不管什么** | 不管已知领域的优化（那是 1→N，归别的） |
| **去哪章** | 第四章 |

|---|---|
| **器官位** | 脾（主运化） |
| **管哪一段** | 外 → 内 |
| **一句话** | 把别人的话，变成自己的话 |

## 🌈 眼 · 五色光思维

| 项 | 内容 |
|---|---|
| **器官位** | 眼（主观察） |
| **管哪一段** | 偏 → 全 |
| **一句话** | 一次只开一种光，让每一面都不能被跳过 |
| **内部构造** | 六模式（白/红/黄/绿/蓝/主持人）／三原则（单色聚焦·序列自由·强制完整）／三体一心 |
| **必用它的时候** | 多选项要权衡；会上吵起来；想确认自己漏了什么；一群人要想一块儿想 |
| **触发信号** | "选哪个""要不要""几个方案" |
| **最小操作** | 白→蓝→绿→黄 走一遍，每色收一句话 |
| **及格线** | 五色齐全 + 有主持人整合 |
| **失败模式** | 混色／用不全／无主持人／不宣布切换／蓝光过敏或缺失 |
| **不管什么** | 不管未知探索（还没到权衡的时候，别开） |
| **去哪章** | 第六章 |

| 项 | 内容 |
|---|---|
| **器官位** | 手（主执行） |
| **管哪一段** | 人 → 机 |
| **一句话** | 先把调度权分清楚，再干活 |
| **内部构造** | Q1 高效助理／Q2 学习伙伴／Q3 共创伙伴／Q4 共创导师／Q5 未知探索域；君臣佐使；[AI]/[人]/[⇄] 三记号 |
| **必用它的时候** | 跟 AI 协作的任何时候；说不清谁主导的时候 |
| **触发信号** | "帮我做""一起想想""这个你懂我不懂" |
| **最小操作** | 三问：我掌握多少？AI 掌握多少？谁主导？然后标三记号 |

| **失败模式** | 全程 Q1／全程 Q3／不敢进 Q4／在 Q2 装懂／没有"佐" |
| **不管什么** | 不管内容质量（它只管分工，不管分完之后干得好不好） |

## 🔄 血 · 知行合一

| 项 | 内容 |
|---|---|
| **器官位** | 血（**贯穿三层**，是循环系统不是器官） |
| **管哪一段** | 做完 → 留下 |
| **一句话** | 让"做完了"不等于"结束了" |
| **内部构造** | 三阶段转化（表示空间→压缩→泛化）／标准沉淀卡／三向同步 |
| **必用它的时候** | 任何有产出的任务收尾；出现新认知；五色光走完；引擎链跑完 |
| **触发信号** | 用户说"行/就这个"；"这个我没想到"；任务状态到达终点 |
| **最小操作** | 出一张卡：≤30 字洞察 + 象征符号 + 三个泛化场景 |
| **及格线** | 三阶段各有及格线（见第八章）+ 七项自检全过 |
| **失败模式** | 只总结不提炼／只提炼不泛化／只泛化不入库／入库永不回看／**沉淀了错的** |
| **不管什么** | **不管判断对错**（那是"事后判定"的事，不是沉淀的事） |
| **去哪章** | 第八章、第十七章 |
