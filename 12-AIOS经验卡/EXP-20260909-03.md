# 改版本号前先 grep changelog 头部

## 现场（当时发生了什么）

准备把总入口升到 v4.13，发现 changelog 里已经是 `v4.13 AIOS自进化引擎`——另一条任务线先占用了。

## 做法（怎么解决的）

顺延 v4.14，并在 changelog 里注明顺延原因。

## 判据（下次怎么一眼认出）

改版本号 = 先 grep changelog 头部看最新一条，别覆盖他人条目。多人/多线并行改同一文件时，版本号是共享资源。
