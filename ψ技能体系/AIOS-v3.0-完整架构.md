# AI OS v4.0 — 超级个人的个人操作系统·完整架构

> **v4.0 重组 (2026-06-29)**: 10-kernel回归三个目录。龙心OS回归1+5纯引擎。龙脑OS升格为方法论+约束层——格式塔具身/AI原生组织/象道全息/驾驭工程/自主进化全部归入。心脏(龙心)管运行，大脑(龙脑)管边界，灵魂(人机共生)管存在。

## 〇、哲学根基

> AI OS 不是"AI工具集"，而是**超级个人的个人操作系统**。
> 它的设计哲学源于三个核心命题：

**命题一：身体不是孤立的生理实体，而是关系场中的动态样态。**
→ 格式塔具身智能横切所有层的感知根基。

**命题二：组织的核心问题不是"谁的效率低"，而是"哪里在逼人串行排队"。**
→ AI原生组织横切所有层的治理哲学。

**命题三：知识与代码一样，需要版本控制、分布式备份、不可篡改的归属。**
→ 六向同步+AI印记构成知识资产的硅基永生。

## 二、10-kernel三核心详解

### 龙心OS — 心脏·1+5引擎

心脏只管跳——引擎只负责运行，不定义方法论。

| 引擎 | 路径 | 功能 |
|------|------|------|
| 总智能体 | SKILL.md | 意图识别·场景路由·组合调度 |
| 知行合一 | engines/知行合一/ | 执行转化·三阶段模型 |
| 知识学习 | engines/知识学习Skills/ | 学习建构·四层归档 |
| 人机协同 | engines/人机协同五象限/ | [AI]/[人]/[⇄]分解 |
| 象思维 | engines/象思维/ | 三模式：认知+感知+类型学 |
| 五色光思维 | engines/五色光思维/ | 多视角·集体思考 |
| 具身关系格式塔引擎 | engines/具身关系格式塔引擎/ | E0-E6运行时引擎 |
| 串行瓶颈诊断引擎 | engines/串行瓶颈诊断引擎/ | BN检测 |
| 瓶颈压缩策略引擎 | engines/瓶颈压缩策略引擎/ | 策略匹配 |

### 龙脑OS — 大脑·方法论+约束层

大脑不定向——它划边界，告诉心脏"在哪里跳，不在哪里跳"。

**四大方法论域**：

| 域 | 路径 | 功能 |
|------|------|------|
| 思维模型 | models/ | 78模型·麦肯锡·教员方法论 |
| 格式塔具身 | 格式塔具身方法论/ | 横切感知方法论·起手即全息·合于场域之道 |
| 象道全息 | 象道全息方法论/ | 认知方法论·全息三层·四象入道·合于道 |
| AI原生组织 | AI原生组织方法论/ | 横切治理方法论·护照·成熟度·工作流 |
| 驾驭工程 | Harness-Engineering/ | 执行约束方法论 |
| 自主进化 | self-improving/self-learning/ | 进化引擎 |

### 人机共生OS — 灵魂·存在

灵魂不定规则——它定义"我是谁，我和用户是什么关系"。

**核心原则**：起手即全息（AI感知用户第一眼已含完整信息）+ 合于道自然显化（改变不是努力，是回归本然）

## 四、自主调用链路

### 4.1 技能发现

```
opencode.json → skills.paths → 遍历 ~/.agents/skills/ 全部SKILL.md
                                    │
                    ┌───────────────┼───────────────┐
                    ▼               ▼               ▼
            00-foundation      10-kernel        20-claws
            (4 底座技能)      (8引擎+治理)     (4龙爪/80+技能)
                                    │
                             30-tools ← 40-rules ← 50-security
```

### 4.2 调度器路由

```
scheduler_main.py
  ├── intent_recognizer.py    → 识别意图类型
  ├── scene_classifier.py     → 分类场景
  ├── engine_router.py        → 路由到龙心OS引擎
  └── skill_discovery.py      → 发现龙爪OS技能（默认路径: ~/.agents/skills/）
```

### 4.3 治理授权

```
governance.py
  ├── authorize(agent, action, severity, user_fatigue)
  ├── 红绿灯三区制 (green/yellow/red)
  ├── 疲劳度动态调整 (管道三: >70自动降级)
  └── audit_log → ~/.aios/audit_log.jsonl
```
