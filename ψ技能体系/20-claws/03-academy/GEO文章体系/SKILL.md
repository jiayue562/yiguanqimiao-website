# GEO文章体系

## 定位
以观其妙书院龙爪的内容分发引擎。基于GEO（Generative Engine Optimization）策略，通过Cloudflare CDN全球加速，实现3552篇GEO文章的规模化生产、部署与曝光。

## 核心策略
- **AI Native写作**：每一篇文章以AI生成+人类审核模式生产
- **GEO优化**：针对生成引擎（Perplexity、Google SGE、Bing Chat等）做结构化内容优化
- **CDN分发**：通过Cloudflare Pages全球边缘节点加速访问
- **域名矩阵**：pages.dev + 自定义域名实现多入口曝光

## 工作流
选题策略 → AI生成初稿 → 人类审核优化 → GEO关键词注入 → Cloudflare部署 → 性能监控 → 迭代优化

## 技术栈
- Cloudflare Pages（托管+CDN）
- GEO优化模板（结构化数据+FAQ+深度内容）
- AI写作引擎（wechat-article-pro风格适配）
- 数据看板（文章曝光/点击/转化）
