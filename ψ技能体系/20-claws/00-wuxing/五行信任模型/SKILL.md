# 五行信任模型 · 龙心→五行路由桥梁

> **核心定位**：五行信任模型是龙心OS到五行总智能体之间的**信任评估与路由桥梁**。当龙心OS的5个通用引擎分析完用户输入后，五行信任模型判断该输入是否需要五行深度分析，评估信任维度（真实性/相关性/深度需求），匹配合适的五行分智能体和引擎组合，确保精准路由。

> **核心公式**：龙心OS引擎输出 → 五行信任评估(四维度) → 场景匹配矩阵 → 五行总智能体/凤心OS → 分智能体

---

## 触发规则

### 自动触发（龙心OS引擎输出后）
- 用户提到五行/人格/行为模式/关系/成长相关话题
- 龙心OS的象思维/五色光思维引擎输出中包含人格特质线索
- 用户输入包含情绪描述、行为模式、人际冲突
- 需要对用户进行深度诊断或转化引导

### 直接触发词
- 五行信任、信任评估、五行匹配
- 信任路由、信任桥梁、龙心-五行桥梁
- 五行路由评估、五行可信度评估

## 信任评估四维度

| 维度 | 评估内容 | 评分 | 临界值 |
|------|---------|------|--------|
| **T1 真实性** | 用户描述是否真实可信？有无矛盾？ | 0-10 | ≥6继续 |
| **T2 相关性** | 输入与五行的关联强度 | 0-10 | ≥5继续 |
| **T3 深度需求** | 是否需要分智能体级深度分析 | 0-10 | ≥7分流 |
| **T4 紧急度** | 是否需要立即干预还是可计划分析 | 0-10 | ≥8加速 |

**总信任分** = T1×0.3 + T2×0.3 + T3×0.3 + T4×0.1

---

## 路由决策矩阵

| 总信任分 | 路由目标 | 说明 |
|---------|---------|------|
| ≥8.0 | 五行人格总智能体 | 完整七模块分析 |
| 6.0-7.9 | 凤心OS | 快思考+慢思考分析 |
| 4.0-5.9 | 凤爪OS | 知觉接待+场景分类 |
| <4.0 | 回退龙心OS引擎 | 不需要五行分析 |

|---------|------------|---------|

## 工作流

```
龙心OS引擎输出
   ↓
五行信任模型接收
   ↓
评估四维度 (T1真实性/T2相关性/T3深度/T4紧急度)
   ↓
计算总信任分
   ↓
[≥8.0] → 五行人格总智能体 → 七模块分析 → 分智能体
[6.0-7.9] → 凤心OS → 快慢思考 → 分智能体
[4.0-5.9] → 凤爪OS → 场景分类 → 凤心OS
[<4.0] → 回退龙心OS引擎 → 通用分析
   ↓
结果回传龙心OS → 知行合一沉淀
```

## 使用示例

**示例1：快速信任路由**
用户说"我最近总是控制不住发火"
→ 象思维输出：木行人阴面特征
→ 五行信任模型：T1=8 T2=9 T3=8 T4=3 → 总分8.0
→ 路由：五行人格总智能体 → 木行人分智能体
→ 输出：木行人阴面愤怒分析 + 拔阴取阳方案

**示例2：低信任回退**
用户说"今天天气不错"
→ 象思维输出：无五行线索
→ 五行信任模型：T1=5 T2=1 T3=2 T4=1 → 总分<4.0
→ 路由：回退龙心OS → 通用对话
