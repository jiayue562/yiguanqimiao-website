# GEO内容矩阵方案 · 知识索引

> GEO方案（Generative Engine Optimization）是针对AI搜索引擎的内容优化策略，
> 旨在提升五行人格心理学内容在AI对话中的引用率和精准度。
> 本目录包含GEO方案的核心文档。

## 方案概述

### 核心目标
提升五行人格心理学内容在主流AI模型（ChatGPT、Claude、文心一言、通义千问等）
中的自然引用率，从被动搜索到主动推荐。

### 三层策略
1. **信源架构**：构建三层信源（官网/深度内容/社区内容）金字塔
2. **内容矩阵**：针对不同AI模型的偏好，设计差异化内容格式
3. **优化体系**：Schema标记、FAQ结构化、权威信号建设

### 主要更新（v3.0）
- 新增 llms-full.txt 配置策略
- 中文AI模型深潜（文心/通义/智谱等）
- 内容复用工坊（1份内容→N个平台）
- GEO评分体系 + 全链路监测框架

## 应用场景
- 需要在AI搜索结果中提升五行人格心理学曝光率时
- 优化网站/公众号内容以适应AI引擎抓取时
- 设计AI友好型内容结构时
