## 🚀 使用示例

### 示例1：用户想了解自己的五行类型
```
用户："我是什么五行？我做事比较急，但也很细心"
调度流程：
1. 五行人格心理学OS接收输入
2. 调用意图识别器 → 识别为"自我认知·人格测评"
3. 调用场景分类器 → 分类为P1-自我认知
4. 调用五行推断引擎 → 行为信号扫描（急躁→火+25%，细心→土+25%）
5. 输出：火土混合型（火0.68，土0.55）
6. 路由至：火行人分智能体 + 土行人分智能体
```

### 示例2：用户咨询亲密关系问题
```
用户："我老公总是沉默不语，我觉得他不在乎我"
调度流程：
1. 意图识别器 → 识别为"关系改善·亲密关系"
2. 场景分类器 → 分类为R1-亲密关系
3. 五行推断引擎（他人模式）→ 推断对方为水行人（内向/沉默/分析型）
4. 用户情绪识别 → 委屈+焦虑（土行阴面信号）
5. 路由至：亲密关系专项 → 水×土相生分析
6. 输出：土生金→金生水间接沟通策略
```

### 示例3：团队建设咨询
```
用户："我们团队最近内耗严重，怎么提升协作效率？"
调度流程：
1. 意图识别器 → 识别为"关系改善·团队建设"
2. 场景分类器 → 分类为W2-团队建设
3. 五行推断引擎（多人模式）→ 团队五行分布诊断
4. 路由至：五行人格总智能体 → 团队诊断模式
5. 输出：五行团队互补配置建议 + 沟通策略
```
