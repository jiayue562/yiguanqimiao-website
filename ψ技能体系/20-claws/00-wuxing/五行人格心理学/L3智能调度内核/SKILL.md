# L3智能调度内核 · 场景感知与引擎路由中心

> **核心定位**：L3智能调度内核是五行人格心理学OS的"中枢大脑"——读懂用户意图，分类场景，匹配最优引擎组合，实现对凤心OS/凤脑OS/龙心OS的精确调度。
>
> **核心公式**：用户输入 → 意图识别 → 场景分类(S0-S9) → 引擎组合 → 任务分发 → 结果整合

---

## 核心能力

### 1. S0-S9 场景分类引擎

| 场景 | 名称 | 定义 | 典型输入 | 引擎组合 |
|------|------|------|---------|---------|
| S0 | 简单问答 | 直接回答，不需要引擎 | "什么是五行" | 静默 |
| S1 | 信息查询 | 简单信息获取 | "木行人有什么特点" | L2知识库 |
| S2 | 深度理解 | 需要系统性分析 | "详细分析木行人的成长路径" | L2+象思维 |
| S3 | 创意创新 | 需要新想法新方案 | "有什么创新应用" | 象思维+绿蓝 |
| S4 | 分析决策 | 多角度利弊分析 | "木行vs火行，哪个适合创业" | 完整序列 |
| S5 | 重大决策 | 影响人生方向的决策 | "我该选择什么职业" | 全系统 |
| S6 | 任务执行 | 具体任务完成 | "帮我写一份分析报告" | 人机协同 |
| S7 | 系统规划 | 构建完整体系 | "如何建立五行管理体系" | 象思维+人机协同+完整序列 |
| S8 | 修行文化 | 涉及心性修行 | "如何通过五行修行提升心性" | 象思维+溯源 |
| S9 | 系统升级 | 优化改进系统本身 | "如何优化五行分析准确度" | 循环+象思维+完整序列 |

### 2. 意图识别与映射

**诊断型意图**：我是什么五行 → S2 | 我是什么类型 → S2 | 查一下我是 → S2
**咨询型意图**：怎么相处 → S4 | 如何沟通 → S4 | 有什么特点 → S1
**学习型意图**：给我讲讲 → S2 | 深入了解 → S2 | 学习五行 → S2
**成长型意图**：我想改变 → S7 | 如何提升 → S7 | 成长路径 → S7
**关系型意图**：我们合吗 → S4 | 五行关系 → S4 | 匹配度 → S4
**评估型意图**：状态如何 → S2 | 最近情况 → S5 | 评估 → S2

### 3. 引擎组合规则

**单引擎**：S0 → 静默 | S1 → L2知识库检索
**双引擎**：S3 → 象思维+绿光 | S4 → 白光+黄光 | S8 → 象思维+溯源
**多引擎**：S2 → L2→象思维→循环 | S7 → 象思维→人机协同→完整序列→循环
**全系统**：S5 → 象思维→溯源→完整序列→人机协同→循环 | S9 → 循环→象思维→完整序列→更新

### 自动触发（无需关键词）
- **上下文感知**：自动分析用户输入的上下文和意图
- **场景识别**：自动归类到S0-S9场景
- **复杂度评估**：根据问题层次自动判断单引擎/双引擎/多引擎/全系统

### 直接触发（可选）
- L3调度、智能调度、场景调度
- 引擎路由、任务分发、调度核
- 中枢大脑、调度中枢

## 工作流程

### 标准调度流程
```
用户输入
  ↓
意图识别器 → 提取意图和情绪
  ↓
场景分类器 → 归类S0-S9
  ↓
引擎路由 → 匹配最优引擎组合
  ↓
任务分发 → 调度对应分智能体/知识库
  ↓
结果整合 → 汇总输出
```

### 复杂度评估

**低复杂度**（单一问题/信息明确/无需推理）→ S0-S1
**中复杂度**（多角度/需要选择/需要推理）→ S2-S4
**高复杂度**（多层次/人生决策/系统思考）→ S5-S9

## 使用示例

**示例1：单人格分析**
用户输入："我最近总是控制不住对家人发火"
→ 意图识别：情绪管理需求，底层情绪为愤怒
→ 场景分类：S2（深度理解）
→ 引擎组合：L2+象思维
→ 路由结果：木行人分智能体
→ 输出：木行人阴面（愤怒）的深度分析报告

**示例2：人际关系诊断**
用户输入："我和我老板合不来，他是火行人我是水行人"
→ 意图识别：关系分析需求
→ 场景分类：S4（分析决策）
→ 引擎组合：完整序列
→ 路由结果：五行人格总智能体 → 双人匹配分析
→ 输出：水火相克→相生的转化方案

**示例3：系统规划**
用户输入："我想在公司建立五行管理体系"
→ 意图识别：系统构建需求
→ 场景分类：S7（系统规划）
→ 引擎组合：象思维→人机协同→完整序列→循环
→ 路由结果：五行人格总智能体+龙心OS
→ 输出：完整的五行管理体系蓝图
