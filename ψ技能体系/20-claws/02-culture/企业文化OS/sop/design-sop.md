# 企业文化设计SOP

> **版本**: v1.0 | **创建**: 2026-04-10

## 前置条件

- [ ] 诊断报告已完成并确认
- [ ] 企业核心决策层可参与共创
- [ ] 至少安排2次共创工作坊时间

## SOP步骤

### Step 1: 共创准备（1天）
1. 精读诊断报告，提炼核心发现
2. 设计共创工作坊流程
3. 准备所需物料（大白纸、便签纸、PPT）

### Step 2: 文化共创工作坊①（0.5天）
**主题: 融入时代 + 经营心法**
1. 八观诊断结果呈现与讨论
2. 使命-愿景-价值观共创
3. 十二要素框架讨论
4. 输出: 文化大纲初稿

### Step 3: 方案细化（2天）
1. 融入时代八观定稿
2. 经营心法十二要素细化
3. 基于价值观的行为定义

### Step 4: 文化共创工作坊②（0.5天）
**主题: 氛围营造 + 礼乐仪式 + 功勋体系**
1. 八要素氛围方案讨论
2. 仪式体系创意设计
3. 功勋体系框架确认
4. 输出: 文化方案v2

### Step 5: 方案完善（2天）
1. 氛围营造要素设计
2. 礼乐仪式流程编写
3. 功勋评定标准制定
4. 商学院课程规划

### Step 6: 整合校验（1天）
1. 各模块一致性校验
2. 价值观行为对照
3. 可行性评估
4. 企业大事件编排

### Step 7: 输出交付（0.5天）
1. 生成完整企业文化设计方案
2. 制作汇报PPT
3. 向高管团队最终汇报

## 后置条件

- [ ] 设计方案通过审核
- [ ] 各模块内容完整一致
- [ ] 实施计划已附在方案中
