# 企业文化落地SOP

> **版本**: v1.0 | **创建**: 2026-04-10

## 前置条件

- [ ] 文化设计方案已通过审核
- [ ] 落地的资源和预算已确认
- [ ] 各部门负责人已明确职责

## SOP步骤

### Phase 1: 理念宣贯（第1-4周）

#### 第1周: 启动会
1. 召开全员文化启动大会
2. 创始人/CEO文化布道
3. 文化手册发放（全员）

#### 第2-3周: 全员培训
1. 文化必修课（2小时/场）
2. 分组研讨（价值观行为讨论）
3. 文化承诺签署

#### 第4周: 文化考试
1. 文化知识测试（≥85分及格）
2. 文化理解分享会
3. 培训效果评估

**验收标准**: 文化培训覆盖率≥95%，考试通过率≥90%

### Phase 2: 氛围营造（第3-8周）

1. VI系统全面上线（办公环境、物料、数字化平台）
2. 企业歌曲录制
3. 着装规范实施
4. 称呼体系推行
5. 24节气文化主题墙

**验收标准**: 视觉覆盖率≥90%，员工知晓率≥90%

### Phase 3: 制度嵌入（第5-10周）

1. 价值观纳入绩效考核（权重≥15%）
2. 文化行为积分制度上线
3. 奖惩机制与文化对齐
4. 招聘标准加入文化匹配度

**验收标准**: 考核体系上线运行，员工理解度≥80%

### Phase 4: 仪式固化（第7-12周）

1. 晨会文化分享环节（5分钟/天）
2. 月度文化之星评选
3. 季度文化主题活动
4. 年度文化盛典

**验收标准**: 仪式执行率≥95%，员工参与率≥80%

### Phase 5: 传承固化（第9周起持续）

1. 商学院文化课程系列开发
2. 师徒制推行
3. 文化故事库建设
4. 文化大使选拔

**验收标准**: ≥5门课程开发完成，师徒结对率≥80%

## 后置条件

- [ ] 各阶段验收完成
- [ ] 文化健康度首次测评完成（目标≥75分）
- [ ] 进入持续迭代循环
