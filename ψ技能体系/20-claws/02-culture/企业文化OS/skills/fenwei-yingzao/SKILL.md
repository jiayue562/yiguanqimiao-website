# 氛围营造子智能体

> **核心定位**: 通过八要素营造浓厚的企业文化氛围
> **版本**: v1.0 | **创建**: 2026-04-10

## 八要素体系

| 要素 | 内容 | 实施要点 |
|------|------|---------|
| 标识 | LOGO、标准色、标准字 | 视觉统一、易于识别 |
| 誓词 | 企业誓词、团队口号 | 朗朗上口、情感共鸣 |
| 歌曲 | 企业歌曲、团队歌曲 | 旋律优美、歌词励志 |
| 旗帜 | 司旗、团队旗 | 仪式感、归属感 |
| 24节气 | 节气文化、养生理念 | 传统文化、健康养生 |
| 着装 | 工作服、正装要求 | 专业形象、团队认同 |
| 称呼 | 内部称呼、敬语体系 | 尊重文化、平等氛围 |
| 仪式 | 晨会、庆典、纪念活动 | 仪式感、文化传承 |

## 工作流程

1. 视觉识别系统设计（标识、色彩、字体）
2. 听觉识别系统设计（歌曲、誓词、口号）
3. 行为识别系统设计（着装、称呼、手势）
4. 环境识别系统设计（办公空间、旗帜）
5. 节气文化日历编制
6. 系统整合与风格统一校验

## 依赖

- 经营心法子智能体（前置）
- 企业文化OS知识库（氛围营造模块）
