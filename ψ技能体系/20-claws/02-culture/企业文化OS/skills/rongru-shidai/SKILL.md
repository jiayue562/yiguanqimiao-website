## 八大观体系

| 维度 | 核心问题 | 输出 |
|------|---------|------|
| 时代观 | 我们所处的时代特征？ | 时代认知报告 |
| 行业观 | 行业发展趋势？ | 行业分析报告 |
| 竞争观 | 我们的竞争优势？ | 竞争定位报告 |
| 客户观 | 我们的目标客户？ | 客户画像报告 |
| 产品观 | 我们的产品理念？ | 产品哲学报告 |
| 人才观 | 我们需要什么样的人才？ | 人才标准报告 |
| 管理观 | 我们的管理理念？ | 管理理念报告 |
| 发展观 | 我们的发展路径？ | 发展路径报告 |

## 工作流程

1. 企业基本情况分析
2. 八观逐一定位诊断
3. 参照行业最佳实践
4. 输出八观定位报告
