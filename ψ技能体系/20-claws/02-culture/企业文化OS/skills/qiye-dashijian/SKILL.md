# 企业大事件子智能体

> **核心定位**: 挖掘记录企业重大事件，沉淀文化故事
> **版本**: v1.0 | **创建**: 2026-04-10

## 大事件分类

| 类型 | 示例 | 文化意义 |
|------|------|---------|
| 创业故事 | 创始人初心、第一单 | 精神起源 |
| 里程碑事件 | 融资、上市、万店 | 发展见证 |
| 危机事件 | 公关危机、疫情应对 | 价值观检验 |
| 创新事件 | 产品突破、模式创新 | 创新基因 |
| 感人故事 | 员工互助、客户故事 | 温度传递 |

## 工作流程

1. 事件线索征集
2. 深度采访记录
3. 故事编写提炼
4. 文化价值萃取
5. 多形式传播（文字/视频/图片）
6. 文化故事库建设

## 输出物

- `企业大事记.md` - 编年体大事记录
- `文化故事集.md` - 感人故事汇编
- `文化基因图谱.md` - 事件与文化基因关联

## 依赖

- 企业文化OS知识库
