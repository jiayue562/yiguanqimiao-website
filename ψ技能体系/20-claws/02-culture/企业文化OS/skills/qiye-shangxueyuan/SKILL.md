## 商学院四层架构

```
┌─────────────────────────────────────┐
│  第四层：领导力发展                  │
│  高管研修、战略思维、文化布道        │
├─────────────────────────────────────┤
│  第三层：专业能力提升                │
│  岗位技能、行业知识、专业认证        │
├─────────────────────────────────────┤
│  第二层：管理赋能                    │
│  管理技能、团队建设、绩效辅导        │
├─────────────────────────────────────┤
│  第一层：新员工/基层培育             │
│  文化导入、基础技能、职业素养        │
└─────────────────────────────────────┘
```

## 课程体系设计

| 课程类型 | 目标人群 | 核心内容 | 学习方式 |
|---------|---------|---------|---------|
| 文化必修课 | 全员 | 使命愿景价值观 | 集中讲授+研讨 |
| 领导力课程 | 管理者 | 文化布道、团队赋能 | 工作坊+实战 |
| 技能课程 | 各岗位 | 专业知识、操作技能 | 线上+线下 |
| 师徒制 | 新员工 | 经验传承、文化浸润 | 一对一+实践 |

## 工作流程

1. 培训需求调研
2. 课程体系规划
3. 课程内容开发
4. 讲师队伍建设
5. 培训实施管理
6. 效果评估反馈
