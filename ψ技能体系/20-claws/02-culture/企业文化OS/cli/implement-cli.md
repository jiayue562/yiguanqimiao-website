# 企业文化落地CLI · 命令行操作入口

> **版本**: v1.0 | **创建**: 2026-04-10 | **维护者**: 龙龟神将

## 核心定位

将文化设计方案转化为可执行、可追踪、可评估的落地实施计划。

## 命令清单

| 命令 | 功能 | 示例 |
|------|------|------|
| `企业文化落地` | 启动完整落地流程 | `企业文化落地 --方案="design.md"` |
| `文化落地检查` | 检查落地进度 | `文化落地检查 --阶段="第一阶段"` |
| `文化效果评估` | 评估落地效果 | `文化效果评估 --周期="季度"` |
| `文化迭代优化` | 基于反馈迭代方案 | `文化迭代优化 --反馈="feedback.md"` |

## 参数规范

| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `--设计方案` | path | 方案路径 | `--设计方案="./design.md"` |
| `--阶段` | string | 实施阶段 | `--阶段="第一阶段"` |
| `--试点部门` | string | 试点部门 | `--试点部门="人力资源部"` |
| `--周期` | string | 实施周期 | `--周期="3个月"` |
| `--反馈` | path | 反馈数据 | `--反馈="./feedback.md"` |
