## 核心定位

基于诊断报告启动企业文化顶层设计，输出完整文化体系方案。

## 命令清单

| 命令 | 功能 | 示例 |
|------|------|------|
| `企业文化设计` | 启动完整设计流程 | `企业文化设计 --诊断报告="report.md"` |
| `文化理念提炼` | 提炼使命愿景价值观 | `文化理念提炼 --关键词="创新,客户第一"` |
| `文化体系构建` | 构建四层文化体系 | `文化体系构建 --重点="制度层,行为层"` |
| `文化手册生成` | 生成企业文化手册 | `文化手册生成 --格式="markdown"` |

## 参数规范

| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `--诊断报告` | path | 诊断报告路径 | `--诊断报告="./diagnose.md"` |
| `--重点模块` | array | 重点设计模块 | `--重点模块="经营心法,氛围营造"` |
| `--风格偏好` | enum | 传统/现代/融合 | `--风格偏好="融合"` |
| `--输出` | path | 输出路径 | `--输出="./design.md"` |
