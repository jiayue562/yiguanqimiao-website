# 企业文化诊断CLI · 命令行操作入口

> **版本**: v1.0 | **创建**: 2026-04-10 | **维护者**: 龙龟神将

## 核心定位

企业文化诊断CLI是企业文化OS的原生操作入口，提供极简、语义清晰的命令行接口。

## 命令清单

| 命令 | 功能 | 示例 |
|------|------|------|
| `企业文化诊断` | 启动完整诊断流程 | `企业文化诊断 --企业="XX科技"` |
| `文化现状扫描` | 快速扫描文化现状 | `文化现状扫描 --部门="销售部"` |
| `文化问题识别` | 识别文化痛点 | `文化问题识别 --类型="沟通"` |
| `文化健康度评估` | 评估文化健康度 | `文化健康度评估 --维度="精神层"` |

## 参数规范

| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `--企业` | string | 企业名称 | `--企业="XX科技"` |
| `--行业` | string | 行业类型 | `--行业="互联网"` |
| `--规模` | string | 企业规模 | `--规模="100-500人"` |
| `--诊断类型` | enum | 全面/快速/专项 | `--诊断类型="全面"` |
| `--调研方法` | array | 问卷/访谈/观察 | `--调研方法="问卷,访谈"` |
| `--样本量` | int | 调研样本数量 | `--样本量=100` |
| `--输出` | path | 输出路径 | `--输出="./report.md"` |
