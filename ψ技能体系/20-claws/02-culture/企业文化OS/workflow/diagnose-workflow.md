# 企业文化诊断工作流

> **版本**: v1.0 | **创建**: 2026-04-10

## 流程图

```
需求接收 → 资料收集 → 工具设计 → 调研执行 → 数据分析 → 报告生成
```

## 详细步骤

### 1. 需求接收
- 确认企业基本信息
- 明确诊断范围和目标
- 确定调研方法和样本量

### 2. 资料收集
- 企业历史文档（使命愿景价值观材料）
- 经营数据（业绩、离职率、满意度）
- 已有文化资产盘点

### 3. 工具设计
- 四层文化模型问卷
- 高管访谈提纲
- 员工座谈提纲
- 现场观察清单

### 4. 调研执行
- 问卷发放与收集（建议样本量≥30%员工数）
- 三级深度访谈（高管/中层/基层各≥3人）
- 现场观察（≥3个工作日）

### 5. 数据分析
- 沙因三层次分析
- 五行团队构成分析
- 差序格局关系分析
- 量化评分（各维度1-10分）

### 6. 报告生成
- 诊断结论
- 核心问题排序
- 改进建议清单
- 文化健康度评分卡

## 诊断工具清单

| 工具 | 用途 | 形式 |
|------|------|------|
| 四层文化问卷 | 量化文化现状 | 问卷星/腾讯问卷 |
| 高管访谈提纲 | 深度了解战略层面 | 一对一访谈 |
| 员工座谈提纲 | 了解基层真实感受 | 小组座谈 |
| 现场观察清单 | 捕捉日常行为 | 观察记录表 |
| 数据统计模板 | 量化分析 | Excel/SPSS |

## 输出物

- `企业文化诊断报告.md`
- `文化健康度评分卡.xlsx`
- `改进建议清单.md`
