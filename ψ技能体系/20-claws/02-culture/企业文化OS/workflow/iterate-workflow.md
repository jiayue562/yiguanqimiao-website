# 企业文化迭代工作流

> **版本**: v1.0 | **创建**: 2026-04-10

## 迭代周期

标准迭代周期: **季度**（3个月）

## 迭代四步法

### 1. 数据收集（第1周）
- 员工满意度调查（年度/半年度）
- 文化健康度复测
- 行为一致性观察
- 离职访谈数据分析
- 部门落地进展汇报

### 2. 差距分析（第2周）
- 目标状态 vs 当前状态对比
- 问题优先级排序
- 根因分析（5Why法）
- 影响范围评估

### 3. 方案调整（第3周）
- 优化方案设计
- 资源重新分配
- 时间表调整
- 负责人确认

### 4. 新循环启动（第4周）
- 新方案宣贯
- 更新迭代后的SOP
- 进入下一轮实施

## 迭代决策树

```
评估结果显示：
├── 健康度≥85分 → 维持现有方案，进入固化阶段
├── 70≤健康度<85 → 局部优化，调整薄弱环节
└── 健康度<70 → 全面复盘，重新诊断
       ├── 文化认知问题 → 强化培训宣贯
       ├── 制度执行问题 → 优化制度嵌入
       └── 领导力问题 → 高管文化赋能
```

## 健康度评分体系

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| 文化认同度 | 25% | 员工对使命愿景价值观认同比例 |
| 行为一致性 | 25% | 日常行为与价值观匹配度 |
| 制度嵌入度 | 20% | 文化纳入考核/激励的程度 |
| 仪式参与度 | 15% | 员工自愿参与仪式的比例 |
| 文化传播度 | 15% | 员工正向传播文化的意愿 |
