**H-BRAND-03**: 8级字体层级 × 倒三角赋能
```

H3-H4(正文/L3指挥层) ────────────│
英文/数据/脚注(L4执行层) ────────┘
```

**H-BRAND-04**: 视觉禁区8条 × 紧箍咒
- 禁区 = 唐僧紧箍咒：保护不是惩罚，约束为了成就

- ❌渐变色 = 纯粹不掺杂（匠心精神）
- ❌>5色 = 克制美学（少即是多）

**H-BRAND-05**: 暖白底色 #F9F8F4 × 文化罗盘
- 白饕餮(客户中心) = 暖白底色(以客户舒适的视角)
- 米白#DAD3C2 = 呼吸空间 = 客户感受的"余地"
- 色温≤4000K = 温度感 = 以食载道传递美好

**H-BRAND-06**: pptxgenjs代码 × 龙爪OS技术执行层
