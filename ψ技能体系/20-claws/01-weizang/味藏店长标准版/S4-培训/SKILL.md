# S4 培训引擎 · 技能培训+系统指引

> "培训不是一次性的事，是每天都要做的事。忙起来放下的培训，就是明天的窟窿。"
> 对应7S维度：培训（Training）| 对应旧版N模块：N6技能引擎·培训部分

---

## 一、核心定义

### 三件套

| 关键动作 | 频率 | 做法 |
|---------|------|------|
| 🥇 技能差距诊断 | 每月 | 对照岗位技能标准→识别短板→制定培训计划 |
| 🥇 新系统操作指引 | 按需 | 你说操作目标→AI给分步指引→图片参考 |
| 🥇 培训效果追踪 | 每周 | 培训完成率→实际操作考核→效果评估 |

### 资源分配

- 时间：培训计划 30min/周 | 新系统指引 按需5-15min/次
- 人力：组长负责岗前培训 | 店长负责技能认证
- 预算：培训材料费 ≤300元/月

### 数据验证指标

- 培训计划完成率（目标≥90%）
- 技能认证通过率（目标≥80%首考通过）
- 新系统操作效率提升（目标每2周提速20%）

```

完成状态：□进行中 □已完成 □未开始

```

### 新系统操作指引

你说："想看昨天酒水销售数据"
AI回应：
  1. 打开系统 → 点击"营业报表"菜单
  2. 选择"酒水"分类
  3. 日期范围设为"昨天"
  4. 数据字段：销售额/成本/毛利/占比（自动计算好推给你）

### 食材验收培训 [松山湖版]

```
验收标准 → 图片参考 → 历史异常案例 → 实操考核
验收清单：
  □ 三文鱼：颜色/纹理/温度
  □ 金枪鱼：色泽/弹性/气味
  □ 贝类：活力/外壳/气味
  □ 蔬菜：新鲜度/重量/包装
```
