# S6 营销引擎 · 线上引流+外卖运营

> "营销不是花钱做广告，是让对的人看到你的好。"
> 对应7S维度：营销（Marketing）| 对应旧版N模块：N6技能引擎·营销部分

---

## 一、核心定义

### 三件套

| 关键动作 | 频率 | 做法 |
|---------|------|------|
| 🥇 每日营销动作清单 | 每天 | 线上推内容+线下追客户+效果追踪 |
| 🥇 外卖差评响应 | 实时 | AI出回复草稿→店长确认→根因追踪 |
| 🥇 营销效果复盘 | 每周 | 线上数据+线下转化+费用分析→下周方向 |

### 资源分配

- 时间：每日营销 ≤20min | 差评响应 ≤10min | 周复盘 30min
- 人力：店长负责营销决策 | 组长协助执行
- 预算：周营销费用 ≤____元 | 差评补偿 ≤200元/单

### 数据验证指标

- 线上曝光量（目标月环比+20%）
- 外卖差评率（目标↓50%）
- 营销ROI（目标≥3:1）

```

店长确认（≤30min）→ AI自动回复

AI记录根因 → 追踪改进进展 → 周汇总
```

## 三、三店差异

| 项目 | [金月湾版] | [松山湖版] | [狮山版] |
|------|-----------|-----------|---------|
| 营销优先级 | 中（有稳定客源） | 低（A档店无需重点） | 🔥最高（最大短板） |
| 最大痛点 | 跨部门营销支持慢 | 无突出痛点 | 线上没人看到+外卖差评 |
| 侧重点 | 线下大客户维护 | 口碑维护 | 线上引流+外卖优化 |
| 推送频率 | 每天1次 | 每周2次 | 每天2次🔥 |

### [狮山版] 外卖优化三板斧

```
第1板斧·出餐流程优化：高峰期外卖插队出餐+指定交接人
第2板斧·包装升级：检查材料库存+防漏操作培训
第3板斧·差评响应：30min内AI出稿→店长确认→回复→根因追踪
```
