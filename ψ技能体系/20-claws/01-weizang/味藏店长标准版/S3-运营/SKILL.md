# S3 运营引擎 · 日反馈+巡检+夕会

> "运营不是做流程，是让流程为人所用。日反馈从1.5h到20min的差距，就是AI的价值。"
> 对应7S维度：运营（Operation）| 对应旧版N模块：N3流程引擎

---

## 一、核心定义

### 三件套

| 关键动作 | 频率 | 做法 |
|---------|------|------|
| 🥇 日反馈标准化 | 每天 | AI自动填数据→店长做判断题→异常高亮 |
| 🥇 电子巡查表 | 每天 | AI推模板→店长勾选→问题进路由 |
| 🥇 夕会材料预审 | 每天 | AI预审组长报告→三级清单→明日巡查初稿 |

### 资源分配

- 时间：日反馈 ≤30min | 巡检 ≤20min | 夕会 ≤15min
- 人力：组长负责数据填报 | 店长负责审核判断
- 工具：电子巡查模板 + 日反馈自动填充 + 夕会预审系统

### 数据验证指标

- 日反馈完成时间（目标≤30min [金月湾]/ ≤20min [松山湖]/ ≤40min [狮山]）
- 巡检完成率（目标100%/天）
- 夕会问题闭环率（目标≥90%）

## 二、触发后的行为

### 日反馈流程

```
AI自动填充：
  今日营业额 / 成本率 / 翻台率 / 好评率 / 客诉数 / 三单元完成率

人工判断（只打钩）：
  □ 今日异常项已确认（高亮项无异议）
  □ 问题分类（1级____ / 2级____ / 3级____）
  □ 昨日问题已闭环（未闭环的：____）
  □ 明日重点（3条以内）

完成时间：____:____（目标≤30min）
```

### 电子巡查模板

```
🥇 昨日遗留复查： □ 问题_____已解决 □ 未解决→追踪

前厅：□人员站岗 □摆台达标 □卫生死角
厨房：□备料表执行 □出品标准 □冰箱温度/储存 □先进先出
[金月湾版] 加: ⭐食材验收专项（琴姐强项）
[松山湖版] 加: 熟客偏好确认
[狮山版]   加: ⭐外卖区出餐流程检查
```

### 夕会材料预审

```
AI预审组长报告 → 标记"可能遗漏"项 → 推店长校验
  ↓
店长校验：
  □ 组长报告质量（完整/有遗漏/不认真）
  □ 今日问题已闭环
  □ 明日重点已明确
  □ 文化交付已检查
  ↓
生成：三级问题清单 + 明日巡查初稿
```

## 三、三店差异

| 项目 | [金月湾版] | [松山湖版] | [狮山版] |
|------|-----------|-----------|---------|
| 日反馈耗时 | 1.5h→目标≤30min🔥 | 20min→维持 | 30-40min→目标≤40min |
| 最大卡点 | 张燕青数据不熟+固执 | 已优化，维持即可 | 新系统不熟练 |
| 巡检重点 | 食材验收（店长强项） | 熟客服务+环境 | 外卖出餐+出品 |
| 夕会模式 | 店长补充型 | 组长主导型 | 店长主导型 |
| AI策略 | 重填充+校验 | 轻推送+维持 | 补模板+引导 |

## 五、风险控制

| 等级 | 场景 | 处置 |
|------|------|------|
| 🟢 轻微 | 日反馈超时15min内、巡检漏1项 | AI提醒+补填 |
