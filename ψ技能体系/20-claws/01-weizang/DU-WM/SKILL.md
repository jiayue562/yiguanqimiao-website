## 四、外卖专属五大红线

```
R-01: ★**食品安全**（外卖配送任何等级) → 一票否决D级+追责
R-02: **配送严重超时**(>30min占比>10%) → 当日St扣20%
R-03: **评价严重下滑**(满意度<4.0连续3天) → S扣15%+整改
R-04: **数据造假**(外卖营业额/利润) → 绩效归零+解职
R-05: ★外卖专属-配送体验崩溃: 及时率<90%→St扣20%+客户补偿
R-06: ★外卖专属-平台合规违规: 活动违规→绩效归零+平台处罚
```

## 五、五大SOP（土行人务实细节版）

1. **线上运营五步法**: 菜单设计→价格策略→活动策划→评价管理→数据分析（土行人务实运营）
2. **配送体验四步法**: 接单→备餐→配送→售后（土行人细节控）
3. **外卖数据巡检六步法**(每日): 营业额→利润→及时率→满意度→评价分析→异常处理
4. **骑手管理五步法**: 招募→培训→排班→激励→留存（土行人团队凝聚）
5. **平台活动策划七步法**: 目标确认→活动设计→价格测算→平台申报→执行监控→效果评估→迭代优化
