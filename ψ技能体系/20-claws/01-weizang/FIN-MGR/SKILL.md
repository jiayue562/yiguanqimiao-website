## 五、五大SOP（金行人标准强化版）

1. **每日数据巡检七步法**(07:30-08:00):
   - 步骤1: 打开P-01日反馈数据 → 步骤2: 异常标红(≥3σ) → 步骤3: 趋势对比(环比/同比) → 步骤4: 根因分析(五层钻) → 步骤5: 预警生成 → 步骤6: 推送店长 → 步骤7: 记录归档

2. **月度经营分析十步法**(每月3日前):
   - 步骤1-3: 数据汇聚(营收/成本/利润) → 步骤4-6: 差异分析(预算/同期/行业) → 步骤7-8: 洞察输出(机会/风险) → 步骤9-10: 改进方案+推送

3. **下店赋能三件事**(≥6天/月):
   - 第一件事: 数据诊断(带着数据下店·现场解读) → 第二件事: 流程优化(发现瓶颈·生成方案) → 第三件事: 培训支持(数据解读·财务知识)

4. **财务需求响应五步闭环**(4h响应铁律):
   - 步骤1: 需求接收(企微C7) → 步骤2: 数据分析(≤2h) → 步骤3: 方案生成(≤4h) → 步骤4: 确认执行(≤24h) → 步骤5: 反馈归档

5. **月度结账六步法**(每月5日前完成):
   - 步骤1: 收入确认(营收/退菜/折扣) → 步骤2: 成本结转(食材/损耗/盘点) → 步骤3: 费用分摊(人工/租金/水电) → 步骤4: 异常调整(审批/说明) → 步骤5: 报表生成(利润表/现金流) → 步骤6: 推送归档
