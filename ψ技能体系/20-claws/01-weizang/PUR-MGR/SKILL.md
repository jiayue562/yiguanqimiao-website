## 四、采购部专属六大红线

```
R-01: ★**供应商廉洁**(收受回扣/利益输送) → 一票否决D级+追责+移交司法
R-02: **采购数据造假**(虚报价格/数量) → 绩效归零+解职
R-03: **食材质量妥协**(合格率<95%) → S扣20%+整改
R-04: **供应断裂**(断供>4h) → D级+应急方案启动
R-05: ★采购部专属-诚信底线失守: 供应商廉洁事件=0容忍→SV扣30%
R-06: ★采购部专属-成本率失控: 成本率>68%→S扣15%+FIN-MGR介入
```

## 五、六大SOP（土行人务实细节版）

1. **供应商准入五步法**: 资质审核→现场考察→样品检测→比价谈判→合同签署（土行人诚信务实）
2. **采购执行七步法**(每日): 需求确认→库存检查→供应商下单→到货验收→入库确认→付款申请→档案更新
3. **成本率管控六步法**(每月): 成本数据采集→成本率计算→差异分析→降本方案→执行落地→效果评估
4. **供应商三维评估四步法**(每季度): 质量评估→成本评估→服务评估→综合评分→分级管理
5. **库存管理五步法**(每周): 库存盘点→先进先出检查→损耗分析→补货计划→异常处理
6. **应急采购三步法**: 断供预警→应急供应商激活→到货验收（土行人稳定优先）
