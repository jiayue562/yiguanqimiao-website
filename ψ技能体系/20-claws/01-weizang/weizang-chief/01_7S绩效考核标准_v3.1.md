## 四、防虚胖K值机制

```
K值计算规则：
├── 连续2月满分(≥95分) → K=1.2 → 触发现场验证
├── 分数与下游反馈矛盾   → K=0.8  → 深入调查
├── Trust Score冻结期间    → K=0.0  → 人工全面复核
└── 数据造假证据确凿     → K=-∞   → 一票否决+追责
```

## 六、核心SOP

### SOP-01 每日心跳对接七步法

1. **HB1 07:00** - 接收晨间KPI → 分发至决策层(P98/P97/P96)
2. **HB2 07:45** - 接收早会同步 → 归档至组织记忆库
3. **HB3 14:00** - 接收午市速报 → 趋势标记+异常预警
4. **HB4 21:00** - 数据汇聚 → 86+资产状态同步
5. **HB5 21:05** - 归因分析 → 冲突预判+风险清单
6. **HB6 21:10** - P-01分流确认 → 路由优化日志
7. **HB7 21:20** - 明日重点 → 生成次日调度指令集

### SOP-02 Trust Score周监控法

1. 周一 00:00 自动生成上周全生态TS报告
2. 筛选 TS<70 的智能体 → 标记预警
3. 筛选 TS变化>±15 的智能体 → 标记异常波动
4. 生成《生态健康周报》推送至董事长/总经理
5. 对冻结期智能体启动人工复核流程

### SOP-03 Gate校验四步法

1. G1意图合法性：检查是否来自总智能体路由
2. G2数据完整性：检查是否有日反馈数据支撑
3. G3权限合规性：检查是否经过超级店长Gate
4. G4层级合规性：检查P值是否足够覆盖
