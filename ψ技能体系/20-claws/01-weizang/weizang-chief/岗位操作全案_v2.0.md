## 三、7大场景入口SOP

### 场景1: 📊 今日数据
**触发词**: "昨天营业额""今天数据""多少""达成"
```
用户输入 → E1意图识别(数据查询) → 路由日反馈引擎 
→ 返回6数字+异常归因+vs昨日对比
→ 人确认是否需要深入分析
```

### 场景2: 🔍 巡检问题
**触发词**: "维修单""巡检""问题""整改"
```
用户输入 → E1意图识别(门店运营) → 路由店长总控N3
→ 返回标准巡检流程+问题描述模板
→ 可选: 创建工单→路由对应部门
```

### 场景3: 👥 人员面谈
**触发词**: "找XX谈谈""面谈""员工""谈话"
```
员工输入 → E1意图识别(人事管理) → 路由店长总控N5
→ 加载面谈SOP+员工档案+近期表现数据
→ 生成面谈提纲(人审核)
```

### 场景4: 🤝 跨部门协作
**触发词**: "需要支援""协作""跨部门""培训"
```
用户输入 → E1意图识别(跨部门) → E2超级店长Gate校验
→ Gate通过 → 路由目标部门Skill
→ 生成协作单+跟踪闭环
```

### 场景5: 🎯 战略方向
**触发词**: "目标""战略""本月""计划"
```
用户输入 → E1意图识别(战略) → 路由董事长/总经理(P=98/97)
→ 返回月度战略简报+解码路径
→ 可选: 深入某维度展开
```

### 场景6: 💡 文化判断
**触发词**: "价值观""文化""符合""对不对"
```
用户输入 → E1意图识别(文化) → 路由HRD/董事长
→ 七维价值观逐项比对+案例参考
→ 输出文化对齐报告
```

### 场景7: 📦 供应链
**触发词**: "食材""到货""供应商""缺货"
```
用户输入 → E1意图识别(供应链) → 路由采购经理PUR-MGR
→ 供应链追踪+预计到货时间+备选方案
```

## 四、Trust Score动态管理SOP

### 4.1 评分计算规则

```
初始分 = 80
每日变动:
  连续无异常 +0.1（封顶100）
  响应准确率>95% +0.3/周
  被投诉查实 -5
  Gate违规 -10 → 冻结
  超时未响应 -0.3/次
  主动上报异常 +1

P值浮动: Trust Score每±10 → P值±1（每层浮动上限±3）
```

### 4.2 冻结期处理流程

```
冻结触发(TS<50 或 3次Gate违规)
    ↓
P值降至该层最低值
    ↓
所有调度需人工复核（7天）
    ↓
连续14天零违规
    ↓
TS恢复≥70 → 解冻
```

## 五、禁止行为清单（7条）

| # | 禁止行为 | 正确做法 | 违规后果 |
|---|---------|---------|---------|
| 1 | 绕过总智能体直接调用分智能体 | 所有请求必须经过总智能体入口 | 三次违规→TS冻结 |
| 2 | 跳过日反馈做战略判断 | 必须基于日反馈数据做判断 | 输出降级为"参考信息" |
| 3 | 两部门私下跳过Gate协作 | 所有跨部门调用经Gate校验 | Gate拦截退回 -5分 |
| 4 | 店长直接指挥前厅/后厨 | 通过店长总控→三单元总→执行 | 指令被否决 |
| 5 | 用董事长智能体处理日常运营 | 自动路由到总经理 | 拒绝并重定向 |
| 6 | 心跳时段发起编排请求 | 排队等待心跳完成 | 延迟执行 |
| 7 | 直接叫智能体名而非场景描述 | 引导使用场景入口 | 系统仍路由但提示改进 |

## 六、三大协同接口

### 6.1 与决策层协同
- **董事长(CHMN-BRAIN)**: 战略文化类请求上浮；文化敏感内容联合审查
- **总经理(GM-CHIEF)**: 运营类请求上浮；战略解码后分发赋能层
- **超级店长**: Gate校验前置；编排请求必须经过Gate

### 6.2 与数据服务层协同
- **日反馈(v3.1)**: 定时接收HB1-HB7数据；心跳时段不抢占资源
- 数据流向: 日反馈 → 总智能体 → 全生态推送

### 6.3 与赋能/执行层协同
- **六部门+三单元**: 经Gate校验后调度；返回结果统一格式化
- **店长总控+三马车**: 执行结果回流；异常自动上升

## 七、应急处理预案

| 场景 | 触发条件 | 处理流程 |
|------|---------|---------|
| 系统过载 | QPS>100或延迟>2s | 启动降级模式：只保核心场景(数据+巡检) |
| Skill离线 | 核心Skill>30min无响应 | 自动切换备用实例+告警 |
| 死循环 | 同一请求循环>3次 | 熔断拦截+人工介入+根因记录 |
| 价值观风险 | 输出触碰红线关键词 | 即时拦截+审计追溯+人工复核 |
| Trust Score暴跌 | TS单日下降>15分 | 冻结保护+全面审计+24h内修复 |
