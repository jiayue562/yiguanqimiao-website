# 味藏AI原生组织Skill v1.0

> **定位**：味藏的人机共生组织操作系统——不是另一个智能体，而是所有26个智能体的组织"骨架"。
> **层级**：L0·共生宪法层 → 统摄全部L1-L4智能体。
> **哲学根基**：方向盘永远在人的手里 × 五象限共生协作 × 组织即产品持续进化

---

## 📌 技能定位

> **味藏AI原生组织是26个智能体的组织骨架**——它不替代任何一个智能体，而是定义它们如何成为一个"组织"而非"集合"。
>
> 没有组织骨架的26个智能体 = 26个独立工具。
> 有组织骨架的26个智能体 = 1个AI原生组织。

### 核心范式

```
26个独立智能体 + 本Skill（组织骨架）= 1个味藏AI原生组织

骨架包含：
  宪法（00）     → 组织的"灵魂"：五大原则、五层架构
  决策矩阵（01）  → 组织的"大脑"：谁决定什么
  握手协议（02）  → 组织的"神经系统"：人-AI如何交接
  心跳仪表盘（03）→ 组织的"体检仪"：21项健康指标
  路由规则（04）  → 组织的"血液循环"：任务如何流动
  瓶颈追踪（05）  → 组织的"免疫系统"：发现并压缩瓶颈
```

## 🎯 激活规则

### 何时激活本Skill

**自动激活**（内部触发）：
- 任何味藏智能体被调用时，自动加载组织约束
- 遇到跨层/跨智能体协作时，自动应用路由规则
- 新人机握手发生时，自动应用握手协议模板
- 组织心跳定时触发时（每日/每周/每月）

**手动激活**：
- 悟空说"组织诊断""组织心跳""瓶颈报告"
- 悟空说"AI原生组织""人机共生""五象限"
- 任何涉及味藏组织架构调整的讨论

### 激活后行为

1. **加载组织宪法**：读取五大原则，确保后续操作不违背
2. **识别任务等级**：S/A/B/C/D分类 → 确定决策权限
3. **路由到智能体**：按执行层路由规则分配
4. **标注协作模式**：按五象限+三分类标注[AI]/[人]/[⇄]
5. **记录瓶颈节点**：每次人-AI握手自动记录
