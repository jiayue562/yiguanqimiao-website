# product-training 产品培训Skills 操作全案 v1.0
> **核心公式**：操作全案 = 5场景路由(S1-S5) × 6引擎(M1-M6) × 4份references × 34触发词 = 可分发·可验证·龙心OS P=91自动调度

## 一、五大场景

### S1 话术开发场景
**触发**：新品上市 / 菜品改良 / 话术老化 / 季节更换
**流程**：
1. 产品工艺采集（SOP-01六步法）：食材→工艺→口感→卖点→故事→价格
2. 话术提炼（SOP-02四步法）：卖点→利益→情感→行动
3. 3+1结构化（3个卖点+1个匠心故事）
4. G1知识验证（闭卷考试≥90分）
5. 录入话术手册 → 同步至前厅

### S2 前厅培训场景
**触发**：新人入职 / 话术更新 / 技能抽查 / 定期复训
**流程**：
1. 培训需求确认（人数/时间/内容）
2. SOP-03五步闭环：听得懂(复述) → 会做(实操) → 能落地(72h回访) → 通过(G2) → 认证(发证)
3. 三遍教学法克制火行人急躁
4. 培训记录归档
5. 通过率<60% → 全店重训

### S3 销售场景设计
**触发**：活动策划 / 旺季备战 / 弱项提升 / 新客转化
**流程**：
1. 目标客户画像（老饕/商务/家庭/情侣）
2. 场景剧本设计（SOP-04四步循环）：入场→体验→推荐→成交
3. MOT关键时刻（10个接触点）优化
4. 角色扮演演练
5. 效果追踪（7日数据）

### S4 匠心故事采集
**触发**：品牌升级 / 文化落地 / 课程开发 / 内容营销
**流程**：
1. 后厨访谈（主厨/料理长）
2. 工艺故事挖掘（食材来源/制作难点/匠心细节）
3. 故事结构化（起承转合）
4. 文化元素注入（以食载道/季节/产地）
5. 多媒体素材（文字+图片+视频脚本）

### S5 考核与通关
**触发**：月度考核 / 认证评审 / 晋升评定
**流程**：
1. 话术考试（闭卷≥90分）
2. 实操演练（自然流畅+客人无感知）
3. 7日数据追踪（转化率提升）
4. 通关卡发放（通过/不通过/待补考）
5. 认证档案更新
