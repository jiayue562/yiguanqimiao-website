# 🍣 味藏顶层设计 · Skill v1.0

> **架构提示**：本 Skill 为战略层顶层设计框架。执行层智能体架构已升级为 **味藏总智能体(P=94·宪法层) → SM-CHIEF 店长7S总控(P=92·调度层) → 7S岗位Skills(P=90)** 三层架构。参见 味藏总智能体、味藏店长标准版/总控 获取执行层架构详情。

> **核心定位**：餐饮企业从"个人魅力"到"系统能力"的顶层设计系统化框架
> **核心问题**："如何将个人魅力与经验，转化为可复制的系统能力？"
> **一句话定义**：通过文化→战略→运营→人才四维联动，实现企业可持续发展的系统化顶层设计。

---

## 📖 核心定义

### What（是什么）

味藏顶层设计是**餐饮企业四维驱动管理系统**，包含：
- **文化层**（L1-L7）：心文化全息体系——使命→愿景→价值观→图腾→罗盘→根基→护航
- **战略层**（S1-S5）：三重重生战略体系——愿景解码→重生能力→单元定位→属性定义→共同体闭环
- **运营层**（O1-O6）：营业额增长飞轮系统——组织→引擎→同轴→SOP→客户流转→数据闭环
- **人才层**（T1-T5）：559型干部复刻体系——实战培养→人格匹配→标准化复制→赛马机制→激励体系

**核心公式**：味藏未来发展 = (文化铸魂 × 战略定向 × 运营筑基 × 人才造血) ^ 时间
- 乘法关系：四维缺一不可，任何一维为零则整体为零
- 时间指数：强调复利效应和持续进化
- **经济生命体**：企业不是静态组织，而是具备自我更新、代谢和进化能力的有机生命

### Why（为什么）

**痛点诊断**：
- 🔴 依赖创始人个人魅力，难以复制
- 🔴 各模块独立存在，缺乏有机联系
- 🔴 知识传承靠口头，人员流失=知识流失
- 🔴 战略与执行脱节，文化落不了地
- 🔴 人才梯队断层，扩张受限于人才

**解决价值**：
- ✅ 四维集成，形成有机整体
- ✅ 明确联动因果链，闭环驱动
- ✅ 含Phase 1/2/3实施路线图
- ✅ 新增SOP、检查表、模板工具
- ✅ 含PDCA闭环与迭代机制

### How（怎么做）

**1+5模式智能调度**：
- **1个总智能体**：味藏顶层设计总调度——场景识别→维度归类→引擎路由→结果整合
- **5个子智能体**：
  - 🏛️ 文化层智能体（心文化全息体系）
  - 🎯 战略层智能体（三重重生战略）
  - ⚙️ 运营层智能体（营业额增长飞轮）
  - 👥 人才层智能体（559型干部复刻）
  - 🔄 四维联动智能体（协同机制）

**使用流程**：
```
用户需求 → 场景归类 → 智能路由 → 子智能体深度分析 → 结果整合 → 输出报告
```

### Step 3: 子智能体深度分析

根据路由结果，调用对应子智能体执行标准流程：

#### 🏛️ 文化层智能体（7步流程）
1. **使命诊断**：检测使命清晰度与行为一致性
2. **愿景解码**：将愿景转化为阶段性目标
3. **价值观审计**：八大观行为化程度评估
4. **图腾能量**：饕餮图腾+老饕赋的品牌应用
5. **罗盘校准**：五方饕餮能量闭环检测
6. **根基稳固**：定海神针双层架构评估
7. **护航机制**：匠心+三昧真火+紧箍咒落地检查

#### 🎯 战略层智能体（5步流程）
1. **愿景解码**：一生二二生三三生万物的阶段映射
2. **重生评估**：机制/人才/文化三重生的健康度
3. **单元定位**：堂食/酒水/外卖三单元的差异化诊断
4. **属性定义**：经济生命体五属性（纯粹/高利润/可复制/有灵魂/自适应）
5. **共同体闭环**：使命/事业/利益三层关系评估

#### ⚙️ 运营层智能体（6步流程）
1. **组织诊断**：三单元岗位矩阵的合理性
2. **引擎检测**：营业额三线（堂食+酒水+外卖）的健康度
3. **同轴校准**：质性价比←匠心←紧箍咒的联动状态
4. **SOP审计**：口味稳定+上菜快+服务适时的执行度
5. **流转优化**：客户流转图（入口→客户池→储值→高客单→裂变）
6. **数据闭环**：三仪表盘+PDCA的运转状态

#### 👥 人才层智能体（5步流程）
1. **培养诊断**：559型干部轮岗路径的执行情况
2. **匹配评估**：五行人格与岗位的匹配度
3. **复制检查**：师徒制+技能认证的运转状态
4. **赛马机制**：优胜劣汰+项目制的公平性
5. **激励审计**：三共同体激励体系的有效性

#### 🔄 四维联动智能体（5步流程）
1. **文化→战略**：根脉是否决定方向
2. **战略→运营**：方向是否指导执行
3. **运营→人才**：执行是否反哺培养
4. **人才→文化**：人是否显道成循环
5. **协同评分**：四维协同度量化评估

#### 👤 董事长讲话·人才管理模块（7步流程）
1. **问题诊断**：识别"老的上去，新的留不住"的根因
2. **店长职能定义**：明确"用人、管人、让人成长"的范畴
3. **筛选机制设计**：建立"7天-半月-1月"筛选流程
4. **培养体系搭建**：业务链培训→ 目标设定→ 协助完成→ 存在感
5. **薪酬工具化**：薪酬作为吸引人才工具，非成本负担
6. **文化机制化**：从感情牌到制度，建立红线意识
7. **组织架构优化**：三驾马车（经理+料理部+店长）协同

**输出标准**：
```yaml
人才管理方案:
  店长职能: [明确范畴]
  筛选流程: [7天/半月/1月]
  培养体系: [业务链→目标→协助→存在感]
  薪酬设计: [工具化方案]

  组织架构: [三驾马车]
  预期效果: [留存率提升/管理效率]
```

- 🚫 将味藏顶层设计视为"通用模板"直接套用——每家企业需要定制化适配
