> **核心金句**："月度考核的本质不是'打分'，而是'校准'——校准方向、校准节奏、校准信心" [G-PERF-01]

> **核心公式**：
> ```
> 绩效考核智能体 v2.0 = 日数据汇聚(日反馈HB1-HB7) × 7S诊断引擎(店长7S总控)

> 原象-Q3: 3604万 = 罗盘（非计分板）

## 一、范式跃迁声明

### 1.1 从"事后评价"到"实时导航"

| 维度 | 旧范式（传统考核） | 新范式（AI+人实时校准） |
|:------|:-------------------|:-------------------------|
| **节奏** | 月度打分，30天等一次 | 每日校准，21:00日反馈黄金窗口自动诊断 |
| **数据** | 人工收集，月底突击填充 | AI自动汇聚(日反馈HB1)→自动填充→人确认(IC-01) |
| **诊断** | 凭印象打分 | 7S雷达图自动生成→5Why归因→PDCA建议 |
| **权重** | 固定不变 | 季度动态重算(企业微信C8推送审定) |
| **防虚胖** | 月底发现已晚 | 每日预警→连续2月触发自动面谈 |
| **反馈** | 面谈="通知结果" | GROW面谈="共同校准"→绩效面谈卡(C9推送) |
| **红线** | 年底才发现 | 实时监控→触碰即熔断→C11红色警报 |
| **透明** | 只有HR和上级知道 | 个人可通过企业微信查看实时达标率 |
| **对标** | 无 | 三店对比雷达图→C12月度对标推送 |

### 5.2 7S全维度自动评分算法

```python
def E2_7S_scoring(position_id, month_data):
    """
    E2引擎核心评分算法
    输入：岗位ID + 月度累计数据
    输出：7S雷达图 + 五档定级 + 红黄绿灯标注
    """
    
    # Step1: 获取岗位7S权重
    weights = get_7S_weights(position_id)  # 从18岗位权重表获取
    
    # Step2: 逐维度评分
    scores = {}
    for dimension in ['SV', 'S', 'St', 'Sy', 'Sty', 'Sf', 'Sk']:
        kpis = get_kpis(position_id, dimension)
        raw_score = 0
        for kpi in kpis:
            # 五档评分转化
            actual = month_data[kpi.id]
            target_S = kpi.target_S  # 卓越目标
            target_A = kpi.target_A  # 优秀目标
            target_B = kpi.target_B  # 达标目标
            
            if actual >= target_S:
                kpi_score = 100  # S档
            elif actual >= target_A:
                kpi_score = 85 + (actual - target_A) / (target_S - target_A) * 15  # A档
            elif actual >= target_B:
                kpi_score = 75 + (actual - target_B) / (target_A - target_B) * 10  # B档
            else:
                kpi_score = max(0, actual / target_B * 75)  # C/D档
            
            raw_score += kpi_score * kpi.weight
        
        scores[dimension] = raw_score
    
    # Step3: 加权总分
    total = sum(scores[d] * weights[d] for d in scores) / 100
    
    # Step4: 加减分项
    total += calculate_bonus_penalty(position_id, month_data)  # ±10%
    
    # Step5: 红黄绿灯标注
    lights = {}
    for d, s in scores.items():
        if s >= 90: lights[d] = '🟢'
        elif s >= 75: lights[d] = '🟡'
        else: lights[d] = '🔴'
    
    # Step6: 五档定级
    if total >= 95: grade = 'S'
    elif total >= 85: grade = 'A'
    elif total >= 75: grade = 'B'
    elif total >= 60: grade = 'C'
    else: grade = 'D'
    
    return {
        'total': round(total, 1),
        'grade': grade,
        'dimensions': scores,
        'lights': lights,
        'radar_chart': generate_radar(scores),
        'trend': compare_to_last_month(position_id, total)
    }
```

def E4_dual_track_scoring(position, data):
    """
    根据岗位轨道类型采用不同的评分侧重
    """
    track = B09_position_classifier(position)  # B-09岗位分类器
    
    if track == 'entrepreneurial':  # 创业单元

        if data['revenue_streak'] >= 3:

    elif track == 'non_entrepreneurial':  # 非创业单元

        process_weight_multiplier = 1.2

        if data['penalty_closure'] == 100:

        if data['mentorship_executed'] == False:
            max_grade = 'B'
