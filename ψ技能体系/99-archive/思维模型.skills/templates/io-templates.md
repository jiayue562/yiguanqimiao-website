**版本**: v1.0

## 输入模板

### 基础输入

```json
{
  "project_name": "项目名称",
  "step_name": "步骤名称",
  "problem_description": "问题描述",
  "context": "背景信息",
  "constraints": "约束条件",
  "expected_output": "期望输出"
}
```

### 简化输入

```
项目：[项目名称]
步骤：[步骤名称]
问题：[问题描述]
```

### 自然语言输入

```
"我想 [做什么]，需要用什么思维模型？"
"这个 [问题类型] 适合用什么模型分析？"
"推荐 [场景] 的模型组合"
```

## 示例

### 示例 1: 概念分析

**输入**:
```
项目：超级个体落地
步骤：概念分析
问题：如何理解超级个体的本质？
```

**输出**:
```markdown
# 思维模型推荐

## 推荐模型
1. 第一性原理
2. MECE 原则

## 使用说明
### 第一性原理
- **适用场景**: 理解概念本质
- **核心思想**: 从基本原理出发，剥离表象
- **使用步骤**:
  1. 剥离表象：超级个体不是什么？
  2. 找到本质：超级个体的核心是什么？
  3. 从本质出发：如何构建超级个体？

### MECE 原则
- **适用场景**: 拆解复杂概念
- **核心思想**: 相互独立，完全穷尽
- **使用步骤**:
  1. 定义整体：超级个体的完整要素
  2. 分类拆解：确保相互独立、完全穷尽
  3. 检查验证：无重叠、无遗漏

## 预期输出
- 超级个体本质分析文档
- 超级个体要素拆解图
```

## 错误处理

### 错误 1: 问题描述不清晰

**错误提示**:
```
⚠️ 问题描述不够清晰

请补充:
1. 具体是什么问题？
2. 问题的背景是什么？
3. 期望的输出是什么？

示例:
"我想分析超级个体这个概念的落地可行性，
需要从哪些角度分析？期望输出分析报告。"
```

### 错误 2: 模型推荐失败

**错误提示**:
```
⚠️ 未找到合适的思维模型

可能原因:
1. 问题类型不明确
2. 超出思维模型适用范围

建议:
1. 重新描述问题
2. 联系龙心 OS 寻求其他帮助
```
