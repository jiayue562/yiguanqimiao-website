## 📋 技能定义

### 核心定位

**思维模型.skills**是龙爪 OS 的方法论工具库，负责将龙脑 OS 的 100 个思维模型转化为项目化的应用工具，每个步骤采用 1-N 个思维模型解决问题。

> "思维模型.skills 是龙爪 OS 的'工具箱'，每个工具都是一个思维模型。"

### 核心功能

- **模型推荐**: 根据项目步骤推荐思维模型
- **模型组合**: 多模型并行应用
- **模型解释**: 提供模型使用说明
- **模型路由**: 根据场景自动选择模型
- **反馈学习**: 持续优化模型推荐

### 系统归属

| 系统 | 归属 | 说明 |
|------|------|------|
| **思维模型.skills** | ✅ 本体 | 龙爪 OS 子技能 - 方法论工具 |
| **龙爪 OS** | ✅ 上级 | 龙爪 OS 调用思维模型.skills |
| **龙脑 OS** | ✅ 协同 | 提供思维模型知识库 |

### 调用关系

```
龙心 OS 决策
    ↓
龙爪 OS 执行项目
    ↓
调用思维模型.skills
    ↓
根据步骤推荐 1-N 个思维模型
    ↓
应用模型 → 输出结果 → 知行合一沉淀
```

## 🔄 工作流程

### 标准工作流

```
项目步骤
    ↓
思维模型.skills 接收请求
    ↓
模型路由器推荐 1-N 个模型
    ↓
提供模型使用说明
    ↓
应用模型 → 输出结果
    ↓
反馈学习 → 优化推荐
```

### 示例：超级个体落地项目

**步骤 1: 概念分析**
- 推荐模型：第一性原理 + MECE 原则
- 使用说明：从基本原理出发，拆解超级个体概念
- 输出：超级个体本质分析文档

**步骤 2: 市场调研**
- 推荐模型：SWOT 分析 + 波特五力
- 使用说明：分析市场机会和竞争格局
- 输出：市场机会评估报告

**步骤 3: 产品设计**
- 推荐模型：象思维 + 商业模式画布
- 使用说明：0→1 原创设计产品
- 输出：产品方案

**步骤 4: 落地实施**
- 推荐模型：知行合一 + PDCA 循环
- 使用说明：制定执行计划并持续优化
- 输出：执行计划

**步骤 5: 复盘优化**
- 推荐模型：5Why 分析法 + 五色光思维
- 使用说明：找到根本原因，多维度复盘
- 输出：优化建议
