# 龙爪OS 工作流程与SOP开发指南

## 5阶20步标准化流程

### 第1阶：需求分析（5步）
1. **明确目标用户和使用场景**：谁用、什么场景下用
2. **定义核心功能和边界**：做什么、不做什么
3. **分析竞品和参考案例**：已有方案分析
4. **确定成功指标**：可量化的验收标准
5. **输出需求文档**：PRD或需求规格

### 第2阶：架构设计（5步）
1. **设计Skill整体架构**：分层、模块、接口
2. **定义输入输出格式**：I/O模板
3. **设计触发规则**：关键词、场景、自动
4. **设计协同路由**：与其他Skills的交互
5. **输出架构文档**：包含架构图和数据流

### 第3阶：内容填充（5步）
1. **编写SKILL.md核心定义**：使命、功能、工作流
2. **编写references/理论原文**：理论基础
3. **编写references/实践指南**：实操步骤
4. **编写I/O模板**：输入输出示例
5. **编写触发配置**：自动触发规则

### 第4阶：测试验证（5步）
1. **设计测试用例**：至少5个，覆盖核心路径
2. **执行功能测试**：每个功能点验证
3. **执行边界测试**：异常输入、极限场景
4. **收集测试反馈**：记录问题和改进
5. **输出测试报告**：通过率、准确率

### 第5阶：封装发布（5步）
1. **编写CHECKLIST.md**：质量检查清单
2. **编写完成报告**：交付物清单
3. **同步到三个知识库**：Agents/Obsidian/OpcClaw
4. **配置自动触发规则**：auto-activate, trigger-rules
5. **正式发布并通知用户**：release note
