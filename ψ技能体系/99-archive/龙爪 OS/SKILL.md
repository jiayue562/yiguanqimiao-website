## 🧭 龙爪OS执行逻辑

龙爪OS本身不进行场景识别（由龙心OS调度），但自带三层执行路由：

| 层级 | 路由条件 | 目标 | 说明 |
|------|---------|------|------|
| L1·直接执行 | 需求明确、有对应子技能 | 直接调用对应子技能 | 无需中间处理 |
| L2·组合执行 | 需求跨多个子技能 | 自动组合多个子技能 | 按依赖关系排序 |
| L3·反馈执行 | 执行结果需要联动调整 | 执行→反馈→调整→再执行 | 闭环迭代 |

**工作流**：龙心OS场景识别 → 龙爪OS接收指令 → L1/L2/L3路由判断 → 调用对应子技能 → 结果整合返回

## 📋 技能定义

### 核心定位

**龙爪 OS**是龙心 OS 的专业领域库和执行引擎，负责将龙心 OS 的决策和龙脑 OS 的思维模型转化为具体的项目、工作流和 SOP。

> "龙心 OS 是'大脑'（决策），龙脑 OS 是'知识'（记忆），龙爪 OS 是'手脚'（执行）。"

### 核心功能

- **项目执行**: 将抽象目标转化为具体步骤
- **工作流管理**: 标准化流程执行
- **SOP 应用**: 标准作业程序应用
- **思维模型整合**: 每个步骤采用 1-N 个思维模型
- **进度跟踪**: 实时监控执行进度
- **反馈学习**: 持续优化执行效率

### 系统归属

| 系统 | 归属 | 说明 |
|------|------|------|
| **龙爪 OS** | ✅ 本体 | 龙心 OS 执行引擎 |
| **龙心 OS** | ✅ 上级 | 龙心 OS 调用龙爪 OS 执行具体任务 |
| **龙脑 OS** | ✅ 协同 | 提供思维模型支持 |

### 调用关系

```
用户输入
    │
    ▼
龙心 OS（调度中枢）
    │
    ├── 调用 ──→ 龙脑 OS（方法论引擎）
    │               │
    │               └── 提供思维模型
    │
    └── 调用 ──→ 龙爪 OS（执行引擎）
                    │
                    ├── 项目执行
                    ├── 工作流管理
                    ├── SOP 应用
                    └── 每个步骤采用思维模型
```
