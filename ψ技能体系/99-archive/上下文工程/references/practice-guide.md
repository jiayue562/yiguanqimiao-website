# 实操指南

## 快速开始
- 保存: "先保存进度，下次继续"
- 恢复: "继续之前的工作"

## 快照模板
```markdown
## 项目/任务信息
## 已完成事项（含进度%）
## 关键决策记录（决策/依据/时间/文件）
## 待办事项（高/中/低）
## 关键上下文（概念/数据/文件路径）
## AI记忆状态（Skills/引擎/知识库）
## 风险提示
## 会话摘要（产出/建议/确认）
## 接力说明（恢复方式+相关快照）
```

## 最佳实践
1. 每完成一个子任务或每30轮对话生成快照
2. 保留快照历史，不覆盖
3. 快照间用双向链接连接
4. 快照中嵌入相关知识库文件引用
