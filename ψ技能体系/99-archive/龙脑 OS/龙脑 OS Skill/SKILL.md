## 技能定义
### 核心定位

**龙脑 OS Skill**是龙心 OS 五大引擎之"脑"——方法论引擎。龙心 OS 负责感知场景（环境层）和决策调度（认知层），龙脑 OS 负责提供思考的工具和方法。当龙心 OS 识别出需要结构化分析的问题时，自动调度龙脑 OS 的思维模型。

> "龙脑 OS 不是思维模型本身，而是调度思维模型的方法论引擎。"

| 属性 | 龙脑 OS Skill | 龙心 OS（调度中枢） |
|------|------------|---------------|
| **核心职能** | 方法论引擎 | 场景识别 + 智能路由 |
| **调度范围** | 100+ 思维模型 + 麦肯锡工具 + 教员方法论 | S0-S9 场景 + 1+5 子智能体 |
| **输出内容** | 思维框架 + 分析模板 + 工具组合 | 决策建议 + 行动方案 |
| **协作模式** | 被龙心 OS 调用 | 调用龙脑 OS 解决实际问题 |

### 系统归属

| 系统 | 归属 | 说明 |
|------|------|------|
| **龙心 OS** | 不属 | 龙心 OS 调用龙脑 OS |
| **龙脑 OS** | 属于 | 龙脑 OS 方法论调度引擎核心 |
| **龙爪 OS** | 同级 | 龙爪 OS 执行龙脑 OS 的方案 |

### 架构示意

```
龙心 OS（感知+决策）
    └── 调用龙脑 OS（方法论引擎）
            ├── 思维模型库（100 个模型）
            ├── 麦肯锡工具集
            ├── 教员方法论
            └── 易经错综复杂思维等独立 Skill
                    方案输出 → 龙爪 OS 执行落地
```

## 理论基础
### 核心定位

**龙脑 OS Skill**是龙心 OS 五大引擎之"脑"部分，管理 100+ 思维模型库、100+ 麦肯锡工具、教员方法论和易经错综复杂思维。龙心 OS 通过 S0-S9 场景识别矩阵判断用户所处的场景类型，按权重自动路由到龙脑 OS 的对应思维模型。
> "龙脑 OS 不是代替你思考，而是让你的思考更有章法。"

### 核心功能

- **场景路由**：S0-S9 场景识别 + 模型权重匹配
- **组合方案**：多模型组合生成分析框架
- **按需加载**：根据场景加载对应的思维模型
- **工具集成**：集成麦肯锡工具 + 教员方法论

### 方法论体系

龙脑 OS 的方法论分为四层：

1. **底层思维**（15 个）：MECE、金字塔原理、第一性原理、系统思维、归纳法、演绎法等
2. **认知与定位**（18 个）：SWOT、PEST、BCG 矩阵、波特五力、核心竞争力分析等
3. **问题与执行**（18 个）：5 Whys、PDCA、OKR、KPI、SMART、RACI 等
4. **增长与创新**（52-100 个）：飞轮效应、网络效应、蓝海战略、颠覆式创新等
