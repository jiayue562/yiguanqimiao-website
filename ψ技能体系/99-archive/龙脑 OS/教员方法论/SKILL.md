## 核心定义

**教员方法论**是基于毛泽东《矛盾论》和《实践论》的系统性问题分析方法论。核心思想：发现问题就是解决问题的一半。通过识别主要矛盾和矛盾的主要方面，从实践中来、到实践中去。

> "事物发展的根本原因，不是在事物的外部而是在事物的内部，在于事物内部的矛盾性。"

## 核心框架

### 矛盾论

> **矛盾是普遍存在的**，每一事物的发展过程中存在着自始至终的矛盾运动。

| 概念 | 说明 | 应用 |
|------|------|------|
| **主要矛盾** | 决定事物发展的根本矛盾 | 找到最关键的问题 |
| **矛盾的主要方面** | 矛盾中起主导作用的方面 | 找到问题的关键要素 |
| **矛盾转化** | 矛盾双方在一定条件下转化 | 识别变化的契机 |

### 实践论

| 阶段 | 说明 | 方法 |
|------|------|------|
| **感性认识** | 从实践中获得的直接经验 | 观察、调查、收集事实 |
| **理性认识** | 经过思考提炼的本质认知 | 分析、归纳、提炼规律 |
| **指导实践** | 用认识去改造世界 | 制定方案、实施行动 |
| **检验修正** | 在实践中检验认识的正确性 | PDCA 循环验证 |

## 七步分析法

```
发现问题  ->  分析问题  ->  定位本质  ->  制定方案
     ->  实施行动  ->  检验效果  ->  总结提升
```

| 步骤 | 方法 | 关键提问 |
|------|------|----------|
| **发现矛盾** | 矛盾识别 | 当前面临的主要矛盾是什么？ |
| **调查事实** | 调查研究 | 实际情况到底如何？ |
| **分析主要矛盾** | 矛盾分析法 | 哪个矛盾起决定性作用？ |
| **矛盾主要方面** | 重点分析 | 矛盾双方哪一方是主要方面？ |
| **制定方案** | 实践计划 | 如何解决主要矛盾？ |
| **实践检验** | 实践论循环 | 方案在实践中效果如何？ |
| **总结经验** | 认识升华 | 从中学到了什么规律？ |

## 核心方法

### 调查研究

没有调查就没有发言权。调查的核心是：

| 原则 | 说明 | 方法 |
|------|------|------|
| **深入实际** | 到一线去了解情况 | 实地走访、深度访谈 |
| **全面系统** | 避免片面性 | 多维度收集信息 |
| **去伪存真** | 区分现象和本质 | 交叉验证数据 |

### 矛盾分析法

| 步骤 | 方法 | 示例 |
|------|------|------|
| **找矛盾** | 列出所有矛盾 | 销量下滑、人才流失、资金紧张 |
| **排主次** | 区分主要次要 | 主要矛盾是产品竞争力不足 |
| **定方面** | 找主要方面 | 产品研发能力是最主要方面 |
| **观转化** | 看矛盾转化趋势 | 竞争对手在快速迭代 |

### 实践检验法

```
实践 -> 认识 -> 再实践 -> 再认识
Plan -> Do -> Check -> Act
```

## 使用示例

**场景**：公司销售额连续下滑

**第一步：发现矛盾**
- 外部：市场竞争加剧、客户需求变化
- 内部：产品创新不足、团队执行力弱
- 主要矛盾：产品迭代速度跟不上市场需求

**第二步：分析矛盾的主要方面**
- 产品迭代慢的原因：研发团队人力不足 vs 流程效率低
- 主要方面：流程效率低（审批环节过多）

**第三步：制定方案**
- 优化产品开发流程
- 减少审批环节
- 建立快速迭代机制

**第四步：实践检验**
- 试点团队实施新流程
- 对比迭代周期变化
- 根据数据调整方案
