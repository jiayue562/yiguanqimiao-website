## 核心定义

**第一性原理**（First Principles Thinking）是一种回归事物最基本的公理和真理，从最基础不可动摇的事实出发，重新推演解决方案的思维方式。与"类比思维"相对。

> "第一性原理是物理学的思维方式——你把事物分解到最基本的真理，然后从那里向上推理。"——埃隆·马斯克

### 核心功能

- 打破思维定势，跳出类比框架
- 发现创新的根本可能性
- 从物理成本而非历史成本思考问题

### 适用场景

- 产品创新和技术突破
- 商业模式的底层重构
- 成本结构优化
- 战略方向的根本性思考

---

## 核心框架

### 分解方式

| 方式 | 描述 | 示例 |
|------|------|------|
| **物理分解** | 分解到物理/化学的基本属性 | 电池成本 = 原材料成本 + 制造成本 |
| **逻辑分解** | 分解到不可动摇的逻辑公理 | 需求 = 用户痛点 + 解决方案 |
| **事实分解** | 分解到可验证的客观事实 | 市场数据、客户反馈等 |

### 与类比思维的对比

| 维度 | 类比思维 | 第一性原理 |
|------|----------|------------|
| **出发点** | 现有方案/经验 | 基本原理/公理 |
| **思维路径** | 横向参考已有做法 | 纵向拆解到不可分 |
| **适用** | 渐进式改进 | 突破式创新 |
| **风险** | 容易陷入思维定势 | 需要大量基础研究 |

---

## 使用步骤

1. **识别现有假设**：列出所有"被认为是理所当然"的假设
2. **分解到基础要素**：追问"为什么会这样？"直到不可再分
3. **从基础重构方案**：基于基本真理推演新方案

---

## 使用示例

### 示例一：降低电池成本

```
类比思维：电池成本一直是 X 元/kWh，降本空间有限
第一性原理：
  -> 分解：电池材料（锂、钴、镍等）的原材料成本
  -> 发现：原材料成本仅占当前价格的 10%
  -> 重构：通过优化结构和制造工艺大幅降本
```

### 示例二：产品创新

```
假设：竞争对手都这样做，所以我们也应该这样做
第一性原理：
  -> 用户真正需要的是什么？
  -> 物理学上可行的最佳方案是什么？
  -> 从用户价值和物理原理重构产品
```
