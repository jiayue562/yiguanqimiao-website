## 核心定义

**MECE 分析法**（Mutually Exclusive, Collectively Exhaustive）是麦肯锡问题解决法的核心原则，要求所有分类和分解做到"相互独立、完全穷尽"。ME 确保不重叠，CE 确保不遗漏。

> "MECE 是麦肯锡思考质量的第一道门槛。"

### 核心功能

- 确保分析框架无重叠、无遗漏
- 提升结构化思维的严谨度
- 与金字塔原理、逻辑树等模型天然互补

### 适用场景

| 场景 | 应用 | 说明 |
|------|------|------|
| **问题分解** | 将复杂问题拆解为可处理子问题 | 如：收入 = 客单价 x 客户数 x 复购率 |
| **方案评估** | 穷尽所有可能的解决方案 | 确保没有遗漏选项 |
| **分组归类** | 将信息无重叠地归入不同类别 | 如：PEST 分析、4P 分析 |

## 核心框架

### MECE 的三种分解方式

| 方式 | 描述 | 适用场景 |
|------|------|----------|
| **公式法** | 用数学公式分解，如收入 = 价格 x 数量 | 有明确量化关系的场景 |
| **流程法** | 按流程步骤分解 | 有先后顺序的业务流程 |
| **分类法** | 按属性特征分类 | 信息归类和组织 |

## 使用步骤

### 步骤 1：定义核心问题

1. 明确要解决的问题及其边界
2. 确定分析的广度和深度

**关键要点**：
- 问题定义需要足够具体
- 避免模糊和宽泛的表述

### 步骤 2：选择分解维度

1. 根据问题性质选择最合适的分解方式
2. 确保选择的维度能够覆盖问题的全部

### 步骤 3：MECE 验证

1. 检查同一层级是否有重叠
2. 检查是否有遗漏项
3. 如有重叠或遗漏，调整分类标准

**验证清单**：
- [ ] 所有子项互不重叠
- [ ] 所有子项覆盖完整
- [ ] 子项之和等于整体

## 使用示例

### 示例一：收入分解（公式法）

```
MECE 收入分解：
收入 = 客单价 x 客户数 x 复购率
  -> 客单价：店内消费 + 线上消费
  -> 客户数：新客 + 老客
  -> 复购率：月度复购 + 季度复购
```

### 示例二：竞争分析（分类法）

```
MECE 竞争对手分类：
现有直接竞争者 + 潜在新进入者 + 替代品
  [直接竞争者 A] [直接竞争者 B]
  [潜在进入者 1] [潜在进入者 2]
  [替代品 X] [替代品 Y]
```
