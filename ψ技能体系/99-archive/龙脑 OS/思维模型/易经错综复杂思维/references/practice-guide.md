## 一、应用场景

### 1.1 适用场景

| 场景类型 | 具体问题 | 推荐卦变维度 |
|----------|----------|--------------|
| **复杂决策** | 职业选择/投资决策/战略方向 | 五卦全用 |
| **困境突破** | 业务瓶颈/关系僵局/个人迷茫 | 错卦 + 综卦 |
| **趋势判断** | 行业走向/市场变化/技术发展 | 本卦 + 变卦 |
| **多方博弈** | 谈判/协作/冲突处理 | 综卦 + 互卦 |
| **内在成长** | 自我认知/心智模式/信念转变 | 互卦 + 错卦 |

### 1.2 不适用场景

- 简单二元选择（用硬币决策即可）
- 紧急危机处理（先行动后反思）
- 纯技术性问题（用专业方法论）
- 创意灵感激发（用象思维/SCAMPER）

## 二、实操步骤详解

### 2.1 第一步：观现状（本卦）

**操作模板**:

```
【本卦分析】

1. 客观描述当前局面（3-5 句话）：
   

2. 识别核心要素（列出 3-5 个）：
   - 
   - 
   - 

3. 主要矛盾是什么（1 句话）：
   

4. 我的情绪状态（诚实记录）：
   
```

**常见误区**:
- ❌ 夹杂评判（"这个情况很糟糕"）
- ✅ 只描述事实（"用户增长率从 20% 降至 5%"）

**示例**:
> "我现在处于创业第 18 个月，产品已上线 6 个月，日活用户 5000 人，月收入 10 万元，但月支出 15 万元，现金流还能支撑 8 个月。核心矛盾是增长放缓与成本刚性。我感到焦虑但仍有信心。"

### 2.2 第二步：判趋势（变卦）

**操作模板**:

```
【变卦分析】

1. 当前的变化信号（变爻）是什么：
   

2. 按这个趋势，3 个月后可能怎样：
   

3. 按这个趋势，6 个月后可能怎样：
   

4. 最好的结局/最坏的结局：
   - 最好：
   - 最坏：
   
```

**常见误区**:
- ❌ 一厢情愿（只想象好结果）
- ✅ 客观推演（好坏都考虑到）

**示例**:
> "变化信号是获客成本持续上升。3 个月后，如果现状持续，现金流将减少 30%。6 个月后，可能面临融资或裁员。最好结局是找到新增长曲线，最坏结局是资金链断裂。"

### 2.3 第三步：挖内因（互卦）

**操作模板**:

```
【互卦分析】

1. 表面现象是什么：
   

2. 隐藏的内在结构（中间四爻）：
   - 下互卦（内因）：
   - 上互卦（外因）：

3. "你中有我，我中有你"的关联：
   

4. 真正驱动变化的力量：
   
```

**常见误区**:
- ❌ 停留在表面（"就是市场不好"）
- ✅ 深挖暗流（"产品价值主张不清晰"）

**示例**:
> "表面是增长放缓。内在结构：下互卦是团队执行力下降，上互卦是市场竞争加剧。关联：执行力下降导致产品迭代慢，产品迭代慢导致竞争力下降。真正驱动力是产品 - 市场匹配度不足。"

### 2.4 第四步：看反面（错卦）

**操作模板**:

```
【错卦分析】

1. 当前困境的正面描述：
   

2. 完全反转后的视角：
   

3. "否极泰来"的转机在哪里：
   

4. 潜在的可能性（列出 3 个）：
   - 
   - 
   - 
   
```

**常见误区**:
- ❌ 强行乐观（"一切都会好的"）
- ✅ 真正反转（"增长慢反而是打磨产品的机会"）

**示例**:
> "当前困境是增长放缓、资金紧张。反转视角：这是从'增长优先'转向'效率优先'的机会。转机：专注核心用户，提升 ARPU 值。潜在可能：1) 找到更精准的获客渠道 2) 开发高价值功能 3) 寻求战略投资而非财务投资"

### 2.5 第五步：换位观（综卦）

**操作模板**:

```
【综卦分析】

1. 我方的核心诉求：
   

2. 对方（投资人/用户/员工）的核心诉求：
   

3. 对方眼中的我：
   

4. 损益平衡点在哪里：
   
```

**常见误区**:
- ❌ 自我中心（"我觉得他们应该..."）
- ✅ 真正换位（"如果我是他，我会..."）

**示例**:
> "我方诉求：获得资金继续发展。投资人诉求：资金安全 + 回报可预期。投资人眼中的我：有潜力但风险高。平衡点：设定明确的里程碑，分阶段注资，降低双方风险。"

## 四、经典案例分析

### 4.1 案例一：创业困境

**背景**: 创业公司，产品上线 6 个月，增长放缓，资金紧张。

**五卦分析**:

| 卦变 | 分析 | 启示 |
|------|------|------|
| 本卦 | 增长从 20% 降至 5%，现金流还能撑 8 个月 | 认清现状，不逃避 |
| 变卦 | 按此趋势，6 个月后资金链断裂 | 必须改变 |
| 互卦 | 表面是市场问题，实际是产品 - 市场匹配不足 | 深挖内因 |
| 错卦 | 增长慢反而是打磨产品的好时机 | 寻找转机 |
| 综卦 | 投资人要的是可预期回报，不是盲目增长 | 换位思考 |

**决策**: 从"增长优先"转向"效率优先"，专注核心用户，提升 ARPU 值，设定明确里程碑寻求分阶段注资。

### 4.2 案例二：职业选择

**背景**: 大厂稳定工作 vs 创业公司机会。

**五卦分析**:

| 卦变 | 大厂 | 创业公司 |
|------|------|----------|
| 本卦 | 稳定、流程化、成长慢 | 不稳定、全面锻炼、成长快 |
| 变卦 | 3 年后可能遭遇瓶颈 | 3 年后可能财务自由或失业 |
| 互卦 | 内在是能力退化风险 | 内在是能力快速积累 |
| 错卦 | 稳定的反面是被淘汰 | 不稳定的反面是无限可能 |
| 综卦 | 老板视角：你是可替代的 | 老板视角：你是核心资产 |

**决策**: 根据人生阶段选择——有家庭责任选大厂，单身无负担选创业公司。

## 五、与麦肯锡工具协同

### 5.1 与 MECE 协同

- 五卦分析时，每个维度内部用 MECE 确保不重不漏
- 示例：分析"核心要素"时，用要素分解法

### 5.2 与金字塔原理协同

- 五卦分析结果用金字塔结构表达
- 结论先行：综合判断一句话
- 以上统下：五卦分析支撑结论

### 5.3 与空 - 雨 - 伞协同

| 空 - 雨 - 伞 | 对应五卦 |
|--------------|----------|
| 空（事实） | 本卦 + 互卦 |
| 雨（解释） | 变卦 + 错卦 |
| 伞（行动） | 综卦→行动方案 |

## 六、练习建议

### 6.1 新手练习路径

1. **第 1 周**: 每天用本卦分析一件小事（如"今天的工作状态"）
2. **第 2 周**: 增加变卦，练习趋势预判
3. **第 3 周**: 增加互卦，练习深挖内因
4. **第 4 周**: 完整五卦分析一个中等复杂度问题

### 6.2 进阶练习

- 每周一次完整五卦分析（复杂问题）
- 记录决策结果，验证卦变推演的准确性
- 建立个人"卦变案例库"

### 6.3 常见错误与纠正

| 错误 | 表现 | 纠正方法 |
|------|------|----------|
| 主观评判 | 本卦分析夹杂情绪 | 强制只写事实 |
| 一厢情愿 | 变卦只想象好结果 | 强制写好/坏两种结局 |
| 表面分析 | 互卦停留在表面 | 追问 3 个"为什么" |
| 强行乐观 | 错卦变成鸡汤 | 真正反转视角 |
| 自我中心 | 综卦还是"我觉得" | 真正角色扮演 |
