## 技能定义
### 核心定位

**思维模型库**是龙脑 OS 的核心组件，收录 100 个经全球验证的商业分析思维模型，涵盖逻辑思考、战略分析、问题解决、决策判断、组织管理、市场营销、创新创造、数据分析和系统思维九大领域。
> "思维模型是你大脑的 App，面对不同问题安装正确的 App。"

### 系统归属

| 系统 | 归属 | 说明 |
|------|------|------|
| **龙脑 OS** | 属于 | 龙脑 OS 方法论调度引擎核心组件 |
| **龙心 OS** | 不属 | 龙心 OS 调用龙脑 OS 解决问题 |

### 架构示意

```
龙脑 OS Skill（方法论引擎）
    └── 思维模型库（100 个模型）
            ├── 底层思维（15 个模型：MECE、金字塔、第一性原理等）
            ├── 认知与定位（18 个模型：SWOT、PEST、BCG 等）
            ├── 问题与执行（18 个模型：5Whys、PDCA、SMART 等）
            ├── 增长与创新（49 个模型：飞轮效应、蓝海战略等）
```

## 系统定位

1. **龙心 OS 感知层驱动**：龙心 OS 通过 S0-S9 场景识别矩阵判断场景后，自动路由到龙脑 OS 方法论库
2. **方法论与场景匹配**：每个场景映射 2-5 个最匹配的思维模型，按置信度排序
3. **模型组合生成方案**：根据问题复杂程度，自动组合 1-3 个模型形成完整分析框架
4. **持续迭代更新**：在实际使用中验证效果，定期更新模型库
