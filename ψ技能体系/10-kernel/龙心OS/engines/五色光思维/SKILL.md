# 五色光思维 Skill - 结构化集体思考与决策过程管理

> 🌈 通过白/红/黄/绿/蓝五色分治，实现同频思考、智慧凝聚、高质决策

**版本**: v1.0  
**构建日期**: 2026-04-17  
**定位**: 龙心 OS 核心思维工具，用于会议管理、决策支持、团队思考、问题分析、创意激发、绩效面谈

---

## 🎯 技能定位

**五色光思维**是基于德博诺六顶思考帽的东方化演进，通过白/红/黄/绿/蓝五色分治，实现结构化、同频化的集体思考与决策过程管理。

**核心价值**:
- **同频思考**: 所有人同一时间用同一模式思考
- **智慧凝聚**: 充分激发集体智慧
- **高质决策**: 避免思维混乱和情绪对抗

**适用场景**:
- 会议管理（避免跑题、提高效率）
- 决策支持（全面分析、减少盲区）
- 团队思考（凝聚共识、减少对抗）
- 问题分析（系统分析、找到根因）
- 创意激发（突破思维定式）
- 绩效面谈（客观评估、共同成长）

**不适用场景**:
- 紧急决策（用红光思维快速行动）
- 个人日常小决策（过度结构化）
- 纯执行任务（用知行合一 Skill）

## 🌈 五色光定义

### ⚪ 白光思维（客观事实）
- **功能**: 呈现客观事实和数据
- **问题**: "我们知道什么？""我们需要知道什么？"
- **特征**: 中立、客观、可验证
- **隐喻**: 白光包含所有颜色，代表完整信息

### 🔴 红光思维（情感直觉）
- **功能**: 表达情感、直觉、预感
- **问题**: "我现在感觉如何？""我的直觉告诉我什么？"
- **特征**: 主观、无需理由、允许情绪
- **隐喻**: 红色代表热情、冲动、情感

### 🟡 黄光思维（价值收益）
- **功能**: 寻找价值、收益、积极面
- **问题**: "有什么好处？""为什么值得做？"
- **特征**: 乐观、建设性、发现价值
- **隐喻**: 黄色代表阳光、温暖、希望

### 🟢 绿光思维（创新成长）
- **功能**: 产生创意、替代方案、新可能
- **问题**: "还有其他方法吗？""如何突破？"
- **特征**: 创造、生长、突破常规
- **隐喻**: 绿色代表生命、生长、新芽

### 🔵 蓝光思维（过程控制）
- **功能**: 控制思考过程、总结结论、制定下一步
- **问题**: "我们思考得怎么样？""下一步做什么？"
- **特征**: 元认知、过程管理、决策
- **隐喻**: 蓝色代表天空、冷静、掌控

## 🧠 理论基础

### 与德博诺六顶思考帽的关系

| 五色光 | 六顶思考帽 | 东方化演进 |
|--------|------------|------------|
| 白光 | 白帽 | 融入"格物致知"理念 |
| 红光 | 红帽 | 融入"诚意正心"理念 |
| 黄光 | 黄帽 | 融入"阴阳平衡"理念 |
| 绿光 | 绿帽 | 融入"生生之谓易"理念 |
| 蓝光 | 蓝帽 | 融入"知行合一"理念 |
| - | 黑帽 | 融入黄光（阴阳平衡，不单独强调负面） |

### 核心原则

**1. 同频原则**
- 同一时间所有人用同一颜色思考
- 避免"你在说事实，他在谈感受"的错位

**2. 分治原则**
- 将复杂思考分解为五个维度
- 每个维度充分展开后再切换

**3. 序列原则**
- 按特定顺序使用五色光
- 不同场景用不同序列

**4. 完整原则**
- 五色光都要用到，避免盲区
- 根据场景调整权重

## 🔧 核心功能

### 1. 会议引导
- 设计会议流程（五色光序列）
- 实时引导讨论方向
- 记录各颜色产出

### 2. 决策支持
- 全面分析选项（五色光分析）
- 减少决策盲区
- 形成可执行结论

### 3. 问题分析
- 系统分析问题（白光事实→红光感受→黄光价值→绿光方案→蓝光决策）
- 找到根本原因
- 生成解决方案

### 4. 创意激发
- 绿光思维主导
- 结合其他颜色验证
- 形成可行创意

### 5. 绩效面谈
- 白光：客观事实
- 红光：双方感受
- 黄光：成绩与价值
- 绿光：改进方案
- 蓝光：下一步计划

## 📋 标准流程

### 通用决策流程

```
蓝光开场 → 白光事实 → 红光感受 → 黄光价值 → 绿光方案 → 蓝光决策
    ↓          ↓          ↓          ↓          ↓          ↓
 设定议程   收集信息   表达直觉   发现收益   产生创意   总结决策
```

### 问题分析流程

```
蓝光定义问题 → 白光收集事实 → 黄光分析价值 → 绿光生成方案 → 蓝光选择方案
```

### 创意激发流程

```
蓝光设定主题 → 绿光自由发散 → 黄光评估价值 → 白光验证实操 → 蓝光确定方向
```

### 会议管理流程

```
蓝光开场（议程）→ 白光（信息同步）→ 绿光（讨论）→ 黄光（共识）→ 蓝光（行动项）
```

## 🎯 应用案例

### 案例 1: 产品方向决策

**背景**: 团队需要决定新产品功能方向

**五色光流程**:
1. **蓝光开场**: "今天决定 A/B/C 三个功能方向的优先级"
2. **白光事实**: 用户调研数据、开发成本、时间估算
3. **红光感受**: "我对 A 方向最有信心""C 方向让我担心"
4. **黄光价值**: A 方向的市场潜力、B 方向的技术积累价值
5. **绿光方案**: "能否结合 A+B?""有没有第四选项？"
6. **蓝光决策**: "先做 A，同时小团队探索 A+B 结合"

---

### 案例 2: 绩效面谈

**背景**: 主管与下属季度绩效面谈

**五色光流程**:
1. **蓝光开场**: "今天回顾 Q1 表现，规划 Q2"
2. **白光事实**: 完成项目、数据指标、客户反馈
3. **红光感受**: "我对 XX 成果很满意""XX 事让我有挫败感"
4. **黄光价值**: 成长点、贡献价值、团队影响
5. **绿光方案**: 改进计划、学习方向、支持需求
6. **蓝光决策**: Q2 目标、行动计划、跟进时间
