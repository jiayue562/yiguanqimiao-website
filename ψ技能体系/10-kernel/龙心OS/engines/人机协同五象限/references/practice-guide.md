# 人机协同五象限实践指南

> 从理论到实践的完整操作手册

---

## 🎯 快速决策树

```
开始：我有一个任务需要与 AI 协作
         ↓
问 1: 我知道这个任务的具体要求吗？
    ├─ 是 → 问 2: AI 知道如何做吗？
    │         ├─ 是 → Q1 效率协作者（指令 - 执行）
    │         └─ 否 → Q3 思辨对话者（对话 - 辩论）
    │
    └─ 否 → 问 3: AI 知道吗？
              ├─ 是 → Q2 知识拓展者（问答 - 学习）
              └─ 否 → 问 4: 问题本身明确吗？
                        ├─ 是 → Q4 协同探索者（协作 - 搜索）
                        └─ 否 → Q5 未知共创者（共创 - 激发）
```

---

## 📋 五象限操作手册

### Q1 效率协作者

**适用场景**:
- ✅ 生成周报、整理数据
- ✅ 格式化文档、翻译内容
- ✅ 批量处理重复任务

**操作步骤**:
1. 明确任务目标和输出格式
2. 提供清晰的指令和示例
3. 审核 AI 输出质量
4. 迭代优化指令

**Prompt 模板**:
```
请帮我 [具体任务]，要求：
- 输出格式：[格式要求]
- 内容要点：[要点列表]
- 风格要求：[风格描述]
- 参考示例：[如有]
```

---

### Q2 知识拓展者

**适用场景**:
- ✅ 学习新领域知识
- ✅ 理解复杂概念
- ✅ 获取结构化信息

**操作步骤**:
1. 提出明确的学习目标
2. 请求结构化呈现
3. 追问关键概念
4. 整合到已有知识体系

**Prompt 模板**:
```
我想学习 [主题/领域]，请帮我：
1. 梳理核心概念框架
2. 解释关键术语
3. 提供入门路径
4. 推荐学习资源
```

---

### Q3 思辨对话者

**适用场景**:
- ✅ 方案评审、风险推演
- ✅ 挑战自己的观点
- ✅ 多角度分析问题

**操作步骤**:
1. 陈述自己的观点/方案
2. 请求 AI 从反方质疑
3. 多轮对话辩论
4. 整合形成更严谨的方案

**Prompt 模板**:
```
我的观点/方案是：[陈述内容]

请从以下角度质疑：
1. 逻辑漏洞
2. 潜在风险
3. 反方观点
4. 改进建议
```

---

### Q4 协同探索者

**适用场景**:
- ✅ 研究无标准答案的问题
- ✅ 技术攻关、方案探索
- ✅ 复杂问题分析

**操作步骤**:
1. 明确探索方向
2. AI 提供多角度分析
3. 人类判断可行性
4. 迭代形成方案

**Prompt 模板**:
```
我们一起探索：[问题描述]

已知条件：[条件列表]
探索方向：[方向描述]

请你：
1. 分析可能的路径
2. 推演每种路径的结果
3. 识别关键变量
4. 提出验证方法
```

---

### Q5 未知共创者

**适用场景**:
- ✅ 定义全新的研究方向
- ✅ 开创新业务模式
- ✅ 0→1 原创突破

**操作步骤**:
1. 描述模糊的直觉/观察
2. AI 帮助模式识别和联想
3. 共同定义新问题
4. 形成创新框架

**Prompt 模板**:
```
我注意到一个有趣的现象：[描述观察]

这似乎暗示着某种模式，但我不确定是什么。

请你：
1. 识别可能的模式
2. 联想相关领域
3. 提出可能的研究问题
4. 共同定义新方向
```

## ⚠️ 常见误区

### 误区 1: 所有任务都用 Q1

**错误**: 把所有任务都当作指令执行

**正确**: 根据任务性质选择对应象限

### 误区 2: Q4 和 Q5 混淆

**错误**: 认为"共同探索"就是"共同创造"

**正确**: Q4 是已知问题框架内求解，Q5 是开创未知领域

### 误区 3: 忽视 Q3 的价值

**错误**: 跳过深度思考直接进入探索

**正确**: Q3 是连接学习与探索的桥梁

### 误区 4: Q5 神秘化

**错误**: 认为 Q5 只属于天才

**正确**: Q5 可以通过象思维训练培养
