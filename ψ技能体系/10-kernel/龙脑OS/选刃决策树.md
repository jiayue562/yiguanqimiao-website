# 选刃决策树

> 龙脑OS v3.1 核心组件。当龙心OS调用龙脑OS时，选刃决策树根据问题类型推荐模型组合。

---

## 一、快速入口：场景缩写速查

| 场景类型 | 简称 | 一句话特征 |
|---------|------|-----------|
| 经营分析型 | JY | 有数据，需归因，找根因 |
| 战略决策型 | ZL | 多选项，不确定高，影响大 |
| 方案设计型 | FA | 从零到方案，需结构化产出 |
| 问题诊断型 | WD | 问题模糊，系统性强，需拆解 |
| 沟通协作型 | GT | 涉及人，需策略，需换位 |
| 学习研究型 | XX | 输入新知识，需消化转化 |
| 自我成长型 | CZ | 向内看，人格完善，身心灵 |
| 创意创新型 | CY | 从无到有，需原创，突破常规 |

---

## 二、八类场景 → 模型映射表

### JY-经营分析型

| 层 | 内容 |
|---|------|
| **特征** | 有数据指标（如毛利、出成率、损耗率），需要找到根因，数据驱动归因 |
| **首选组合** | **瓶颈理论 + 五层分析法** |
| **备选组合** | 系统思维 + 帕累托法则 + 概率思维 |
| **选择理由** | 瓶颈理论定位阻塞环节，五层分析法从信息→逻辑→系统→人性→意义逐层穿透 |
| **理论支撑** | 认知吝啬者理论（人倾向简单归因，需用结构化方法对抗），组织信息加工理论 |
| **参考文件** | 02-思维模型/02-问题分析类/「五层分析法.md、03-理论/02-社会认知类/认知吝啬者理论.md |

**模型组合逻辑**：
```
瓶颈理论 → 定位阻塞点在哪一环节
  ↓
五层分析法 → 对阻塞点逐层拆解（信息/逻辑/系统/人性/意义）
  ↓
帕累托法则（可选）→ 筛选20%的核心因素
```

**典型场景**：
- "为什么这个月毛利下降了？"
- "外卖渠道的复购率为什么低于堂食？"
- "这个损耗数据异常，根因是什么？"

---

### ZL-战略决策型

| 层 | 内容 |
|---|------|
| **特征** | 多个选项，不确定性高，影响面大，需要长期视角 |
| **首选组合** | **易经错综复杂 + 决策矩阵 + 二阶思维** |
| **备选组合** | 概率思维 + 逆向思维 + 机会成本 |
| **选择理由** | 错综复杂提供五维全局审视（本卦/变卦/互卦/错卦/综卦），决策矩阵量化评分，二阶思维考虑后果的后果 |
| **理论支撑** | 解释水平理论（远用抽象近用具体），恐惧管理理论（重大决策触发生存焦虑） |
| **参考文件** | 02-思维模型/07-易经卦变类/易经错综复杂.md、02-思维模型/01-元认知类/思维模型——人类认知的底层操作系统.md |

**模型组合逻辑**：
```
易经错综复杂 → 五维审视（本/变/互/错/综）
  ↓
决策矩阵 → 多指标量化评分
  ↓
二阶思维 → 每个选项的"后果的后果"
  ↓
逆向思维（备选）→ "怎么让这个决策失败？"反推风险
```

**典型场景**：
- "该不该开新店？"
- "这个创业单元总的人选怎么定？"
- "酒水创业单元是独立还是合并在堂食里？"

---

### FA-方案设计型

| 层 | 内容 |
|---|------|
| **特征** | 从零开始，需要产出完整的、可落地的方案，结构化要求高 |
| **首选组合** | **5W2H + 金字塔原理 + ORID** |
| **备选组合** | 框架-思维框架-框架思维 + 价值聚焦 |
| **选择理由** | 5W2H无死角检查清单，金字塔原理结构化表达，ORID从客观事实到决定行动的完整闭环 |
| **理论支撑** | 过程调节法（方案执行的动态调节），建构发展理论（方案的认知结构层次） |
| **参考文件** | 02-思维模型/02-问题分析类/5W2H七维分析.md、02-思维模型/03-提问工具类/ORID焦点讨论法.md |

**模型组合逻辑**：
```
5W2H → 全面检查（What/Why/Who/When/Where/How/How much）
  ↓
金字塔原理 → 结构化组织方案内容（结论先行+以上统下）
  ↓
ORID → 方案落地的复盘闭环（O事实→R感受→I诠释→D行动）
```

**典型场景**：
- "怎么做储值活动方案？"
- "新员工的90天培训计划怎么设计？"
- "下个月的促销策略怎么定？"

---

### WD-问题诊断型

| 层 | 内容 |
|---|------|
| **特征** | 问题本身模糊，不够具体，不知道问题是什么，需要先界定问题、再找根因 |
| **首选组合** | **5Whys + 系统思维 + 苏格拉底式提问** |
| **备选组合** | 五维问题拆解法 + 从一团乱麻到清晰方案 |
| **选择理由** | 苏格拉底式提问澄清问题本身，5Whys沿因果链深挖，系统思维防止单点归因 |
| **理论支撑** | 意义构建理论（人在模糊时会主动构建意义），嵌入理论（问题嵌入更大系统） |
| **参考文件** | 02-思维模型/03-提问工具类/苏格拉底6大提问框架.md、03-理论/02-社会认知类/意义构建理论.md |

**模型组合逻辑**：
```
苏格拉底式提问 → 先界定"问题到底是什么"
  ↓
5Whys → 纵向深挖根因（每个"为什么"必须基于事实）
  ↓
系统思维 → 横向扩展（检查其他环节是否联动异常）
```

**典型场景**：
- "团队执行力差，问题在哪？"
- "这家店的服务评分为什么持续低？"
- "为什么招不到合适的人？"

---

### GT-沟通协作型

| 层 | 内容 |
|---|------|
| **特征** | 涉及人的问题，需要说服、协调、谈判、反馈，情绪因素重 |
| **首选组合** | **六顶思考帽 + 拉波波特法则 + SBI反馈模型** |
| **备选组合** | 沟通五层次 + 换位式提问 + 三的法则 |
| **选择理由** | 六顶思考帽剥离人与立场，拉波波特法则让对方听见你的反对，SBI用事实替代评判 |
| **理论支撑** | 社会促进理论（他人在场影响表现），自我呈现理论（人管理形象的行为逻辑） |
| **参考文件** | 02-思维模型/05-决策与沟通类/8个沟通模型速查手册.md、03-理论/03-社会关系类/自我呈现理论.md |

**模型组合逻辑**：
```
六顶思考帽 → 团队讨论时平行思考（白帽事实/红帽感受/黑帽风险/黄帽价值/绿帽创新/蓝帽流程）
  ↓ 或
拉波波特法则 → 一对一说服（复述→认同→收获→批评）
  ↓
SBI反馈模型 → 给出具体反馈（情境→行为→影响）
```

**典型场景**：
- "怎么跟料理长沟通成本问题？"
- "如何说服董事长接受这个方案？"
- "团队内部有矛盾，怎么协调？"

---

### XX-学习研究型

| 层 | 内容 |
|---|------|
| **特征** | 需要理解新知识、消化外部信息、转化为自己的认知 |
| **首选组合** | **十种知识整合方式 + 第一性原理 + 框架思维** |
| **备选组合** | 教员方法论（矛盾论×实践论） + 从第一层到第二层 |
| **选择理由** | 第一性原理回归概念本质，框架思维将新知识套入已有认知结构，十种知识整合方式提供跨领域连接 |
| **理论支撑** | 建构发展理论（认知发展是建构过程），意义构建理论（理解新知识即意义构建） |
| **参考文件** | 02-思维模型/01-元认知类/十种知识整合方式.md、02-思维模型/01-元认知类/第一性原理.md |

**模型组合逻辑**：
```
第一性原理 → 拆解到不可再分的核心概念
  ↓
框架思维 → 套入已有认知地图（"这个新理论像什么？"）
  ↓
十种知识整合方式 → 与已有知识连接融合
```

**典型场景**：
- "我想理解这个理论怎么用在味藏？"
- "这个新商业模式背后是什么逻辑？"
- "帮我深度学习一下这篇文章"

---

### CZ-自我成长型

| 层 | 内容 |
|---|------|
| **特征** | 向内看，涉及人格、情绪、状态、信念，需要诊断和转化 |
| **首选组合** | **五层分析法 + 逆向思维 + 价值聚焦** |
| **备选组合** | 观比体化（体-共情体感） + 从锚定到破局 |
| **选择理由** | 五层分析法的人性层和意义层适合向内审视，逆向思维问"怎么让自己更糟"反推路径，价值聚焦锚定什么最重要 |
| **理论支撑** | PERMA幸福理论（幸福五要素），积极情绪的拓展-建构理论（积极情绪扩展认知边界） |
| **参考文件** | 03-理论/01-动机行为类/PERMA幸福理论.md、03-理论/01-动机行为类/积极情绪的拓展-建构理论.md |

**模型组合逻辑**：
```
五层分析法 → 从信息到意义逐层向内（尤其人性层+意义层）
  ↓
逆向思维 → "如果我要让自己状态更差，会做什么？"反推
  ↓
价值聚焦 → "当前什么对我最重要？"锚定方向
```

**典型场景**：
- "我的五行人格测出来是什么？"
- "最近状态不好，怎么调整？"
- "我这个能力短板怎么补？"

---

### CY-创意创新型

| 层 | 内容 |
|---|------|
| **特征** | 从无到有，需要真正的原创，打破常规，需要灵感 |
| **首选组合** | **象思维观比体化 + SCAMPER + 逆向思维** |
| **备选组合** | 第一性原理 + 爱因斯坦式提问 + 隐喻式提问 |
| **选择理由** | 象思维提供原创灵感（观/比/体/化），SCAMPER提供结构化创新框架，逆向思维打破思维惯性 |
| **理论支撑** | 积极情绪的拓展-建构理论（情绪拓展认知边界），最佳唤醒理论（创新需要适度唤醒） |
| **参考文件** | 01-象思维/象思维理论体系：回归原创之思与实.md、01-象思维/象道思维："观·比·体·化"四字循环法.md、02-思维模型/04-创意创新类/SCAMPER奔驰法.md |

**模型组合逻辑**：
```
象思维·观比体化 → 先"观"（整体感知），再"比"（类比迁移），再"体"（共情体感），最后"化"（创造意义）
  ↓
SCAMPER → 对现有方案七维度改造（替代/合并/调整/修改/他用/消除/重组）
  ↓
逆向思维 → "怎么让这个产品卖不出去？"反推爆品方案
```

**典型场景**：
- "除了金枪鱼，还能做什么爆品？"
- "怎么把堂食体验做到让顾客主动传播？"
- "三驾马车之外，还有没有第四种业态可能？"

## 三、模型组合模式速查

### 3.1 单模型场景
什么情况只用1个模型就够了？

| 场景 | 模型 | 原因 |
|------|------|------|
| 快速归因单一问题 | 5Whys | 因果链清晰，不需要多维度 |
| 快速了解一件事 | 框架思维 | 已有现成框架套用 |
| 简单的利弊权衡 | 决策矩阵 | 选项少，指标明确 |

### 3.2 双模型组合
什么情况用2个模型配合？

| 组合 | 配合逻辑 | 适用场景 |
|------|---------|---------|
| 瓶颈理论 + 五层分析法 | 定位+穿透 | 有明确异常数据的经营分析 |
| 易经错综复杂 + 决策矩阵 | 全局审视+量化 | 重大但不太紧急的战略决策 |
| 5W2H + 金字塔原理 | 检查+组织 | 需要从零搭建方案 |
| 六顶思考帽 + SBI | 会议+反馈 | 团队沟通场景 |

### 3.3 多模型链
什么情况用3+模型串联？

| 组合链 | 适用场景 |
|--------|---------|
| 苏格拉底提问 → 5Whys → 系统思维 | 问题本身模糊，需要先界定再深挖 |
| 观比体化 → SCAMPER → 逆向思维 | 需要真正的原创突破 |
| 第一性原理 → 框架思维 → 十种整合 | 深度学习新领域知识 |
| 五层分析法 → 逆向思维 → 价值聚焦 | 个人成长/状态调整 |
| 概率思维 → 二阶思维 → 决策矩阵 | 高风险高不确定性的决策 |

## 四、选刃协议

### 4.1 调用规则

1. **先分类，后选刃**：龙心OS识别问题类型后，先查选刃决策树获取推荐组合
2. **首选为主，备选为辅**：优先使用首选组合，若推理中发现不适用则切换到备选
3. **可自定义组合**：经验丰富后，可不限于推荐组合，但需声明理由
4. **切换需声明**：如"初始选了瓶颈理论，但发现不是阻塞问题，切换为系统思维"

### 4.2 模型调用格式

每个模型被调用时，需输出：
```
模型：瓶颈理论
来源：龙脑OS/思维模型库/瓶颈理论/
选择理由：当前问题的特征是某环节阻塞导致整体下降
引用文件：思维模型_问题分析_从一团乱麻到清晰方案.md
输出痕迹：[推理过程中应能看到何时用了此模型、得出了什么结论]
```

### 4.3 选刃错误可纠正

如果推理中发现所选模型不适用，应当声明切换：
```
模型切换：瓶颈理论 → 系统思维
切换理由：分析发现不是单点阻塞，而是多环节联动失调
```
