## 龙龟OS学到的东西

### 1. 管理者到任生命周期模型
```
启动(制度建设) → 布点(培训架构) → 爆发(开门红利) 
→ 回落(真实暴露) → 阵痛(指标在降体系在涨) → 暴露(结构性问题)
```

### 2. 金行人自我消耗循环
```
追求标准 → 没人执行 → 自己去做 → 没时间建标准 → 更没人执行
```

### 3. 被修正的认知
- 五色光思维的正确用法是"过程管理"，不是"五维诊断"
- 金行人的分析应该作为固定诊断维度
- 指标下降不等于系统变差——体系初创期指标必然下降
