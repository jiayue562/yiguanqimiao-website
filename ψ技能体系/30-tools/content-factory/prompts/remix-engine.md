# Content Remix Engine

**Source content:**
```
[SOURCE]
{source_content}
[/SOURCE]
```

Remix this into ALL of the following formats. Keep the core message identical. Adapt tone to each platform.

## 1. Twitter/X Thread (8-10 tweets)
- Hook tweet that stops scrolling (no "Thread 🧵")
- Each tweet stands alone with value
- Final tweet: CTA or reflection

## 2. LinkedIn Post (150 words)
- Professional but warm
- Open with insight
- Close with question

## 3. Email Newsletter Section (250 words)
- Subject line + preview text
- Personal, intimate tone
- One clear CTA

## 4. Slide Deck Outline (8 slides with bullet points)
- One idea per slide
- Speaker notes for context

## 5. Executive Summary (3 paragraphs)
- What, so what, now what

## 6. FAQ Section (5 questions)
- Real questions parents would ask
- Conversational answers

## 7. Pull Quotes (5 tweetable quotes)
- Self-contained wisdom
- Under 280 characters each

## 8. Podcast Script Intro (2-min read time)
- Conversational, sets up "why this matters"

## 9. Instagram Caption (100 words + 10 hashtags)
- Most arresting line first
- Mix niche + broad hashtags

## 10. Reddit Post (200 words, conversational)
- Zero marketing smell
- Genuine, vulnerable, discussion-seeking

## 11. 30-Second Animation Scripts (3 variations)
- Use formats from scriptwriter.md
- Hook (3s) → Core truth (20s) → Identity affirmation (7s)
- Include visual direction notes

## Quality Check
Before delivering, verify:
- [ ] Core message identical across all 11 formats
- [ ] Each format feels native to its platform
- [ ] Theological guardrails passed on every format
- [ ] No performance language anywhere
- [ ] Animation scripts end in emotional regulation
