# 记忆压缩归档 Skill

> 🗄️ 自动化冷存储 · 3 个月前记忆压缩 · 节省空间 + 保持检索

**版本**: v1.0  
**创建**: 2026-04-17  
**标签**: #记忆压缩 #冷存储 #归档

---

## 📋 核心定义

**一句话定义**: 自动压缩 3 个月前的记忆到冷存储，节省空间同时保持检索能力的归档系统。

**三行问题陈述**:
- **What**: 解决记忆系统膨胀、热存储压力大、检索变慢的问题
- **Why**: 记忆随时间增长，但近期记忆使用频率远高于历史记忆
- **How**: 分层存储（热/温/冷）+ 自动压缩 + 按需解压

---

## 🏛️ 分层存储架构

```
┌─────────────────────────────────────────────────────────┐
│                  记忆分层存储架构                        │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  🔥 热存储 (Hot Storage)                                │
│  ├── 时间范围：最近 7 天                                │
│  ├── 位置：memory/YYYY-MM-DD.md                        │
│  ├── 访问速度：即时                                    │
│  └── 压缩：无压缩                                      │
│                                                         │
│  🌡️ 温存储 (Warm Storage)                              │
│  ├── 时间范围：7 天 -3 个月                            │
│  ├── 位置：memory/archive/YYYY-MM/                     │
│  ├── 访问速度：<1s                                     │
│  └── 压缩：按月归档                                    │
│                                                         │
│  ❄️ 冷存储 (Cold Storage)                              │
│  ├── 时间范围：>3 个月                                 │
│  ├── 位置：云存储/外部硬盘                             │
│  ├── 访问速度：分钟级（按需解压）                      │
│  └── 压缩：高压缩率 ZIP                                │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 🔄 归档流程

```
每日检查（心跳时）
    ↓
1. 识别可归档记忆（>3 个月）
    ↓
2. 生成归档包（ZIP + 索引）
    ↓
3. 上传到冷存储（IMA/云存储）
    ↓
4. 本地保留索引（元数据）
    ↓
5. 删除原始文件（可选）
    ↓
6. 更新归档日志
```

## 📊 压缩策略

### 压缩算法

| 算法 | 压缩率 | 速度 | 适用场景 |
|------|--------|------|----------|
| **ZIP (Deflate)** | 60-80% | 快 | 温存储 |
| **7z (LZMA2)** | 70-90% | 中 | 冷存储 |
| **Zstandard** | 50-70% | 极快 | 实时压缩 |

### 压缩配置

```powershell
# PowerShell 7z 压缩
7z a -t7z -m0=lzma2 -mx=9 archive.7z *.md

# 参数说明:
# -t7z: 7z 格式
# -m0=lzma2: LZMA2 算法
# -mx=9: 最高压缩率
```
