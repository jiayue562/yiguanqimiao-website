# 跨 Skills 上下文协同协议

> 🤝 统一上下文协议规范 · 确保跨 Skills 协同一致性

**版本**: v1.0  
**创建**: 2026-04-16  
**状态**: 正式规范

---

## 📋 协议目标

确保不同 Skills 之间上下文共享的一致性、安全性和高效性。

---

## 🏗️ 架构原则

### 1. 统一数据格式

所有上下文数据遵循统一格式：

```json
{
  "id": "context-uuid",
  "type": "memory|knowledge|session",
  "content": "上下文内容",
  "metadata": {
    "created_at": "ISO8601",
    "updated_at": "ISO8601",
    "source": "skill-name",
    "importance": "critical|high|medium|low",
    "tags": ["tag1", "tag2"],
    "relevance": ["related-context-ids"]
  },
  "version": 1
}
```

---

### 2. 权限控制

| 操作 | 权限要求 | 说明 |
|------|----------|------|
| **读取** | read_access | 需要目标上下文的读取权限 |
| **写入** | write_access | 需要目标存储的写入权限 |
| **删除** | admin_access | 需要管理员权限 |
| **共享** | share_access | 需要共享权限 |

---

### 3. 协同流程

```
Skill A 请求上下文
    ↓
验证权限
    ↓
检查协议合规性
    ↓
访问共享存储
    ↓
返回上下文数据
    ↓
记录依赖关系
```

---

## ⚠️ 使用规范

### 必须遵守

1. **格式统一**: 所有上下文数据遵循统一格式
2. **权限验证**: 访问前必须验证权限
3. **版本管理**: 保留上下文版本历史
4. **日志记录**: 记录所有访问操作

### 禁止行为

1. **直接修改**: 禁止直接修改其他 Skills 的上下文
2. **越权访问**: 禁止访问未授权的上下文
3. **数据冗余**: 禁止不必要的上下文复制
4. **循环依赖**: 禁止创建上下文循环依赖
