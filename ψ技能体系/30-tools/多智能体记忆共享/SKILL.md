## 📋 核心定义

**一句话定义**: 实现多个 OpenClaw 实例之间的记忆共享与同步，构建分布式记忆网络。

**三行问题陈述**:
- **What**: 解决单智能体记忆孤岛、经验无法跨实例复用的问题
- **Why**: 多个智能体应该共享学习成果，避免重复学习
- **How**: 记忆同步协议 + 冲突解决 + 权限控制

## 🔄 同步协议

### 1. 推送模式（Push）

**场景**: 本地有新记忆，推送到共享层

```
本地记忆更新
    ↓
检查是否可共享（权限/质量）
    ↓
推送到共享层
    ↓
其他智能体拉取
```

### 2. 拉取模式（Pull）

**场景**: 定期从共享层拉取更新

```
定时触发（每日 03:00）
    ↓
查询共享层更新
    ↓
下载新记忆
    ↓
合并到本地记忆库
```

### 3. 广播模式（Broadcast）

**场景**: 重要记忆立即同步到所有智能体

```
重要记忆创建
    ↓
广播到所有智能体
    ↓
各智能体确认接收
    ↓
重传未确认的
```

## 📁 共享记忆分类

### 公共记忆（Public）

**定义**: 所有智能体可访问  
**内容**:
- 核心技能（龙心 OS 架构等）
- 通用模式（思维模型等）
- 公开知识（方法论等）

**同步策略**: 全量同步

### 受限记忆（Restricted）

**定义**: 需要权限验证  
**内容**:
- 专业技能（特定领域）
- 优化模式（高级技巧）
- 案例库（实践案例）

**同步策略**: 按需同步

### 私有记忆（Private）

**定义**: 不共享  
**内容**:
- 用户个人信息
- 敏感配置
- 临时记忆

**同步策略**: 不同步

## 🔐 权限控制

### 权限级别

| 级别 | 说明 | 示例 |
|------|------|------|
| **公开** | 所有智能体可访问 | 龙心 OS 架构 |
| **认证** | 需要身份验证 | 专业技能库 |
| **授权** | 需要显式授权 | 案例库 |
| **私有** | 不共享 | 用户个人信息 |

### 权限验证

```json
{
  "memory_id": "mem-001",
  "access_level": "public",
  "allowed_agents": ["*"],  // 或指定 agent IDs
  "requires_auth": false,
  "requires_approval": false
}
```

## ⚠️ 冲突解决

### 冲突类型

| 类型 | 说明 | 解决策略 |
|------|------|----------|
| **内容冲突** | 同一记忆不同版本 | 时间戳优先 / 人工确认 |
| **命名冲突** | 同名不同内容 | 添加前缀 / 合并 |
| **语义冲突** | 相同概念不同定义 | 保留多版本 / 人工确认 |

### 解决策略

```
检测到冲突
    ↓
自动合并（简单冲突）
    ↓
标记冲突（复杂冲突）
    ↓
人工确认（用户决策）
    ↓
更新冲突解决日志
```

## 📊 同步统计

### 指标

| 指标 | 说明 | 目标值 |
|------|------|--------|
| **同步延迟** | 创建到同步的时间 | <5min |
| **同步成功率** | 成功同步的比例 | >95% |
| **冲突率** | 发生冲突的比例 | <5% |
