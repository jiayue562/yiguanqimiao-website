# Skill Builder - 自动化 Skill 构建工具

## 核心定位
从理论到 Skill 的工业化生产工具 · 5 阶 20 步自动化

---

## 📋 功能概述

### What（这是什么）
自动化 Skill 构建工具，将理论文档/需求描述转化为完整的 Skill 包。

### Why（为什么需要）
- 手动构建 Skill 耗时 3-5 小时
- Skill Builder 缩短到 30-60 分钟
- 保证质量一致性（符合 20 步 SOP）

### How（怎么用）
```
1. 提供理论文档/需求描述
2. Skill Builder 执行 5 阶 20 步
3. 输出 70% 填充的 Skill 包
4. 用户完成剩余 30% 手工优化
```

## 🔧 5 阶 20 步自动化流程

### 阶段一：理论解析（Step 1-4）

**Step 1: 核心定义提取**
- 提问：这个 Skill 解决什么问题？
- 输出：一句话核心定义（<30 字）

**Step 2: 可执行操作流程识别**
- 拆解：理论里有几个操作步骤？
- 排序：逻辑优先级
- 输出：N 步操作流程图

**Step 3: 输入输出规范化**
- Input：用户提供什么信息？
- Process：Skill 内部如何处理？
- Output：返回什么具体结果？

**Step 4: 核心算法/逻辑提炼**
- 识别：关键决策点
- 规则：每个决策点的规则
- 输出：决策树/流程图

### 阶段二：架构设计（Step 5-8）

**Step 5: Skill 粒度判断**
```
单体 Skill vs 生态 Skill 判断矩阵：
| 维度 | 单体 | 生态 |
|------|------|------|
| 操作步数 | 3-7 步 | 8 步以上 |
| 决策点数 | 1-2 个 | 3 个以上 |
| 依赖关系 | 独立 | 有依赖链 |
| 触发复杂度 | 简单 | 复杂 |
```

**Step 6: 触发机制设计**
- 维度 1：直接触发词
- 维度 2：场景触发词
- 维度 3：信号触发
- 输出：四维触发矩阵

**Step 7: 关键词权重设计**
- P0 关键词（绝对触发）：权重 5
- P1 关键词（强触发）：权重 4
- P2 关键词（弱触发）：权重 3

**Step 8: 与现有 Skills 的关系映射**
- 协同 Skills 识别
- 调用顺序
- 输出：协同图

### 阶段三：SKILL.md 编码（Step 9-12）

**Step 9: SKILL.md 主文档编写**
```markdown
【必填部分】
1. 标题 + 版本
2. 一句话核心定义
3. 三行问题陈述（What/Why/How）
4. 核心能力（3-5 个子能力）
5. 使用边界

【功能设计部分】
6. 触发条件（直接词 + 场景 + 信号）
7. 激活后的行为流程
8. 核心原则（禁忌 + 必须）
9. 与其他 Skills 的关系

【实现部分】
10. 标准输入格式
11. 处理流程（伪代码/决策树）
12. 标准输出格式
13. 示例（真实案例）
14. 异常处理
```

**Step 10: References 参考资料**
- theory.md：理论完整版
- practice-guide.md：实操指南
- prompts.md：提示词模板
- sop.md：标准操作流程

**Step 11: Templates 模板库**
- input_template.md：输入模板
- output_template.md：输出模板
- workflow_template.md：流程模板

**Step 12: Triggers 触发配置**
- trigger-rules.yaml：关键词权重表
- skill-routes.yaml：与其他 Skills 关系
- auto-activate.json：自动触发规则

### 阶段四：测试验证（Step 13-15）

**Step 13: 单点测试用例**
- 用例 1：标准场景
- 用例 2：边界场景
- 用例 3：负面场景

**Step 14: 集成测试**
- 与其他 Skills 协同是否正常？
- 触发机制是否误触发？
- 输出是否符合预期？

**Step 15: 反馈收集与优化**
- 准确性
- 完整性
- 实用性

## 📌 使用示例

### 场景：从理论创建 Skill

**输入**：
```
我想创建一个"五行人格分析"Skill
理论：五行人格包括木火土金水五种类型
每种类型有不同的认知风格和行为特征
需要能根据用户描述判断其五行类型
```

**处理**：
1. 核心定义：五行人格类型识别与分析
2. 操作流程：收集描述→特征匹配→类型判断→输出报告
3. 触发机制：五行/人格/认知风格等关键词
4. 生成 SKILL.md 框架

**输出**：
- 完整的 Skill 包目录结构
- 70% 填充的 SKILL.md
- CHECKLIST.md（待完成项）

## ⚠️ 边界条件与异常

| 异常情况 | 处理方式 |
|----------|----------|
| 理论过于抽象 | 提示用户补充具体操作步骤 |
| 需求不明确 | 追问澄清问题 |
| 与现有 Skill 重复 | 提示已存在类似 Skill |
| 超出能力范围 | 明确告知无法自动化的部分 |
