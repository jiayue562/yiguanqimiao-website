# Content Creator Wiki - 内容创作者知识库

## 核心定位
系统化 > 碎片化 · 数据驱动 > 凭感觉 · 复用 > 重新创作

---

## 📋 功能概述

### What（这是什么）
为内容创作者打造的知识库系统，管理选题、素材、文稿、数据、方法论。

### Why（为什么需要）
- 每次都从零开始写，效率低
- 以前写的好内容找不到、无法复用
- 不知道什么选题会爆
- 标题/开头没有方法论，凭感觉
- 发布后不记录数据，无法复盘

### How（怎么用）
```
想法 → 选题记录 → 素材检索 → 文稿生成 → 标题/封面 → 发布 → 数据记录 → 方法论迭代
```

## 🔄 完整工作流闭环

### 6.1 记录选题
**触发**: 用户有碎片想法

**输入**:
```
记录选题：[想法内容]
来源：[读书/对话/观察/...]
情绪点：[为什么这个点打动人]
目标受众：[写给谁看]
```

**处理**:
1. 打开 `01-内容生产/选题管理/选题库.md`
2. 追加新选题记录
3. 添加标签和分类
4. 记录时间戳

**输出**: 选题已记录，编号 #[XXX]

---

### 6.2 深化选题
**触发**: 用户选择某个选题深化

**输入**:
```
深化选题：#[选题编号] 或 [选题关键词]
```

**处理**:
1. 检索素材库（核心概念/金句/案例）
2. 检索爆款文稿库（相似主题）
3. 建议可复用的框架和表达
4. 生成文稿大纲

**输出**:
```
## 深化建议

### 可复用素材
- 概念：[[XXX 理论]]
- 金句：[[XXX 金句]]
- 案例：[[XXX 案例]]

### 相似爆款
- [[爆款标题 1]] - 数据：XXX
- [[爆款标题 2]] - 数据：XXX

### 文稿大纲
1. 开头：[吸引力公式]
2. 正文：[框架结构]
3. 结尾：[行动号召]
```

---

### 6.3 生成标题
**触发**: 用户需要标题选项

**输入**:
```
生成标题：[文稿主题/核心内容]
```

**处理**:
1. 读取 `05-方法论沉淀/标题方法论.md`
2. 应用标题公式生成 10+ 选项
3. 按吸引力排序
4. 标注每个标题使用的公式

**输出**:
```
## 标题选项（按吸引力排序）

### 🔥 强烈推荐
1. [标题 1] - 使用公式：数字 + 痛点 + 解决方案
2. [标题 2] - 使用公式：反差 + 好奇

### ✅ 推荐
3. [标题 3] - 使用公式：问题 + 答案
...
```

---

### 6.4 优化开头
**触发**: 用户需要优化内容开头

**输入**:
```
优化开头：[当前开头内容]
平台：[小红书/抖音/公众号/...]
```

**处理**:
1. 读取 `05-方法论沉淀/开头方法论.md`
2. 分析当前开头的问题
3. 基于数据优化前 5 秒/前三行
4. 生成 3-5 个优化版本

**输出**:
```
## 开头优化建议

### 当前问题分析
- 问题 1：前 3 秒没有抓住注意力
- 问题 2：缺少情绪触发点

### 优化版本

#### 版本 1（强烈推荐）
[优化后的开头]
使用技巧：痛点直击 + 数字冲击

#### 版本 2
[优化后的开头]
使用技巧：反差 + 好奇
...
```

---

### 6.5 检索素材
**触发**: 用户需要查找可复用内容

**输入**:
```
检索素材：[关键词/主题]
类型：[概念/金句/案例/全文]
```

**处理**:
1. 搜索核心概念库
2. 搜索金句库
3. 搜索案例库
4. 搜索爆款文稿库
5. 综合排序输出

**输出**:
```
## 检索结果：[关键词]

### 核心概念
- [[XXX 理论]] - 使用次数：X 次

### 金句
- [金句内容] - 来源：[XXX]

### 案例
- [案例内容] - 类型：[个人/客户/热点]

### 相似爆款
- [标题] - 数据：XXX
```

---

### 6.6 数据复盘
**触发**: 内容发布后记录数据

**输入**:
```
记录数据：
- 标题：[内容标题]
- 发布时间：YYYY-MM-DD HH:mm
- 平台：[小红书/抖音/...]
- 播放/阅读量：XXX
- 互动数据：点赞 XXX / 收藏 XXX / 评论 XXX
- 复盘：[成功点/失败点/改进方向]
```

**处理**:
1. 打开 `04-内容数据统计/发布记录.md`
2. 追加数据记录
3. 更新数据表现分析
4. 如为爆款，复制到爆款文稿库
5. 反哺方法论（如触发新规律）

**输出**:
```
## 数据已记录

### 数据概览
- 播放/阅读：XXX
- 互动率：X.X%
- 表现评级：🔥 爆款 / ✅ 良好 / ⚠️ 一般

### 复盘要点
- 成功点：[XXX]
- 改进点：[XXX]

### 方法论更新
- [如有新发现，更新到方法论]
```

---

### 6.7 发布归档
**触发**: 内容发布后归档

**输入**:
```
归档内容：[内容标题/编号]
发布平台：[平台名称]
发布日期：YYYY-MM-DD
```

**处理**:
1. 将内容从待发布移动到已发布
2. 按时间归档到 `03-已发布内容/2026/MM/`
3. 按主题归档到对应分类
4. 更新索引

**输出**: 内容已归档到 `[路径]`

## 📊 核心原则

| 原则 | 说明 | 实现方式 |
|------|------|----------|
| **系统化 > 碎片化** | 每次创作都在给系统添砖加瓦 | 所有内容入库，形成资产 |
| **数据驱动 > 凭感觉** | 记录数据，用数据指导迭代 | 发布记录 + 数据分析 |
| **复用 > 重新创作** | 好的框架、表达、案例要反复使用 | 素材库检索优先 |
| **先跑起来 > 完美设计** | 不追求一次到位，边用边迭代 | 方法论持续更新 |

## 📌 使用示例

```
记录选题：为什么很多人努力但没结果

情绪点：努力不一定成功，方法更重要
```

```
生成标题：为什么很多人努力但没结果
```
