# 叙述 CONTEXT 冻结（模板）

> **用途**：在 **大规模成文 / 扩写 / 多章并行** 前，把「一句话大纲撑不起的细节」落成 **单文件真源**，供 team-lead、writer、质检与脚本引用。  
> **建议路径**：本书根 `.fbs/narrative-context.md`（`init-fbs-multiagent-artifacts` 可初始化空壳）。  
> **权威配合**：`author-meta.md`、`术语锁定记录.md`、`outline-freeze` / `project-config`、`.fbs/book-context-brief.md`。

---

## 1. 读者与立场

- **主读者**：（岗位 / 认知水平 / 阅读场景）
- **次要读者**：（如有）
- **本书承诺**：（一句话，与 `author-meta` 对齐）
- **明确不做的事**：（不涉及的读者、不碰的争议）

---

## 2. 叙述参数（扩写 / 并行前必填）

| 维度 | 选择或说明 |
|------|------------|
| **篇幅节奏** | 偏案例 / 偏论述 / 均衡；章平均字数区间 |
| **案例深度** | 姓名化故事 / 匿名化 / 仅数据 |
| **风险与合规** | 必须免责声明、禁止表述、需法务复核的段落类型 |
| **对话与引语** | 是否使用直接引语、虚构对话是否允许 |

---

## 3. 与大纲的边界（防重复）

- **ChXX 独有论点**：（本章只在此处展开的内容）
- **须引用而非重复**：（已在前章写死的结论，本章只呼应）

---

## 4. 冻结与变更

- **冻结版本**：（日期 + 与用户确认方式）
- **变更流程**：若需改叙述 CONTEXT，须 **更新本文件 + 登记** `outline-freeze` / 变更单或会话纪要，再进入扩写或并行。

---

## 5. 与 GSD「discuss-phase」对齐说明

外部工作流中的 **讨论阶段** 产出 **CONTEXT.md**；福帮手用本文件承担 **叙事维度的等价物**，**不**替代 `REQUIREMENTS` / 大纲，而是 **约束执行与质检**。
