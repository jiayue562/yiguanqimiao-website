# LLM Wiki 实操指南

---

## 快速开始

```bash
# 1. 编译文档
python compiler/ingest.py

# 2. 查询知识
python compiler/query.py search 概念名

# 3. 健康检查
python scripts/health-check.py

# 4. 重建索引
python scripts/rebuild-index.py
```

## 最佳实践

1. 每篇文档编译时提取 3-5 个核心概念
2. 每个新页面最少建立 3 个双向链接
3. 每周运行一次健康检查
4. 高质量问答及时归档到 Wiki
