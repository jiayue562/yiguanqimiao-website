# 标准操作流程

---

## SOP-001: 知识编译

1. 获取原始资料（URL/文件/代码）
2. 保存到 Layer 1 raw 目录
3. 提取核心概念
4. 生成实体/概念页面到 Layer 2
5. 建立双向链接（≥3 个/页）
6. 更新索引
7. 运行健康检查确认

## SOP-002: 健康检查

1. 运行 health-check.py
2. 检查链接率/孤立率/平均链接数
3. 修复问题（自动+人工）
4. 生成报告存档
