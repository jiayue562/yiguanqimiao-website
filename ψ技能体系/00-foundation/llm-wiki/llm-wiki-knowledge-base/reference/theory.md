## 核心命题

1. 知识以网状结构天然存在
2. 双向链接是知识学习的本质能力，不是工具功能
3. 五行分类图谱是网状知识的最早实现
4. 机器编译 + 人类审核 = 知识生产的最优效率

## 理论基础

- Karpathy: "LLM 最好的知识来源不是 RAG，而是编译好的 Wiki"
- 三层架构: 原始资料层(只读) + Wiki 本体层(LLM维护) + Schema 配置层(行为准则)
- 四步流程: 录入 → 查询 → 检查 → 进化
