## 编译提示词

```
请将以下文章编译为 Wiki 页面：
1. 提取 3-5 个核心概念
2. 为每个概念生成定义
3. 建立概念间的双向链接
4. 标注来源和版本

```

```
包括：
- 核心定义
- 相关内容（通过双向链接导航）
- 应用场景
- 参考资料
```
