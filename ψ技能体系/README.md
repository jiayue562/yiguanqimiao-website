# AI OS v3.0 — 超级个人的个人操作系统

> **定位**：未来每个超级个人的个人操作系统。LLM Wiki为底座，龙心OS+龙脑OS为内核，人机共生为灵魂，龙爪OS为项目组。
> **核心理念**：龙心OS是唯一入口，所有内容经过1+5引擎处理得出结论；龙脑OS划定AI边界；龙爪OS按领域解决问题。

## 二、核心设计原则

### 2.1 龙心OS是唯一入口

所有内容经过龙心OS的1+5引擎处理，输出结论。不是"调用多个工具"，而是"同一套引擎始终在背景中运行"。

```
用户输入 → 龙心OS(1+5引擎始终在线) → 结论
                                         ↓
                               按需调用龙爪OS Skill组合
```

### 2.2 龙脑OS划定AI边界

用思维模型和框架给AI划定行动边界。不是"AI能做就做"，而是"在框架内做"。78+个思维模型是AI的"宪法"。

### 2.3 龙爪OS按领域独立

每个龙爪是一个独立的项目组，专门解决一类问题。龙爪之间互不干扰，但共享龙心OS+龙脑OS的底座。

### 2.4 人机共生是灵魂

不是"AI替代人"，也不是"人指挥AI"。而是**有身体、有记忆、有进化方向、有协作边界的共生伙伴**。

### 2.5 AI原生组织是治理哲学

不是"用AI提效"。而是**持续压缩串行瓶颈**——让组织中的信息综合/决策审批/跨部门协调/上下文切换四个维度的串行等待被AI并行化替代。组织不是AI的宿主，组织本身是AI重塑的对象。

内核中的具象化：
- **串行瓶颈诊断引擎** → 四大结构性瓶颈自动检测
- **瓶颈压缩策略引擎** → 6类瓶颈×压缩策略自动匹配
- **AI原生组织成熟度评估** → L1-L5演进+死亡陷阱预警
- **Agent护照治理** → 红绿灯三区制+疲劳度动态权限
- **人机握手协议** → S/A/B/C/D五级决策标准

### 2.6 格式塔具身智能是感知根基

不是"AI看你的表情"。而是**从语言反推身体状态**——格式塔心理学的核心洞见：身体不是孤立的生理实体，而是关系场中的动态样态。个体的"问题"往往是场域的结构性产物。

内核中的具象化：
- **具身样态推断** → 文本→呼吸/肩颈/能量/压力点/在场质量
- **注意力范围检测** → 固化格式塔识别（威胁/自我/闪回固着）
- **场域压力映射** → 瓶颈率→人格偏移方向（木→金等5种）
- **内摄模式识别** → 7种核心内摄×神经系统身体映射
- **特质律动分析** → 5种律动模式×30秒在场练习协议
- **三条管道闭环** → 人格↔系统↔治理双向实时反馈

> 这两层不是"龙爪里的应用"，而是**横切整个内核的架构层**——龙心OS的引擎在它们之上运行，龙脑OS的思维模型为它们划定边界，人机共生OS的灵魂由它们赋形。

## 三、层级关系

```
00-foundation (底座)
    ↓ 知识供给
10-kernel (内核)
    │
    ├── 龙心OS(1+5引擎) ← 📐 AI原生组织(横切治理层)
    ├── 龙脑OS(78模型)  ← 🫁 格式塔具身智能(横切感知层)
    ├── 人机共生OS(灵魂)
    ├── governance + diagnosis
    │
    ↓ 引擎输出 + 思维框架 + 具身感知
20-claws (龙爪) ← 30-tools (工具) ← 40-rules (规则) ← 50-security (安全)
    ↓ 产品输出
  用户/组织
```

**关键约束**：
- 龙心OS+龙脑OS变动很少（像人的心脏和大脑一样稳定）
- 龙爪OS可以按需无限扩展（今天有4个，明天可以有40个）
- 每个龙爪的基础都是龙心OS+龙脑OS
- 人机共生OS是横切所有层的灵魂
