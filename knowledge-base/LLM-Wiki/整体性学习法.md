# 整体性学习法

> **创始人**：斯科特·扬（MIT，1年完成4年33门课程）

## 核心理念
大脑通过数十亿神经元相互联系储存信息。创造的联系越多，记忆越牢、理解越深。大脑不是存储设备，而是联系网络。

## 核心隐喻
- **结构** = 思想的城市（宏观框架）
- **模型** = 城市中的建筑物（简化的结构、压缩的信息）
- **高速公路** = 结构与结构之间的联系（跨域联结）

## 五大技术
1. **比喻法**：用已知解释未知
2. **内在化**：脑海图像+声音+触觉+情感
3. **图表法**：图形压缩多个信息
4. **联想法**：信息串联链条
5. **笔记流**：网状结构笔记

## 六层递进
获取→理解→拓展→纠错→应用→测试
